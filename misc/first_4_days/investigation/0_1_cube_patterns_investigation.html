2. Represent the same pattern

Plot at least five ordered pairs from your table. The horizontal coordinate is the stage number; the vertical coordinate is the number of cubes.

Describe it in words

Write a rule that would let someone find the number of cubes in any stage without building every earlier stage.

Describe it with symbols

Let s = stage number and C = number of cubes. Write a rule connecting s and C.

3. Now design the pattern

New rule: Stage 0 has 6 cubes. Every new stage adds 3 cubes.

Invent a physical cube pattern that follows that rule. Your design can look different from another group’s design—as long as the mathematics works.
