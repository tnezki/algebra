Teacher Guide

0.1 Get Acquainted — Activity

Use the same mapped content through different participation structures. Choose the structure that serves the classroom state; do not try to use every option.

Teacher moves: Protect individual think time, probe for how a student knows, ask partners to restate each other, and reinforce that an incomplete response can still communicate useful thinking.
Student moves: Solve, explain, restate, compare, ask a clarifying question, revise, and communicate where confusion begins instead of leaving work blank.

Internal evidence map

  • Course routine: warm-up start, three-day section rhythm, first-week learning target, and communicating when unsure
  • Fraction multiplication and simplification
  • Fraction addition and simplification
  • All four one-step equation forms
  • Coordinate-plane language and ordered pairs

Set use

Set 1 and Set 2 are parallel 24-question activity pools. Problems 1–5 are course-routine questions; Problems 6–24 are mathematics aligned to the Practice and Extra Practice. Projection structures use the question/solution files. Stations use the matching station printouts. Find Someone Who remains a separate 16-question social baseline.
