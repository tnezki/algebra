Teacher Guide

0.1 Get Acquainted — Activity

Use the same mapped mathematics through different participation structures. Choose the structure that serves the classroom state; do not try to use every option.

Teacher moves: Protect individual think time, probe for how a student knows, ask partners to restate each other, and select a few contrasting strategies to connect. Require explanation before a signature in Find Someone Who.
Student moves: Solve, explain, restate, compare, ask a clarifying question, and revise when a partner provides stronger evidence.

Internal evidence map

  • Fraction computation and simplification
  • One-step equation reasoning
  • Coordinate-plane language and ordered pairs
  • Product/sum number relationships through diamond-style reasoning

Set use

Set 1 and Set 2 are parallel activity pools. Projection structures use the question/solution files. Stations use the station printouts. Find Someone Who is a shorter 16-question social baseline.
