# CC Course 2 — recreated student textbook

This folder is a self-contained static HTML textbook built from the teacher-supplied CC Course 2 captures.

## Open it
Open `index.html` in a browser. Chapter 1 is active. Chapters 2–9 have reserved navigation paths for future source material.

## What was intentionally removed
- teacher notes / answers tabs
- CPM account/app navigation
- Homework Help links

## Visual rebuild
Mathematical number lines, axes, a histogram, and the coordinate-plane triangle that could be reliably reconstructed from the supplied descriptions were redrawn as crisp SVG using the district graph-tool styling conventions. Other supplied instructional diagrams are localized from the teacher-provided captures so the textbook works without the original web app.

## Future expansion
Keep the existing folder routes (`chapter-2/`, ..., `chapter-9/`). When a later chapter is supplied, its active lesson pages can replace the placeholders without changing existing links.
