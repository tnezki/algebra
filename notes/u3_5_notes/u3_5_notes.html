I can formulate a system of inequalities that represents multiple constraints.

A system of inequalities models a situation with more than one restriction. Each inequality represents one constraint, such as a budget limit, minimum requirement, capacity, or nonnegative quantity. The same variables appear across the constraints because every condition applies to the same decision or set of quantities.

Writing the model begins with variable definitions and careful translation of comparison language. Words such as “at most,” “no more than,” and “cannot exceed” usually signal $\le$, while “at least” and “minimum” usually signal $\ge$. The coefficients and constants still come from the quantities and units in the situation, just as they do when modeling with equations.

A system is stronger than any single inequality because a candidate point must satisfy all constraints. Writing one correct inequality is not enough if the situation includes several independent restrictions. Before graphing, read each inequality back in words and ask what real condition it enforces.

  1. What does each inequality in a system represent?
  2. What wording often signals $\le$ or $\ge$?

I can extend graphing strategies to represent overlapping solution regions.

Graph each inequality using the same boundary-and-test-point ideas from a single linear inequality. Every constraint creates its own solution region. When the graphs are placed on the same coordinate plane, the important part is the overlap: points in that shared region satisfy every inequality simultaneously.

Boundary style still matters for each line. A system can contain both solid and dashed boundaries because some constraints may include equality while others do not. Shading should be interpreted one constraint at a time first, then combined. This prevents the common mistake of following only the last inequality graphed.

The overlapping region is called the feasible region. It may be a bounded polygon, an unbounded region, a line or edge when equalities force a narrow set, or even empty if the constraints conflict. Its shape is a visual summary of all restrictions working together.

Stop and Discuss
  1. What does the overlap of shaded regions represent?
  2. Can one system contain both solid and dashed boundaries? Explain.
  3. What could it mean if the shaded regions have no overlap at all?

I can apply feasible-region reasoning to interpret possible solutions in context.

A feasible point is an ordered pair that satisfies every constraint. The fastest way to check a specific point is often to substitute its coordinates into each inequality. One failed inequality is enough to make the point infeasible, even if it satisfies all the others.

In context, feasible points represent choices that are allowed by the model. A point on a solid boundary can be feasible because equality is permitted there; a point on a dashed boundary is excluded. Additional context restrictions, such as nonnegative quantities or whole-number counts, may further narrow which points are realistic decisions.

Feasible-region reasoning connects algebra, graphing, and decision making. The graph shows all possible choices at once, while substitution verifies individual candidates. A strong interpretation names which constraints a point satisfies or violates and connects that evidence back to the situation rather than simply saying “inside” or “outside.”

Summary

  • Each inequality models one constraint on the same variables.
  • Graph each inequality accurately, then find the overlap of all solution regions.
  • The overlap is the feasible region: the set of points satisfying every constraint.
  • A candidate is feasible only if it passes every inequality and any context restrictions.
