I can build translated graphs by moving key points and key features from a parent function.

A translation moves a graph without changing its basic shape or orientation. Start with a parent function and identify a few key points or features, such as a vertex, an intercept, or another easy point. If every point moves by the same horizontal and vertical amounts, the result is a translated copy of the original graph.

A horizontal movement changes every x-coordinate by the same amount, and a vertical movement changes every y-coordinate by the same amount. Moving right 3 and down 2 sends $(x,y)$ to $(x+3,y-2)$. The distances between points stay the same, so the translated graph preserves the parent graph’s shape, symmetry, and relative spacing.

Tracking points is often more reliable than trying to redraw a shape from memory. For a parabola, move the vertex and one or two symmetric points. For an absolute-value graph, move the vertex and points on both arms. For any family, checking several moved points confirms that the whole graph followed one consistent rule.

Stop and Discuss
  1. What coordinate rule moves every point right 3 and down 2?
  2. What graph properties stay unchanged under a translation?
  3. Why is moving several key points safer than moving only the vertex?

Teacher answer: 1) $(x,y)\to (x+3,y-2)$. 2) Basic shape, orientation, symmetry pattern, and distances between corresponding points stay unchanged. 3) Several points verify that the same movement was applied to the whole graph rather than just one feature.

Listen for: students naming the mathematical feature or structure that justifies the claim, not only describing appearance.

I can use horizontal and vertical shifts to write equations for translated functions.

Equation form can record the same movement. A vertical shift is easiest to see because adding $k$ outside a function changes every output: $y=f(x)+k$ moves the graph up $k$ units when $k\gt0$ and down when $k\lt0$. The same amount is added to every y-value, so the movement matches the point rule $(x,y)\to (x,y+k)$.

A horizontal shift appears inside the input: $y=f(x-h)$ moves the graph right $h$ units. The sign looks reversed because the new graph reaches the old output when its input is $h$ units larger. For example, the parent $y=x^2$ has vertex $(0,0)$, while $y=(x-4)^2$ has vertex $(4,0)$.

Combining the two gives $y=f(x-h)+k$, which moves the parent right $h$ and up $k$. For a quadratic, $y=(x-h)^2+k$ makes the vertex $(h,k)$. For absolute value, $y=|x-h|+k$ does the same. The equation and key-point movement should tell the same story.

Stop and Discuss
  1. What does $+k$ outside $f(x)$ do to the graph?
  2. Why does $f(x-4)$ move right instead of left?
  3. For $y=|x+2|-3$, where is the vertex?

Teacher answer: 1) It shifts every output vertically by $k$. 2) The graph needs an input 4 larger to make the inside expression match the parent input. 3) $(-2,-3)$.

Listen for: students naming the mathematical feature or structure that justifies the claim, not only describing appearance.

I can predict how changing values in an equation moves a graph left, right, up, or down.

Parameters in transformation form act like movement instructions. Changing the outside constant moves a graph vertically in the same sign direction. Changing the inside number produces horizontal motion with opposite sign behavior: $x-5$ means right 5, while $x+5$ means left 5. Instead of memorizing this as a trick, test which input makes the inside expression equal the parent input you want.

Prediction is easier when you identify an anchor feature. For a quadratic or absolute-value function, use the vertex. For an exponential function, use a convenient point such as where the parent has input 0. Once the anchor moves, apply the same translation to additional points and verify that no stretching or reflection occurred.

A translation changes location, not family. It does not change distances between corresponding points or the basic pattern of change. If one side of a graph moves differently from another, or the spacing between key points changes, the transformation is not a pure translation. Equations, tables of points, and graphs should all show one consistent movement.

Stop and Discuss
  1. Which parameter direction is easiest to read directly from its sign: horizontal or vertical?
  2. What anchor feature is useful for predicting a translated quadratic?
  3. How can you tell from points that a change is not a pure translation?

Teacher answer: 1) Vertical shift. 2) The vertex. 3) If different points move by different vectors or distances between corresponding points change, it is not a pure translation.

Listen for: students naming the mathematical feature or structure that justifies the claim, not only describing appearance.

Summary

  • A translation moves every point by the same vector and preserves the graph’s shape.
  • Key points and key features provide efficient anchors for building a translated graph.
  • $y=f(x-h)+k$ shifts the graph right $h$ and up $k$; signs inside the input behave oppositely from the visible movement.
  • Equations, coordinate rules, tables, and graphs should all describe the same translation.
