I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.

A transformation can change a graph’s position, scale, or orientation while keeping it connected to a parent family. A translation changes position. A stretch makes distances from an axis larger, a compression makes them smaller, and a reflection flips the graph across an axis. These effects can be combined in one equation.

An outside multiplier in $y=a f(x)$ changes the outputs. If $|a|\gt 1$, y-values are farther from the x-axis, creating a vertical stretch. If $0\lt |a|\lt 1$, y-values move closer to the x-axis, creating a vertical compression. If $a\lt 0$, the signs of all outputs reverse, so the graph also reflects across the x-axis.

Translations can be added to the same structure: $y=a f(x-h)+k$. A reliable design process is to start with key parent points, apply the scale/reflection to their outputs, then apply the translation. This keeps the transformation connected to an explicit rule instead of relying on a memorized sketch.

Stop and Discuss
  1. What does $|a|\gt 1$ do in $y=a f(x)$?
  2. What extra effect occurs when $a\lt 0$?
  3. Why should scale/reflection usually be applied to key points before the final translation?

I can apply transformation rules to key points and features across function families.

A transformation parameter tells how one part of a graph changes. For outside scaling, each parent point $(x,y)$ becomes $(x,ay)$ before any translation. If $a=-2$, the output doubles in distance from the x-axis and changes sign. Key features transform with the same rule: a vertex’s y-coordinate scales, and every other output scales consistently.

Different function families preserve different recognizable features under these changes. A quadratic stays parabolic, an absolute-value graph keeps two straight arms meeting at a vertex, and a linear graph stays a line. Scaling may make the graph steeper, flatter, narrower, or wider in appearance, but corresponding points must still obey the same transformation rule.

Tables are useful for checking point transformations because they show exact before-and-after values. If a supposed vertical stretch by 3 changes one output from 2 to 6 but another from 4 to 9, the rule is inconsistent. A correct table, graph, and equation should all produce matching transformed points.

Stop and Discuss

  3. How can a table reveal an inconsistent transformation?

I can assess whether an equation, graph, or table represents the same transformed function.

To decide whether several representations show the same transformed function, compare invariant and transformed features. Check the family first, then inspect anchor points, symmetry, intercepts, and the way outputs scale or shift. A matching picture is not enough; the equation and table must agree on exact values at corresponding inputs.

For $y=a f(x-h)+k$, use the equation to predict a few strategic points. Evaluate or transform the parent at those inputs, then compare with the table and graph. If the graph claims a vertex at one location but the equation predicts a different location, the representations do not match even if their overall shapes look similar.

Assessment is strongest when you name both the agreement and the contradiction. “These are the same because they are both parabolas” is weak. “They have the same vertex, the same opening direction, and the table values match the equation at selected inputs” is stronger. One precise mismatch is enough to show that representations are not the same function.

Summary

  • Outside multipliers change outputs, creating vertical stretches/compressions and possibly reflections.
  • Combined transformations can be tracked with key-point rules such as $(x,y)\to (x+h,ay+k)$.
  • Function-family structure remains recognizable even when scale, orientation, and location change.
  • To verify equivalent representations, compare exact points and features, not just overall appearance.

Common Mistakes

Watch for...Correct it by...
Confusing vertical stretch/compression with horizontal movement.
