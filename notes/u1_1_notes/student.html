Multiple Representations of Relationships

Same relationship. Different view.

What you'll learn about

...and why

Moving between representations helps you test claims and choose the view that makes a pattern easiest to see.

Section Introduction

One relationship, many views

Algebra becomes more useful when you can recognize the same relationship even after its appearance changes. A table lists values, a rule compresses the pattern, and a context gives the quantities meaning.

The goal is to track what stays mathematically the same across those views.

I Can 1Find matching values across different representations.

A relationship can appear as words, a rule, a table, or a graph. Matching representations share the same input-output pairs even when they look different. Start by choosing one input and tracing its output through each view.

An ordered pair records a matching input and output as \((x,y)\). A table row and a point can therefore describe the same values, while a rule explains how the values are produced. Matching is about the mathematics, not the surface appearance.

I Can 2Create a table or graph from another representation.

To create a new representation, keep the same relationship while changing its form. A rule can generate a table by substituting inputs. A table can become a graph by plotting each row as an ordered pair.

The important values and pattern must survive the translation. If the rule increases outputs by 2 whenever inputs increase by 1, a correctly built table should show that same change.

I Can 3Check whether two representations describe the same relationship.

Two representations describe the same relationship only if their corresponding values follow the same rule or pattern. Checking a few strategically chosen inputs can reveal a mismatch quickly.

Use values that are easy to compare, such as \(x=0\), and another input farther from zero. If both the starting value and the pattern disagree, the representations cannot be the same.

I Can 4Use values, rate, or pattern as evidence.

Evidence is a mathematical reason that supports a claim. In relationships, useful evidence often comes from matching values, a common rate, or a repeated pattern.

Different evidence answers different questions. Matching one value shows a local connection; matching a rate shows how change behaves; matching several values and the rate gives a stronger case.
