Multiple Representations of Relationships

One relationship can speak in several mathematical languages.

What you'll learn about

Learning Target: Connect tables, graphs, equations or rules, and contexts that represent the same relationship.

  • Find matching values across different representations.
  • Create a table or graph from another representation.
  • Check whether two representations describe the same relationship.
  • Use values, rate, or pattern as evidence.
...and why

Moving between representations helps you see what stays the same even when the mathematical picture changes.

Section Introduction

Same relationship, different view

A relationship connects quantities. A table lists matching values, a graph places those values as points, a rule tells how to calculate one quantity from another, and a context explains what the quantities mean. These forms can look very different while describing exactly the same relationship.

The key is to look for mathematical evidence instead of surface appearance. Matching ordered pairs, a shared starting value, or the same rate of change can show that two representations belong together.

As you read, keep asking: What information is preserved when the representation changes?

I Can 1Find matching values across different representations.

A representation is a way to show the same input-output relationship. A table stores matching values in rows, while an ordered pair writes one row as \((x,y)\). When a graph contains the point \((2,8)\), it is showing the same matched values as a table row with input 2 and output 8.

To match representations, choose one or two convenient inputs and compare the outputs. A single mismatch proves the representations are different. Several matching values plus the same rule or rate give stronger evidence that they describe the same relationship.

I Can 2Create a table or graph from another representation.

Creating a new representation means translating information without changing the relationship. From a rule, choose inputs and calculate outputs to build a table. From a table, each row becomes an ordered pair that can be plotted on a coordinate plane.

The order matters. In \((x,y)\), move horizontally using the input first, then vertically using the output. A table is often the safest bridge because it makes each matching pair explicit before you graph.

I Can 3Check whether two representations describe the same relationship.

Two representations describe the same relationship when they make the same input-output claims. You can test a table against a rule by substituting a table input into the rule and checking the output. You can also compare rates and starting values when the relationship is linear.

Do not assume two representations match because both increase or because their numbers are close. The check must be exact for the values being compared. One contradictory row is enough to show that the representations are not the same.

MATH NOTESA mismatch is decisive

Exact match

Rule: \(y=2x+1\)

Row: \((3,7)\)

Check: \(2(3)+1=7\)

Mismatch

Rule: \(y=2x+1\)

Row: \((4,10)\)

Check: \(2(4)+1=9\), not 10.

A representation must agree with the relationship on every value it claims to show.

I Can 4Use values, rate, or pattern as evidence.

Evidence explains why representations belong together. Matching values are direct evidence: the same input produces the same output. A rate is another kind of evidence because it describes how outputs change as inputs change. Patterns can also reveal repeated structure.

When you justify a match, name the evidence and connect it to both representations. “They both go up” is weak. “Both increase by 5 for each increase of 1 in x, and both start at 9 when x=0” is specific evidence.

MATH NOTESUse an evidence frame

Value evidence

At \(x=2\), both representations give \(y=19\).

Rate evidence

Both outputs increase by 5 whenever the input increases by 1.

Evidence frame: These representations match / do not match because ______. For example, ______.

Strong evidence names a value, rate, or pattern and shows how it appears in both representations.

Section Summary

  • A table, graph, rule, and context can represent the same input-output relationship.
  • Ordered pairs provide a direct bridge between tables and graphs.
  • Matching values and rates are stronger evidence than visual similarity.
  • A graph scale must be read before values are compared.
