I can construct a table, graph, equation, or context from another representation of the same relationship.

A relationship can be described in several forms without becoming a different relationship. A table lists input-output pairs, a coordinate graph places those same pairs on axes, an equation gives a rule for producing outputs, and a context explains what the quantities mean. Each form is an equivalent representation only when the mathematical connection between the quantities stays the same.

When you translate from one representation to another, preserve the ordered pairs. For example, if a table contains $(0,2)$ and $(3,11)$, then a matching graph must pass through those points and a matching equation must make both pairs true. A new representation is not a guess about what the original might mean; it is another way to communicate the same evidence.

Pay attention to scale and units. A graph can look steeper or flatter when the axes use different scales, even though the underlying rate is unchanged. In a context, units tell you what an input-output pair means. Translating well means carrying both the numerical pattern and the meaning of the quantities into the new form.

Stop and Discuss
  1. What must stay the same when a relationship is translated from a table to a graph or equation?
  2. Why can two graphs of the same relationship look different even when both are correct?
  3. Suppose a table includes $(2,9)$. What evidence would you expect to find in a matching graph and equation?

I can use features in one representation to work with a related table, graph, equation, or context.

Features help you move between representations efficiently. In a linear relationship, the rate tells how much the output changes for each one-unit change in input, while a starting value or intercept tells where the relationship begins when the input is zero. In a table, these features appear as repeated changes; in an equation such as $y=mx+b$, they appear in the coefficients.

A graph also stores exact information. Coordinates of visible points can be read as ordered pairs, and the change between two points can reveal a rate. Instead of treating a graph as a picture, read it as a collection of mathematical statements: this point is on the relationship, this amount of horizontal change pairs with this vertical change, and this intercept gives a particular input-output pair.

Using one representation to fill in another is a form of reasoning. If an equation produces a missing table value, or a graph supplies a point that can be substituted into an equation, you are using shared features as a bridge. The more reliable the feature, the stronger the translation.

Stop and Discuss
  1. In a linear relationship, what does the rate describe?
  2. How can a visible point on a graph be used to check an equation?
  3. Why is an intercept more useful than simply saying where a graph “looks like it starts”?
MATH NOTES
Two Reliable Checkpoints

Checkpoint 1: a shared point. Pick an input-output pair that appears in both forms.

Checkpoint 2: a shared rate or pattern. Compare repeated table changes, graph rise/run, or the equation coefficient.

If both checkpoints agree, the representations have strong evidence of belonging to the same relationship.

I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Two representations are equivalent only when they describe the same set of input-output connections. Similar-looking equations, tables, or graphs are not enough. A single mismatched value can show that two forms are not equivalent, while one matching point alone is usually not enough to prove that they are.

For a linear relationship, rate is especially powerful evidence. If two forms share a point and the same constant rate, then they describe the same line. If a table has one incorrect row, checking the equation at each input can isolate the mismatch. This is why substitution is useful as an evidence tool, not only as a calculation skill.

Comparison should be deliberate. Ask: Do important ordered pairs agree? Do the rates or patterns agree? Does the context assign the quantities the same meaning and units? A confident decision comes from evidence across forms rather than from visual resemblance.

Stop and Discuss
  1. Why is one matching ordered pair usually not enough to prove two linear representations are equivalent?
  2. What two kinds of evidence are especially strong for comparing linear representations?
  3. If every row of a table but one matches an equation, what is the most efficient way to find the error?
MATH NOTES
Equivalent Representations

Equivalent representations have the same value for every input under consideration. For linear relationships, a shared point plus a shared rate is a strong equivalence test.

Appearance can mislead: axis scale, table order, or equation form may change while the mathematics stays the same.
