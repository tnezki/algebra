Multiple Representations of Relationships

Same relationship, different view.

Learning Target

Connect tables, graphs, equations or rules, and contexts that represent the same relationship.

  • Find matching values across different representations.
  • Create a table or graph from another representation.
  • Check whether two representations describe the same relationship.
  • Use values, rate, or pattern as evidence.

Find matching values across different representations.

A relationship can be shown with words, a table, a graph, or a rule. The format changes, but the matching input-output values must stay the same. On a graph, each point is an ordered pair (input, output).

Math NotesMatch by values, not appearance

To match two representations, choose an input that appears in both. Compare the outputs. Repeat with another input when possible. A visual resemblance by itself is not enough evidence.

Example

The table and rule are supposed to show the same relationship.

Rule: \(y=-2x+3\)

Check the row with \(x=3\). Does its output match the rule?

Answer: Yes. The table gives y = -3 when x = 3, and the rule also gives y = -3.

Reasoning: Substitute x=3: y=-2(3)+3=-6+3=-3. The table row (3,-3) matches.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Create a table or graph from another representation.

To build a new representation, keep the same input-output pairs. From a rule, substitute selected inputs to make a table. From a table, plot each row as an ordered pair on a coordinate plane.

Math NotesTranslation check

After creating a table or graph, test one or two points in the original rule or situation. A translated representation should preserve the same values and pattern.

Check whether two representations describe the same relationship.

Two representations describe the same relationship only when their important values and pattern agree. One conflicting input-output pair is enough to show that they are different.

Math NotesFast comparison

Check a convenient input such as 0, 1, or a value shown in both representations. Then compare the rate or pattern if the relationship changes regularly.

Example

A student says the table and rule show the same relationship.

Rule: \(y=3x+5\)

Is the student correct? Use at least two values.

Answer: Yes. For example, x=0 gives y=5 and x=2 gives y=11 in both representations.

Reasoning: Check the rule: 3(0)+5=5 and 3(2)+5=11. Both match the table, and the +3 rate also agrees.

Use values, rate, or pattern as evidence.

Evidence names the mathematical feature that supports your decision. Strong evidence can be a matching value, a constant rate of change, a shared starting value, or another clear pattern.

Math NotesEvidence sentence

A useful explanation has the form: “When the input is ___, both representations give ___; they also change by ___, so ___.”
