I can construct a table, graph, equation, or context from another representation of the same relationship.

A relationship connects quantities. In a table, each row records an input-output pair. On a coordinate graph, that same pair becomes a point. In an equation, the same connection is written as a rule. A context gives the quantities meaning, such as time and distance or hours and cost.

Changing the representation should not change the relationship itself. If the ordered pair $(2,7)$ belongs to a table, the matching graph should contain the point $(2,7)$ and the matching equation should produce $7$ when the input is $2$. The form changes; the mathematical facts do not.

For relationships with a constant rate, a table can reveal the repeated change, a graph shows the same change as a steady rise or fall, and an equation records it in a compact rule. Moving from one form to another means preserving those shared values and features, not inventing a new pattern.

Stop and Discuss
  1. What does one row of a table become on a coordinate graph?
  2. What must stay true when a relationship is rewritten from a table as an equation?
  3. Why can two representations look different but still describe the same relationship?

Teacher answer / listen for:

  1. A row $(x,y)$ becomes the point $(x,y)$.
  2. The equation must generate the same input-output pairs and preserve the same pattern/rate.
  3. They encode the same values and relationships in different visual or symbolic forms.

I can use features in one representation to work with a related table, graph, equation, or context.

A useful representation lets you read features that help you build or interpret another form. In a table, repeated first differences can reveal a constant rate. On a graph, a steady line shows that the output changes by the same amount for equal changes in input. In an equation such as $y=mx+b$, the coefficient of $x$ records that constant change and the constant term gives the output when $x=0$.

These features can be used in both directions. If an equation is known, substitute selected inputs to build a table. If a graph is known, read exact points and compare how $y$ changes as $x$ changes. If a context says there is a starting amount plus a repeated amount, those two quantities can become the starting value and rate in a rule.

Scale matters when reading graphs. A line can look steep or flat depending on the axis scales, so the picture alone is not enough. Read the labels and values before deciding what a graphical feature means.

Stop and Discuss
  1. In $y=3x+1$, what feature tells the constant change in output?
  2. How can an equation be used to build a table?
  3. Why is graph steepness by appearance alone weak evidence for a rate?

Teacher answer / listen for:

  1. The coefficient 3 gives a change of 3 in output per 1 unit of input.
  2. Choose inputs, substitute each into the equation, and record the resulting ordered pairs.
  3. Axis scales can change the visual steepness without changing the relationship.
Math NotesReading a Constant Rate Across Forms

For a constant-rate relationship, compare $\frac{\Delta y}{\Delta x}$ using two points. In a table, look for equal input steps and matching output changes. In a graph, use labeled coordinates rather than appearance. In $y=mx+b$, $m$ is the constant rate and $b$ is the output at input 0.

Quick check: for $y=-2x+5$, every increase of 1 in $x$ changes $y$ by $-2$.

Discourse Moves

Teacher Moves

  • Have students point to the rate in an equation, table, and graph.
  • Ask one student to explain how scale could mislead a visual judgment.
  • Compare forward substitution with reading points from a graph.

Student Moves

  • Identify a feature and explain what it means.
  • Compare how the same rate appears in two forms.
  • Challenge a visual claim using axis values.

I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Two representations are equivalent representations when they describe the same relationship. Matching one convenient feature is helpful, but stronger evidence comes from checking more than one mathematical fact.

One checkpoint is shared values: choose an input and see whether both representations give the same output. A second checkpoint is shared structure: compare a rate, pattern, starting value, or other defining feature. If even one required ordered pair disagrees, the representations cannot be equivalent as written.

Visual similarity is not enough. Two graphs may have a similar shape while using different scales or values, and two tables may begin with matching rows before separating later. Evidence should come from the actual numbers, rates, or rules that define the relationship.

Stop and Discuss
  1. What is one value-based way to test whether two representations match?
  2. What structural feature could serve as a second checkpoint for a constant-rate relationship?
  3. If two representations match at one point but have different rates, can they be the same relationship? Explain.

Teacher answer / listen for:

  1. Use the same input in both and compare outputs, or verify a shared ordered pair.
  2. Compare the constant rate and often the output at input 0.
  3. No. A shared point alone is not enough; different rates make the relationships diverge elsewhere.
Math NotesTwo-Checkpoint Equivalence Test
  1. Check a value: verify at least one ordered pair in both forms.
  2. Check structure: compare rate, pattern, intercept/start value, or another defining feature.
  3. Use a mismatch decisively: one contradictory ordered pair proves the two forms are not equivalent as written.

Discourse Moves

Teacher Moves

  • Ask for two independent pieces of evidence before accepting “same relationship.”
  • Revoice vague claims such as “they look the same” into testable numerical claims.
  • Probe mismatches: “Which exact row, point, or feature breaks the match?”

Student Moves

  • Cite a specific value and a structural feature.
  • Restate a peer’s evidence as an ordered-pair or rate claim.
  • Challenge appearance-only reasoning with numerical evidence.

Example 6: Compare Relationships

Relationship A is $y=\frac12x-3$. Relationship B contains the points $(0,-3)$ and $(6,0)$. Determine whether they can be the same relationship and cite two pieces of evidence.

Teacher answer:

Yes. Both contain $(0,-3)$, and the rate from $(0,-3)$ to $(6,0)$ is $\frac{3}{6}=\frac12$, matching the equation.

You Try It 6: Compare Relationships

Relationship A is $y=-3x+2$. Relationship B contains $(0,2)$ and $(2,-4)$. Determine whether they are the same relationship and explain with values or rate.

Teacher answer:

Yes. Both have starting value 2, and B has rate $(-4-2)/(2-0)=-3$.

Summary

  • A table row, graph point, equation value, and context statement can encode the same input-output fact.
  • Translate among forms by preserving ordered pairs, rates, starting values, and patterns.
  • Use numerical and structural evidence—not appearance alone—to decide whether representations are equivalent.

Common Mistakes

  • Matching representations by visual appearance while ignoring scale or values.
  • Changing a table or graph without preserving the same ordered pairs or relationship.
