I can build graphs of linear functions using slope and intercept information.

A linear equation in the form $y=mx+b$ gives two pieces of information that can build a graph efficiently. The number $b$ is the vertical intercept, so $(0,b)$ is a starting point on the graph. The number $m$ is the slope, which tells how to move from one point to another using vertical change over horizontal change.

For a positive slope, a convenient slope step can move right and up; for a negative slope, it can move right and down. Fractional slopes are often easier to graph when written as a ratio such as $\frac{2}{3}$ or $-\frac{3}{2}$. A zero slope creates a horizontal line. The linear graph is determined once the intercept and a second correct point are located.

Tables provide another route to the same graph. Each row gives an ordered pair. If the table represents a linear relationship, the plotted points lie on one straight line and reveal the same slope and intercept that an equation would. The goal is not three separate procedures; it is one relationship seen through different representations.

Stop and Discuss
  1. In $y=mx+b$, which value gives the first point to plot?
  2. How can a slope of $-\frac{3}{2}$ be used as graphing steps?
  3. Why should a table and an equation for the same linear relationship produce the same line?

Teacher support: 1) $b$ gives the point $(0,b)$. 2) Move right 2 and down 3, or an equivalent ratio step. 3) They encode the same ordered pairs/rate/start, so their plotted points must align.

Math NotesGraphing from $y=mx+b$
  1. Plot the intercept $(0,b)$.
  2. Rewrite $m$ as a vertical-change/horizontal-change ratio if useful.
  3. Use the slope step to locate another point.
  4. Draw the line through the points and check the direction against the sign of $m$.

I can use key features of a line to interpret a relationship.

A graph communicates more than a collection of points. Its scale tells how numerical changes correspond to visual distances, while the intercept shows an input-zero value. The direction of the line indicates whether outputs increase or decrease as inputs increase, and the steepness combines with scale to show the numerical rate of change.

In context, these features acquire meaning. A vertical intercept might represent an initial fee, starting balance, or beginning distance. Slope might represent dollars per visit, miles per hour, or centimeters per week. Axis labels and units are therefore part of the mathematics, not decoration.

When reading a graph, separate starting value from rate. Two relationships can start at the same value but change at different rates, or change at the same rate but start at different values. Checking both features prevents conclusions based only on one visible point or on how steep the line appears.

Stop and Discuss
  1. What graph feature represents a starting value in many contexts?
  2. Why can visual steepness be misleading when graph scales differ?
  3. How do slope and intercept answer different questions about a relationship?

Teacher support: 1) The $y$-intercept. 2) The same number of visual grid squares can represent different numerical changes. 3) Slope answers how fast/how much it changes; intercept answers where it starts when input is 0.

Example 4: Graph a Context

A gym charges a 30-dollar joining fee plus 8 dollars per visit. Sketch a graph with visits on the horizontal axis and total cost on the vertical axis. Identify what the intercept means.

Teacher answer:

The graph is a line with slope $8$ and vertical intercept $30$. The intercept represents the starting total cost.

Teacher answer:

The graph is a line with slope $10$ and vertical intercept $45$. The intercept represents the starting savings.

Example 5: Use Graph Scale Correctly

On a graph, each horizontal grid step is 2 units and each vertical grid step is 5 units. A student moves right 1 square and up 1 square and calls the slope 1. Identify the error and correct it.

Teacher answer:

The slope is $5/2$, not 1, because grid squares represent different numerical changes.

You Try It 5: Use Graph Scale Correctly

A student graphs $y=\frac12x-4$ by moving right 1 and up 2 from $(0,-4)$. Identify the error and correct it.

Teacher answer:

The slope $1/2$ means right 2 and up 1, or an equivalent ratio.

I can extend a graph to predict outputs within a meaningful range.

A linear graph can be used to predict an output because the straight-line pattern continues at the same rate. Predictions inside the displayed or observed input range are usually better supported because the graph already shows the relationship there. Reading the graph carefully means locating the input, moving to the line, and then reading the corresponding output using the axis scale.

Extending a graph beyond a shown point is reasonable only when the situation supports continuing the same rate. A mathematical line extends forever, but a real situation may not. A savings pattern might continue for several weeks; a physical quantity may eventually hit a limit. The model and the situation both matter.

A useful prediction should include interpretation. State the predicted output and its units, then note whether the input lies within a meaningful range. This keeps graph reading connected to modeling rather than treating the coordinate plane as an isolated picture.

Stop and Discuss
  1. What steps let you read a predicted output from a graph?
  2. Why is a prediction inside the shown range usually better supported than one far outside it?
  3. Why can a mathematical line extend farther than a real-world model should?

Teacher support: 1) Locate the input, move to the line, then read the output using the scale. 2) It relies on behavior already represented by the graph. 3) Real contexts can have limits or changing behavior that the ideal line does not capture.

Math NotesPrediction from a Graph

Interpolate: read or estimate within the represented range.

Extend cautiously: continuing the line assumes the same rate remains meaningful in the situation.
