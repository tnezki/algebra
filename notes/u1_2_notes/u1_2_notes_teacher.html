Inputs, Outputs, and Functions

Follow the input to its one output.

What you'll learn about

Learning Target: Use input-output rules and the basic idea of a function.

  • Identify the input and output in a relationship.
  • Use a rule to find outputs.
  • Write ordered pairs from inputs and outputs.
  • Decide whether each input has only one output.
...and why

Functions organize cause-and-result relationships: each allowed input has one output. This idea becomes the language for nearly every later Algebra 1 topic.

Section Introduction

From a rule to a function

An input is the value you start with, and an output is the value produced by the relationship. A rule can connect them numerically, while tables, ordered pairs, mappings, and graphs show the same connection in other forms.

A function has one important restriction: each input is paired with only one output. Different inputs are allowed to share an output; the problem occurs only when the same input is assigned two different outputs.

Track every input carefully and ask what output it is allowed to produce.

I Can 1Identify the input and output in a relationship.

The input is the quantity supplied to a relationship; the output is the quantity produced. In a table the input is often listed first, and in an ordered pair (x, y) the first coordinate is the input.

In a context, use meaning rather than position alone. If total cost depends on the number of tickets, tickets are the input and cost is the output because the cost changes in response to the number chosen.

Ask which quantity is chosen or supplied first and which quantity depends on it.

I Can 2Use a rule to find outputs.

A rule tells what operation to perform on an input to create its output. To find an output, replace the input variable with the given value and then follow the operations in the rule.

A useful check is to estimate whether the direction of change makes sense. If the rule multiplies by a positive number and then subtracts a small amount, larger positive inputs should generally produce larger outputs.

MATH NOTESSubstitute an input into a rule

Rule: y = 4x - 3

Input x = 2

y = 4(2) - 3 = 8 - 3 = 5

So the pair is (2, 5).

Substitute the input first; do not replace the output variable.

Example 2: Find three outputs

Use y = 4x - 3 to find the outputs for x = -2, 1, and 4.

Answer / reasoning: For x=-2, y=-11; x=1, y=1; x=4, y=13.
Teacher move: Ask the student to point to the exact step or representation that justifies the answer.

You Try It 2: Use a decreasing rule

Use p = 7 - 2n to find p when n = 0, 3, and 5.

Answer / reasoning: Outputs: 7, 1, -3.

I Can 3Write ordered pairs from inputs and outputs.

An ordered pair records one complete input-output match. The first coordinate is the input; the second is the output. A row with input -2 and output 9 becomes (-2, 9).

Keeping the order consistent matters because reversing the coordinates changes the relationship. Use the table headings or context labels to decide what each coordinate means.

I Can 4Decide whether each input has only one output.

A relation is a function when each input has exactly one output. Scan the inputs first: if the same input appears with two different outputs, the relation is not a function.

Repeated outputs are not a problem. For example, (1, 5) and (3, 5) can both belong to a function because the inputs are different. Each input still points to only one result.

MATH NOTESOne output for each input

Function

(1,5), (2,5), (3,8)

Every input appears with one output.

Not a function

(1,5), (1,7), (3,8)

Input 1 has two different outputs.

Repeated outputs are allowed; repeated inputs with different outputs are not.

Example 4: Decide from ordered pairs

Is {(0,4), (2,4), (5,9), (7,12)} a function? Explain.

Answer / reasoning: Yes. No input is paired with more than one output. Repeated output 4 is allowed.
Teacher move: Ask the student to point to the exact step or representation that justifies the answer.

You Try It 4: Find the conflict

Is {(-1,3), (2,5), (-1,6), (4,8)} a function? Explain.

Answer / reasoning: No. Input -1 is paired with both 3 and 6.
Teacher move: If work stalls, ask what the input/structure/evidence tells them to do first rather than supplying the next operation.

Stop and Discuss

  1. Why are repeated outputs allowed in a function?
  2. What should you look for first when checking a long table for the function rule?

Vocabulary Reference

TermMeaning in this section
inputa value supplied to a relationship or rule
outputthe value produced for a given input
functiona relationship in which each input has exactly one output
ordered paira pair written (input, output), usually (x, y)
mappinga diagram or list showing which inputs are paired with which outputs

Section Summary

  • Inputs are starting values; outputs are the values produced by a rule or relationship.
  • An ordered pair records an input and its matching output as (input, output).
  • A function assigns exactly one output to each input.
  • Repeated outputs are allowed when they come from different inputs.

Common Mistakes to Watch

MistakeWhat to remember
Reversing inputs and outputs.In an ordered pair (x, y), the first coordinate is the input and the second is the output.
Thinking repeated outputs make a relation not a function.Different inputs may share an output; one input may not have two different outputs.
Substituting without using the whole rule.Replace the input variable, then follow the operations in the rule.
