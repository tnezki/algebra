I Can 1 — I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.

An input is the value that goes into a rule; the output is the value produced by the rule. In a table, the input and output columns show paired values. In a context, the quantities must be named before the rule has meaning—for example, hours watched as input and gigabytes used as output.

A rule should describe every listed pair, not just one convenient row. If the output changes by a constant amount when the input increases by 1, that repeated change can help reveal a linear rule.

Function notation is another way to name the output. In $f(x)=2x-5$, $x$ is the input and $f(x)$ is the output. The notation does not mean multiplication; it means “the output of function $f$ when the input is $x$.”

If $f(x)=3x+2$, then $f(4)=3(4)+2=14$. The ordered pair is $(4,14)$.

Example 5: Name Inputs and Outputs in Context

At a copy shop, input is the number of pages and output is total printing cost. The shop charges 8 cents per page. Name the input and output quantities and write a rule using dollars.

Teacher answer: Input: pages $p$. Output: cost $C$. A rule is $C=0.08p$ dollars.

You Try It 5: Name Inputs and Outputs in Context

A movie download uses 1.5 gigabytes per hour. Let input be hours watched. Name the output and write a rule.

Teacher answer: Output is data used $D$ in gigabytes, and $D=1.5h$.

Example 6: Build a Rule from Ordered Pairs

The ordered pairs are $(-1,4),(0,1),(1,-2),(2,-5)$. Formulate a rule and use it to predict the output when the input is 5.

Teacher answer: The rule is $y=-3x+1$. At $x=5$, $y=-14$.

You Try It 6: Build a Rule from Ordered Pairs

The pairs $(0,6),(1,4),(2,2),(3,0)$ follow one rule. Write it and find the output for input 8.

Teacher answer: $y=-2x+6$, so the output is -10.

I Can 2 — I can apply an input-output rule to generate missing values and ordered pairs.

Applying a rule forward means substitute an input and calculate the output. The resulting input-output pair can be written as an ordered pair and plotted on a graph.

Sometimes you know the output and need the input. Then the rule becomes an equation. For example, if $y=4x+1$ and the output is 29, the question is which input makes $4x+1=29$ true.

Keep the roles clear. Reversing input and output changes the relationship and can lead to a different rule.

Stop and Discuss. How is “find the output when the input is known” different from “find the input when the output is known”?

Teacher support: Expected distinction: forward evaluation substitutes a known input to compute an output; working backward sets the rule equal to the known output and solves for the input.

Example 2: Evaluate a Function Rule

For $f(x)=2x-5$, find $f(-2)$, $f(0)$, and $f(6)$.

Teacher answer: $f(-2)=-9$, $f(0)=-5$, and $f(6)=7$.

You Try It 2: Evaluate a Function Rule

For $g(x)=-3x+2$, find $g(-1)$, $g(2)$, and $g(5)$.

Teacher answer: $g(-1)=5$, $g(2)=-4$, and $g(5)=-13$.

Example 3: Work Backward from an Output

A function rule is $y=4x+1$. The output is 29. Determine the input.

Teacher answer: $29=4x+1$, so $x=7$.

You Try It 3: Work Backward from an Output

A rule is $y=5x-7$. The output is 18. Find the input.

Teacher answer: $x=5$.

I Can 3 — I can assess whether a rule gives one output for each input in a situation.

A function has one essential input-output condition: each input is assigned exactly one output. Different inputs are allowed to share the same output. The problem occurs when one input is paired with two different outputs.

In a table, scan for repeated inputs and compare their outputs. In a mapping diagram, look at the arrows leaving each input. One input may have only one outgoing result if the relation is a function.

This definition is about assignment, not about whether the rule is linear, whether the outputs repeat, or whether the graph looks familiar.

Function test: one input → one output. Many inputs may point to the same output.

Summary

  • Inputs are values supplied to a rule; outputs are values produced by the rule.
  • A rule must match all represented input-output pairs.
  • A function assigns exactly one output to each input.
Summary notes / questions / connections

Teaching note: Listen for the one-output-per-input condition and for students distinguishing the role of an input from the value of an output.
