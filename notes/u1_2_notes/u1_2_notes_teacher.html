...and why

Function language lets you describe how one quantity depends on another and prepares you to work with graphs, formulas, data, and models throughout algebra.

Section Introduction

Follow the input through the rule

An input-output relationship starts with a value or quantity, applies a rule, and produces an output. Tables, ordered pairs, mappings, and graphs can all record that same process.

A function has one special requirement: every allowed input must point to only one output. Different inputs are allowed to share an output.

Focus on the direction of the relationship and keep input and output roles clear.

I Can 1Identify the input and output in a relationship.

The input is the value you choose or control, and the output is the value the relationship produces. In a table, inputs are often listed in the first column and outputs in the second.

In a real situation, identify the quantities before using symbols. Ask which quantity is being used to determine the other. That direction tells you which is input and which is output.

The letters do not have to be x and y. Meaning comes from the relationship, so labels and units are more reliable than guessing from a variable name.

Example 1: Name input and output

A copier uses the number of packets \(p\) to determine total pages \(N=25p\). Identify the input and output quantities.

Teacher key / reasoning:

Input: number of packets \(p\). Output: total pages \(N\).

A sensor uses time \(t\) in seconds to report distance \(d\). Which quantity is the input and which is the output?

Input is time \(t\); output is distance \(d\).

I Can 2Use a rule to find outputs.

To use a rule, replace the input variable with the given input value. Parentheses help keep the substituted value together, especially when the input is negative.

Then follow the order of operations. The result is the output paired with that input.

A quick reasonableness check can catch errors: estimate the size or sign of the output and compare it with the exact result.

MATH NOTESSubstitute, calculate, pair

Rule: \(y=4x-7\), input \(x=6\)

\(y=4(6)-7=24-7=17\)

So the input-output pair is \((6,17)\).

Connect the operation or feature back to the relationship you are describing.

Example 2: Evaluate an input-output rule

Use \(y=3x-4\) to find the output when \(x=7\).

Teacher key / reasoning:

\(y=3(7)-4=21-4=17\).

You Try It 2: Evaluate an input-output rule

Use \(m=6n+2\) to find the output \(m\) when the input \(n=-2\).

Teacher key / reasoning:

\(m=6(-2)+2=-12+2=-10\).

Stop and Discuss

  1. Why are parentheses useful when substituting a negative input?
  2. What does the final value represent?
  3. How can estimation help catch an evaluation error?

I Can 3Write ordered pairs from inputs and outputs.

An ordered pair records one complete input-output event. The input is written first and the output second: \(( ext{input}, ext{output})\).

Each row of an input-output table can be converted directly into an ordered pair. The same pair can also be plotted as a point on a coordinate graph when the first coordinate is horizontal and the second is vertical.

Keeping the order consistent makes it possible to move cleanly among tables, mappings, ordered pairs, and graphs.

I Can 4Decide whether each input has only one output.

A relationship is a function when every input is assigned exactly one output. Scan by input, not by output.

Different inputs may share the same output and the relationship can still be a function. The violation occurs only when one input points to two different outputs.

In a mapping, check arrows leaving each input. In ordered pairs, look for a repeated first coordinate paired with different second coordinates.

MATH NOTESThe one-output-per-input test

Function

\((1,4),(2,4),(3,7)\)

Each input appears with one output. Repeated output 4 is allowed.

Not a function

\((1,4),(1,6),(3,7)\)

Input 1 has two outputs.

Connect the operation or feature back to the relationship you are describing.

Example 4: Apply the function test

Is \(\{(-2,5),(0,5),(4,9)\}\) a function? Explain.

Teacher key / reasoning:

Yes. Every input appears once. The repeated output 5 does not violate the function rule.

You Try It 4: Apply the function test

Is \(\{(3,8),(5,2),(3,-1)\}\) a function? Explain.

Teacher key / reasoning:

No. Input 3 is paired with both 8 and -1.

Stop and Discuss

  1. Why are repeated outputs allowed in a function?
  2. What should you scan first in a list of ordered pairs?
  3. How does a mapping diagram show a function violation?

Section Summary

  • Inputs are the values supplied to a relationship; outputs are the results.
  • A rule can be evaluated by substituting an input.
  • Ordered pairs record input first and output second.
  • A function gives each input exactly one output.

Common Mistakes to Watch

MistakeWhat to remember
Reversing inputs and outputsName the quantities first and keep the input in the first coordinate or left column.
Thinking repeated outputs mean not a functionRepeated outputs are allowed. A problem occurs only when the same input is paired with more than one output.
