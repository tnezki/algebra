Section 1.2

Inputs, Outputs, and Functions

One input. One output.

Learning Target

Use input-output rules and the basic idea of a function.

  • Identify the input and output in a relationship.
  • Use a rule to find outputs.
  • Write ordered pairs from inputs and outputs.
  • Decide whether each input has only one output.

Identify the input and output in a relationship.

The input is the value you start with. A rule acts on that input to produce an output. In a table, the input is usually the x-column and the output is the y-column.

Math NotesInput → rule → output

When the quantities have names, say what each variable means. The input/output role is about dependence, not simply which number is larger.

Example

The table records the cost of notebooks.

number of notebooks, ncost, C ($)
13
26
412

Which quantity is the input? Which is the output?

Answer: Input: number of notebooks n. Output: cost C.

Reasoning: The number chosen determines the resulting cost, so n is the input and C is the output.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

A conversion rule is \(F=1.8C+32\), where a Celsius temperature is entered and a Fahrenheit temperature is produced. Identify the input and output variables.

Answer: Input: C (Celsius). Output: F (Fahrenheit).

Reasoning: The rule takes a Celsius value C and produces F, so C is the input and F the output.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Use a rule to find outputs.

To use a rule, replace the input variable with the given number and evaluate in the correct order. Parentheses are especially important when the input is negative.

Math NotesSubstitution routine
  1. Write the rule.
  2. Replace the input variable.
  3. Evaluate carefully.
  4. Record the output with the input.

Example

Use \(y=4x-1\) to find the outputs when \(x=2\) and \(x=6\).

Answer: The outputs are 7 and 23.

Reasoning: For x=2: y=4(2)-1=7. For x=6: y=4(6)-1=23.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

A delivery fee is modeled by \(p=3n+8\). Complete the missing outputs.

np
0 
5 
9 

Answer: Outputs: 8, 23, 35.

Reasoning: p=3(0)+8=8; p=3(5)+8=23; p=3(9)+8=35.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Write ordered pairs from inputs and outputs.

An ordered pair records input first and output second: \((x,y)\). Every completed input-output row can be written as one ordered pair.

Math NotesOrder matters

The pair \((3,8)\) means input 3 gives output 8. Reversing the order changes the relationship.

Example

Write the table as a set of ordered pairs.

inputoutput
-25
12
4-1

Answer: (-2,5), (1,2), (4,-1).

Reasoning: Read each row left to right as (input, output).

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

Use \(y=2x+7\) for inputs \(x=-3,0,2\). Find the outputs and write the three ordered pairs.

Answer: (-3,1), (0,7), (2,11).

Reasoning: Evaluate the rule for each input, then place input first and output second.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Decide whether each input has only one output.

A relationship is a function when every input has exactly one output. Different inputs may share the same output; that is allowed. The problem occurs when one input is assigned two different outputs.

Math NotesFunction test

Scan the inputs. If an input repeats, compare its outputs. Same input + different outputs means the relation is not a function.

Example

Is this relation a function? Explain.

inputoutput
17
27
39
410

Answer: Yes, it is a function.

Reasoning: Each input appears with exactly one output. The repeated output 7 is allowed because it comes from two different inputs.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

Is this relation a function? Identify the input that decides the answer.

inputoutput
-23
06
-25
49

Answer: No. Input -2 has two different outputs, 3 and 5.

Reasoning: A function cannot send the same input to two different outputs.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Common Mistakes to Watch

MistakeWhat to remember
Repeated outputsAllowed: different inputs may have the same output.
Repeated input with different outputsNot a function: one input cannot have two outputs.

Use: Ask students to explain why the incorrect move changes the meaning or value, not only to memorize a rule.
