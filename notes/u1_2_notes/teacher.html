I Can 1Identify the input and output in a relationship.

An input is the value sent into a relationship; an output is the value produced. In an ordered pair \((x,y)\), x is the input and y is the output.

Tables, rules, mappings, and graphs can all organize the same input-output idea. Keep the direction clear: input first, output second.

Example 1: Model it together

In the rule \(p=7n+2\), identify the input variable and output variable. Then state the ordered-pair order.

Answer / Worked Reasoning: Input n; output p; ordered pairs are (n,p).

You Try It 1: Fresh attempt

For \(b=10-2a\), identify the input and output. Write the pair when a=3.

Answer / Worked Reasoning: Input a, output b; b=4, so (3,4).

Stop and Discuss

  1. How does an ordered pair preserve input-output direction?
  2. Why can reversing input and output change the meaning?

I Can 2Use a rule to find outputs.

A rule tells how to turn each allowed input into an output. Substitute the input for the variable, then simplify carefully.

When several inputs are given, use the same rule each time. The pattern in the outputs can help you notice an arithmetic mistake.

Example 2: Model it together

Use \(y=-2x+9\) to find the output when x=4.

Answer / Worked Reasoning: 1. y=-8+9=1.

I Can 3Write ordered pairs from inputs and outputs.

After finding an input and output, write them together as an ordered pair. The input always comes first. This makes table rows easy to place on a coordinate graph later.

Ordered pairs are not two unrelated numbers; they record one complete input-output event.

Example 3: Model it together

For \(y=x^2+1\), use inputs -2, 0, and 3. Write the three ordered pairs.

Answer / Worked Reasoning: (-2,5), (0,1), (3,10).

You Try It 3: Fresh attempt

For \(q=2p+6\), use p=-1, 2, 5 and write the ordered pairs (p,q).

Answer / Worked Reasoning: (-1,4), (2,10), (5,16).

Stop and Discuss

  1. What information is lost if you list outputs without their inputs?
  2. How does a table row become an ordered pair?

I Can 4Decide whether each input has only one output.

A function assigns exactly one output to each input. Different inputs may share the same output; that is allowed.

The problem occurs when one input is paired with two different outputs. In a table or mapping, scan each input and ask whether it points to more than one output.

MATH NOTESFunction decision

Function

1→5, 2→5, 3→7

Each input has one output.

Not a function

1→5 and 1→8

Input 1 has two outputs.

Use the visible mathematics as evidence for the I Can statement above.

Example 4: Model it together

Is {(1,4),(2,4),(3,7),(5,9)} a function? Explain.

Answer / Worked Reasoning: Yes. Every input appears with only one output; repeated output 4 is allowed.

You Try It 4: Fresh attempt

Is {(-2,1),(0,3),(-2,5),(4,7)} a function? Explain.

Answer / Worked Reasoning: No. Input -2 has outputs 1 and 5.

Stop and Discuss

  1. Why are repeated outputs allowed?
  2. What exact evidence makes a relation not a function?
Teacher Move: Ask students to point to the exact value, structure, or pattern that supports their explanation. Listen for reasoning that uses the representation rather than appearance alone.
