Inputs, Outputs, and Functions

A function is a dependable input-output relationship.

What you'll learn about

Learning Target: Use input-output rules and the basic idea of a function.

  • Identify the input and output in a relationship.
  • Use a rule to find outputs.
  • Write ordered pairs from inputs and outputs.
  • Decide whether each input has only one output.
...and why

Function language gives us a precise way to describe which quantity controls another and whether a rule gives a dependable result.

Section Introduction

What goes in, what comes out

An input is the value you start with; an output is the value produced by a rule or relationship. Tables, ordered pairs, mappings, and equations all organize the same basic idea: one quantity is used to determine another.

A function adds one important condition. Each input is allowed to have only one output. Different inputs may share an output, but one input cannot point to two different outputs in the same function.

Track each input carefully, then ask whether it has exactly one destination.

I Can 1Identify the input and output in a relationship.

The input is the quantity you choose, control, or start with. The output is the quantity that results. In an equation such as \(y=4x+1\), x is usually the input and y is the output. In a context, the names of the quantities matter more than the letters.

Ask “What value goes into the relationship?” and “What value comes out?” A mapping diagram makes this especially visible because arrows travel from the input side to the output side.

The first coordinate should represent the input quantity and the second should represent the output quantity.

Example 1: Identify the quantities

A plant’s height is recorded each week. Which quantity is the input and which is the output?

Teacher key: Input: week; output: plant height.
Reasoning: Time is selected first, and the measured height depends on that time.

You Try It 1: Read the dependency

The total cost depends on the number of tickets purchased. Identify the input and output and write the meaning of an ordered pair in words.

Teacher key: Input: number of tickets; output: total cost; a pair means (tickets, cost).
Reasoning: The cost is determined after the ticket count is chosen.

Stop and Discuss

  1. What word in a context often helps you identify the output quantity?
  2. Why should an ordered pair keep the input first?

I Can 2Use a rule to find outputs.

A rule is a machine: substitute the input, carry out the operations, and record the output. Parentheses are useful when an input is negative because they keep the sign attached to the value.

After calculating, keep the result connected to its input. The completed input-output row can then be written as an ordered pair.

Substitution replaces the input variable; the rule then determines exactly one output.

I Can 3Write ordered pairs from inputs and outputs.

An ordered pair records an input and its matching output in one compact object. The input is first and the output is second. A table row with input -2 and output 7 becomes \((-2,7)\).

Writing pairs preserves the matching structure of a table. If rows are mixed up or the coordinates are reversed, the relationship changes.

I Can 4Decide whether each input has only one output.

A function is a relationship in which each input has exactly one output. The fastest check is to scan the inputs. If an input repeats with two different outputs, the relationship is not a function.

Outputs are allowed to repeat. For example, \((1,5)\) and \((3,5)\) can belong to a function because the inputs are different. The problem occurs only when one input is assigned to more than one output.

MATH NOTESFunction check

Function

\((0,2),(1,2),(3,6)\)

Each input appears with one output.

Not a function

\((1,4),(2,5),(1,7)\)

Input 1 has two outputs.

Repeated outputs are okay; one input with two outputs is not.

Example 4: Decide from ordered pairs

Is \({(1,4),(2,5),(1,7)}\) a function? Explain.

Teacher key: No.
Reasoning: Input 1 is paired with both 4 and 7.

You Try It 4: Repeated outputs

Is \({(0,2),(1,2),(3,6)}\) a function? Explain why the repeated output does or does not matter.

Teacher key: Yes.
Reasoning: Each input has one output. Output 2 can be shared by different inputs.

Stop and Discuss

  1. Why do repeated outputs not violate the definition of a function?
  2. What is the minimum evidence needed to prove a relation is not a function?

Section Summary

  • Inputs are the starting values; outputs are the resulting values.
  • A rule can be used to calculate outputs for chosen inputs.
  • Each row of an input-output table can be written as an ordered pair.
  • A function gives exactly one output for every input.
