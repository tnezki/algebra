Inputs, Outputs, and Functions
A function is a dependable input-output rule.

Core idea: For every allowed input, a function produces exactly one output.

You will evaluate rules, build rules from pairs, and decide whether input-output relationships behave as functions.

Reading: Read a function as an input-output process

An input is a value placed into a rule, and an output is the value produced. A function is a relationship in which each allowed input is connected to exactly one output. The rule may be shown with an equation, a table, ordered pairs, a graph, or a machine-style description.

An ordered pair writes the input first and the output second: $(x,y)$. In function notation, $f(x)$ names the output produced by the function $f$ when the input is $x$. For example, if $f(x)=4x-3$, then $f(2)=4(2)-3=5$.

Evaluating a function means substituting an input and following the rule accurately. Negative inputs need extra care because the negative value replaces the variable as a complete number. Parentheses make that substitution visible: $f(-1)=4(-1)-3$.

You can also work backward from pairs. If outputs change by the same amount when inputs increase by $1$, that repeated change can help build a rule. Then test the proposed rule on more than one pair before treating it as a match.

Stop and Discuss

Reading: Use the one-output rule and work in either direction

A mapping diagram draws arrows from inputs to outputs. It is a function when each input has only one arrow leading to an output. Two different inputs may point to the same output; the restriction is on one input splitting into different outputs.

The same test works for ordered pairs. Repeated inputs are not automatically a problem, but a repeated input paired with two different outputs violates the function rule. For example, $(1,5)$ and $(1,9)$ cannot both belong to one function because input $1$ would have two outputs.

Function rules can be written from verbal processes. “Double the input, then subtract $5$” becomes $y=2x-5$. Once the rule is written, it can produce outputs for given inputs or be solved backward when an output is known.

Working backward does not change the meaning of input and output. If $y=3x+4$ and the output is $19$, the equation $3x+4=19$ asks which input makes the rule produce $19$. Solving gives the missing input.

Stop and Discuss

  1. Why can two inputs share one output in a function, while one input cannot have two outputs?
  2. How does the equation change when you know an output and need to find the input?

Vocabulary / Key Terms — Definitions

TermMeaning
inputa value supplied to a rule or relationship
outputthe value produced from an input
functiona relationship that assigns exactly one output to each allowed input
ordered paira pair $(x,y)$ that records an input first and its output second
mapping diagrama diagram using arrows to connect inputs with outputs

Summary

  • A function assigns exactly one output to each allowed input.
  • Function notation such as $f(2)$ names the output for a particular input.
  • Tables, ordered pairs, equations, and mappings can all represent input-output rules.
  • A repeated input with two different outputs means the relationship is not a function.
