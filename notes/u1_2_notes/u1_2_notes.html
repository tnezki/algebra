I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.

An input is a value that goes into a relationship, and an output is the value produced from it. The names $x$ and $y$ are common, but input and output are roles, not permanent labels. In a context, hours might be the input and cost the output; in another situation, temperature might be the input and energy use the output.

A rule describes how to move from an input to its output. The rule may be shown in words, a table, an equation, or a context. A function is a relationship in which each input is assigned exactly one output. That condition is about how inputs are paired, not about whether the rule is linear or whether the graph looks familiar.

When a table shows a steady pattern, compare how outputs change as inputs change. A rule can often be built from the repeated change and a known input-output value. In a context, make sure the rule also matches the units and meaning of the quantities.

Stop and Discuss
  1. What is the difference between an input and an output?
  2. What condition must every function satisfy?
  3. Why are input and output not always the same as x and y?

I can apply an input-output rule to generate missing values and ordered pairs.

Function notation such as $f(x)$ names the output produced when the input is $x$. For example, if $f(x)=2x+1$, then $f(3)$ means “the output when the input is 3.” Substitute the input into the rule, carry out the operations, and interpret the result as an output.

An ordered pair records the connection as $(\text{input},\text{output})$. If $f(3)=7$, then $(3,7)$ is a point on the graph of the function. A table row, a function value, and a plotted point can therefore be three views of the same input-output event.

Sometimes the output is known and the input is missing. Then reason backward through the rule. Instead of evaluating the rule forward, set the rule equal to the known output and determine which input makes the statement true.

Stop and Discuss
  1. What does $f(3)$ mean?
  2. How is $f(3)=7$ connected to the ordered pair $(3,7)$?
  3. What changes when you know the output but not the input?

I can assess whether a rule gives one output for each input in a situation.

The defining function check is simple: one input cannot point to two different outputs. A repeated input is not automatically a problem. If the same input repeats with the same output, the relationship can still be a function because the input has not been assigned a second value.

A mapping diagram displays inputs on one side and outputs on the other, with arrows showing the pairings. To check whether the mapping is a function, focus on arrows leaving each input. One input may share an output with another input; that is allowed. What is not allowed is one input sending arrows to two different outputs.

Context matters too. Ask whether one input value could reasonably have two different outputs under the stated rule. If the rule describes total cost for a fixed pricing plan, the same number of items should not produce two different totals.

Stop and Discuss
  1. Can a repeated input appear twice in a function table?
  2. What do you inspect in a mapping diagram to decide whether it is a function?
  3. Why can two different inputs share the same output without violating the function rule?

Summary

  • Inputs go into a rule; outputs come out.
  • A function assigns exactly one output to each input.
  • Function notation, ordered pairs, tables, and graph points can describe the same pairing.
  • A repeated input is allowed only when it repeats the same output.
  • Known outputs can be used to reason backward for missing inputs.
