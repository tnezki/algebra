I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.

An input is the value put into a relationship, and an output is the value produced. In an ordered pair $(x,y)$, the first coordinate records the input and the second records the output when those roles have been defined that way.

A rule describes how to get from input to output. A table may reveal the rule through repeated changes, an equation states it symbolically, a graph shows many input-output pairs at once, and a context explains what the quantities mean. The labels matter: input and output are roles, not automatic names for particular real-world quantities.

When building a rule, look for what happens repeatedly and what value appears when the input is zero if that information is available. Then test the rule on more than one row or point. A good rule must reproduce the listed values, not just fit one convenient example.

Stop and Discuss
  1. In an ordered pair used as input-output data, which coordinate is normally the input?
  2. What two pieces of table evidence can help build a constant-rate rule?
  3. Why should a proposed rule be tested on more than one row?
Math NotesFrom Pattern to Rule

For a constant-rate table, first find how the output changes when the input increases by 1. Then identify the output at input 0 when possible. A rule can be written as $y=(\text{rate})x+(\text{starting output})$.

Always test the rule on another row before trusting it.

I can apply an input-output rule to generate missing values and ordered pairs.

Applying a rule means replacing the input variable with a specific value and carrying out the operations carefully. With $f(x)=2x-5$, the notation $f(3)$ means the output when the input is 3; it does not mean $f$ multiplied by 3.

Each evaluated input and output can be written as an ordered pair. For example, if $f(3)=1$, then $(3,1)$ is a point on the graph of the same relationship. This is another way tables, equations, and graphs stay connected.

Sometimes the output is known and the input is missing. Then reason backward: replace the output with its known value and solve for the input. Forward evaluation and backward reasoning use the same rule; only the missing quantity changes.

Stop and Discuss
  1. What does $f(3)$ mean in words?
  2. If $f(3)=1$, what ordered pair belongs to the relation?
  3. How does the task change when the output is known but the input is missing?
Math NotesEvaluate Forward, Reason Backward

Forward: if $g(x)=3x+2$, then $g(4)=3(4)+2=14$.

Backward: if $g(x)=14$, solve $3x+2=14$ to find $x=4$.

Both statements describe the same ordered pair $(4,14)$.

I can assess whether a rule gives one output for each input in a situation.

A function is a relationship in which each input has exactly one output. Different inputs are allowed to share the same output. What is not allowed is one input being assigned two different outputs.

A table gives direct evidence: scan the input column. If an input repeats, check whether its outputs agree. A mapping diagram shows the same idea with arrows; every input should have exactly one arrow leaving it toward an output.

A repeated input with the same repeated output does not create a conflict—it is simply the same assignment listed more than once. The key question is consistency: does the rule know exactly what output to give for each input?

Stop and Discuss
  1. What condition must be true for a relationship to be a function?
  2. Can two different inputs share one output and still form a function?
  3. Why does a repeated input with two different outputs violate the function rule?

Summary

  • Inputs are values supplied to a rule; outputs are the values the rule produces.
  • Evaluate a rule forward to find outputs or reason backward when an output is known.
  • A function gives exactly one output for each input; repeated outputs are allowed.

Common Mistakes

  • Reversing inputs and outputs when applying a rule.
  • Treating a repeated input with two different outputs as a function.
