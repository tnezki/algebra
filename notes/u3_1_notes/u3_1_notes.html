I can construct graphical representations of systems and connect intersection points to solutions.

A system of equations asks us to consider two equations at the same time. Each linear equation represents a set of ordered pairs that make that equation true. When the two lines are drawn on the same coordinate plane, a point that lies on both lines satisfies both equations, so it is a solution of the system. This is why the intersection is more than a place where two lines happen to cross: it is shared evidence from both relationships.

Graphing a system connects directly to what you already know about linear functions. You can graph each equation from slope-intercept form, from a table, or by using intercepts or other convenient points. The important move is to keep the two relationships on the same axes and use the same scale. A graph with a distorted or inconsistent scale can make an intersection appear to be somewhere it is not.

The graphical solution should always be read as an ordered pair, not as two unrelated numbers. If the lines cross at $(3,-2)$, then $x=3$ and $y=-2$ must work in both original equations. A graph is especially useful for seeing the big picture quickly, while substitution into the equations can verify an estimate when the intersection is not exactly on grid lines.

Stop and Discuss
  1. What must be true about an ordered pair for it to be a solution of a system?
  2. Why does the intersection of two graphed equations represent a shared solution?
  3. If a graph suggests an intersection at about $(4,1)$, how could you check whether that estimate is exact?

I can use elimination to solve systems and interpret the solution type.

Elimination solves a system by combining equivalent equations so that one variable disappears. The method works because adding equal quantities to equal quantities preserves equality. If the $y$-coefficients are opposites, adding the equations removes $y$; if the $x$-coefficients are opposites, adding removes $x$. The goal is not to follow a memorized direction but to create a one-variable equation that still describes the same shared solution.

Sometimes a variable is ready to eliminate immediately. Other times, one or both equations must be multiplied by a nonzero number first. That multiplier applies to every term on both sides of the equation because the whole equation is being replaced by an equivalent equation. Multiplying only the term you want to eliminate changes the equation and can create a false solution.

After one variable is found, substitute it into either original equation to find the other coordinate. Then check the ordered pair in both original equations, especially if fractions or sign changes were involved. Elimination and graphing are different representations of the same idea: both are searching for the point, if any, that satisfies both constraints simultaneously.

Stop and Discuss
  1. What is the purpose of elimination?
  2. Why must a multiplier be applied to every term in an equation?
  3. How does an elimination step preserve the same solution even though the equations may look different?
Math NotesElimination Preserves Equality

Choose operations that create opposite coefficients. For $\begin{cases}2x+y=7\\3x-y=8\end{cases}$, add the equations:

$(2x+y)+(3x-y)=7+8 \Rightarrow 5x=15 \Rightarrow x=3$.

The $y$-terms cancel because $y+(-y)=0$. Then use an original equation to find $y$.

I can determine whether a system has one solution, no solution, or infinitely many solutions from algebraic and graphical evidence.

Not every pair of linear equations has one shared point. Two nonparallel lines meet once, so the system has one solution. Distinct parallel lines never meet, so the system has no solution. If the equations describe the same line, every point on that line satisfies both equations, giving infinitely many solutions.

You can often predict the solution type from slope-intercept form. Different slopes guarantee one intersection. Equal slopes with different intercepts describe parallel lines, while equal slopes and equal intercepts describe the same line. Algebra can reveal the same structure even when the equations begin in standard form or another arrangement.

Elimination gives another useful signal. If the variables disappear and a true statement such as $0=0$ remains, the equations are equivalent and the system has infinitely many solutions. If the variables disappear and a false statement such as $0=4$ remains, the constraints contradict each other and there is no solution. The algebraic result and the graphical picture should tell the same story.

Summary

  • A system solution must satisfy both equations at once.
  • Graphing finds shared points visually; elimination finds the same shared solution algebraically.
  • Equivalent operations must be applied to entire equations.
  • Solution type can be recognized from line relationships or algebraic identities/contradictions.

Common Mistakes

Assuming every system has exactly one solution.Check whether the lines intersect once, are parallel, or are the same line.

Stopping after finding one variable.Substitute back to find the second coordinate and check both equations.
