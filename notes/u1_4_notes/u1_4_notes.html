I Can 1 — I can build equivalent expressions by using structure, grouping, and properties of operations.

An expression is built from terms, operations, and grouping. A term is separated from another term by addition or subtraction. In a variable term such as $5x$, the coefficient is the numerical factor 5.

Equivalent expressions look different but have the same value for every allowed input. Combining like terms preserves value because the same kind of quantity is being counted together. For example, $5x+2x$ is seven copies of $x$, so it becomes $7x$.

The distributive property connects a product to a sum: $a(b+c)=ab+ac$. An area model makes the same structure visible by splitting one rectangle into partial rectangles whose areas add to the total.

Math NotesStructure that preserves value

$3(x+4)=3x+12$ because the factor 3 multiplies both terms inside the grouping.

$5x+2x=7x$ because both terms contain the same variable factor $x$.

I Can 2 — I can apply rewriting strategies to make the meaning of an expression easier to work with.

Rewriting is useful when a different form reveals something you want to see. Expanding removes grouping and displays partial products. Factoring reverses that process and reveals a common factor.

Before distributing, read the entire factor outside the parentheses, including its sign. Before factoring, identify the greatest factor shared by every term. Neither process should change the value of the expression.

Context can make one form more informative than another. A perimeter written as a sum may show the side lengths being added; a simplified form may make total variable and constant contributions easier to see.

Stop and Discuss. How can two equivalent forms emphasize different information even though they always have the same value?

I Can 3 — I can determine whether two expressions are equivalent by using structure, substitution, or properties.

You can test equivalence in more than one way. Algebraic properties can transform one expression into the other. Substitution can provide evidence by showing that the forms agree at selected inputs. Tables can organize several such checks.

A few matching substitutions are useful evidence, but structure explains why the expressions agree for every input. When possible, use substitution to check and properties to justify.

If two expressions disagree for even one input, they are not equivalent. That makes a carefully chosen substitution an efficient way to disprove an equivalence claim.

Equivalence means same value for every input. Properties can prove equivalence; one counterexample can disprove it.

Summary

  • Equivalent expressions preserve value even when their form changes.
  • Combining like terms, distributing, and factoring are structure-based rewriting strategies.
  • Substitution can check equivalence; algebraic properties explain why equivalence holds.
