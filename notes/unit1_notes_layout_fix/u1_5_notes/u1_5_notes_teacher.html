I can construct an equation that models a situation using meaningful quantities and operations.

A variable represents a quantity whose value may be unknown or change. In modeling, define the variable before writing mathematics so the symbols keep a clear meaning. An equation states that two expressions represent the same quantity or value.

To build an equation from a situation, identify the starting amount, repeated change, total, and unknown quantity when those features are present. Each number should have a job. A contextual quantity carries units and meaning, so an equation should match both the arithmetic relationship and the real quantities being compared.

Before solving, estimate what size of answer makes sense. A rough prediction helps detect modeling mistakes: if a fixed fee plus a per-unit charge totals only a little more than the starting fee, a very large number of units would be suspicious.

Stop and Discuss
  1. What does an equation state?
  2. Why should a variable be defined before modeling?
  3. How can an estimate help before solving?

Teacher answer: 1. That the expressions on both sides represent the same value or quantity. 2. So its meaning and units stay clear throughout the equation and interpretation. 3. It provides a reasonableness target that can reveal a modeling or arithmetic error later.

Example 1: Construct an Equation from a Context

A gym charges a 25-dollar joining fee plus 8 dollars per visit. A member has paid 73 dollars. Let $v$ be the number of visits. Construct an equation.

Teacher answer: $25+8v=73$.

You Try It 1: Construct an Equation from a Context

A bike shop charges 10 dollars plus 3 dollars per hour. The total is 28 dollars. Let $h$ be hours. Write the equation.

Teacher answer: $10+3h=28$.

Example 2: Create a Situation for an Equation

Write a plausible situation that could be modeled by $15+4x=43$. Define what $x$ represents and interpret the solution.

Teacher answer: Answers vary. Example: a 15-dollar starting fee plus 4 dollars per hour totals 43 dollars. Then $x=7$ hours.

You Try It 2: Create a Situation for an Equation

Create a situation for $20+2x=34$ and interpret the solution.

Teacher answer: Answers vary; a consistent interpretation has $x=7$ units of the repeated quantity.

Stop and Discuss
  1. If every number in a word problem appears in your equation, does that guarantee the model is correct?

Teacher answer: 1. No. The operations and quantity meanings must also match the situation.

I can use solution steps to solve an equation and connect the result to the situation.

A solution is a value that makes the original equation true. Solving uses equivalent transformations to isolate the variable while preserving equality. Whatever operation is performed on one side must be matched on the other side so both expressions remain equal.

An inverse operation undoes another operation: addition and subtraction are inverses, as are multiplication and division. In a multi-step equation, undo operations in an order that keeps the work organized. The goal is not to “move” terms magically; it is to create equivalent equations until the variable is isolated.

A check substitutes the proposed solution back into the original equation. If both sides evaluate to the same value, the solution satisfies the equation. In a context, the check should also include units and meaning.

Stop and Discuss
  1. What is a solution to an equation?
  2. Why must you perform matching operations on both sides?
  3. What is the difference between “moving a term” and using an inverse operation?

Teacher answer: 1. A value that makes the original equation true. 2. To preserve equality and create an equivalent equation. 3. Inverse operations explain the equivalent transformation; “moving” hides the operation that preserves equality.

Math NotesPreserve Equality

For $3x+5=26$, subtract 5 from both sides to get $3x=21$, then divide both sides by 3 to get $x=7$. Each line is an equivalent equation because the same operation was applied to both sides.

Math NotesCheck in the Original Equation

Substitute the solution into the original equation, not only the last simplified line. For $x=7$: $3(7)+5=26$, so the check is true.

Example 3: Solve with an Inverse Operation

Solve $x+7=19$ and state the inverse operation used.

Teacher answer: $x=12$ by subtracting 7 from both sides.

You Try It 3: Solve with an Inverse Operation

Solve $y-9=14$ and name the inverse operation.

Teacher answer: $y=23$ by adding 9 to both sides.

Example 4: Solve and Check a Two-Step Equation

Solve $3x+5=26$ and check the solution in the original equation.

Teacher answer: $3x=21$, so $x=7$. Check: $3(7)+5=26$.

You Try It 4: Solve and Check a Two-Step Equation

Solve $4x-7=21$ and check.

Teacher answer: $x=7$; check $4(7)-7=21$.

Example 5: Preserve Equality with Variables on Both Sides

Solve $5x-4=2x+17$ by preserving equality on both sides.

Teacher answer: $3x=21$, so $x=7$.

You Try It 5: Preserve Equality with Variables on Both Sides

Solve $6x+2=3x+20$.

Teacher answer: $3x=18$, so $x=6$.

Stop and Discuss
  1. Why is checking in the original equation stronger than checking only the final line x=7?

Teacher answer: 1. The original equation verifies that the value satisfies the relationship you were asked to solve.

I can predict whether a solution is reasonable by interpreting it in the original context.

A mathematically correct solution can still be unreasonable in a situation. Interpret what the variable represents, attach units, and compare the result with the conditions in the problem. A negative number of tickets, for example, would not fit an ordinary ticket-count context even if an algebraic model produced it.

Reasonableness can be checked before and after solving. Before solving, estimate a sensible range. After solving, substitute into the equation and ask whether the answer fits the context. These two checks catch different kinds of mistakes.

Modeling also works in reverse. Given an equation, you can invent a situation whose quantities and operations fit it. A good context assigns meaning to the starting amount, repeated rate, total, and variable without changing the mathematical structure.

Stop and Discuss
  1. What two checks should you make after solving a contextual equation?
  2. Why can a correct algebraic value still be unacceptable in a context?
  3. How can you tell whether a story you invent truly matches a given equation?

Teacher answer: 1. Verify the value in the original equation and interpret whether it makes sense with units/context. 2. The situation may impose constraints such as nonnegative counts or realistic ranges. 3. Each number, operation, variable, and total in the story must correspond to the equation structure.

Math NotesInterpret the Solution

A complete contextual answer includes the value, units, and meaning. If $d=6$ in a rental model where $d$ is days, report “6 days,” then check that 6 fits the original conditions.

Math NotesReverse Modeling

The equation $15+4x=43$ can model any coherent situation with a starting amount of 15, a repeated change of 4 per unit, and a total of 43. The context must define what $x$ counts or measures.

Example 6: Solve and Interpret with Units

A phone plan is modeled by $18+6g=54$, where $g$ is gigabytes of extra data. Solve and interpret the answer with units.

Teacher answer: $6g=36$, so $g=6$ gigabytes of extra data.

You Try It 6: Solve and Interpret with Units

A rental is modeled by $9+5d=39$, where $d$ is days. Solve and interpret.

Teacher answer: $d=6$ days.

Stop and Discuss
  1. A solution is x=-3, but x counts tickets sold. What should you conclude?

Teacher answer: 1. The algebraic result does not fit the context; revisit the model/conditions or interpret that there is no feasible ticket count under the setup.

Summary

  • Define variables and keep units/quantity meanings visible when modeling.
  • An equation states an equality between two expressions.
  • Use inverse operations on both sides to preserve equality while solving.
  • Check solutions in the original equation and interpret them in context.
  • Estimate before solving and judge reasonableness after solving.
