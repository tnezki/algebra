Equations as Models

An equation connects the quantities; a solution answers the situation.

What you'll learn about

Learning Target: Write an equation from a situation and explain what its solution means.

  • Define a variable.
  • Write an equation that matches a situation.
  • Use equivalent steps to solve when needed.
  • Check and interpret a solution in context.
...and why

Equations let you turn a situation into a mathematical model, solve for an unknown quantity, and then return to the situation with a meaningful conclusion.

Section Introduction

Translate, solve, then return to the story

An equation is useful when it represents how quantities in a situation are connected. Before writing symbols, decide what is unknown and define a variable with units or meaning.

After you solve, the number is not the whole answer. Check it in the original relationship and explain what the value means in the context. That final interpretation is what turns algebra back into a model of the situation.

Every symbol should have a job, and every solution should return to the situation.

What's To Come

PREVIEW / DECOMPOSE. Use the connected parts to see where this section is headed. Annotate the representations and prompts as you work.

A school club already has $45 in donations and earns $8 for each ticket sold. The club wants a total of $125. Use this one fundraiser for Parts A–D.

Part A

Define a variable for the unknown quantity.

Part B

Write an equation that represents reaching $125.

Part C

Solve the equation using equivalent steps.

Part D

Check the solution in the situation and write a sentence interpreting it.

Teacher support

Answer: A: let t = number of tickets sold. B: 45+8t=125. C: t=10. D: 45+8(10)=125, so the club must sell 10 tickets.

Reasoning: The start amount is fixed, the per-ticket amount multiplies the unknown count, and the target is the total.

Teaching move / likely issue: If students write 8+45t, ask which quantity repeats once per ticket.

I Can 1Define a variable.

A variable represents an unknown or changing quantity. A useful definition says more than “let x be the answer.” It names what the number counts or measures and, when helpful, includes units.

Choose a variable that fits the situation. If the unknown is minutes, you might write “Let \(m\) be the number of minutes.” A clear definition makes the equation easier to read and the final solution easier to interpret.

MATH NOTESDefine the unknown before using it

Situation: A taxi ride costs a $4 start fee plus $3 per mile.

Variable definition: Let \(m\) = number of miles traveled.

Then \(4+3m\) represents total cost.

Example 1: Define a variable

A student has read 36 pages of a book and reads 12 more pages each day. The unknown is how many days it will take to reach 120 pages. Define a variable clearly.

Teacher support

Answer: Example: Let d = number of days of additional reading.

Reasoning: The unknown in the question is a count of days, not pages.

Teaching move / likely issue: If a student defines p=pages, ask which quantity the question actually asks them to find.

You Try It 1: Name the unknown quantity

A phone plan charges $25 plus $6 per gigabyte. You want to know how many gigabytes were used when the bill is $49. Define a variable with meaning.

Teacher support

Answer: Example: Let g = number of gigabytes used.

Reasoning: The variable represents the unknown usage amount.

Teaching move / likely issue: Insist that the definition include the quantity, not only a letter.

Stop and Discuss

  1. What makes a variable definition useful instead of vague?
  2. How can the question itself help you identify the unknown quantity?
Teacher support: Listen for explanations that cite the representation, operation, or pattern rather than only the final answer.

I Can 2Write an equation that matches a situation.

To write an equation, connect the quantities exactly as the situation describes them. Identify fixed amounts, rates or repeated amounts, the unknown quantity, and any total or comparison.

Units can help. If a cost is $6 per ticket and \(t\) counts tickets, then \(6t\) is dollars. Adding a fixed dollar amount still gives dollars, so it can be set equal to a total cost in dollars.

MATH NOTESMatch each phrase to an algebraic role

Situation

$12 entry fee plus $5 per ride totals $42.

Equation

\(12+5r=42\)

r = number of rides

Fixed amount + rate × count = total.

Example 2: Write the equation

A streaming service charges $9 for the month plus $2 for each movie rental. The bill is $23. Let \(m\) be the number of movies. Write an equation that matches the situation.

Teacher support

Answer: 9+2m=23.

Reasoning: The fixed $9 is added once; $2 repeats for each of m movies.

Teaching move / likely issue: Look for 2+9m, which reverses fixed and repeated quantities.

You Try It 2: Model another situation

A container already holds 18 liters and fills at 4 liters per minute until it reaches 50 liters. Let \(t\) be minutes. Write an equation for the time when it reaches 50 liters.

Teacher support

Answer: 18+4t=50.

Reasoning: Start amount + rate·time = target amount.

Teaching move / likely issue: Ask students to identify the units of every term: liters.

Stop and Discuss

  1. How can units help you test whether an equation matches a situation?
  2. What is the difference between a fixed amount and a rate times a count?
Teacher support: Listen for explanations that cite the representation, operation, or pattern rather than only the final answer.

I Can 3Use equivalent steps to solve when needed.

Solving an equation means finding a value that makes both sides equal. Use equivalent steps—operations that preserve the equality—to isolate the variable.

An inverse operation undoes another operation. If 7 is added, subtract 7 from both sides. If the variable is multiplied by 4, divide both sides by 4. Show enough structure that someone can see why equality was preserved.

MATH NOTESUndo operations while keeping balance

\(5x+7=32\)

Subtract 7 from both sides: \(5x=25\)

Divide both sides by 5: \(x=5\)

Whatever operation preserves one side must also preserve the other side.

Example 3: Solve with equivalent steps

Solve \(6x+11=47\). Show equivalent steps.

Teacher support

Answer: x=6.

Reasoning: Subtract 11 to get 6x=36, then divide by 6.

Teaching move / likely issue: If students divide 47 by 6 first, ask which operation is outermost around x.

You Try It 3: Solve another model equation

Solve \(25+4g=49\). Show equivalent steps.

Teacher support

Answer: g=6.

Reasoning: Subtract 25 to get 4g=24, then divide by 4.

Teaching move / likely issue: Keep the work connected to equality signs rather than a chain of disconnected arithmetic.

Stop and Discuss

  1. Why must the same equality-preserving operation be applied to both sides?
  2. How do inverse operations help you decide what step to use next?
Teacher support: Listen for explanations that cite the representation, operation, or pattern rather than only the final answer.

I Can 4Check and interpret a solution in context.

A solution must satisfy the equation and make sense in the situation. Substitute the value back into the original equation to check the equality. Then ask whether the value is reasonable for the quantity being modeled.

Interpretation includes meaning and units. Writing only “x=7” hides the story. A complete conclusion might say “The student needs 7 days” or “The tank reaches the target after 7 minutes.”

MATH NOTESCheck the equation, then state the meaning

Model: \(18+4t=50\), solution \(t=8\)

Check: \(18+4(8)=18+32=50\) ✓

Interpret: The container reaches 50 liters after 8 minutes.

Example 4: Check and interpret

A movie plan is modeled by \(9+2m=23\), and a student says \(m=7\). Check the value and interpret the solution in context.

Teacher support

Answer: The value is correct; the customer rented 7 movies.

Reasoning: 9+2(7)=23, so it satisfies the model.

Teaching move / likely issue: Require both the numerical check and a sentence with the unit/meaning.

You Try It 4: Reject or confirm a proposed solution

A fundraiser is modeled by \(30+5t=80\), where \(t\) is tickets sold. A student claims \(t=12\). Check the claim. If it is incorrect, find the correct solution and interpret it.

Teacher support

Answer: The claim is incorrect; t=10, so 10 tickets must be sold.

Reasoning: 30+5(12)=90, not 80. Solving gives 5t=50, t=10, and 30+5(10)=80.

Teaching move / likely issue: Use the failed substitution as evidence, not simply “wrong.”

Stop and Discuss

  1. What two different checks should a solution pass?
  2. Why is a sentence with units or meaning part of a complete model solution?
Teacher support: Listen for explanations that cite the representation, operation, or pattern rather than only the final answer.

Vocabulary Reference

TermMeaning in this section
variableA symbol representing an unknown or changing quantity.
equationA statement that two expressions are equal.
solutionA value that makes an equation true and, in a model, fits the situation.
inverse operationAn operation that undoes another operation, such as subtraction undoing addition.
quantityA measurable or countable amount described by a number and often a unit.

Section Summary

  • Define the unknown quantity before writing the model.
  • Build an equation that matches fixed amounts, rates, counts, and totals.
  • Use equivalent steps and inverse operations to solve.
  • Check the solution in the original equation and interpret it in context.

What I Understand Now

Think about the full modeling cycle: define, write, solve, check, interpret. Which step helps you catch the most errors? Explain how that step can reveal a mistake made earlier.

Common Mistakes to Watch

MistakeWhat to remember
Using a variable with no meaningDefine what the variable counts or measures.
Writing an equation that swaps fixed and repeated amountsAsk which amount occurs once and which is multiplied by the unknown.
Changing only one side of an equalityUse equivalent steps that preserve both sides.
Giving only a numberCheck the solution and state what it means with units or context.
