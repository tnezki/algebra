Equations as Models
An equation turns a situation into a balance you can solve and interpret.

Core idea: Model the quantities, preserve equality while solving, then return the solution to the context.

You will write equations from situations, solve with equivalent transformations, check solutions, and interpret what the answer means.

Learning Target

Students will write, solve, and interpret equations that model situations.

Reading: Translate a situation into a balanced equation

A variable can stand for an unknown contextual quantity, such as number of rides, visits, or wins. An equation states that two quantities are equal, so a model should connect the story’s amounts and operations in a way that preserves their meaning.

A solution is a value that makes the equation true. Before solving, estimate what size of answer seems reasonable. An estimate is not a substitute for algebra, but it gives you a useful check against a sign error or an answer that does not fit the situation.

A fixed amount plus a repeated amount often has the structure $b+rx=T$. Here $b$ is the fixed amount, $r$ is the amount per unit, $x$ is the unknown number of units, and $T$ is the total. Units help you assign each number to the correct role.

Stop and Discuss

  1. In $7+3r=31$, what does each number and the variable represent in the ride-pass context?
  2. Why is an estimate useful even when you will solve exactly?

Teacher answer: Expected reasoning: 7 is the fixed entry charge, 3 is dollars per ride, r is number of rides, and 31 is total dollars. An estimate catches unreasonable exact results.

Example 1: Solve and Check a Two-Step Equation

Solve $4x+7=31$ and check the solution in the original equation.

Teacher answer: Answer: $x=6$; check: $4(6)+7=31$.

You Try It 1: Reverse Operations and Verify

Solve $5x-9=26$ and verify.

Teacher answer: Answer: $x=7$; check: $5(7)-9=26$.

Reading: Reverse operations while preserving equality

Solving uses an inverse operation to undo an operation while keeping the equation balanced. If you subtract from one side, subtract the same amount from the other. If you divide one side by a nonzero number, divide the other side by the same number.

Context equations are solved with the same algebra as symbolic equations. For a registration fee plus a cost per visit, first isolate the repeated-cost term, then divide by the cost per visit. The final number should be interpreted as visits, not left as a bare number.

Grouping symbols affect the order of useful transformations. In $3(x+2)=24$, dividing both sides by $3$ first removes the outside multiplication and exposes $x+2=8$. This is valid because the same nonzero division is applied to both sides.

Stop and Discuss

  1. What makes an algebra step an equivalent transformation of an equation?
  2. Why can dividing first be efficient in $3(x+2)=24$?

Teacher answer: Expected reasoning: the transformation preserves the same solution set by applying a valid operation to both sides. Dividing by 3 undoes the outer multiplication and simplifies the grouped expression.

Example 2: Model a Fee-and-Visit Situation

A gym charges a 12-dollar registration fee plus 8 dollars per visit. A total of 60 dollars was spent. Write and solve an equation for the number of visits.

Teacher answer: Answer: $12+8v=60$, so $v=6$ visits.

You Try It 2: Write and Solve a Points Model

A game account starts with 15 points and earns 6 points per win. It reaches 57 points. Write and solve an equation for the number of wins.

Teacher answer: Answer: $15+6w=57$, so $w=7$ wins.

Example 3: Solve a Grouped Equation

Solve $3(x+2)=24$. Explain why dividing by 3 first is valid.

Teacher answer: Answer: $x=6$; dividing both sides by 3 preserves equality and gives $x+2=8$.

You Try It 3: Use Equivalent Transformations

Solve $-2(x-5)=18$ using equivalent transformations.

Teacher answer: Answer: $x=-4$.

Reading: Check the algebra and interpret the result

A check substitutes the proposed solution into the original equation. If both sides evaluate to the same value, the solution satisfies the equation. Checking the original form is stronger than checking only your last simplified line because it tests the entire solution path.

In a context, there is a second check: does the answer make sense for the quantity? A negative number of visits would usually be impossible, while a fractional value may or may not be meaningful depending on what is being counted. The model and units determine the interpretation.

When analyzing an incorrect solution, identify the first step that breaks equality. A common error is changing only one side of the equation. Correcting that step restores the balance and usually makes the remaining solution path straightforward.

Stop and Discuss

  1. Why should a solution be checked in the original equation?
  2. What is the first thing to inspect when a student changes only one side of an equation?

Teacher answer: Expected reasoning: substitution into the original equation verifies the complete result. An operation on only one side breaks equality unless it is part of a valid simplification that changes both expressions equivalently.

Example 4: Diagnose an Unbalanced Solution Step

A student solves $2x+5=17$ by subtracting 5 only from the left side. Explain the error and give the correct solution.

Teacher answer: Answer: An equal operation must be applied to both sides. Subtract 5 from both sides: $2x=12$, so $x=6$.

You Try It 4: Solve and Name the Inverse Operation

Solve $7-3x=-8$, then explain what operation reverses the multiplication by -3.

Teacher answer: Answer: $x=5$; divide both sides by -3 after isolating the $-3x$ term.

Vocabulary / Key Terms — Definitions

TermMeaning
variablea symbol representing a quantity that may be unknown or change
equationa statement that two expressions or quantities are equal
solutiona value that makes an equation true
inverse operationan operation used to undo another operation
contextual quantitya mathematical quantity tied to a real situation and its units

Summary

  • An equation model connects meaningful quantities from a situation.
  • Equivalent transformations preserve equality and the solution set.
  • Inverse operations help isolate an unknown quantity.
  • A complete solution includes an algebra check and an interpretation in context.
Summary notes / questions / connections

Synthesis: ask students to distinguish “solving the equation” from “answering the situation.” The latter requires interpretation.
