Section 1.5

Equations as Models

Model the quantities, then explain the answer.

Learning Target

Write an equation from a situation and explain what its solution means.

  • Define a variable.
  • Write an equation that matches a situation.
  • Use equivalent steps to solve when needed.
  • Check and interpret a solution in context.

Define a variable.

Before writing an equation, decide what the unknown quantity is. Define a variable with words and units when units are part of the situation.

Math NotesVariable definition

Write something like “Let \(n\) be the number of notebooks.” A variable definition should make the later equation easy to read.

Example

A school club pays a fixed $18 materials fee plus $4 for each student. The total is $74. Define a variable for the unknown.

Answer: Let s be the number of students.

Reasoning: The unknown quantity is a count of students, so s should represent the number of students; it has no dollar unit.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

A rectangle has perimeter 46 cm and length 15 cm. Define a variable for the unknown width.

Answer: Let w be the width of the rectangle in centimeters.

Reasoning: The unknown is a length, so define w with the width meaning and centimeter unit.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Write an equation that matches a situation.

An equation says that two quantities are equal. Translate the situation by matching each operation to what happens in the context, then set the resulting expression equal to the known total.

Math NotesBuild from quantities

Fixed amount + (rate per item)(number of items) = total is one common structure. Use the structure only when the situation actually describes it.

Example

A music app charges a $7 monthly fee plus $2 per download. One month costs $23. Let \(d\) be the number of downloads. Write an equation.

Answer: 7 + 2d = 23.

Reasoning: The fixed fee is 7, downloads cost 2d, and their sum equals the total 23.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

Three identical notebooks and a $5 pen cost $26 total. Let \(n\) be the price of one notebook in dollars. Write an equation that matches the situation.

Answer: 3n + 5 = 26.

Reasoning: Three notebooks cost 3n, then add the $5 pen to equal $26.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Use equivalent steps to solve when needed.

Equivalent steps keep the same solution set. Undo operations in reverse order and perform the same operation on both sides of the equation.

Math NotesKeep the balance

For \(3x+5=20\), subtract 5 from both sides, then divide both sides by 3.

Example

Concert tickets cost the same amount each. Five tickets minus a $9 group coupon cost $31. Let \(t\) be the price of one ticket. Solve \(5t-9=31\).

Answer: $8 per ticket.

Reasoning: Add 9 to both sides: 5t=40. Divide by 5: t=8.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

A game starts with 4 bonus points, then awards 3 points per round. A player has 25 points. Solve \(4+3r=25\) for the number of rounds \(r\).

Answer: r = 7 rounds.

Reasoning: Subtract 4: 3r=21. Divide by 3: r=7.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

Check and interpret a solution in context.

A solved number is not the end of a modeling problem. Substitute it back into the original equation to check it, then state what the number means in the situation with an appropriate unit or label.

Math NotesCheck + interpret

A correct final sentence connects the number to the variable: “There were 7 rounds,” not just “7.”

Example

A shuttle ride costs a $6 start fee plus $3 per mile. The total is $27. Solve \(6+3m=27\), check the result in the original equation, and interpret \(m\).

Answer: m = 7, so the ride was 7 miles. Check: 6+3(7)=27.

Reasoning: Subtract 6 to get 3m=21, divide by 3 to get m=7, then substitute: 6+21=27. The variable was miles, so the interpretation is 7 miles.

Teacher move: Ask students to name the mathematical evidence before confirming the result.

You Try It

A jar starts with 12 marbles. Four marbles are added each round until there are 40. The equation is \(12+4r=40\). A student says \(r=8\). Check the claim, correct it if needed, and interpret the solution.

Answer: The claim is wrong. 12+4(8)=44. The correct solution is r=7, so 7 rounds were completed.

Reasoning: Check the claim first: 44≠40. Solve: 4r=28, so r=7. Check: 12+28=40.

Teacher move: Ask students to name the mathematical evidence before confirming the result.
