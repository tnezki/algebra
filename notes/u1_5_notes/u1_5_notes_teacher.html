I can construct an equation that models a situation using meaningful quantities and operations.

A variable stands for a quantity that can vary or is not yet known. When modeling a situation, define the variable first so every symbol has a clear meaning and unit.

An equation states that two expressions represent the same quantity. A situation with a starting fee, a repeated hourly charge, and a known total can often be modeled as starting amount + repeated rate × number of units = total.

The operations in the equation should match the story. A one-time fee is added once; a per-unit amount is multiplied by the number of units. Reading the equation back in words is a powerful check that the model matches the context.

Stop and Discuss
  1. Why should a variable be defined before writing a context equation?
  2. In a model “starting fee + rate × hours = total,” which quantity is repeated?
  3. How can reading an equation back in words help check a model?

Teacher answer / listen for:

  1. It fixes the meaning and units of the unknown quantity.
  2. The rate is repeated once for each hour, so it is multiplied by hours.
  3. Each operation and term can be compared with the story to catch modeling mismatches.
Math NotesContext → Quantities → Equation

Example structure: start fee $12$, rate $4$ per hour, total $32$.

Let $h$ = hours. Then $12+4h=32$.

Read it back: “12 dollars to start plus 4 dollars for each hour equals 32 dollars total.”

Discourse Moves

Teacher Moves

  • Ask students to define the variable with units before accepting an equation.
  • Invite two verbal readings of the same equation.
  • Probe what each term represents in the situation.

Student Moves

  • Define the variable and unit.
  • Connect each term to a contextual quantity.
  • Read the equation back as a sentence about the situation.

Example 1: Model a Situation

A gym charges a 25-dollar joining fee plus 8 dollars per visit. A member has paid 73 dollars. Let $v$ be the number of visits. Construct an equation.

Teacher answer:

$25+8v=73$.

You Try It 1: Model a Situation

A bike shop charges 10 dollars plus 3 dollars per hour. The total is 28 dollars. Let $h$ be hours. Write the equation.

Teacher answer:

$10+3h=28$.

Example 2: Create a Situation

Write a plausible situation that could be modeled by $15+4x=43$. Define what $x$ represents and interpret the solution.

Teacher answer:

Answers vary. Example: a 15-dollar starting fee plus 4 dollars per hour totals 43 dollars. Then $x=7$ hours.

You Try It 2: Create a Situation

Create a situation for $20+2x=34$ and interpret the solution.

Teacher answer:

Answers vary; a consistent interpretation has $x=7$ units of the repeated quantity.

I can use solution steps to solve an equation and connect the result to the situation.

A solution is a value that makes an equation true. Solving is not about moving symbols randomly; it is about preserving equality while isolating the unknown quantity.

An inverse operation undoes another operation. Addition and subtraction undo each other, and multiplication and division undo each other. Whatever operation is applied to one side of an equation must also be applied to the other side so the two expressions remain equal.

For multi-step equations, simplify or undo operations in a sensible order. When variables appear on both sides, equivalent transformations can gather variable terms on one side and constants on the other. A final substitution into the original equation checks whether the proposed solution truly makes both sides equal.

Stop and Discuss
  1. Why must the same operation be performed on both sides of an equation?
  2. What operation undoes multiplication by 5?
  3. What is the purpose of substituting a solution back into the original equation?

Teacher answer / listen for:

  1. It preserves the equality/balance between the two expressions.
  2. Division by 5, assuming the usual nonzero factor context.
  3. It verifies that both sides produce the same value in the original equation.
Math NotesPreserve Equality

Solve $3x+5=26$:

$3x+5-5=26-5$

$3x=21$

$\frac{3x}{3}=\frac{21}{3}$

$x=7$

Check: $3(7)+5=26$.

Discourse Moves

Teacher Moves

  • Have students explain what each operation is undoing.
  • Ask another student to verify that equality is preserved after each line.
  • Compare two valid solution pathways when possible.

Student Moves

  • Name the inverse operation and its purpose.
  • Explain why both sides remain equivalent.
  • Check a proposed solution in the original equation.

Example 3: One-Step Equation

Solve $x+7=19$ and state the inverse operation used.

Teacher answer:

$x=12$ by subtracting 7 from both sides.

You Try It 3: One-Step Equation

Solve $y-9=14$ and name the inverse operation.

Teacher answer:

$y=23$ by adding 9 to both sides.

Example 4: Two-Step Equation

Solve $3x+5=26$ and check the solution in the original equation.

Teacher answer:

$3x=21$, so $x=7$. Check: $3(7)+5=26$.

You Try It 4: Two-Step Equation

Solve $4x-7=21$ and check.

Teacher answer:

$x=7$; check $4(7)-7=21$.

Example 5: Variables on Both Sides

Solve $5x-4=2x+17$ by preserving equality on both sides.

Teacher answer:

$3x=21$, so $x=7$.

You Try It 5: Variables on Both Sides

Solve $6x+2=3x+20$.

Teacher answer:

$3x=18$, so $x=6$.

I can predict whether a solution is reasonable by interpreting it in the original context.

Before solving a context equation, make a rough prediction. Estimate the unknown from the sizes of the numbers and the units. This creates a reasonableness target that can catch arithmetic or modeling errors later.

After solving, interpret the value as a contextual quantity. A bare answer such as $6$ is incomplete when the problem asks about hours, visits, or days. The unit and meaning belong to the solution.

Finally, check both mathematics and context. Substitute the value into the original equation, then ask whether the result is plausible in the situation. A mathematically correct value may still signal a bad model if it violates a real constraint such as negative time or an impossible count.

Stop and Discuss
  1. Why make an estimate before solving?
  2. What should be added to a numerical answer so it becomes an interpreted context solution?
  3. What two checks should be made after solving a model equation?

Teacher answer / listen for:

  1. An estimate gives a reasonableness benchmark and can expose later errors.
  2. The quantity meaning and unit, such as 6 gigabytes or 6 days.
  3. Verify it in the original equation and check that it makes sense in the context.
Math NotesPredict, Solve, Check, Interpret
  1. Predict: estimate a reasonable range.
  2. Solve: use equivalent transformations.
  3. Check: substitute into the original equation.
  4. Interpret: state the answer with its meaning and units.

Discourse Moves

Teacher Moves

  • Ask for an estimate before algebra begins.
  • Have students compare the exact solution with their prediction.
  • Probe whether the final number is meaningful in the original situation.

Student Moves

  • State a reasonable estimate and why.
  • Verify the solution mathematically.
  • Interpret the value with units and context.

Example 6: Solve and Interpret

A phone plan is modeled by $18+6g=54$, where $g$ is gigabytes of extra data. Solve and interpret the answer with units.

Teacher answer:

$6g=36$, so $g=6$ gigabytes of extra data.

You Try It 6: Solve and Interpret

A rental is modeled by $9+5d=39$, where $d$ is days. Solve and interpret.

Teacher answer:

$d=6$ days.

Summary

  • Define quantities before writing a model equation and make each operation match the context.
  • Solve by using equivalent transformations that preserve equality, then verify in the original equation.
  • Predict reasonableness and interpret the final value with its units and contextual meaning.

Common Mistakes

  • Performing an operation on only one side of an equation.
  • Reporting a numerical solution without interpreting units or context.
