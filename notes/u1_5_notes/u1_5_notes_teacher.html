I Can 1 — I can construct an equation that models a situation using meaningful quantities and operations.

An equation model connects quantities that are equal in a situation. Before writing symbols, identify what the unknown represents, what amount is fixed, what amount repeats, and what total or comparison is known.

A common structure is “starting amount + repeated amount = total.” If a gym charges a joining fee plus a cost per visit, the variable should represent the number of visits, and the units help decide which numbers are multiplied or added.

An equation is more than a calculation. Each term should have a meaning. A useful model lets you point to a number or variable and explain the quantity it represents.

Example 1: Write an Equation from a Situation

A gym charges a 25-dollar joining fee plus 8 dollars per visit. A member has paid 73 dollars. Let $v$ be the number of visits. Construct an equation.

Teacher answer: $25+8v=73$.

You Try It 1: Write an Equation from a Situation

A bike shop charges 10 dollars plus 3 dollars per hour. The total is 28 dollars. Let $h$ be hours. Write the equation.

Teacher answer: $10+3h=28$.

Example 6: Create a Situation from an Equation

Write a plausible situation that could be modeled by $15+4x=43$. Define what $x$ represents and interpret the solution.

Teacher answer: Answers vary. Example: a 15-dollar starting fee plus 4 dollars per hour totals 43 dollars. Then $x=7$ hours.

You Try It 6: Create a Situation from an Equation

Create a situation for $20+2x=34$ and interpret the solution.

Teacher answer: Answers vary; a consistent interpretation has $x=7$ units of the repeated quantity.

I Can 2 — I can use solution steps to solve an equation and connect the result to the situation.

Solving an equation means finding a value that makes both sides equal. Each transformation must preserve equality, so whatever operation you perform to one side must also be performed to the other side.

Inverse operations undo one another. Addition and subtraction are inverses; multiplication and division are inverses. In a two-step equation, undo operations in an order that isolates the variable while keeping the equation balanced.

When the variable appears on both sides, collect variable terms on one side and constants on the other. After solving, substitute the value into the original equation to verify that both sides are equal.

Stop and Discuss. Why does doing the same operation to both sides preserve the solutions of an equation?

Teacher support: Expected idea: equal quantities remain equal when the same operation is applied to both. This creates an equivalent equation with the same solution set.

Example 2: Solve with an Inverse Operation

Solve $x+7=19$ and state the inverse operation used.

Teacher answer: $x=12$ by subtracting 7 from both sides.

You Try It 2: Solve with an Inverse Operation

Solve $y-9=14$ and name the inverse operation.

Teacher answer: $y=23$ by adding 9 to both sides.

Example 3: Solve and Check a Two-Step Equation

Solve $3x+5=26$ and check the solution in the original equation.

Teacher answer: $3x=21$, so $x=7$. Check: $3(7)+5=26$.

You Try It 3: Solve and Check a Two-Step Equation

Solve $4x-7=21$ and check.

Teacher answer: $x=7$; check $4(7)-7=21$.

Example 4: Preserve Equality with Variables on Both Sides

Solve $5x-4=2x+17$ by preserving equality on both sides.

Teacher answer: $3x=21$, so $x=7$.

You Try It 4: Preserve Equality with Variables on Both Sides

Solve $6x+2=3x+20$.

Teacher answer: $3x=18$, so $x=6$.

I Can 3 — I can predict whether a solution is reasonable by interpreting it in the original context.

A numerical answer is not complete in a context until you interpret it. Attach the correct units and state what the variable means.

Reasonableness starts before exact solving. Estimate the size of the unknown from the given quantities. After solving, compare the exact value with that estimate and with any practical constraints in the situation.

Finally, check the solution in the original model. A value that satisfies the algebra but makes no sense in context may signal that the model, variable definition, or interpretation needs another look.

Model → estimate → solve → check → interpret. The algebra and the situation should support the same conclusion.

Example 5: Interpret a Solution in Context

A phone plan is modeled by $18+6g=54$, where $g$ is gigabytes of extra data. Solve and interpret the answer with units.

Teacher answer: $6g=36$, so $g=6$ gigabytes of extra data.

You Try It 5: Interpret a Solution in Context

A rental is modeled by $9+5d=39$, where $d$ is days. Solve and interpret.

Teacher answer: $d=6$ days.

Summary

  • Define the variable and connect every term in an equation to a meaningful quantity.
  • Solve by equivalent transformations that preserve equality.
  • Estimate, check, and interpret solutions with units and context.
