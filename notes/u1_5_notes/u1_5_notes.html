Equations as Models

Model the quantities, solve the equation, interpret the result.

What you'll learn about

Learning Target: Write an equation from a situation and explain what its solution means.

  • Define a variable.
  • Write an equation that matches a situation.
  • Use equivalent steps to solve when needed.
  • Check and interpret a solution in context.
...and why

Equations turn a situation into a mathematical model. A good model names the unknown, connects the quantities correctly, and ends with an answer that makes sense in the original situation.

Section Introduction

An equation is a claim about quantities

When a situation contains an unknown quantity, a variable gives that unknown a name. An equation then states that two quantities are equal. The operations in the equation should come from the relationships described in the situation, not from guessing a familiar form.

Solving uses equivalent steps to isolate the variable. But a solution is not finished until it is checked and interpreted with the correct quantity and units.

A model is complete when the equation fits the situation and the solution has meaning.

I Can 1Define a variable.

A variable is a symbol that represents an unknown or changing quantity. Define it with words before writing the equation so every later step has a clear meaning.

A strong variable definition names the quantity and, when useful, its units. “Let n = number of notebooks” is more useful than writing only “n.”

MATH NOTESDefine the unknown quantity

Situation: A student buys some notebooks.

Let n = number of notebooks purchased.

If each notebook costs $3, then 3n represents the notebook cost.

Define the variable as a quantity before using it in an equation.

Example 1: Define a count variable

A theater sells an unknown number of student tickets. Define a variable for the unknown.

You Try It 1: Define a measurement variable

A tank contains an unknown number of liters of water before 6 liters are added. Define a variable with units.

Stop and Discuss

  1. Why is “let x = unknown” weaker than naming the quantity?
  2. When should units be included in a variable definition?

I Can 2Write an equation that matches a situation.

An equation should reproduce the relationships in the situation. Fixed amounts become constants, per-item or per-unit rates multiply the variable, and the total appears on the other side of the equality.

Read the finished equation back into words. If each part of the equation can be matched to a quantity in the situation, the model is more likely to be correct.

MATH NOTESSituation → equation

Situation

A club charges a $9 signup fee plus $6 per visit. The total is $39.

→

Model

Let v = number of visits.

9 + 6v = 39

Every number and operation in the equation should have a job in the situation.

Example 2: Write a cost equation

An art class charges a $14 materials fee plus $7 per session. The total charge is $49. Let s be the number of sessions. Write an equation.

You Try It 2: Write a distance equation

A hiker has already walked 3 miles and then walks 2 miles per hour for h hours. The total distance is 13 miles. Write an equation.

Stop and Discuss

  1. How can reading an equation back into words expose a modeling mistake?
  2. What clues in a situation suggest multiplication by a variable?

I Can 3Use equivalent steps to solve when needed.

Solving an equation means finding the value that makes the equality true. Equivalent operations preserve the solution set, so whatever operation is applied to one side must also be applied to the other side.

Work backward through the operations around the variable. For a two-step equation, undo addition or subtraction before undoing multiplication or division, unless another equivalent route is more efficient.

MATH NOTESUse equivalent steps

7 + 5n = 42

7 + 5n - 7 = 42 - 7

5n = 35

n = 7

Keep the equation balanced by making equivalent changes to both sides.

Example 3: Solve a two-step equation

Solve 7 + 5n = 42 using equivalent steps.

You Try It 3: Solve with subtraction

Solve 3m - 8 = 19 using equivalent steps.

Stop and Discuss

  1. Why does changing both sides by the same amount preserve the solution?
  2. How can you decide which operation to undo first?

I Can 4Check and interpret a solution in context.

A solution should satisfy the original equation. Substitute it back in and verify that both sides are equal. This check catches arithmetic mistakes and can also reveal whether the equation itself was modeled incorrectly.

Then interpret the value in context. Include the quantity and units, and ask whether the result is reasonable. A numerical value such as 6 is incomplete if the situation requires “6 hours” or “6 tickets.”

MATH NOTESCheck, then interpret

Model: 8 + 4h = 32

Candidate: h = 6

Check: 8 + 4(6) = 32 ✓

Interpretation: The activity lasted 6 hours.

A complete solution answers the equation and the situation.

Example 4: Check a claimed solution

A museum charges $10 plus $5 per workshop. A visitor paid $35. The model is 10 + 5w = 35. Check w = 5 and interpret it.

You Try It 4: Reject and repair a claim

A box starts with 18 items and 4 are removed each round. After r rounds, 6 remain: 18 - 4r = 6. A student claims r=4. Check the claim and find the correct r.

Stop and Discuss

  1. Why can a mathematically correct number still be an incomplete answer to a context problem?
  2. What does a failed substitution check tell you to investigate?

Section Summary

  • Define the unknown quantity before writing an equation.
  • Translate the relationship among quantities into an equality.
  • Equivalent operations preserve the solution while isolating the variable.
  • Check the solution in the original equation and interpret it in context.

Common Mistakes to Watch

MistakeWhat to remember
Writing an equation that does not match the quantities.Identify what each number represents before choosing operations.
Using a variable without defining it.State what the variable measures and include units when appropriate.
Changing only one side of an equation.Use equivalent operations on both sides to preserve equality.
Giving a number without meaning.Interpret the solution in the original situation with its quantity and units.
