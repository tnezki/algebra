I can construct an equation that models a situation using meaningful quantities and operations.

An equation states that two expressions represent the same quantity. In a model, each part of the equation should correspond to something meaningful in the situation. A fixed starting amount, a repeated rate, and a total can often be connected in the structure $\text{start}+\text{rate}(\text{count})=\text{total}$.

A variable stands for a quantity that can vary or is unknown. In a model it represents a contextual quantity—a value such as hours, dollars, distance, or number of items. Define it before solving so the symbols keep their meaning. If $h$ represents hours, then a term such as $4h$ represents a rate of 4 dollars per hour multiplied by the number of hours; the units help verify that the model is sensible.

Constructing the equation is different from solving it. First decide what each quantity means and how the quantities are related. Then write a mathematical statement that preserves that relationship. A well-built model should be readable in both directions: from the words to the equation and from the equation back to the situation.

Stop and Discuss
  1. What does an equation claim about its two sides?
  2. Why should a variable be defined before solving a modeling problem?
  3. In $12+4h=32$, what does the term $4h$ represent if $h$ is rental hours?

Model Structure

Fixed amount + repeated amount = total

Example: $25+8v=73$

  • $25$: joining fee
  • $8v$: 8 dollars for each of $v$ visits
  • $73$: total paid

I can use solution steps to solve an equation and connect the result to the situation.

Solving an equation means finding the value that makes the equality true. Every step should preserve equality. If you add, subtract, multiply, or divide by a nonzero number on one side, perform the corresponding operation on the other side so the two expressions remain balanced.

Inverse operations undo one another. Addition and subtraction are inverse operations; multiplication and division are inverse operations. Solving often works by reversing the operations that were used to build the expression around the variable, while maintaining equality at every stage.

A solution should be checked in the original equation. Substitution confirms whether both sides become equal and can catch arithmetic or sign errors. In a context, the check also returns the number to the model, which is important because a correct algebraic value can still be unreasonable for the situation if the model or interpretation was wrong.

Stop and Discuss

  2. How do inverse operations help isolate a variable?

MATH NOTES
Preserve Equality

If $3x+5=26$:

$3x+5-5=26-5$ → $3x=21$

$\frac{3x}{3}=\frac{21}{3}$ → $x=7$

Check: $3(7)+5=26$.

The goal is not “move terms”; the goal is to perform equality-preserving operations.

I can predict whether a solution is reasonable by interpreting it in the original context.

A numerical answer is not the end of a modeling problem. The solution must be interpreted as the quantity represented by the variable, with appropriate units. If $g$ means gigabytes, then $g=6$ means 6 gigabytes, not simply “6.”

Reasonableness can be predicted before or checked after solving. Estimate from the context: should the answer be positive, whole-numbered, smaller than a given total, or within a physical limit? These expectations do not replace algebra, but they provide a filter for catching results that conflict with the situation.

Interpretation also tests the model itself. Substitute the solution, check the total, and ask whether the value answers the original question. When you create a situation for a given equation, every constant, coefficient, and operation should have a plausible meaning and the resulting solution should make sense in that setting.

  4. Judge reasonableness in the original situation.
