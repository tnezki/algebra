Equations as Models

An equation turns a situation into a statement you can solve and interpret.

What you'll learn about

Learning Target: Write an equation from a situation and explain what its solution means.

  • Define a variable.
  • Write an equation that matches a situation.
  • Use equivalent steps to solve when needed.
  • Check and interpret a solution in context.
...and why

Modeling with equations lets you organize a real situation, solve for an unknown, and explain what the answer means in the original setting.

Section Introduction

From quantities to an equation

A good model begins by naming the unknown quantity. Once the variable has a clear meaning, translate the relationships in the situation into an equation. Fixed amounts, repeated rates, totals, and comparisons should all have a mathematical role.

Solving is only part of the process. Equivalent steps isolate the variable without changing the solution. Then the result should be checked in the original relationship and interpreted with the correct quantity and units.

A number is not a complete answer until you know what it represents.

I Can 1Define a variable.

A variable should stand for one clearly named unknown quantity. “Let x be the number of tickets” is useful; “let x be the answer” is not, because it does not preserve the meaning of the situation.

Choose a variable that makes the later equation easy to read, but the letter itself is less important than the definition. Include units or quantity words when they matter.

MATH NOTESDefine the unknown before modeling

Question

How many tickets were purchased?

Variable

Let \(t\) = number of tickets.

Not enough

“Let t = answer.”

Why

The equation and final interpretation now keep the quantity meaning.

A variable definition should name the quantity, not just the symbol.

Example 1: Define the unknown

A concert order costs $84 total. There is a $12 service fee plus $18 per ticket. Define a variable for the unknown number of tickets.

You Try It 1: Choose a meaningful variable

A storage bin contains 46 liters after 7 liters are added each minute to an initial amount. Define a variable for the number of minutes.

Stop and Discuss

  1. Why is “let x equal the answer” a weak variable definition?
  2. Does the variable letter have to match the first letter of the quantity?

I Can 2Write an equation that matches a situation.

Translate quantities into an equation by identifying what is fixed, what repeats, and what total or comparison is given. A fixed fee appears once. A per-item cost is multiplied by the number of items. The total is connected with an equals sign.

Read the equation back in words. If the equation no longer tells the same story as the context, revise it before solving.

MATH NOTESFixed amount + repeated amount = total

Situation pieces

$7 shipping + $3 per notebook; total $31.

→

Equation

\(7+3n=31\)

Each number and operation in the equation should have a meaning in the situation.

Example 2: Write the model

A club pays $7 shipping plus $3 per notebook and spends $31 total. Let n be the number of notebooks. Write an equation.

You Try It 2: Translate another context

Bowling costs $4 for shoes plus $6 per game. The total is $28. Let g be the number of games. Write an equation.

Stop and Discuss

  1. What does the equals sign represent in a context equation?
  2. How can reading an equation back in words help catch a modeling mistake?

I Can 3Use equivalent steps to solve when needed.

Equivalent steps change the appearance of an equation without changing which value makes it true. The goal is to isolate the variable by undoing operations in a sensible order.

Whatever operation you apply to one side must also be applied to the other. In a two-step equation such as \(5x+7=42\), undo the added 7 first, then undo multiplication by 5.

MATH NOTESUndo operations while preserving equality
EquationEquivalent stepResult
\(5x+7=42\)Subtract 7 from both sides\(5x=35\)
\(5x=35\)Divide both sides by 5\(x=7\)

Equivalent steps keep both sides balanced and preserve the solution.

Example 3: Solve with inverse operations

Solve \(5x+7=42\). Show equivalent steps.

You Try It 3: Solve another equation

Solve \(3y-8=19\). Show equivalent steps.

Stop and Discuss

  1. Why must the same operation be performed on both sides?
  2. Which operation should be undone first in a two-step equation and why?

I Can 4Check and interpret a solution in context.

A solution is complete only after it is checked and interpreted. Substitute it into the original equation to verify that both sides are equal. Then return to the variable definition to state what the number means.

Units and quantity words matter. If \(t=5\) and t represents tickets, the conclusion is “5 tickets,” not simply “5.” A correct equation with an impossible contextual result can also signal that the model or arithmetic should be rechecked.

MATH NOTESCheck → interpret

Check

For \(9+6t=39\), test \(t=5\): \(9+6(5)=39\).

Interpret

The customer bought 5 tickets.

Use the original equation to check the number, then use the variable definition to explain it.

Example 4: Check the solution in context

A museum order follows \(9+6t=39\), where t is the number of tickets. Solve, check, and interpret the result.

You Try It 4: Interpret a fundraiser model

A fundraiser uses \(15+4b=43\), where b is the number of boxes sold. Solve, check, and interpret.

Stop and Discuss

  1. Why is a numerical answer without units or quantity meaning incomplete?
  2. What should you do if your algebraic solution does not make sense in the original context?
