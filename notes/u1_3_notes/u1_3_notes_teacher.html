I Can 1 — I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.

A function family is a group of relationships that share important structural features. You can often recognize a family from an equation, but a strong classification also connects the equation to a graph, table, or context.

Linear equations have the variable to the first power and produce constant additive change. Quadratic equations include a squared input and produce parabolic graphs. Exponential equations place the input in an exponent and produce repeated multiplication. Absolute-value equations contain an absolute-value expression and produce two linear arms meeting at a vertex.

Designing an example means making the representations agree. If you choose an equation, the points or table values you provide must actually satisfy that equation.

Example 1: Recognize Families from Equation Structure

Classify each equation by family: $y=3x-2$, $y=x^2+1$, $y=2^x$, and $y=|x|-4$. State the structural clue in each equation.

Teacher answer: Linear, quadratic, exponential, absolute value. Clues are first power of x, squared x, variable exponent, and absolute-value bars.

I Can 2 — I can extend patterns in tables, graphs, equations, and contexts to work with common function families.

Tables make change patterns visible. First differences compare consecutive outputs. If those first differences are constant for equal input steps, the relationship is linear.

If first differences change but the second differences are constant, that is evidence of a quadratic pattern. Exponential patterns behave differently: consecutive outputs are multiplied by the same factor, so the ratio between outputs is constant instead of the difference.

Extending a pattern means preserve the family’s defining change. Do not continue a quadratic table by forcing a constant first difference, or an exponential table by adding the same amount each time.

Stop and Discuss. Why is “the outputs are getting bigger faster” not enough evidence to distinguish a quadratic pattern from an exponential pattern?

Teacher support: Expected idea: both quadratic and exponential outputs can increase faster over time. The distinguishing evidence is constant second difference versus constant multiplicative ratio.

I Can 3 — I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Family classification should use evidence, not a guess from one visual feature. A graph may suggest a family, but scale can make different relationships look similar over a small window. A table may suggest growth, but “grows quickly” does not tell you whether the change is additive, quadratic, or multiplicative.

Use the evidence that fits the representation: rate of change or differences in a table, shape and key features in a graph, variable placement in an equation, and the kind of repeated change described by a context.

When someone proposes a family, your critique should name the claim and the evidence. Strong reasoning sounds like “quadratic because the second differences are constant,” not merely “it looks quadratic.”

Use at least two forms of evidence when the family is not obvious. Equation structure, table pattern, graph shape, and context behavior should support the same conclusion.

Example 3: Compare Families on Graphs

Compare the two graphs. Classify each family and name one feature that distinguishes them.

Teacher answer: One graph is quadratic and one is exponential. The quadratic has a turning point and symmetric parabola shape; the exponential grows multiplicatively and does not have a turning point in the displayed window.

You Try It 3: Compare Families on Graphs

Classify the graph and state one visible feature that supports your answer.

Teacher answer: Quadratic; it is a parabola with one turning point.

Example 4: Choose a Family from Context

A savings account balance is multiplied by 1.05 each year. Which family is a natural model, and what feature of the context supports that choice?

Teacher answer: Exponential, because the balance changes by a constant multiplicative factor (1.05) each year.

You Try It 4: Choose a Family from Context

The distance from a fixed point on a straight trail is modeled from a signed position. Which family naturally describes distance from that point?

Teacher answer: Absolute value, because distance uses magnitude from a fixed center.

Summary

  • Linear, quadratic, exponential, and absolute-value families have different structural patterns.
  • Differences and ratios help identify families from tables.
  • A family claim should be supported with evidence from the representation, not appearance alone.
Summary notes / questions / connections

Teaching note: Look for students naming family-specific evidence such as first differences, second differences, constant ratios, equation structure, and graph features.
