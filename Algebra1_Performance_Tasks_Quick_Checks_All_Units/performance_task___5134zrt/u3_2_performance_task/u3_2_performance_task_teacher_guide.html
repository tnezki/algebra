Situation / Starting Evidence

System 1: y=4x-7 and 2x+y=8.   System 2: 3x+2y=12 and -3x+5y=9.
Pencil, calculator if normally allowed

Plan before solving

Choose substitution or elimination for each system and explain the structural clue behind your choice.

Teacher evidence / sample: System 1 substitution is efficient because y is isolated. System 2 elimination is efficient because x coefficients are opposites.

Use substitution

Solve System 1 and interpret the ordered pair as the point satisfying both equations.

Teacher evidence / sample: 2x+(4x-7)=8 -> 6x=15 -> x=2.5, y=3. Ordered pair (2.5,3).
