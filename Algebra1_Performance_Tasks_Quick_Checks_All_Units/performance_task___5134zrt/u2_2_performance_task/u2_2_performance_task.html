Evidence Focus
  1. I can build graphs of linear functions using slope and intercept information.

A robot begins at a starting height and moves by a repeated slope instruction. You will build its path, read features, and validate a prediction. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Robot rule: start at (0, -2). For every 2 units right, move 3 units up.
Pencil, calculator if normally allowed

Build the path

Plot the start and at least four more points from the repeated slope move. Draw the line.

Read the features

State the slope and y-intercept and explain what each tells you about the path.
