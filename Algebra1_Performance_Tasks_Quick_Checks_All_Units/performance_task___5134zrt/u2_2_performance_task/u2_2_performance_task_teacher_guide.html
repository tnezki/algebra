Evidence Focus
  1. I can build graphs of linear functions using slope and intercept information.
  2. I can use key features of a line to interpret a relationship.
  3. I can extend a graph to predict outputs within a meaningful range.

A robot begins at a starting height and moves by a repeated slope instruction. You will build its path, read features, and validate a prediction. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Robot rule: start at (0, -2). For every 2 units right, move 3 units up.
Pencil, calculator if normally allowed

Build the path

Plot the start and at least four more points from the repeated slope move. Draw the line.

Teacher evidence / sample: Points can include (0,-2),(2,1),(4,4),(6,7),(-2,-5); line y=1.5x-2.

Read the features

State the slope and y-intercept and explain what each tells you about the path.

Teacher evidence / sample: Slope 3/2 gives vertical change per horizontal change; y-intercept -2 is the starting output at x=0.

Extend within range

Predict y when x=8 without plotting every intermediate point.

Teacher evidence / sample: y=1.5(8)-2=10.

Audit a plotted point

A student places (5,6) on the line. Decide whether it belongs and repair it if needed.

Teacher evidence / sample: At x=5, y=7.5-2=5.5, so (5,6) is not on the line; repaired point is (5,5.5).
