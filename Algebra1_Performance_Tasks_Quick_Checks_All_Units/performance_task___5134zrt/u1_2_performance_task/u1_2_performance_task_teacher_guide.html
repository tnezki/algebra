Evidence Focus
  1. I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  2. I can apply an input-output rule to generate missing values and ordered pairs.
  3. I can assess whether a rule gives one output for each input in a situation.

A function-machine designer has mixed correct rules with a machine that violates the one-output-per-input requirement. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Input-2035
Output-7-1814
Pencil, calculator if normally allowed

Recover the machine rule

Find a rule that produces every input-output pair in the table. Show how two pairs verify your rule.

Teacher evidence / sample: Rule y=3x-1; for x=-2 gives -7 and x=5 gives 14.

Stress-test a new input

Use your rule to predict the output for input 12 and the input that would produce output 29.

Teacher evidence / sample: Input 12 gives 35. Output 29 requires 3x-1=29, so x=10.

Inspect a second machine

The second machine records (2,5), (4,9), (2,7), (6,13). Decide whether it can be a function and identify the exact evidence.

Teacher evidence / sample: It is not a function because input 2 has two outputs, 5 and 7.

Repair without changing the idea

Change exactly one ordered pair so the second machine becomes a function with a consistent linear rule. State the repaired rule.

Teacher evidence / sample: One valid repair: change (2,7) to (8,17), producing y=2x+1; other coherent single-pair repairs may be accepted if all pairs fit one rule.
