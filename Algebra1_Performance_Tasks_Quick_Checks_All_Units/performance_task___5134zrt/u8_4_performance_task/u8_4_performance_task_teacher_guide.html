Evidence Focus
  1. I can formulate a mathematical model from real-world data and state the assumptions used.
  2. I can extend a model to make predictions within a reasonable domain.
  3. I can critique how well a model fits data, constraints, and the situation being studied.

A ball is rolled down a ramp and its distance from the start is recorded. Choose a model, state assumptions, make a prediction, and critique fit. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Time (s)01234
Distance (cm)27183558
Pencil; calculator optional. If teacher chooses, ramp/ball/timer may replace supplied data.

Select a model family

Use differences/ratios and context to decide which familiar family is most plausible.

Teacher evidence / sample: First differences 5,11,17,23 have constant second difference 6, supporting a quadratic model.

Build a candidate model

Find a quadratic model fitting the pattern.

Teacher evidence / sample: d=3t^2+2 fits: t0 2, t1 5? That does not fit. Correct model from differences: second difference 6 -> a=3. Let d=3t^2+bt+2; t=1 gives 3+b+2=7 -> b=2. So d=3t^2+2t+2. It gives 18,35,58.

Predict within range

Predict distance at 5 seconds and identify the assumption behind extending the pattern.

Teacher evidence / sample: d(5)=75+10+2=87 cm; assumes same ramp/motion conditions and model pattern continue.

Critique model limits

Name at least two reasons the quadratic model may stop fitting in a real experiment.

Teacher evidence / sample: Examples: ramp ends, friction changes, speed limits/obstacles, measurement error, different release conditions.
