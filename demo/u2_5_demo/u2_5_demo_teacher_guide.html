How thick is one index card if a single card is too thin to measure accurately?

Linear Modeling with Data

Why This Fits

This mini class data collection creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will use linear models to represent and interpret real-world data.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • Expected pattern is approximately linear because each added card contributes about the same thickness.
  • Slope has units millimeters per card and estimates card thickness.
  • A small nonzero intercept can arise from measurement/fit error; it should be interpreted cautiously.

Watch For

  • Treating every data set as perfectly linear.
  • Using a prediction far outside the meaningful data range without considering model limits.

Strong Synthesis

A model can capture the overall constant-rate trend while real measurements include small error. Fit quality and residual direction matter more than exact coincidence.

Interpret

What does the data suggest?

Using change in stack height over change in card count estimates thickness per card; multiple measurements reduce the effect of small measurement error.

Teacher notes

Expected/acceptable evidence: A 50-card prediction is reasonable only if the same card type and stacking method continue.

Discussion

Carry the idea into instruction

1. Why is measuring a stack more reliable than one card?

2. What should slope mean in this data set?

3. Why might the intercept not be exactly zero?
