Can a machine be a function if two different buttons give the same snack?

Inputs, Outputs, and Functions

Why This Fits

This error or contradiction reveal creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • A is a function even though output 4 repeats.
  • B is not a function because input 1 has two outputs.
  • C follows output = 3(input)+5.

Watch For

  • Reversing inputs and outputs when applying a rule.
  • Treating a repeated input with two different outputs as a function.

Strong Synthesis

Each input must have exactly one output. Repeated outputs are allowed; repeated inputs with different outputs are not.
Choose

Can a machine be a function if two different buttons give the same snack?

Mapping A: 1→4, 2→4, 3→7. Mapping B: 1→4 and 1→6, 2→7.

Commit to a claim, vote, or prediction and prepare one reason.

Teacher notes

Purpose: create a quick commitment before formal instruction. Ask for reasons, not just answers.

Expected/acceptable evidence: A is a function even though output 4 repeats.

Move on when students can state a reason connected to a value, feature, structure, or representation—not merely a guess.

Reveal

Test the claim

A repeated output is allowed; one input producing two outputs breaks the function rule.

Teacher notes

Expected/acceptable evidence: B is not a function because input 1 has two outputs.

Move on when students can state a reason connected to a value, feature, structure, or representation—not merely a guess.

Discussion

What changed your mind?

1. Which mapping fails and what exact feature causes the failure?

2. Why does a repeated output not automatically cause a problem?

3. In a real context, what could input and output mean?

We will treat functions as dependable input-output rules.
