What does “shift up 3” mean for a line, parabola, exponential curve, and absolute-value graph?

Transformations Across Function Families

Why This Fits

This four view mystery creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will analyze transformations across multiple function families.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • Up 3 adds 3 to all y-coordinates across every family.
  • Right 2 adds 2 to all x-coordinates of corresponding points (represented as f(x-2)).
  • Reflection over x-axis negates y-values.

Watch For

  • Applying a transformation rule as though it behaves identically in every algebraic position.
  • Moving one key feature without transforming the rest of the function consistently.

Strong Synthesis

Coordinate changes such as shifts/reflections/scales generalize; the named key features affected—slope, vertex, asymptote, intercepts—depend on the family.

Discussion

What carries forward?

1. What transformation rule generalizes across all four families?

2. Which features are family-specific?

3. How is a vertical stretch different from a vertical shift?

We will use one transformation language across function families while tracking each family’s key features.
