Algebra 1 · Section 3.4 Demo Teacher Guide

If the boundary is y=2x+1, which side of the classroom represents y>2x+1?

Graphing Linear Inequalities

Why This Fits

This human movement or position model creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will graph and interpret linear inequalities.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • Strict < or > uses a dashed boundary; ≤ or ≥ uses a solid boundary.
  • For y>2x+1, test (0,0): 0>1 is false, so shade the side not containing the origin.
  • For y≤-x+4, (0,0) works, so shade the side containing the origin.

Watch For

  • Using a solid boundary for a strict inequality or dashed boundary for an inclusive inequality.
  • Shading by memorized direction instead of testing a point.

Strong Synthesis

Boundary style communicates whether equality is included; shading communicates all ordered pairs that satisfy the inequality.

Reveal

Compare with the mathematical model

Evaluating test points shows which side satisfies the inequality; a strict inequality excludes the boundary.

Discussion

What should we carry forward?

1. Why does one test point decide an entire half-plane?

2. When must the boundary be dashed?

3. What does a shaded point mean in the original inequality?
