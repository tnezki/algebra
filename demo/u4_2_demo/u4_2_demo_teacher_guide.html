Algebra 1 · Section 4.2 Demo Teacher Guide

If f(x)=x², where will the vertex go for f(x-3)+2?

Translations

Why This Fits

This build then reveal creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will graph and write translated functions using key points and key features.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • g shifts right 3 and up 2; vertex moves (0,0)→(3,2).
  • h shifts left 2 and down 4; vertex moves (0,0)→(-2,-4).
  • Every point translates by the same vector; shape/orientation stay unchanged.

Watch For

  • Reversing the direction of horizontal shifts in equation form.
  • Moving only the vertex while leaving other key points inconsistent.

Strong Synthesis

A true translation moves every point by the same horizontal/vertical amount. Multiple points reveal whether only a single feature was moved or the whole graph was transformed.

Discussion

What should we carry forward?

1. Why does x-3 move the graph right?

2. Which features stay unchanged under a translation?

3. How can matching one point be insufficient?

We will describe translations by tracking corresponding points, not memorizing isolated sign rules.
