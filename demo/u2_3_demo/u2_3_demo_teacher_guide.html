A line passes through (0,-2) and (3,4). Which equation belongs to it?

Writing Linear Equations

Why This Fits

This competing claims or models creates a short point of tension that surfaces the section misconception without trying to teach the whole lesson.

Time5–8 minutes
GroupingWhole class / projector
Core ideaStudents will write linear equations from graphs, tables, and situations.

Materials

Projector/screen; student notebook or mini whiteboard when the slide asks students to record or commit.

Before Class

Open the deck in presentation view. If a reveal figure is used, confirm the local image loads. Do not reveal later slides early.

Suggested Flow

Use the slide-specific notes below. Keep the pace brisk; the goal is noticing and a productive question, not complete instruction.

Answer / Evidence Guide

  • Provided graph is built for $y=2x-2$.
  • Table has slope 3 and intercept 5, so $y=3x+5$.
  • Context gives $C=4v+12$.

Watch For

  • Using an arbitrary table value as the intercept.
  • Confusing the roles of $m$ and $b$ in $y=mx+b$.

Strong Synthesis

Constant rate of change (slope) and the starting value (y-intercept when x=0).
Choose

A line passes through (0,-2) and (3,4). Which equation belongs to it?

Claims: y=2x-2, y=-2x+4, y=3x-2.

Commit to a claim, vote, or prediction and prepare one reason.

Teacher notes

Purpose: create a quick commitment before formal instruction. Ask for reasons, not just answers.

Expected/acceptable evidence: Provided graph is built for $y=2x-2$.

Move on when students can state a reason connected to a value, feature, structure, or representation—not merely a guess.

Reveal

Test the claim

Slope is (4-(-2))/(3-0)=2 and the intercept is -2, so y=2x-2.

Teacher notes

Expected/acceptable evidence: Table has slope 3 and intercept 5, so $y=3x+5$.

Move on when students can state a reason connected to a value, feature, structure, or representation—not merely a guess.

Discussion

What changed your mind?

1. Which feature can be read without calculating?

2. How could you verify the equation using the second point?

3. Why is an arbitrary table output not automatically the intercept?

We will recover m and b from graphs, tables, and situations.
