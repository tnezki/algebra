Algebra 1 - Unit 2: Linear Functions and Modeling

Essential Standard

Students will interpret, represent, solve, and model linear relationships by using slope as a measure of constant rate of change across graphs, tables, equations, data, and contextual situations.

Section Outline

Section 2.1: Rate of Change and Slope

Learning Target: Students will interpret slope as a measure of constant rate of change.

I Can Statements

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

Key Representations

  • Slope triangles on coordinate graphs
  • Tables showing equal input intervals
  • Contextual rate statements
  • Ratio notation for vertical change over horizontal change
  • Positive, negative, zero, and undefined slope examples

Modeling Opportunities

  • Connect speed, cost per item, and growth rates to slope
  • Build verbal interpretations for slopes in real situations
  • Use table patterns to model constant change
  • Represent increasing and decreasing rates with graph features
Section 2.2: Graphing Linear Functions

Learning Target: Students will graph linear functions and interpret key features.

I Can Statements

  • I can build graphs of linear functions using slope and intercept information.
  • I can use key features of a line to interpret a relationship.
  • I can extend a graph to predict outputs within a meaningful range.

Key Representations

  • Coordinate plane graphs
  • Slope-intercept form
  • Intercepts and starting values
  • Tables generated from linear rules
  • Contextual graphs with labeled axes

Modeling Opportunities

  • Graph savings, distance, or subscription situations
  • Use intercepts to represent initial values
  • Connect slope direction to increasing or decreasing behavior
  • Create graphs from equations and contextual descriptions
Section 2.3: Writing Linear Equations

Learning Target: Students will write linear equations from graphs, tables, and situations.

I Can Statements

  • I can formulate linear equations from graphs, tables, and situations.
  • I can apply slope-intercept structure to connect rate and starting value.
  • I can design equivalent equations that represent the same linear relationship.

Key Representations

  • Slope-intercept equations
  • Tables of input-output values
  • Graphs with marked intercepts
  • Verbal descriptions of rates and starting values
  • Equivalent equation forms

Modeling Opportunities

  • Write rules for cell phone plans, savings, or distance
  • Translate graphs into equations
  • Use tables to calculate slope and initial value
  • Revise equations to make context features visible
Section 2.4: Comparing Linear Representations

Learning Target: Students will analyze and compare linear relationships using multiple representations.

I Can Statements

  • I can construct comparison models for linear relationships shown in different forms.
  • I can use slope and intercept information to interpret similarities and differences.
  • I can critique conclusions about linear relationships using evidence from representations.

Key Representations

  • Pairs of graphs
  • Tables with different scales
  • Equations in slope-intercept form
  • Contextual descriptions
  • Feature comparison organizers

Modeling Opportunities

  • Compare competing plans or rates
  • Use representations to support choices
  • Translate unlike representations into common features
  • Check claims about which relationship grows faster
Section 2.5: Linear Modeling with Data

Learning Target: Students will use linear models to represent and interpret real-world data.

I Can Statements

  • I can design linear models that represent patterns in real-world data.
  • I can predict values using a linear model and interpret the result.
  • I can assess whether a linear model fits a data situation well enough for the question being asked.

Key Representations

  • Scatter plots
  • Lines of fit
  • Tables of real-world data
  • Linear model equations
  • Residual-style reasonableness observations

Modeling Opportunities

  • Model trends in measurement, cost, or time data
  • Use lines of fit to make predictions
  • Interpret slope and intercept in data contexts
  • Discuss when linear models are useful or limited
Unit Modeling Themes
  • Slope as constant rate of change across representations
  • Initial value as a contextual starting point
  • Linear equations as compact models of repeated change
  • Comparing relationships by translating features into common language
  • Using linear models to make and critique predictions from data

Assessment Methods by DOK Level

DOK 1 - Rungs 1-2

Format: 3-5 minute warm-up, vocabulary check, representation recognition, or exit ticket

Purpose: DOK 1 checks whether students can read linear features, use slope language, and connect coordinate plane details to the basic meaning of a linear relationship.

Assessment Ideas

  1. Slope Language Check Can Be Assessed After Section 2.1 - Use slope vocabulary to connect direction, steepness, and constant rate of change.
  2. Point and Intercept Read Can Be Assessed After Section 2.2 - Interpret points and intercepts from a linear graph with labeled axes.
  3. Rate from a Table Can Be Assessed After Section 2.1 - Calculate a constant rate of change from adjacent rows in a table.
  4. Equation Feature Read Can Be Assessed After Section 2.3 - Represent slope and initial value features from a linear equation.
What this tells the teacher:
DOK 1 performance shows whether students have the basic graph, table, and equation language needed before writing, comparing, or modeling linear relationships.
DOK 2 - Rungs 3-4

Format: Mini-quiz, graph/table task, matching task, partner check, or short written task

Purpose: DOK 2 reveals whether students can carry out multi-step linear procedures and connect slope and intercept information across two representations.

Assessment Ideas

  1. Graph from Features Can Be Assessed After Section 2.2 - Construct a graph from a given slope and intercept, then interpret both features.
  2. Equation from Table Can Be Assessed After Section 2.3 - Formulate a linear equation using constant change and starting value from a table.
  3. Context to Rule Can Be Assessed After Section 2.3 - Translate a situation into a linear equation and a short interpretation.
  4. Representation Bridge Can Be Assessed After Section 2.4 - Compare a graph and an equation by using slope and initial value.
What this tells the teacher:
DOK 2 evidence shows whether students can move beyond reading features to creating and using linear representations accurately.
DOK 3 - Rungs 5-6

Format: Constructed response, model critique, strategy comparison, representation analysis, or discourse prompt

Purpose: DOK 3 reveals whether students can reason with linear features, critique claims, and choose representations that fit a situation.

Assessment Ideas

  1. Faster Growth Claim Can Be Assessed After Section 2.4 - Analyze two linear relationships and support which one changes faster using representation evidence.
  2. Best Representation Choice Can Be Assessed After Section 2.4 - Determine which representation makes slope and starting value easiest to interpret for a given question.
  3. Model Reasonableness Check Can Be Assessed After Section 2.5 - Estimate whether a linear prediction is reasonable based on the data pattern and context.
  4. Strategy Comparison Can Be Assessed After Section 2.3 - Critique two methods for writing a linear equation and choose the more efficient strategy for the representation given.
What this tells the teacher:
DOK 3 evidence shows whether students can use slope and intercept as reasoning tools rather than isolated procedures.
DOK 4 - Rungs 7-8

Format: Brief performance task, modeling task, critique-and-revise task, design task, or capstone synthesis task

Purpose: DOK 4 reveals whether students can synthesize tables, graphs, equations, contexts, and data into coherent linear models.

Assessment Ideas

  1. Mini Data Model Can Be Assessed After Section 2.5 - Design a linear model for a small data set and interpret the meaning of the slope in context.
  2. Revise the Model Can Be Assessed After Section 2.5 - Develop a revised line of fit after checking whether the first model overpredicts or underpredicts key values.
  3. Four-Representation Snapshot Can Be Assessed After Section 2.4 - Create a table, graph, equation, and context that all represent the same linear relationship.
  4. Model Critique Card Can Be Assessed After Section 2.5 - Apply a proposed linear model to the question, data pattern, and context limitations.
What this tells the teacher:
DOK 4 tasks reveal whether students can synthesize slope, intercept, representation choice, and data-based prediction into a coherent linear model. These should remain short performance tasks rather than large projects.

Summative Assessment Plan

Unit 2 Summative Assessment Revisited in Subsequent Units

Assessment is designed for a 45-minute paper-only time limit and is built around balanced evidence rather than a fixed question-count breakdown. Each version includes a mix of slope interpretation, graphing, equation writing, representation comparison, and short data-modeling tasks aligned to the unit learning targets and Depth of Knowledge expectations.

Assessments emphasize slope as constant rate of change, intercepts as starting values, connections among graphs, tables, equations, and contexts, and reasoning about linear models in real-world situations.

Summative assessments are intentionally focused on DoK 1-3 evidence within a paper-only environment. Extended DoK 4 modeling, critique, design, and performance tasks are assessed separately through formative assessments, collaborative activities, investigations, discourse tasks, and performance assessments rather than embedded directly into the summative assessment.

Because of the spiraling course structure, Unit 2 content is revisited through subsequent units via retrieval practice, warm-ups, and formative assessments.

Holistic Rubric

A - Highly Proficient

The student demonstrates strong flexible understanding of slope, intercepts, linear equations, multiple representations, and linear modeling with data. Work is accurate, well-organized, and supported by clear reasoning. The student consistently connects equations, graphs, tables, and contexts while justifying conclusions using precise mathematical language.

B - Proficient

The student demonstrates solid understanding of slope as constant rate of change, linear graphing, equation writing, representation comparison, and basic data modeling. Most work is accurate, and the student can complete standard and moderately complex tasks independently. Explanations are generally clear, though they may lack some precision or depth.

C - Developing Proficiency

The student demonstrates partial but passable understanding of slope, intercepts, graphing, equation writing, and linear model interpretation. The student can complete many routine tasks but may need support with notation, reasoning, restrictions, representations, or multi-step problem solving. Work may contain errors or incomplete explanations, but there is enough evidence that the student understands the main ideas.

Not Yet - Insufficient Evidence

The student does not yet demonstrate sufficient understanding of slope, linear representations, equation writing, or linear modeling. Work shows major errors, missing reasoning, weak conceptual understanding, or inability to connect representations. The student may need reteaching, additional practice, or reassessment to demonstrate proficiency.
