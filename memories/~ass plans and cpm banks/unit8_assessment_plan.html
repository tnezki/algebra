Algebra 1 - Unit 8: Function Analysis, Modeling, and Synthesis

Essential Standard

Students will analyze, model, and interpret situations using linear, quadratic, exponential, absolute value, and piecewise function representations to select appropriate models and support conclusions.

Section Outline

Section 8.1: Selecting Appropriate Models

Learning Target: Students will determine whether a situation is best modeled by a linear, quadratic, or exponential function.

I Can Statements

  • I can construct evidence from tables, graphs, and contexts to choose a linear, quadratic, or exponential model.
  • I can apply rate, second-difference, and ratio patterns to select an appropriate function family.
  • I can determine whether a chosen model is reasonable for a situation and its data pattern.

Key Representations

  • Linear, quadratic, and exponential graphs
  • Tables showing first differences, second differences, and ratios
  • Equations in familiar function forms
  • Context descriptions with quantities and constraints
  • Verbal claims about growth, change, and turning behavior

Modeling Opportunities

  • Sort situations by evidence rather than by surface words.
  • Choose a model for a data table and state the feature that supports the choice.
  • Revise a model choice when a new data point changes the pattern.
  • Connect real-world behavior to graph shape and equation structure.
Section 8.2: Transformations Across Function Families

Learning Target: Students will analyze transformations across multiple function families.

I Can Statements

  • I can build transformed function rules from parent functions across linear, quadratic, exponential, and absolute value families.
  • I can use key points and key features to graph transformations across multiple function families.
  • I can formulate a transformation description that connects parameter changes to key point shifts across function families.

Key Representations

  • Parent function graphs
  • Transformed equations such as $f(x)+k$, $f(x-h)$, and $af(x)$
  • Key points before and after transformations
  • Feature tables for intercepts, vertex, asymptote, and direction
  • Context descriptions involving shifted or scaled models

Modeling Opportunities

  • Move key points to create a transformed model for a situation.
  • Predict how changing a parameter changes a graph and its meaning.
  • Use transformations to adapt a familiar model to a new context.
  • Check whether a transformed equation preserves important constraints.
Section 8.3: Absolute Value Functions and Piecewise Thinking

Learning Target: Students will analyze and model situations involving absolute value functions.

I Can Statements

  • I can design an absolute value or piecewise representation for situations with distance, change in direction, or two-part behavior.
  • I can apply key features of absolute value graphs to interpret vertex, intercepts, and rate of change.
  • I can predict outputs and intervals from absolute value and piecewise rules in context.

Key Representations

  • Absolute value graphs with a vertex
  • Equations using $|x-h|$ structure
  • Piecewise rules and interval restrictions
  • Tables showing symmetry or two rates
  • Contexts involving distance from a target or changing direction

Modeling Opportunities

  • Model distance from a target value using absolute value.
  • Create a piecewise rule for a situation with different rates over intervals.
  • Connect a vertex to a minimum distance or turning point in context.
  • Use domain restrictions to make a model fit the situation.
Section 8.4: Modeling Investigation

Learning Target: Students will create and analyze mathematical models using real-world data.

I Can Statements

  • I can formulate a mathematical model from real-world data and state the assumptions used.
  • I can extend a model to make predictions within a reasonable domain.
  • I can critique how well a model fits data, constraints, and the situation being studied.

Key Representations

  • Real-world data tables
  • Scatterplots or plotted coordinate pairs
  • Candidate linear, quadratic, exponential, or absolute value models
  • Residual-style observations about overprediction and underprediction
  • Written interpretation of model parameters and limits

Modeling Opportunities

  • Choose a model for a small data set and defend the choice with evidence.
  • Use a model to make and check a prediction.
  • Revise a model when the data or domain makes the first model weak.
  • Interpret parameters and outputs in the original context.
Section 8.5: Function Synthesis and Capstone Analysis

Learning Target: Students will synthesize understanding of function families and representations to solve complex problems.

I Can Statements

  • I can construct a solution pathway that connects equations, graphs, tables, and contexts across function families.
  • I can use multiple representations to solve complex function problems and interpret results.
  • I can assess competing solution strategies and choose the representation that best supports the conclusion.

Key Representations

  • Multiple function-family graphs
  • Tables, equations, and contexts used together
  • Function-feature summaries
  • Student-generated model comparisons
  • Written reasoning about model choice and solution meaning

Modeling Opportunities

  • Select efficient representations for multi-step function tasks.
  • Synthesize evidence from several function families to solve a problem.
  • Revise a model or solution when a representation reveals a conflict.
  • Communicate why a chosen model or strategy fits the problem conditions.
Unit Modeling Themes
  • Choosing function families based on evidence from patterns, features, and context
  • Connecting equations, graphs, tables, and verbal descriptions as equivalent or complementary representations
  • Interpreting parameters, intercepts, vertices, asymptotic behavior, and intervals in context
  • Using transformations and restrictions to adapt parent functions to real situations
  • Critiquing model fit, domain, reasonableness, and representation choice

Assessment Methods by DOK Level

DOK 1 - Rungs 1-2

Format: 3-5 minute warm-up, vocabulary check, representation recognition, or exit ticket

Purpose: DOK 1 reveals whether students can access the basic vocabulary, features, and pattern clues needed before selecting or building models across function families.

Assessment Ideas

  1. Function Feature Quick Read Can Be Assessed After Section 8.1 - Use first differences, second differences, ratios, and graph features to classify the likely behavior shown in short prompts.
  2. Representation Signal Check Can Be Assessed After Section 8.1 - Represent a table or short context with the feature clue that supports a linear, quadratic, or exponential model.
  3. Transformation Vocabulary Exit Can Be Assessed After Section 8.2 - Apply transformation language to changes in key points, graph shape, and function notation.
  4. Absolute Value and Interval Check Can Be Assessed After Section 8.3 - Classify vertex, interval, and distance-from-target information in absolute value or piecewise representations.
What this tells the teacher:
DOK 1 performance shows whether students can notice the basic clues that make higher-level model selection and synthesis possible.
DOK 2 - Rungs 3-4

Format: Mini-quiz, graph/table task, matching task, partner check, or short written task

Purpose: DOK 2 reveals whether students can connect representations and carry out the procedures needed to build, transform, and use models.

Assessment Ideas

  1. Model From Evidence Can Be Assessed After Section 8.1 - Construct a model choice from a table, graph, and context by using the strongest available evidence.
  2. Transformed Family Builder Can Be Assessed After Section 8.2 - Interpret how a transformation changes key points and features across more than one function family.
  3. Absolute Value Model Card Can Be Assessed After Section 8.3 - Build an absolute value or piecewise rule that fits a short distance, rate, or interval situation.
  4. Prediction With Limits Can Be Assessed After Section 8.4 - Use a selected model to make a prediction and state whether the input is inside a reasonable domain.
What this tells the teacher:
DOK 2 performance shows whether students can move from recognizing features to building and using representations with attention to context and constraints.
DOK 3 - Rungs 5-6

Format: Constructed response, model critique, strategy comparison, representation analysis, or discourse prompt

Purpose: DOK 3 reveals whether students can reason about why a model, representation, or strategy is appropriate rather than only carrying out a procedure.

Assessment Ideas

  1. Best Model Reasoning Prompt Can Be Assessed After Section 8.1 - Determine which of two possible function families better fits a situation and support the choice with representation-based evidence.
  2. Transformation Claim Check Can Be Assessed After Section 8.2 - Assess a student's transformation claim by checking it against the equation, graph features, and key points.
  3. Piecewise Constraint Analysis Can Be Assessed After Section 8.3 - Analyze whether intervals, vertex information, and rates make a piecewise or absolute value model reasonable.
  4. Model Revision Strategy Can Be Assessed After Section 8.4 - Formulate a revision to a model when new data or a context limit makes the original model weaker.
What this tells the teacher:
DOK 3 performance shows whether students can critique model choices, interpret constraints, and communicate reasoning across representations.
DOK 4 - Rungs 7-8

Format: Brief performance task, modeling task, critique-and-revise task, design task, or capstone synthesis task

Purpose: DOK 4 reveals whether students can synthesize function-family knowledge in short, complex tasks that require model choice, revision, and interpretation.

Assessment Ideas

  1. Mini Modeling Investigation Can Be Assessed After Section 8.4 - Design a short model from a small data set, state assumptions, and interpret one prediction in context.
  2. Function Family Synthesis Can Be Assessed After Section 8.5 - Generate a solution that uses at least two representations to select and analyze a function family.
  3. Critique and Revise a Model Can Be Assessed After Section 8.5 - Validate or revise a proposed model using data, graph features, domain, and context constraints.
  4. Capstone Representation Choice Can Be Assessed After Section 8.5 - Create a concise argument for which representation best supports a complex function-analysis conclusion.
What this tells the teacher:
DOK 4 tasks reveal whether students can synthesize function-family knowledge, select appropriate models, revise weak choices, and communicate conclusions from multiple representations. These should remain short performance tasks rather than large projects.

Summative Assessment Plan

Unit 8 Summative Assessment End-of-course synthesis checkpoint

Assessment is designed for a 45-minute paper-only time limit and is built around balanced evidence rather than a fixed question-count breakdown. Each version includes a mix of model-selection tasks, transformation analysis, absolute value and piecewise interpretation, data-based modeling, and multi-representation synthesis aligned to the unit learning targets and Depth of Knowledge expectations.

Assessments emphasize selecting appropriate function families, connecting representations, interpreting key features in context, using model constraints, and reasoning about the strength of a model choice.

Summative assessments are intentionally focused on DoK 1-3 evidence within a paper-only environment. Extended DoK 4 modeling, critique, design, and performance tasks are assessed separately through formative assessments, collaborative activities, investigations, discourse tasks, and performance assessments rather than embedded directly into the summative assessment.

Because of the spiraling course structure, Unit 8 is assessed during a future course checkpoint or final exam after students have had additional opportunities to revisit and strengthen understanding through retrieval practice, warm-ups, formative assessments, and subsequent instruction.

Holistic Rubric

A - Highly Proficient

The student demonstrates strong, flexible understanding of function analysis, model selection, transformations, absolute value or piecewise behavior, and synthesis across representations. Work is accurate, well-organized, and supported by clear reasoning. The student consistently connects equations, graphs, tables, and contexts while justifying conclusions using precise mathematical language.

B - Proficient

The student demonstrates solid understanding of model selection, function-family features, transformations, and multi-representation analysis. Most work is accurate, and the student can complete standard and moderately complex tasks independently. Explanations are generally clear, though they may lack some precision or depth.

C - Developing Proficiency

The student demonstrates partial but passable understanding of function families, model choice, transformations, and representation connections. The student can complete many routine tasks but may need support with notation, reasoning, restrictions, representations, or multi-step problem solving. Work may contain errors or incomplete explanations, but there is enough evidence that the student understands the main ideas.

Not Yet - Insufficient Evidence

The student does not yet demonstrate sufficient understanding of function analysis, modeling decisions, transformations, or synthesis across representations. Work shows major errors, missing reasoning, weak conceptual understanding, or inability to connect representations. The student may need reteaching, additional practice, or reassessment to demonstrate proficiency.
