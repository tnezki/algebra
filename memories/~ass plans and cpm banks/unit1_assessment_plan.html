Algebra 1 - Unit 1: Foundations of Functions and Algebra

Essential Standard

Students will represent and interpret relationships by connecting tables, graphs, equations, and contexts that model the same situation.

Section Outline

Section 1.1: Multiple Representations of Relationships

Learning Target: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

I Can Statements

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key Representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Modeling Opportunities

  • Build a graph from a context about distance, cost, or time.
  • Formulate an equation from a table of values.
  • Use a graph to predict a missing table value.
  • Check whether a context and equation communicate the same relationship.
Section 1.2: Inputs, Outputs, and Functions

Learning Target: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

I Can Statements

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.

Key Representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities

Modeling Opportunities

  • Build a function rule from repeated input-output calculations.
  • Use a context to assign inputs and outputs meaning.
  • Predict outputs for new inputs using a rule.
  • Check a mapping for repeated inputs with different outputs.
Section 1.3: Function Families

Learning Target: Students will recognize common function families from graphs, tables, equations, and contexts.

I Can Statements

  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Key Representations

  • Linear patterns
  • Quadratic patterns
  • Exponential growth and decay patterns
  • Absolute value patterns
  • Family features across representations

Modeling Opportunities

  • Create a context that fits a given family feature.
  • Use table patterns to choose a likely family.
  • Predict how a graph changes when a family pattern changes.
  • Critique family choices that rely only on appearance.
Section 1.4: Expressions and Structure

Learning Target: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

I Can Statements

  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Key Representations

  • Algebraic expressions
  • Equivalent forms
  • Grouped terms and factors
  • Context meanings for terms
  • Substitution checks

Modeling Opportunities

  • Build an expression for a cost, perimeter, or repeated quantity.
  • Rewrite an expression to reveal a useful structure.
  • Use substitution to test equivalence.
  • Connect terms and coefficients to a context.
Section 1.5: Equations as Models

Learning Target: Students will write, solve, and interpret equations that model situations.

I Can Statements

  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.

Key Representations

  • Context-based equations
  • Solution steps
  • Variables as quantities
  • Balanced relationships
  • Interpreted solutions

Modeling Opportunities

  • Formulate an equation from a real-world situation.
  • Use a solution to answer a context question.
  • Predict a reasonable value before solving.
  • Check whether a solution makes sense in context.
Unit Modeling Themes
  • Relationships can be represented by tables, graphs, equations, and contexts.
  • Functions connect inputs to outputs through rules and patterns.
  • Function families have features that appear across representations.
  • Expression structure can reveal meaning and support rewriting.
  • Equations can model situations and produce interpretable solutions.

Assessment Methods by DOK Level

DOK 1 - Rungs 1-2

Format: 3-5 minute warm-up, vocabulary check, representation recognition, or exit ticket

Purpose: DOK 1 tasks reveal whether students can use foundational notation, vocabulary, and simple input-output procedures before moving into connected representations.

Assessment Ideas

  1. Input-Output Quick Check Can Be Assessed After Section 1.2 - Use a given rule to produce output values and ordered pairs.
  2. Representation Readiness Can Be Assessed After Section 1.1 - Apply basic table, graph, equation, and context notation to short relationship prompts.
  3. Expression Structure Snapshot Can Be Assessed After Section 1.4 - Interpret coefficients, terms, and grouped parts in simple expressions.
  4. Equation Solution Check Can Be Assessed After Section 1.5 - Determine whether a proposed value satisfies a simple equation in context.
What this tells the teacher:
DOK 1 performance shows whether students have the basic language, notation, and procedural readiness needed for later representation and modeling tasks.
DOK 2 - Rungs 3-4

Format: Mini-quiz, graph/table task, matching task, partner check, or short written task

Purpose: DOK 2 tasks reveal whether students can transfer a relationship from one form to another and use rules, structure, and solution steps in familiar situations.

Assessment Ideas

  1. Build the Missing Representation Can Be Assessed After Section 1.1 - Construct a missing table, graph, equation, or context from a given representation.
  2. Rule to Values Can Be Assessed After Section 1.2 - Extend an input-output rule to generate new values and ordered pairs.
  3. Family Evidence Sort Can Be Assessed After Section 1.3 - Classify likely function families using evidence from table patterns, equation structure, and graph features.
  4. Rewrite and Solve Can Be Assessed After Section 1.5 - Solve an equation after rewriting or simplifying expressions that model the situation.
What this tells the teacher:
DOK 2 performance shows whether students can carry out familiar representation, function, expression, and equation tasks with enough fluency to support reasoning.
DOK 3 - Rungs 5-6

Format: Constructed response, model critique, strategy comparison, representation analysis, or discourse prompt

Purpose: DOK 3 tasks reveal whether students can use evidence to assess connections, reasonableness, and structure rather than relying on surface features.

Assessment Ideas

  1. Representation Evidence Check Can Be Assessed After Section 1.1 - Assess whether two representations model the same relationship using values, rates, and context meaning.
  2. Function Rule Reasonableness Can Be Assessed After Section 1.2 - Develop a corrected input-output rule for a situation when the proposed rule does not fit the evidence.
  3. Family Claim Critique Can Be Assessed After Section 1.3 - Critique a function family claim using evidence beyond the visual shape of the graph.
  4. Expression Strategy Choice Can Be Assessed After Section 1.4 - Determine which equivalent expression is most useful for a stated purpose and support the choice with structure.
What this tells the teacher:
DOK 3 performance shows whether students can make evidence-based judgments about representations, function rules, family choices, and expression structure.
DOK 4 - Rungs 7-8

Format: Brief performance task, modeling task, critique-and-revise task, design task, or capstone synthesis task

Purpose: DOK 4 tasks reveal whether students can synthesize the unit by designing, revising, and coordinating multiple representations within short performance tasks.

Assessment Ideas

  1. Four-Representation Model Can Be Assessed After Section 1.1 - Design a short model that includes a table, graph, equation, and context for one relationship.
  2. Function Family Mini-Design Can Be Assessed After Section 1.3 - Extend a selected function family feature into a brief table, equation, and context that work together.
  3. Expression Model Revision Can Be Assessed After Section 1.4 - Generate and revise two equivalent expressions so each form reveals a different meaning in the same context.
  4. Equation Model Challenge Can Be Assessed After Section 1.5 - Develop a context, equation, solution, and reasonableness check that work together in a short modeling task.
What this tells the teacher:
DOK 4 tasks reveal whether students can synthesize representations, function rules, expression structure, and equation models into coherent mathematical relationships. These should remain short performance tasks rather than large projects.

Summative Assessment Plan

Unit 1 Summative Assessment Early-course foundation revisited throughout subsequent units

Assessment is designed for a 45-minute paper-only time limit and is built around balanced evidence rather than a fixed question-count breakdown. Each version includes a mix of representation connection tasks, input-output rule tasks, function-family evidence tasks, expression rewriting tasks, and equation modeling tasks aligned to the unit learning targets and Depth of Knowledge expectations.

Assessments emphasize connecting tables, graphs, equations, and contexts; interpreting input-output relationships; using family features as evidence; rewriting expressions with structure; and solving equations as models.

Summative assessments are intentionally focused on DoK 1-3 evidence within a paper-only environment. Extended DoK 4 modeling, critique, design, and performance tasks are assessed separately through formative assessments, collaborative activities, investigations, discourse tasks, and performance assessments rather than embedded directly into the summative assessment.

Because of the spiraling course structure, Unit 1 content is revisited through subsequent units via retrieval practice, warm-ups, and formative assessments.

Holistic Rubric

A - Highly Proficient

The student demonstrates strong flexible understanding of relationships, functions, expression structure, and equations as models across multiple representations. Work is accurate, well-organized, and supported by clear reasoning. The student consistently connects equations, graphs, tables, and contexts while justifying conclusions using precise mathematical language.

B - Proficient

The student demonstrates solid understanding of the essential ideas in representing relationships, interpreting functions, working with expression structure, and using equations as models. Most work is accurate, and the student can complete standard and moderately complex tasks independently. Explanations are generally clear, though they may lack some precision or depth.

C - Developing Proficiency

The student demonstrates partial but passable understanding of connecting representations, using input-output rules, recognizing function-family evidence, rewriting expressions, and solving model equations. The student can complete many routine tasks but may need support with notation, reasoning, restrictions, representations, or multi-step problem solving. Work may contain errors or incomplete explanations, but there is enough evidence that the student understands the main ideas.

Not Yet - Insufficient Evidence

The student does not yet demonstrate sufficient understanding of the essential concepts in relationships, functions, expressions, and equations as models. Work shows major errors, missing reasoning, weak conceptual understanding, or inability to connect representations. The student may need reteaching, additional practice, or reassessment to demonstrate proficiency.
