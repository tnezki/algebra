CANONICAL PRINCIPLE (from spiral plan):
  Bank items are the canonical specification.
  The summative copies them or generates variants.
  It does not invent independently.
  Every question must trace to a specific bank item.

SPIRAL PLAN ALIGNMENT ADDENDUM:
  The summative is a compact 45-minute snapshot of the spiral plan's
  current priority skills. Reassessment versions may be scrambled and
  reworded, but they must preserve the same skill targets, section
  coverage, and DOK balance as the test-day versions. Do not use
  reassessment forms to introduce new content targets that were not part
  of the original summative blueprint.

Fill the V1-V4 source slots (exactly 10 content targets total):
  - Prefer assessment-grade items.
  - Select items that represent distinct skills and sections.
  - Prefer visual/graph/model items when they align to the same
    learning target and DOK level, especially when they check
    mastery better than a text-only version.
  - If fewer AG items than needed at a DOK level, supplement
    with the strongest non-AG items (self-contained, no
    cross-references, naturally variantable).

Fill the V5-V6 reassessment/makeup slots:
  - Cover the same content targets and DOK distribution as V1-V4.
  - Use different bank items from V1-V4 where possible.
  - When the same source item must be reused, use a stronger adaptation
    than a single number swap: reword, change context, switch order,
    or use a closely related bank item.
  - Scramble the order so the V5/V6 problem numbers are not a direct
    slot-by-slot match to V1-V4.
  - V5 and V6 should be parallel to each other, but not identical.

Fill the V7-V8 second reassessment/makeup slots:
  - Cover the same content targets and DOK distribution as V1-V4.
  - Use questions different from V5-V6, not merely one-number changes.
  - Prefer a third bank item, a different entry point, a different context,
    or a different representation of the same skill target.
  - Scramble the order again; V7/V8 should not use the same reassessment
    order as V5/V6.
  - V7 and V8 should be parallel to each other, but not identical.

MODIFICATION MODES — ordered by frequency of use:

  MOSTLY — NUMBER-SWAP
    Change the numbers, values, or surface quantities in the
    bank item. Keep structure, wording, and DOK identical.
    This is the default. Use for the majority of questions.
    Example: bank item uses $3x+12=33$
             V1: $4x+9=29$  V2: $2x+15=37$  V3: $5x-6=44$

  MOSTLY — LIGHT REWRITE
    Change a phrase or context while preserving the
    mathematical structure and DOK level.
    Example: "gym charges \$20 to join" becomes
             "library card costs \$15 to open"
    Use when a number-swap alone feels too superficial.

  OCCASIONALLY — SWITCH ORDER INFO IS PRESENTED
    Reorder what's given vs. what's asked without changing
    the underlying math.
    Example: bank gives equation → asks for context meaning
             → switch to: give context description → ask
             for equation. Same skill, different entry point.
    Use for 1–2 questions per form at most.

  OCCASIONALLY — MERGE 2 INTO 1
    Combine two bank items at adjacent DOK levels into one
    multi-part question.
    Part a = lower-DOK bank item (DOK 1 or 2).
    Part b = higher-DOK bank item that extends Part a's setup.
    Count the merged question at the higher DOK level.
    Use for 1–2 merges per form maximum.
    Do not merge questions from unrelated sections.

VERSION DESIGN -- V1 THROUGH V8

The same 10 content targets are represented across all 8 versions.
All versions must keep exactly 10 questions with the fixed DOK distribution:
DOK 1 = 4, DOK 2 = 4, DOK 3 = 2, DOK 4 = 0.

V1 / V2 / V3 / V4 -- SAME-DAY TEST FORMS
  These are used on the original test day to prevent copying.
  Students seated near each other may receive different versions.
  V1-V4 must be parallel forms: same problem numbers, same section tags,
  same DOK levels, same ans-labels, and same question structure for each
  slot. Only the specific numbers, coordinates, function rules, contexts,
  or figures change.

V5 / V6 -- FIRST REASSESSMENT OR MAKEUP PAIR
  These cover the same content and DOK blueprint as V1-V4, but they are
  not just V1-V4 with new numbers. Reword them, use slightly different
  bank questions where possible, change contexts or representations, and
  scramble the order of the 10 content targets.

  V5 and V6 should be parallel to each other for grading consistency, but
  they should not be direct slot-by-slot copies of V1-V4. A student who
  took V1-V4 should feel that V5/V6 is a fresh reassessment of the same
  skills, not a shared answer key in a new order.

V7 / V8 -- SECOND REASSESSMENT OR MAKEUP PAIR
  These also cover the same content and DOK blueprint, but they must be
  different from V5-V6. Use a different bank item, a different wording,
  a different context, a different representation, or a different entry
  point whenever possible. Scramble the order again so V7/V8 are not
  ordered like V5/V6.

  V7 and V8 should be parallel to each other, but they must be a second
  fresh reassessment/makeup set, not a duplicate of V5/V6.

QUESTION TYPE CONSISTENCY RULE:
  For V1-V4, the same slot number must test the same learning target and
  use the same question structure. Do not change ans-labels, DOK level,
  or section tag between V1-V4 for the same slot.

  For V5-V6 and V7-V8, preserve the same overall blueprint: all 10 content
  targets, all 5 sections, and the 4/4/2/0 DOK distribution. The order may
  and should be scrambled. Track the mapping privately and in the catalog
  so each reassessment question can be traced back to its content target
  and bank source.

FIGURE RULES

CORE PRINCIPLE:
  Graphs/images/models are not a limited resource. They are easy to
  create with graph_tool.py and are often the best way to check
  conceptual mastery, representation fluency, and student reasoning.
  Use them whenever they improve the item. Do not ration them. Do not
  avoid them to keep the ZIP simpler. Treat an all-text summative as
  suspicious unless the bank and unit truly provide no useful visual
  opportunities.

COMMON HIGH-VALUE VISUALS:
  — Number lines for ordering, signed numbers, inequality solutions,
    compound inequalities, and answer graphs.
  — Coordinate planes for points, functions, comparisons, intercepts,
    slope, transformations, or model interpretation.
  — Area models, algebra tiles, diamonds, diagrams, or structured
    visual models for expressions and equation reasoning.
  — Tables or data displays when students must interpret, compare,
    complete, or critique patterns.
  — Evidence graphs where students explain, correct, or compare claims.

NAMING CONVENTION:
  Version-specific figures (change per version):
    descriptor_v[N].png   e.g., points_v1.png through points_v8.png
  Shared figures (same across all versions):
    descriptor.png        e.g., blank_plane.png, family_linear.png

SHARING RULE:
  If a figure is structurally identical across versions — share it.
  Blank number lines, blank coordinate planes, pre-made function
  family graphs, and evidence graphs that don't change = shared.
  Figures that differ by version (different points, different lines,
  different table values rendered as a graph) = version-specific.
  Do NOT create blank1, blank2, blank3 numbered duplicates.

GRAPH_TOOL.PY RULES (same as all other artifacts):
  Copy graph_tool.py in full as generate_graphs.py.
  Append generation calls only below the final append marker.
  Never modify source lines above the marker.
  Never duplicate imports, OUTPUT_DIR, or os.makedirs.
  Never use raw matplotlib outside graph_tool functions.
  All math in title=, xlabel=, ylabel=, cell values must use
  LaTeX r'$...$' strings.
  Never put the answer or value being found in title= or alt=.

FIGURE CREATION PATTERN:
  fig, ax = plt.subplots(figsize=(3.5, 3.5))
  fig.patch.set_facecolor('white')
  make_standard_graph(ax, functions, title='')
  save_graph(fig, 'points_v1.png')
  plt.close(fig)

  For number lines: figsize=(3.5, 1.25)
