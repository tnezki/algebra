First Semester Sequence
════════════════════════════════════════════════════════════════

OVERVIEW

After all banks are built and polished, we build an artifact
map for each unit. The map assigns specific bank questions
(by item ID) to every slot in every artifact for that unit.
The map is the bridge between the banks and the final
practice sets, activities, warmups, examples, YTIs, etc.

When the map is approved, building the actual artifacts
becomes mechanical — the questions are already chosen.

════════════════════════════════════════════════════════════════

WHAT YOU UPLOAD FOR EACH MAPPING SESSION

  Current unit bank  — the unit being taught
  Last unit bank     — one unit back
  Mastery unit bank  — two units back

Claude reads all three banks and builds the map.

WHAT THE MAP CONTAINS

For each of the 5 sections of the current unit, for each
of the 3 days, the map lists:

  Warmup:        item IDs by slot (current/last/mastery)
  Examples:      item IDs (4 per section, DOK 1–2)
  YTIs:          note that these are AI-derived from examples
  Practice Set:  item IDs by slot (16 total)
  Activity 1:    item IDs by slot (16 total)
  Activity 2:    item IDs by slot (16 total)
  Exit tickets:  note that these are AI-derived
  CYU:           note that these are AI-derived

For formatives and summatives:
  Adjacent ladder-rung pairs identified from current unit bank
  assessment-grade tagged items called out by ID
  Multi-part pairing suggested (Part a = lower rung,
  Part b = upper rung)

KEY PRINCIPLE

The map does not build artifacts — it assigns questions.
Once the map exists, artifact construction is a separate
pass that copies or variants the mapped items into the
correct HTML templates. Two distinct phases, two distinct
sessions.
