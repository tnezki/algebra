I-CAN STATEMENTS — HARD RULES

Each section gets exactly 3 I-can statements. Not 2. Not 4.
Total across all 5 sections = 15 I-cans.

UNIT BUDGET (enforce at unit level, not per section):
  Modeling (M):   6  ±1  (range 5–7)
  Applying (A):   6  ±1  (range 5–7)
  Justifying (J): 3  ±1  (range 2–4)
  M + A combined: 12 ±1  (range 11–13)

PER-SECTION FLOOR (enforce at section level):
  Every section must have at least 1 Modeling AND 1 Applying.
  No section is required to have a Justifying I-can.
  A section may have 2M+1A, 1M+2A, 2M+0J, etc. — content drives it.

JUSTIFYING PLACEMENT RULE:
  Write a Justifying I-can only when the section content
  genuinely involves comparing, critiquing, or checking
  reasonableness. Do not force one because a slot needs filling.

VERB TIERS:
  Modeling:   construct / formulate / build / design
  Applying:   apply / use / predict / extend
  Justifying: determine / assess / critique

BANNED verbs — never appear in I-cans:
  identify / describe / match / recognize / list / name /
  explain / compare / decide / evaluate / show / find /
  justify / defend / argue

No verb repeated more than twice across all 15 I-cans.

VERB COUNT — required before delivering:
  List every opening I-can verb.
  Tally M / A / J totals.
  Confirm M+A is 11–13 and J is 2–4.
  Flag and fix before output if out of range.

LEARNING LADDER — HARD RULES

Exactly 8 rungs. Exactly 2 per DOK level.
Rows listed highest to lowest: rung 8 first, rung 1 last.
Each row gets a class: dok4 / dok3 / dok2 / dok1.
DOK 1-3: Level = Essential. DOK 4: Level = Above.
No two adjacent rungs share the same Math Practice.
Ladder I-cans must reflect the unit M/A/J budget
(M+A dominant, J only where reasoning is genuine).

────────────────────────────────────────────────────────────────
DOK RATIO — FORMATIVE DESCRIPTIONS

Applies to all 16 formative description opening verbs.
Task names are labels only — descriptions drive the ratio.

TARGET (mirrors I-can budget):
  Modeling  (~6-7 of 16): construct, formulate, build, design,
    model, represent, develop, create, generate, translate,
    establish, map, diagram, sketch
  Applying  (~6-7 of 16): apply, use, predict, extend, solve,
    calculate, compute, evaluate, estimate, substitute,
    simplify, interpret, convert, adapt, compare, classify
  Justifying (~3 of 16):  determine, assess, critique, justify,
    defend, verify, validate, support, prove, reason, argue,
    analyze, examine, conclude, infer, generalize

Spread rule: modeling and applying verbs should be distributed
across DOK levels 1-4, not clustered at one end.
DOK 1-2 may lean applying; DOK 4 may lean modeling —
but no single DOK level should be all one verb type.

Weak verbs — replace these:
  identify / describe / match / explain / show / list

DOK 3 must NOT default to error analysis every time.
Vary: strategy construction, reasonableness, critique,
constraint analysis, discourse prompts.

DOK 4 must NOT be projects. Keep to 5-10 minutes:
design tasks, modeling tasks, critique-and-revise tasks.

VERB COUNT — required before delivering:
  List all 16 description opening verbs.
  Tally M / A / J totals.
  Confirm M is 5-8, A is 5-8, J is 2-4.
  Flag and fix before output if out of range.
