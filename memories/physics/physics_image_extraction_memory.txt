## NAMING CONVENTION (LOCKED)
Format: u{unit}_{section}_from_ch_{chapter}_{fignum}_{description}.png

Examples:
  u1_1_from_ch_1_1_eratosthenes_earth_measurement.png
  u2_4_from_ch_3_7_falling_rock_speedometer_t0_to_t5.png
  u3_3_from_ch_4_16_two_parachutists_air_resistance_vs_gravity.png

Rules:
  - unit = curriculum unit number (1–8)
  - section = curriculum section within that unit (1–5)
  - from_ch = literal text separator
  - chapter = textbook chapter number
  - fignum = textbook figure number (use "pp" for Practicing Physics figures)
  - description = snake_case description
