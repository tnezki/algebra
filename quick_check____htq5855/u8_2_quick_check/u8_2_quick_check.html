Transformations Across Function Families

Section 8.2
Name:
Date:
Evidence Focus
  1. I can build transformed function rules from parent functions across linear, quadratic, exponential, and absolute value families.
  2. I can use key points and key features to graph transformations across multiple function families.
  3. I can formulate a transformation description that connects parameter changes to key point shifts across function families.

Work independently. Show enough mathematics, representations, and interpretation to make your thinking judgeable.

1

Apply the translation $(x,y)\to(x+1,y+2)$ to key points of a linear parent and a quadratic parent. List at least two transformed points for each.

2

Graph one transformed family using its transformed key points and write a rule for it.

3

Compare what stays invariant under the same translation across linear, quadratic, exponential, and absolute-value families.
