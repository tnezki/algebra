Graphing Linear Functions

Section 2.2
Name:
Date:
Evidence Focus
  1. I can build graphs of linear functions using slope and intercept information.
  2. I can use key features of a line to interpret a relationship.
  3. I can extend a graph to predict outputs within a meaningful range.

Work independently. Show enough mathematics, representations, and interpretation to make your thinking judgeable.

1

Graph $y=2x+1$ using the intercept and repeated slope moves.

2

For the line $y=2x+1$, state the slope and y-intercept and interpret what each would mean in a cost-vs-items context.

3

Use the same linear relationship to predict $y$ when $x=4$. Explain whether extending the graph to that input is reasonable for a small-item purchase context.
