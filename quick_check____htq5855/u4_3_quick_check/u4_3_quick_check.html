Section 4.3
Name:
Date:
Evidence Focus
  1. I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.
  2. I can apply transformation rules to key points and features across function families.
  3. I can assess whether an equation, graph, or table represents the same transformed function.

Work independently. Show enough mathematics, representations, and interpretation to make your thinking judgeable.

1

For parent $y=x^2$, apply a vertical factor of $2$ and then shift up 1. Transform the key points $(-1,1),(0,0),(1,1)$ and graph them.

2

State whether the transformation includes a reflection, stretch, or compression, and identify the evidence in the parameter.

3

A classmate says horizontal and vertical scaling always move the same points in the same way. Critique the claim using an equation/point example.
