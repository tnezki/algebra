SYSTEM LESSONS
--------------
- Numbered Example/YTI quality must be audited as paired evidence jobs, not as two individually valid questions; valid items can still form a structurally invalid pair.
- “Many rows” is not abundance when several forms recycle the same small instantiated seed set. Capping accidental exact reuse while preserving two purposeful parallels improves variation without creating anti-repetition quotas.
- Hidden student_text can become stale after HTML-level inequality repairs; canonical text should be regenerated from final student_html after semantic edits.
- Matching activities need answer-key collision checks, not only duplicate-prompt checks. Tarsia can contain 18 unique prompts yet remain ambiguous if answer labels repeat.
- A mathematical solve audit should accompany quality/variation work: polished wording can conceal a dependent-system / single-solution contradiction.
- Representation repairs from 3d should be treated as protected prior work; quality changes should not rebuild good figures merely to create novelty.
