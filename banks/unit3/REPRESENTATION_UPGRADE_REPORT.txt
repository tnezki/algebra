SYSTEM LESSONS FOR REVIEW
1. A broad Bank upgrade can still miss representation duplication when different filenames render identical pixels. The representation pass must compare hashes and generation signatures, not filenames alone.
2. In-place overwrite calls can make a later graph silently stop matching an earlier canonical answer. A clean one-call-per-output generation section makes source-to-byte behavior auditable.
3. Graph correctness includes visibility: a mathematically correct intersection outside the displayed window is not usable evidence for a graph-reading task.
4. For independent graph-reading items, variation should change the actual mathematical instance while preserving target, evidence job, representation type, and natural Algebra 1 values.
