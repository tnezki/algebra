SYSTEM LESSONS FOR REVIEW
-------------------------
1. Practice abundance should be judged across the complete route set, not only one form at a time. A Bank can pass every within-form duplicate check while still recycling the same seeds across all teacher-choice forms.
2. Exact repeats are most concerning when they cluster in the same conceptual slots across every Practice route. Preserve the family and learning job, but instantiate genuinely new student work.
3. Replacement values must be checked against the whole section after authoring; a value can be new relative to the item being replaced but still collide with another existing question.
4. Purposeful retrieval repetition is different from Practice seed collapse. Warm-Up recurrence should not be rewritten merely because exact instances reappear across days.
5. Representation repairs should be treated as locked unless the question-quality defect truly requires changing the representation. This pass improved abundance without disturbing any 3d figure work.
