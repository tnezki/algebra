SYSTEM LESSONS
----------------------------------------------------------------------
- Figure QA must test underlying mathematical instance/bytes, not just filenames;
  unique filenames can still hide copied content.
- Table-plus-graph tasks need same-instance synchronization across every
  representation and the answer key; an answer should not explain away a
  transformation that the table never encoded.
- Area-model prompts should ask about the singular model actually shown unless
  a second model is intentionally supplied.
- Parallel secure forms may preserve structure while still requiring distinct
  content-bearing figure instances.
- A representation-specialist pass can preserve a strong unit map while making
  substantial figure-level corrections; remapping is not required when the
  instructional architecture is already sound.
