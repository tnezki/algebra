Section 1.4

Shared stimulus

A school store models a discount expression as 3(2x - 5) + 4x + 7, where x represents the number of item groups.

\[3(2x-5)+4x+7\]
U1-S1.4-WTC-A | Intro
Identify terms, coefficients, and factors.

In the shared expression 3(2x - 5) + 4x + 7, identify the coefficient of x inside the parentheses, the outside factor, and the constant term outside the parentheses.

\[3(2x-5)+4x+7\]
Answer / solution

Coefficient 2; outside factor 3; outside constant 7.

Read each factor/term directly from the expression structure.

U1-S1.4-WTC-B | Intro
Substitute values into an expression.

Evaluate the shared expression when x = 4.

\[3(2(4)-5)+4(4)+7\]
Answer / solution

32

3(8-5)+16+7 = 9+16+7 = 32.

U1-S1.4-WTC-C | Intro
Combine like terms.

Rewrite the shared expression in simplest equivalent form.

\[3(2x-5)+4x+7\]
Answer / solution

10x - 8

Distribute: 6x-15+4x+7. Combine like terms to get 10x-8.

U1-S1.4-WTC-D | Intro
Use the distributive property correctly.

A student rewrites 3(2x - 5) + 4x + 7 as 6x - 5 + 4x + 7. Identify the error and give the corrected simplified expression.

\[3(2x-5)+4x+7\]
Answer / solution

The student failed to multiply -5 by 3; correct simplified expression is 10x - 8.

Distribute 3 to both terms: 3(2x)=6x and 3(-5)=-15. Then combine to 10x-8.

Section 1.5

Shared stimulus

A robotics club has $92 to spend after paying a fixed $20 registration fee. Each sensor kit costs the same amount, and the club wants to buy 6 sensor kits.

U1-S1.5-WTC-A | Intro
Define a variable.

For the shared robotics-club situation, define a variable for the unknown quantity.

Answer / solution

Let k = cost of one sensor kit in dollars.

The unknown repeated quantity is the cost of one kit.

U1-S1.5-WTC-B | Intro
Write an equation that matches a situation.

Write an equation that matches the shared robotics-club quantities.

\[20+6k=92\]
Answer / solution

20 + 6k = 92

The fixed fee plus six equal kit costs equals the total budget.

U1-S1.5-WTC-C | Intro
Use equivalent steps to solve when needed.

Solve the shared equation 20 + 6k = 92 using equivalent steps.

\[20+6k=92\]
Answer / solution

k = 12

Subtract 20 to get 6k=72, then divide by 6 to get k=12.

U1-S1.5-WTC-D | Intro
Check and interpret a solution in context.

Check k = 12 in the shared situation and explain what the solution means.

\[20+6(12)=92\]
Answer / solution

The check is 20 + 6(12) = 92; each sensor kit costs $12.

Substituting 12 gives the correct total budget, so the solution is valid and represents the price of one kit.
