Give one piece of table evidence that distinguishes B from C.

Answer / solution

B has square-number growth; C doubles each step.

The B column has changing additive differences but matches x squared, while C has a constant multiplicative factor of 2.

U1-S1.3-WTC-D |
Explain why one family is more likely than another.

Why is A more likely linear than exponential?

Answer / solution

A changes by a constant difference rather than a constant factor.

A adds 2 each step. Exponential patterns use a constant multiplication factor instead.

Section 1.4

Shared stimulus

Use the same expression for all four parts.

\[3(2x-5)+4x+7\]
U1-S1.4-WTC-A |
Identify terms, coefficients, and factors.

Identify the coefficient of x inside the parentheses and the factor multiplying the parentheses.

Answer / solution

Coefficient 2; factor 3.

Inside the group, 2 multiplies x. Outside the group, 3 multiplies the entire quantity.

U1-S1.4-WTC-B |
Substitute values into an expression.

Evaluate the expression when \(x=2\).

Answer / solution

12

3(2(2)-5)+4(2)+7 = 3(-1)+8+7 = 12.

U1-S1.4-WTC-C |
Combine like terms.

After distributing, which terms are like terms and can be combined?

Answer / solution

6x and 4x; -15 and 7.

Distributing gives 6x - 15 + 4x + 7. The variable terms combine with each other, and the constants combine with each other.

U1-S1.4-WTC-D |
Use the distributive property correctly.

Use the distributive property and simplify the expression.

Answer / solution

10x - 8

3(2x-5)=6x-15. Then 6x+4x=10x and -15+7=-8.

Section 1.5

Shared stimulus

The club charges $8 to join and $3 for each event. A student has paid $29 total.

U1-S1.5-WTC-A |
Define a variable.

Define a variable for the number of events attended.

Answer / solution

Let e = number of events attended.

The unknown quantity is the number of events, so e is a clear variable.

U1-S1.5-WTC-B |
Write an equation that matches a situation.

Write an equation that matches the total cost situation.

Answer / solution

8 + 3e = 29

The fixed $8 fee plus $3 per event equals the $29 total.

U1-S1.5-WTC-C |
Use equivalent steps to solve when needed.

Solve the equation for the number of events.

Answer / solution

\(e=7\)

Subtract 8 to get 3e = 21, then divide by 3 to get \(e=7\).

U1-S1.5-WTC-D |
Check and interpret a solution in context.

Check the solution and interpret it in the situation.

Answer / solution

7 events.

8 + 3(7) = 29, so the solution checks. The student attended 7 events.
