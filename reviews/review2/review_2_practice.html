Unit 2 Review Practice

Open-response practice organized by your Unit 2 Mastery Goals.

Read and Create Graphs · U2-MG01

1. Plot the points $(-2,5)$ and $(2,1)$ on a coordinate plane. Draw the line through them, identify the $y$-intercept, and explain how the coordinates show the direction of the line.

2. A line crosses the $y$-axis at $4$ and contains the point $(3,-2)$. Determine the slope, sketch the graph, and identify one more lattice point on the line.

3. A graph uses a horizontal scale of 1 and a vertical scale of 5. The line passes through $(0,10)$ and $(2,0)$. Find the rate of change and explain why reading the scale correctly matters.

4. A distance-time graph contains the points $(0,6)$ and $(4,18)$. Graph the relationship, identify the vertical-axis intercept, and explain what both coordinates of $(4,18)$ mean.

Build and Extend Rules · U2-MG02

1. A pattern has outputs 3, 7, 11, 15 for inputs 0, 1, 2, 3. Write a verbal rule and a symbolic rule, then predict the output for input 8.

2. The rule is $y=-3x+10$. Build a table for inputs $-1,0,2,5$ and write the resulting ordered pairs.

3. A machine starts with 12 items and adds 5 items each cycle. Represent cycles 0 through 3 in a table, write a rule, and find the number of items after 7 cycles.

4. The ordered pairs $(0,-4)$, $(2,2)$, and $(5,11)$ follow one linear rule. Determine the rule and find the input that produces an output of 20.

Represent Linear Change · U2-MG03

1. A table contains $(0,7),(2,13),(4,19),(6,25)$. Determine the constant rate and starting value, write an equation, and explain how the table shows both features.

2. A line has slope $-2$ and $y$-intercept $5$. Write its equation, create a small table, and explain how the outputs change as $x$ increases.

3. A quantity begins at 30 and decreases by 4 each minute. Write an equation, predict the value after 6 minutes, and interpret the slope in context.

4. Decide whether the outputs 5, 9, 14, 17 for inputs 0, 1, 2, 3 show constant rate of change. Support your conclusion with numerical evidence.

Compare Relationships · U2-MG04

1. Relationship A is $y=3x+2$. Relationship B has outputs 8, 12, 16 for inputs 0, 2, 4. Compare their rates and starting values, then decide which has the greater output at $x=6$.

2. Plan A costs 15 dollars plus 4 dollars per visit. Plan B costs 7 dollars plus 6 dollars per visit. Compare the plans at 2 visits and 8 visits, then explain why the better choice changes.

3. Two graphs use different axis scales. Explain what numerical features you must calculate before deciding which relationship grows faster.

4. Relationship A starts at 20 and changes by $-1.5$ per unit. Relationship B starts at 8 and changes by $0.5$ per unit. Find when their outputs are equal and use that value to compare the relationships.
