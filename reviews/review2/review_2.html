U2-MG01

Read and Create Graphs

Interpret and create coordinate-plane graphs, including ordered pairs, axes, scales, and intercepts, in mathematical and contextual situations.

I Can Checklist

  • I can construct coordinate graphs that connect points, axes, and intercepts to a situation.
  • I can apply coordinate plane information to interpret locations, trends, and key graph features.
  • I can determine whether a graph feature makes sense for the situation it represents.

Summary

  • Use coordinates, scale, intercepts, and plotted points to read or create a graph that matches the situation.

Useful Representations

  • Coordinate plane graphs
  • Ordered pairs
  • Axis labels and scales
  • Intercepts
  • Contextual graph features

Common Traps

  • Uses a procedure without checking meaning or equivalence.
  • Produces a result that is not connected back to the original representation or context.

U2-MG03

Represent Linear Change

Recognize constant rate of change and represent linear relationships with tables, graphs, equations, slope, and starting value.

I Can Checklist

  • I can design tables and graphs that display constant rate of change.
  • I can extend linear patterns using repeated equal change.
  • I can assess whether a table, graph, or situation has a constant rate of change.
  • I can construct linear relationships from tables, graphs, equations, and contexts.
  • I can apply slope and starting value information to write a linear equation.
  • I can use multiple representations to predict values in a linear situation.

Summary

  • Track constant rate and starting value across tables, graphs, equations, and contexts.

Useful Representations

  • Tables with equal input steps
  • Linear graphs
  • Visual patterns
  • Rates of change
  • Contextual change statements

Common Traps

  • Uses a procedure without checking meaning or equivalence.
  • Produces a result that is not connected back to the original representation or context.

U2-MG04

Compare Relationships

Compare relationships across equations, graphs, tables, visual patterns, and contexts and justify conclusions with representation evidence.

I Can Checklist

  • I can build organized comparisons across equations, graphs, tables, visual patterns, and contexts.
  • I can predict which relationship has greater values or faster change using representation evidence.
  • I can critique conclusions about relationships using features from more than one representation.

Summary

  • Translate different representations into comparable features, then justify conclusions with rate, starting value, and output evidence.

Useful Representations

  • Equations
  • Graphs
  • Tables
  • Visual patterns
  • Context comparisons

Common Traps

  • Uses a procedure without checking meaning or equivalence.
  • Produces a result that is not connected back to the original representation or context.
