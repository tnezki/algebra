Rules, Forms & Relationships

The structures Unit 0B expects you to use

Use these relationships only in the situations where their structure applies. The section review below shows how they connect to representations and contexts.

Ordered pairs

$(x,y)$

The first coordinate is horizontal/input information; the second is vertical/output information.

Vertical intercept

$(0,b)$

At a vertical intercept, the input is 0. In a linear model, this is the starting value.

Rate of change

$m=\frac{\Delta y}{\Delta x}$

Compare output change to input change using consistent intervals and units.

Linear relationship

$y=mx+b$

The slope $m$ gives repeated change and $b$ gives the starting value.

Constant rate test

$\frac{\Delta y}{\Delta x}=\text{constant}$

A linear pattern has the same rate when equal input intervals are compared.

Compare linear models

$m\;\text{and}\;b$

Use both rate and starting value when comparing two linear relationships; one feature alone may be misleading.

Section 0B.1

Coordinate Plane and Graph Interpretation

↑ Top
Learning Target

Students will interpret and create graphs on the coordinate plane while connecting points, axes, intercepts, and graphical information to mathematical situations.

I can…

  • I can construct coordinate graphs that connect points, axes, and intercepts to a situation.
  • I can apply coordinate plane information to interpret locations, trends, and key graph features.
  • I can determine whether a graph feature makes sense for the situation it represents.

Summary

  • Ordered pairs connect horizontal and vertical coordinates to locations on the coordinate plane.
  • Axes, scale, and labels determine what a graph communicates; read them before interpreting points.
  • Intercepts occur where a graph crosses an axis and often represent meaningful starting or boundary information.
  • A graph feature should be checked against the context instead of interpreted only from appearance.

Common traps to avoid

Reversing coordinates

The first coordinate gives the horizontal position and the second gives the vertical position.

Ignoring the scale

Equal-looking spaces may represent different numerical intervals when scales change.

Calling every axis crossing the same intercept

An $x$-intercept has $y=0$; a $y$-intercept has $x=0$.

Reading a graph without context

A mathematically visible feature may not be meaningful for the situation.

Section 0B.2

Patterns and Input-Output Rules

↑ Top
Learning Target

Students will identify patterns and represent relationships using input-output rules, tables, words, and symbols.

I can…

  • I can formulate input-output rules from tables, words, and symbols.
  • I can use a rule to predict outputs and extend a pattern.
  • I can build tables that organize inputs, outputs, and repeated change.

Summary

  • An input-output rule describes how each input is changed to produce an output.
  • Tables organize inputs and outputs so repeated patterns are easier to see.
  • A rule can be expressed in words, symbols, ordered pairs, or a pattern diagram.
  • Use a rule to extend a pattern and then check predicted outputs against known values.
Key representations:Input-output tablesVerbal rulesSymbolic rulesPattern diagramsOrdered pairs

Common traps to avoid

Switching input and output

Decide which quantity is chosen first and which depends on it.

Extending a pattern from too little evidence

Check more than one input-output pair before committing to a rule.

Treating the starting value as the repeated change

The output at input 0 and the amount added each step have different roles.

Using a rule without checking it

Substitute known inputs to verify the rule reproduces the table.

Section 0B.3

Linear Patterns and Rate of Change

↑ Top
Learning Target

Students will recognize constant rate of change in tables, graphs, visual patterns, and situations.

I can…

  • I can design tables and graphs that display constant rate of change.
  • I can extend linear patterns using repeated equal change.
  • I can assess whether a table, graph, or situation has a constant rate of change.

Summary

  • A linear pattern has a constant rate of change when equal input steps produce proportional equal output change.
  • Rate of change can be positive, negative, or zero depending on the direction of the pattern.
  • Tables, graphs, visual patterns, and situations can all show the same repeated change.
  • Do not claim a rate is constant until equal input intervals have been compared.
Key representations:Tables with equal input stepsLinear graphsVisual patternsRates of changeContextual change statements

Common traps to avoid

Comparing unequal input steps as though they were equal

Rate requires change per unit or a consistent ratio of changes.

Assuming increasing values automatically mean constant rate

Linear change must repeat at the same rate.

Losing the sign of a decreasing rate

Downward change should be represented with a negative rate when direction matters.

Using only graph appearance

Confirm constant rate with coordinates, a table, or a context statement.

Section 0B.4

Writing Linear Relationships

↑ Top
Learning Target

Students will represent linear relationships using tables, graphs, equations, and contextual descriptions.

I can…

  • I can construct linear relationships from tables, graphs, equations, and contexts.
  • I can apply slope and starting value information to write a linear equation.
  • I can use multiple representations to predict values in a linear situation.

Summary

  • A linear relationship can be represented by a table, graph, equation, and context that all share the same starting value and rate.
  • In $y=mx+b$, $m$ represents rate of change and $b$ represents the output when the input is zero.
  • Use a graph or table to verify that an equation generates matching values.
  • Linear rules can be extended to predict values within a meaningful range of the situation.

Common traps to avoid

Swapping slope and starting value

In $y=mx+b$, $m$ multiplies the input and $b$ is the output at $x=0$.

Writing an equation from one point

A linear rule needs enough information to determine both rate and starting value.

Predicting outside a meaningful context without checking

Algebra may extend indefinitely even when the situation does not.

Letting representations disagree

A table, graph, equation, and context for one relationship must generate the same values.

Section 0B.5

Comparing Representations

↑ Top
Learning Target

Students will compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

I can…

  • I can build organized comparisons across equations, graphs, tables, visual patterns, and contexts.
  • I can predict which relationship has greater values or faster change using representation evidence.
  • I can critique conclusions about relationships using features from more than one representation.

Summary

  • Comparisons are strongest when they use more than one feature, such as starting value and rate of change.
  • A relationship can start higher but change more slowly, so “greater now” and “growing faster” are different claims.
  • Equations, tables, graphs, patterns, and contexts should tell a consistent story about the same quantities.
  • Critique a comparison by pointing to specific representation evidence rather than relying on visual impression alone.
Key representations:EquationsGraphsTablesVisual patternsContext comparisons

Common traps to avoid

Comparing only starting values

A higher start does not mean a faster rate of change.

Comparing only slopes

Two relationships with different starts can cross, so the input matters.

Ignoring different graph scales

Visual steepness is unreliable when axes use different units or intervals.

Making a claim from one representation when another contradicts it

Use multiple pieces of evidence before concluding.
