Section Review
Section 1.1

Multiple Representations of Relationships

↑ Top
Learning Target

Students will connect tables, graphs, equations, and contexts that represent the same relationship.

I-can checklist

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

What to remember

  • A relationship can be shown with a table, graph, equation or rule, or verbal context.
  • Equivalent representations preserve the same input-output pairs and the same underlying relationship.
  • Use actual values, rates, and patterns—not just visual appearance—to decide whether representations match.

Check that the equation and table generate the same ordered pairs before calling them equivalent.

Common traps

Appearance is not enough

Two representations can look similar while using different scales or values.

Preserve the relationship

When you change forms, the ordered pairs and relationship must stay consistent.

Section 1.2

Inputs, Outputs, and Functions

↑ Top
Learning Target

Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

I-can checklist

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.

What to remember

  • A function acts like a rule: each allowed input is connected to one output.
  • Use the rule to generate missing outputs and ordered pairs.
  • A repeated input connected to two different outputs is a warning that the relationship is not a function.
Vocabulary:inputoutputfunctionordered pairmapping diagram

Rule → values → ordered pairs

$y=3x-2$
Input $x$Output $y$Ordered pair
0-2$(0,-2)$
24$(2,4)$

Apply the same rule consistently to every input.

Common traps

Input vs. output

Keep the direction of the rule clear; do not reverse the quantities.

Function test

One input cannot be assigned two different outputs in the same function.

Section 1.3

Function Families

↑ Top
Learning Target

Students will recognize common function families from graphs, tables, equations, and contexts.

I-can checklist

  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

What to remember

  • Use more than graph appearance when classifying a function family.
  • Look for evidence in table patterns, graph shape, rate of change, and equation structure.
  • Linear, quadratic, exponential, and absolute value relationships have different structures that should agree across representations.
Vocabulary:linearquadraticexponentialabsolute valuefunction family

Equation structure clues

$y=3x+1$   ·   $y=x^2$
$y=2^x$   ·   $y=|x|$

These examples represent linear, quadratic, exponential, and absolute value families.

Common traps

Do not classify by shape alone

Check table patterns or equation structure before deciding.

Quadratic vs. exponential

Both can grow quickly; use structural evidence rather than growth alone.

Section 1.4

Expressions and Structure

↑ Top
Learning Target

Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

I-can checklist

  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

What to remember

  • Equivalent expressions have the same value even when they look different.
  • Use grouping, factors, and properties of operations to rewrite without changing value.
  • Substitution can be used as a check on an equivalent-form claim.
Vocabulary:termcoefficientfactorequivalent expressiondistributive property

Rewrite, then verify

$3(x+2)=3x+6$

At $x=4$, both forms equal $18$. Structure creates the rewrite; substitution checks it.

Common traps

Unlike terms stay unlike

Do not combine terms unless their variable structure matches.

Distribute to every term

A factor outside parentheses multiplies every term inside.

Section 1.5

Equations as Models

↑ Top
Learning Target

Students will write, solve, and interpret equations that model situations.

I-can checklist

  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.

What to remember

  • Choose variables that represent quantities in the situation and build an equation that preserves the relationships among them.
  • Use balanced solution steps and inverse operations when solving.
  • A numerical answer is not finished until it is interpreted in the original context and checked for reasonableness.
Vocabulary:variableequationsolutioninverse operationcontextual quantity

Context → equation

A taxi charges a \$5 starting fee and \$3 per mile.

$C=5+3m$

$m$ represents miles and $C$ represents total cost. The quantities give meaning to the equation.

Common traps

Keep equations balanced

An operation used to solve must preserve equality.

Interpret the result

Include the meaning and units of a solution, not just the number.

DOK Perspective

Think about depth, not a proficiency ladder

The canonical companion Review Practice items are primarily tagged DOK 1–2. Deeper reasoning appears when you justify, critique, connect representations, or defend whether a model or classification makes sense.

DOK 1

Recall / straightforward use

  • Identify a function family from a clear equation.
  • Apply a rule to generate an output.
  • Recognize terms, factors, or equation parts.
DOK 2

Connect / represent / verify

  • Move between a rule and an input-output table.
  • Rewrite and verify an equivalent expression.
  • Build an equation from a situation and explain quantity meanings.
DOK 3

Justify / critique

  • Defend whether two representations show the same relationship.
  • Critique a function-family choice using multiple pieces of evidence.
  • Evaluate whether a model or solution is reasonable in context.
DOK 4

Not a forced quota

Extended investigation can reach DOK 4, but a conventional review does not need artificial DOK 4 work just to fill a category.

Final Check

Before you call yourself ready

Represent

  • I can move among tables, graphs, equations, rules, and contexts.
  • I preserve the same relationship when I change representations.

Reason

  • I can explain why a function/family/equivalent-form claim is supported.
  • I can catch common structure and interpretation mistakes.

Model

  • I can write an equation for a situation.
  • I can connect a solution back to quantities, units, and reasonableness.
