Rules & Structures

Core Structures

Systems

A solution must satisfy both equations or inequalities.

Elimination

Combine equivalent equations to remove one variable.

Substitution

Replace a variable with an equal expression.

Inequalities

Boundary type and shading communicate which points satisfy the constraint.

Mastery Focus

Representations & Evidence

Mastery Goal: Connect tables, graphs, equations, and contexts that represent the same relationship and use evidence to determine whether representations agree.
  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.
Mastery Focus

Functions & Family Evidence

Mastery Goal: Interpret functions through inputs, outputs, rules, and family features, and distinguish common function families using representation evidence.
  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.
  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.
Mastery Focus

Expression Structure

Mastery Goal: Interpret and rewrite algebraic expressions by using structure, grouping, properties, substitution, and equivalent forms.
  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.
Mastery Focus

Equations & Context

Mastery Goal: Write, solve, and interpret equations that model situations and judge whether solutions are reasonable in context.
  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.
DOK Perspective

What the Thinking Can Look Like

DOK 1

Identify a solution, boundary type, or algebraic feature.

DOK 2

Solve, graph, compare methods, or use a test point.

DOK 3

Justify a method, critique a graph, or interpret a feasible region in context.

Final Check

Before the Assessment

Can I solve and check systems?

Use graphing, elimination, or substitution and interpret the ordered pair or solution type.

Can I represent constraints?

Use correct boundaries, shading, and overlap to identify feasible solutions.

Can I explain evidence?

Connect representations and context meaning instead of reporting an answer only.
