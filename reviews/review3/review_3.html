Review Focus 1

Rate of Change and Slope

Back to top
Review Target

Students will interpret slope as a measure of constant rate of change.

I can...

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

What to remember

  • Slope triangles on coordinate graphs
  • Tables showing equal input intervals
  • Contextual rate statements
  • Ratio notation for vertical change over horizontal change
  • Positive, negative, zero, and undefined slope examples
Key words:sloperate of changerise/runpositive/negative/zero/undefined slope

Representation focus

Slope triangles on coordinate graphs; Tables showing equal input intervals; Contextual rate statements; Ratio notation for vertical change over horizontal change

Common traps

Common trap

Reversing vertical and horizontal change or using inconsistent point order.

Common trap

Interpreting slope as a starting value rather than a rate.
