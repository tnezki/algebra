At a Glance

What connects all four days?

A linear relationship changes by the same amount for every equal input step. You can see that pattern in a story, table, graph, or equation. The slope tells how much and which way it changes; the starting value tells what happens when the input is zero.

Vocabulary

Words worth knowing

Function · Each input has exactly one output.
Domain · All distinct input values.
Range · All distinct output values.
Linear relationship · Constant rate of change; straight-line graph.
Horizontal change (Δx) · Change in input values.
Vertical change (Δy) · Change in output values.
Slope (m) · Vertical change divided by horizontal change.
Rate of change · Output change per input change; include units.
Positive / negative slope · Outputs rise / fall as inputs increase.
Starting value (b) · Output when input is zero.
Linear model · An equation, table, or graph representing constant change.
Domain restriction · Inputs that make sense for the situation.
Rules & Structures

Four checks you can use

1 · Check the function

\(\text{one input}\;\longrightarrow\;\text{one output}\)

A repeated input is fine if its output is unchanged. A repeated input with different outputs is not a function.

2 · Find slope

\(m=\frac{\Delta y}{\Delta x}=\frac{y_2-y_1}{x_2-x_1}\)

Use the same point order in the numerator and denominator. For a table, compare equal input intervals.

3 · Write the model

\(y=mx+b\)

The slope is \(m\); the starting value is \(b\). If \(b\) is not given, use a known point and \(b=y-mx\).

4 · Check meaning

\(\text{units}\;\cdot\;\text{sign}\;\cdot\;\text{prediction}\)

Interpret the sign and units, substitute a point to check your equation, and ask whether the input is sensible in context.
