Rules & Structures

Order of operations

Group → exponents → multiply/divide → add/subtract, working left to right within each level.

Signed-number check

Track the operation and sign separately; estimate the sign and size before finalizing.

Distributive property

$a(b+c)=ab+ac$ and $a(b-c)=ab-ac$.

Equation balance

Apply the same valid operation to both sides until the variable is isolated.

Inequality direction

Reverse $\lt ,\gt ,\le,\ge$ only when multiplying or dividing both sides by a negative number.

Boundary graph

Use an open circle for $\lt $ or $\gt $ and a closed circle for $\le$ or $\ge$.
Mastery Focus

Rational Numbers & Expression Evaluation

↑ Top

Mastery Goal: Compute with rational numbers and evaluate numerical or algebraic expressions accurately, using order of operations and substitution while checking reasonableness.

I can...

  • I can construct accurate rational number computations using integers, fractions, and decimals in mathematical and contextual situations.
  • I can apply operation rules to calculate sums, differences, products, and quotients with rational numbers.
  • I can assess whether rational number results are reasonable for the situation they represent.
  • I can formulate a clear sequence of steps for evaluating numerical and algebraic expressions.
  • I can use substitution and order of operations to calculate expression values accurately.
  • I can determine whether an expression value makes sense after substitution.

What to remember

Compute carefully with signed, fractional, and decimal values; then evaluate expressions by substituting first and following the order of operations. Check whether the result is reasonable in the original setting.

Useful representations

Integer expressions, Fraction operations, Decimal operations, Number line models, Contextual quantities

Common traps

  • Ignoring a negative sign when combining values.
  • Substituting without parentheses when the input is negative.
  • Skipping a reasonableness check in context.

Equivalent Expressions & Structure

↑ Top

Mastery Goal: Rewrite algebraic expressions into equivalent forms by using properties, structure, terms, factors, and the distributive property.

I can...

  • I can build equivalent algebraic expressions using properties of operations and structure.
  • I can extend expression work by rewriting terms, factors, and sums into useful equivalent forms.
  • I can critique whether two rewritten expressions preserve the same value for all valid inputs.

What to remember

Equivalent expressions may look different while keeping the same value. Use the distributive property, combine like terms, factor common factors, and use substitution or structure to verify equivalence.

Useful representations

Equivalent expressions, Terms and coefficients, Factors and products, Distributive property structures, Algebra tiles or area models

Common traps

  • Distributing to only one term.
  • Combining terms that are not like terms.
  • Assuming two forms are equivalent without a structural or substitution check.

Solving & Checking Equations

↑ Top

Mastery Goal: Solve one-variable equations with equivalent transformations and verify and interpret solutions.

I can...

  • I can design a balanced equation-solving pathway that keeps both sides equivalent.
  • I can use inverse operations to solve one-variable equations accurately.
  • I can assess whether a solution satisfies the original equation and fits the context.

What to remember

Keep an equation balanced by applying equivalent transformations to both sides. Use inverse operations strategically, then substitute the solution into the original equation and interpret it when a context is present.

Useful representations

One-variable equations, Balance models, Inverse operations, Solution checks, Contextual equations

Common traps

  • Changing only one side of the equation.
  • Using an inverse operation inconsistently.
  • Reporting a number without checking or interpreting it.

Inequalities & Number-Line Solutions

↑ Top

Mastery Goal: Solve one-variable inequalities, represent solution sets on number lines, and interpret boundaries and constraints.

I can...

  • I can construct inequality models for situations with more than one possible solution.
  • I can apply inverse operations to solve inequalities and account for direction changes when needed.
  • I can extend solutions by representing and interpreting solution sets on a number line.

What to remember

Solve inequalities with the same balance ideas used for equations, but reverse the inequality symbol when multiplying or dividing by a negative number. Represent the full solution set with the correct open or closed boundary.

Useful representations

One-variable inequalities, Number line graphs, Open and closed circles, Solution set notation, Contextual constraints

Common traps

  • Forgetting to reverse the inequality after multiplying or dividing by a negative.
  • Using a closed circle for a strict inequality.
  • Treating one test value as the entire solution set.
