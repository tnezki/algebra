What this Unit Review is about

Rules & Structures

Keep these structures ready

Order of operations

Group → Exponents → Multiply/Divide → Add/Subtract

Preserve grouping and substitution before simplifying.

Distributive property

$a(b+c)=ab+ac$

Distribute to every term inside the grouping.

Equation balance

same operation on both sides

Equivalent transformations preserve equality.

Inequality reversal

multiply/divide by a negative → reverse the inequality sign

Then interpret and graph the complete solution set.

Check the meaning: A correct symbolic result still needs to fit the original expression, equation, inequality, or context.
Mastery Goal 1

Rational Numbers & Expressions

Back to top
Mastery Goal

Compute with rational numbers and evaluate numerical or algebraic expressions accurately, using order of operations and substitution while checking reasonableness.

I can...

  • I can construct accurate rational number computations using integers, fractions, and decimals in mathematical and contextual situations.
  • I can apply operation rules to calculate sums, differences, products, and quotients with rational numbers.
  • I can assess whether rational number results are reasonable for the situation they represent.
  • I can formulate a clear sequence of steps for evaluating numerical and algebraic expressions.
  • I can use substitution and order of operations to calculate expression values accurately.
  • I can determine whether an expression value makes sense after substitution.
Key representations: Integer expressions, Fraction operations, Decimal operations, Number line models, Contextual quantities, Numerical expressions, Algebraic expressions, Substitution tables, Operation hierarchy, Contextual expression values

Common traps

  • Uses a procedure without checking meaning or equivalence.
  • Produces a result that is not connected back to the original representation or context.

Useful habits

  • Reason quantitatively with signed and fractional values
  • Use structure and properties to preserve equivalence
  • Check solutions and interpret constraints in context

Final Check

Before you call yourself ready

Compute accurately

  • Use order of operations and substitution carefully.
  • Check rational-number signs and reasonableness.

Preserve equivalence

  • Use properties across the whole expression.
  • Apply the same valid transformation to both sides of equations.

Interpret solutions

  • Verify equation solutions.
  • Graph and interpret inequality solution sets and boundaries.
