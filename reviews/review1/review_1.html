At a Glance

Unit 1 connects four ideas that will keep returning all year: reading graphs accurately, measuring how relationships change, evaluating expressions, and using rules to connect inputs and outputs.

  • Coordinate-Plane Graphs: Use ordered pairs, axes, scales, and intercepts to read and create graphs.
  • Slope in Four Views: Find slope or rate of change from a graph, table, equation, or context.
  • Evaluate Expressions: Evaluate numerical and algebraic expressions using substitution and order of operations.
  • Input / Output Rules: Use an input-output rule to find values, ordered pairs, and patterns.

Rules & Structures

Ordered pair

$(x,y)$

Move horizontally using $x$, then vertically using $y$.

Slope

$m=\frac{\Delta y}{\Delta x}=\frac{\text{rise}}{\text{run}}$

Use two points from the same relationship and keep the subtraction order consistent.

Slope from an equation

$y=mx+b$

When an equation is in slope-intercept form, the coefficient of $x$ is the slope.

Substitution

$x=-3\Rightarrow 2x+5=2(-3)+5$

Replace the variable with the given value. Parentheses help protect negative inputs.

Order of operations

Group → powers → ×/÷ → +/−

Work left to right within multiplication/division and within addition/subtraction.

Input / output pair

$(\text{input},\text{output})$

A rule turns each input into an output. The ordered pair records both values.

Mastery Focus

Coordinate-Plane Graphs

↑ Top

Mastery Goal: Use ordered pairs, axes, scales, and intercepts to read and create graphs.

I can...

  • Plot and read ordered pairs.
  • Use the x- and y-axes correctly.
  • Read a graph using its scale.
  • Identify and interpret intercepts when they are shown.

What to remember

In an ordered pair $(x,y)$, the first coordinate tells horizontal movement and the second tells vertical movement. Before reading a point, check the axis labels and scale. An x-intercept is where a graph crosses the x-axis, so $y=0$ there. A y-intercept is where a graph crosses the y-axis, so $x=0$ there.

Useful representations

Coordinate planes, ordered pairs, labeled axes, scaled graphs, intercepts, contextual graphs

Common traps

  • Reversing the x- and y-coordinates.
  • Counting grid marks instead of reading the stated scale.
  • Calling any point on a graph an intercept.
DOK perspective

Accurately read or create a graph first; then explain what a coordinate, scale, or intercept means when a context is present.

Mastery Focus

Slope in Four Views

↑ Top

Mastery Goal: Find slope or rate of change from a graph, table, equation, or context.

I can...

  • Find slope from a graph.
  • Find slope from a table.
  • Find slope from an equation.
  • Find and interpret rate of change from a context.

What to remember

Slope measures how much $y$ changes for each 1-unit change in $x$. From a graph, use rise over run between two points. From a table, compare changes in $y$ to changes in $x$. From $y=mx+b$, slope is $m$. In a context, include units and explain what the rate means.

Useful representations

Graphs, tables, equations, ordered pairs, verbal situations, units such as miles per hour or dollars per item

Common traps

  • Using run over rise instead of rise over run.
  • Subtracting coordinates in different orders.
  • Giving a number from a context without units or meaning.
DOK perspective

Be able to calculate the same rate from different representations and explain why the values agree.

Mastery Focus

Evaluate Expressions

↑ Top

Mastery Goal: Evaluate numerical and algebraic expressions using substitution and order of operations.

I can...

  • Substitute a value for a variable.
  • Use order of operations correctly.
  • Evaluate expressions with positive and negative numbers.
  • Check whether an answer is reasonable.

What to remember

Substitute first, then simplify using the order of operations. When a substituted value is negative, place it in parentheses. Keep track of signs separately from the operation, and estimate the likely sign and size of the result before accepting an answer.

Useful representations

Numerical expressions, algebraic expressions, substitution work, calculator checks, estimates

Common traps

  • Replacing only some occurrences of a variable.
  • Forgetting parentheses around a negative input.
  • Working strictly left to right instead of following operation priority.
DOK perspective

Accurate calculation matters, but so does noticing when an answer has the wrong sign or an unreasonable size.

Mastery Focus

Input / Output Rules

↑ Top

Mastery Goal: Use an input-output rule to find values, ordered pairs, and patterns.

I can...

  • Use input/output language and ordered pairs.
  • Use a rule to find an output from an input.
  • Find a missing input or output when enough information is given.
  • Use a rule to build or extend a table.

What to remember

The input is the starting value and the output is the result after the rule is applied. Write an input-output pair as $(\text{input},\text{output})$. To find a missing output, apply the rule. To find a missing input, reason backward from the known output. A table should follow the same rule in every row.

Useful representations

Input-output tables, ordered pairs, rules, arrows, patterns, simple equations

Common traps

  • Writing ordered pairs in output-input order.
  • Applying the rule inconsistently from one row to the next.
  • Guessing a missing value without checking it against the rule.
DOK perspective

Move flexibly among the rule, a table, and ordered pairs while keeping the input-output relationship consistent.

DOK Perspective

1

Recall & Execute

Read a point, calculate a slope, substitute a value, or apply an input-output rule accurately.

2

Connect & Explain

Choose information from a graph, table, equation, or context and explain the strategy or meaning.

3

Reason & Critique

Analyze an error, defend whether a result is reasonable, or connect multiple representations of the same relationship.

Final Check

  • Can I read and create coordinate-plane graphs using the correct axes and scale?
  • Can I identify and interpret x- and y-intercepts when they are shown?
  • Can I find slope from a graph, table, equation, and context?
  • Can I substitute values and evaluate expressions with correct operation order and signs?
  • Can I use an input-output rule forward and backward and represent the result as a table or ordered pair?
