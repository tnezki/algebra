Mastery Goal 1

Solve & Interpret Systems

Back to top
Mastery Goal

Solve systems of linear equations graphically and algebraically, choose efficient methods, and interpret one, none, or infinitely many solutions.

I can...

  • I can construct graphical representations of systems and connect intersection points to solutions.
  • I can use elimination to solve systems and interpret the solution type.
  • I can determine whether a system has one solution, no solution, or infinitely many solutions from algebraic and graphical evidence.
  • I can formulate a substitution plan when one equation is already written in an efficient form.
  • I can apply substitution to solve systems and interpret the ordered-pair solution.
  • I can assess which algebraic method is more efficient for a given system.

What to remember

  • A system solution must satisfy both equations.
  • Choose substitution when a variable is already isolated or easy to isolate.
  • Choose elimination when coefficients make cancellation efficient.
  • Parallel distinct lines have no solution; the same line has infinitely many solutions.
Key words:systemintersectionsubstitutioneliminationsolution type

Mastery Goal 2

Model Two Constraints

Back to top
Review Target

Write and solve systems that model two constraints in a situation, define variables, and interpret the ordered-pair solution.

I can...

  • I can build a system of equations that represents two constraints in a situation.
  • I can predict the meaning of a solution before solving from the context and variables.
  • I can design a solution pathway that connects equations, calculations, and a contextual conclusion.

What to remember

  • Define variables before writing equations.
  • Each equation should represent a different constraint from the situation.
  • Solve the system, then interpret the ordered pair using units and context.
  • Check that the solution makes sense in both constraints.

Mastery Goal 3

Graph Linear Inequalities

Back to top
Review Target

Graph linear inequalities with correct boundary lines and shading and use test points to interpret solution regions.

I can...

  • I can construct a boundary line and shaded region for a linear inequality.
  • I can use test points to interpret which region satisfies an inequality.
  • I can critique a graph of a linear inequality using the boundary, shading, and solution region.

What to remember

  • Use a solid boundary for ≤ or ≥ and a dashed boundary for < or >.
  • Graph the boundary line accurately before shading.
  • Use a test point to decide which side satisfies the inequality.
  • A point in the shaded region is a solution to the inequality.
Key words:inequalityboundarytest pointhalf-planesolution region

Rate from two points

$m=\dfrac{\Delta y}{\Delta x}=\dfrac{y_2-y_1}{x_2-x_1}$

For $(2,3)$ and $(6,11)$: $m=\dfrac{11-3}{6-2}=2$.

Common traps

Watch for this

Using a solid boundary for a strict inequality or dashed boundary for an inclusive inequality.

Watch for this

Shading by memorized direction instead of testing a point.

Mastery Goal 4

Reason About Feasible Regions

Back to top
Review Target

Represent systems of linear inequalities, identify feasible regions, and interpret feasible and non-feasible solutions in context.

I can...

  • I can formulate a system of inequalities that represents multiple constraints.
  • I can extend graphing strategies to represent overlapping solution regions.
  • I can apply feasible-region reasoning to interpret possible solutions in context.

What to remember

  • A feasible region is the overlap satisfying every inequality.
  • A point is feasible only if it satisfies all constraints.
  • Boundary inclusion depends on each inequality symbol.
  • Interpret feasible and non-feasible points in the original context.
Key words:system of inequalitiesfeasible regionoverlapconstraintfeasible point

Same rate, different start

$A: y=2x+1$    $B: y=2x-4$

Both have rate 2. Their y-intercepts are 1 and -4, so the graphs are parallel distinct lines.

Common traps

Watch for this

Treating any point satisfying one inequality as feasible for the system.

Watch for this

Overlooking that the feasible region is the overlap of all constraints.

Depth of thinking

DOK perspective

DOK describes the kind of thinking a task asks for. It is not a proficiency score.

DOK 1 · Recall / Execute

Read or calculate

  • Name coordinates or intercepts.
  • Evaluate a rule.
  • Compute a straightforward rate.
DOK 2 · Connect / Represent

Use relationships among ideas

  • Translate a table into a rule.
  • Compare rates or starting values.
  • Write a linear equation from another representation.
DOK 3 · Reason / Justify

Defend a conclusion

  • Use multiple features to support a comparison.
  • Critique a rule or model using evidence.
  • Explain why representations do or do not match.
Extended thinking

Only when the task genuinely requires it

  • Collect or analyze richer data over time.
  • Build, test, and revise a model across several connected steps.
Final check

Before you call yourself ready

Without notes

  • I can solve systems by substitution or elimination and interpret the solution type.
  • I can write a system from two contextual constraints and interpret the ordered pair.
  • I can graph a linear inequality using the correct boundary and test-point shading.
  • I can identify and interpret the feasible region of a system of inequalities.

Across representations

  • Move among tables, words, symbols, and graphs.
  • Compare two relationships using the same features.
  • Write a linear equation from evidence.

Explain your thinking

  • Use values or features as evidence.
  • Attach units or context when appropriate.
  • Check that your answer matches the original relationship.
