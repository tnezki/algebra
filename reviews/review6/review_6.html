Function-family evidence

Transformation form

$y=a\,f(b(x-h))+k$

Interpret parameters through the function family and the direction/scale of the transformation.

Quadratic structure

$y=a(x-r_1)(x-r_2)$   or   $y=a(x-h)^2+k$

Equivalent forms reveal intercepts, vertex, symmetry, and opening in different ways.

Mastery Focus 1

Recognize Function Families

Back to top
Mastery Goal

Identify common function families using evidence from graphs, equations, tables, contexts, and key features.

I can...

  • I can construct evidence for a function family using patterns in graphs, equations, tables, and contexts.
  • I can apply family features to sort representations into linear, quadratic, exponential, absolute value, and other familiar forms.
  • I can determine which representation gives the strongest evidence for a function family when features seem similar.

What to remember

  • Use rate patterns, second differences, multiplicative change, graph shape, and equation structure as evidence.
  • Do not classify a function from appearance alone; verify with another feature or representation.
Key words:linearquadraticexponentialabsolute valuerate patternkey feature

Mastery Focus 2

Transform Parent Functions

Back to top
Mastery Goal

Represent translations, stretches, compressions, and reflections of parent functions across graphs, equations, tables, and key points.

I can...

  • I can build translated graphs by moving key points and key features from a parent function.
  • I can use horizontal and vertical shifts to write equations for translated functions.
  • I can predict how changing values in an equation moves a graph left, right, up, or down.
  • I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.
  • I can apply transformation rules to key points and features across function families.
  • I can assess whether an equation, graph, or table represents the same transformed function.

What to remember

  • Track key points and defining features before and after a transformation.
  • Connect equation parameters to horizontal/vertical shifts, reflections, stretches, and compressions.

Mastery Focus 3

Operate with Polynomials

Back to top
Mastery Goal

Add, subtract, and multiply polynomial expressions using structure, like terms, equivalent forms, and area-based representations.

I can...

  • I can formulate polynomial sums, differences, and products from area, perimeter, and expression contexts.
  • I can use structure and like terms to add, subtract, and multiply polynomial expressions.

Mastery Focus 4

Connect Structure to Graphs

Back to top
Mastery Goal

Connect polynomial and quadratic expression structure to graph features such as vertex, intercepts, symmetry, and direction of opening.

I can...

  • I can construct connections between polynomial structure, quadratic graphs, and key features.
  • I can predict graph features from equivalent quadratic expressions.
  • I can critique whether a polynomial expression supports a claimed vertex, intercept, axis of symmetry, or direction of opening.

What to remember

  • Use equivalent quadratic forms to reveal different graph features.
  • Connect factors to intercepts, vertex form to vertex/symmetry, and leading coefficient to opening/scale.

Depth of thinking

DOK perspective

DOK describes the kind of thinking a task asks for. It is not a proficiency score.

DOK 1 · Recall / Execute

Read or calculate

  • Identify a family feature or transformation parameter.
  • Combine like terms or read a graph feature.
DOK 2 · Connect / Represent

Use relationships among ideas

  • Translate between equations, graphs, and tables.
  • Apply transformations or polynomial structure across steps.
DOK 3 · Reason / Justify

Defend a conclusion

  • Critique a classification or graph-feature claim.
  • Choose the strongest representation or form and justify why.
Extended thinking

Only when the task genuinely requires it

  • Build, test, and revise a model across connected representations.
Final check

Before you call yourself ready

Without notes

  • Classify familiar function families from evidence.
  • Apply translations, stretches, compressions, and reflections.

With algebraic structure

  • Add, subtract, and multiply polynomials accurately.
  • Connect equivalent quadratic forms to graph features.

Explain your thinking

  • Use values, features, or structure as evidence.
  • Check that representations agree.
