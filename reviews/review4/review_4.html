Rules, Forms & Relationships

The structures Unit 2 expects you to use

Use these relationships only in the situations where their structure applies. The section review below shows how they connect to representations and contexts.

Slope from change

$m=\frac{\Delta y}{\Delta x}$

Slope measures vertical change per horizontal change and should be interpreted with units.

Slope from two points

$m=\frac{y_2-y_1}{x_2-x_1}$

Subtract coordinates in the same order in numerator and denominator.

Slope-intercept form

$y=mx+b$

Use $m$ for constant rate and $b$ for the output when $x=0$.

Vertical intercept

$(0,b)$

The $y$-intercept often represents an initial or fixed amount in context.

Parallel linear models

$m_1=m_2$

Equal slopes mean equal rates of change, even when starting values differ.

Linear prediction

$\hat y=mx+b$

A fitted linear model can be used to estimate outputs within a reasonable data range.

Section-by-Section Review
Section 2.1

Rate of Change and Slope

↑ Top
Learning Target

Students will interpret slope as a measure of constant rate of change.

I can…

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

Summary

  • Slope describes constant rate of change in student-friendly language: how much the output changes for each input step.
  • The main notation is $m=\frac{\Delta y}{\Delta x}$, and the order of subtraction must match in numerator and denominator.
  • A common error is deciding slope sign from where a point sits instead of from how the output changes.
  • Strong understanding means naming the rate with units and using values, graphs, or context to justify whether the slope is reasonable.
Key representations:Slope triangles on coordinate graphsTables showing equal input intervalsContextual rate statementsRatio notation for vertical change over horizontal changePositive, negative, zero, and undefined slope examples

Common traps to avoid

Subtracting in different directions

Why it is tempting: students may compute quickly from two points. What to check instead: subtract the second coordinate minus the first coordinate in both numerator and denominator.

Ignoring units

Why it is tempting: the number alone feels complete. What to check instead: state output units per input unit.

Using only steepness

Why it is tempting: a line may look steep on a scaled graph. What to check instead: use exact changes from coordinates or table values.

Confusing negative slope with negative values

Why it is tempting: negative coordinates look connected to negative slope. What to check instead: check whether outputs decrease as inputs increase.

Section 2.2

Graphing Linear Functions

↑ Top
Learning Target

Students will graph linear functions and interpret key features.

I can…

  • I can build graphs of linear functions using slope and intercept information.
  • I can use key features of a line to interpret a relationship.
  • I can extend a graph to predict outputs within a meaningful range.

Summary

  • Graphing linear functions means using slope and intercept information to build or interpret a straight-line relationship.
  • The main representation rule is $y=mx+b$: $b$ gives the starting point and $m$ gives the repeated move.
  • A common error is graphing the intercept correctly but using the slope in the wrong direction.
  • Strong understanding means using the graph, equation, and context labels together to make predictions within a meaningful range.

Common traps to avoid

Switching $m$ and $b$

Why it is tempting: both are numbers in the equation. What to check instead: identify $b$ as the output when $x=0$.

Using slope backward

Why it is tempting: rise and run both appear in a ratio. What to check instead: connect numerator to vertical change and denominator to horizontal change.

Ignoring slope sign

Why it is tempting: the fraction may look positive. What to check instead: check whether the line rises or falls left to right.

Matching by position

Why it is tempting: lists can seem organized. What to check instead: use feature evidence, not order.

Section 2.3

Writing Linear Equations

↑ Top
Learning Target

Students will write linear equations from graphs, tables, and situations.

I can…

  • I can formulate linear equations from graphs, tables, and situations.
  • I can apply slope-intercept structure to connect rate and starting value.
  • I can design equivalent equations that represent the same linear relationship.

Summary

  • Writing linear equations means turning rate and starting value information into a rule.
  • Slope-intercept form $y=mx+b$ records both features in one compact expression.
  • A common error is finding the slope correctly but using the wrong starting value.
  • Strong understanding means being able to write an equation from a graph, table, or story and explain why the pieces match.
Key representations:Slope-intercept equationsTables of input-output valuesGraphs with marked interceptsVerbal descriptions of rates and starting valuesEquivalent equation forms

Common traps to avoid

Using any two numbers as slope

Why it is tempting: nearby table values look related. What to check instead: divide output change by input change.

Forgetting to divide by input change

Why it is tempting: outputs may increase by a clear amount. What to check instead: check whether $x$ changes by 1 or by a larger step.

Reading $b$ from the wrong row

Why it is tempting: the first row feels like the start. What to check instead: use the row where $x=0$.

Rounding a graph estimate too early

Why it is tempting: points may be hard to read. What to check instead: use exact marked points when possible.

Section 2.4

Comparing Linear Representations

↑ Top
Learning Target

Students will analyze and compare linear relationships using multiple representations.

I can…

  • I can construct comparison models for linear relationships shown in different forms.
  • I can use slope and intercept information to interpret similarities and differences.
  • I can critique conclusions about linear relationships using evidence from representations.

Summary

  • Comparing linear representations means translating each relationship into common features.
  • Slope tells repeated change and intercept tells starting value, even when the relationship is shown as a table, graph, equation, or context.
  • A common error is choosing the greater starting value without checking the slope.
  • Strong understanding means supporting comparison claims with numerical evidence from each representation.
Key representations:Pairs of graphsTables with different scalesEquations in slope-intercept formContextual descriptionsFeature comparison organizers

Common traps to avoid

Comparing only one feature

Why it is tempting: one number may stand out. What to check instead: check both slope and starting value.

Ignoring negative signs

Why it is tempting: larger absolute values look like larger outputs. What to check instead: separate direction from magnitude.

Assuming cheaper stays cheaper

Why it is tempting: one tested input may be persuasive. What to check instead: test the input asked about and consider slope.

Reading table slope from adjacent outputs only

Why it is tempting: input steps may not be 1. What to check instead: divide by the input change.

Section 2.5

Linear Modeling with Data

↑ Top
Learning Target

Students will use linear models to represent and interpret real-world data.

I can…

  • I can design linear models that represent patterns in real-world data.
  • I can predict values using a linear model and interpret the result.
  • I can assess whether a linear model fits a data situation well enough for the question being asked.

Summary

  • Linear modeling with data means using a line to summarize a trend in scattered real-world points.
  • Scatter plots show association, and a line of fit gives an approximate equation for prediction and interpretation.
  • A common error is treating a line of fit like it must pass through every data point.
  • Strong understanding means making predictions, interpreting slope in context, and explaining whether the model is reasonable for the question.
Key representations:Scatter plotsLines of fitTables of real-world dataLinear model equationsResidual-style reasonableness observations

Common traps to avoid

Calling every rising pattern linear

Why it is tempting: positive association can still curve. What to check instead: check whether a straight line fits well enough.

Forcing the line through every point

Why it is tempting: equations in earlier units often matched exactly. What to check instead: remember data models are approximate.

Using an outlier to set the line

Why it is tempting: an extreme point is easy to notice. What to check instead: choose points near the middle of the trend.

Extrapolating too far

Why it is tempting: the equation continues algebraically. What to check instead: ask whether the input is near the data range.
