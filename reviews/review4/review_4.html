Rules & structures

Keep these structures ready

Slope

$m=\dfrac{y_2-y_1}{x_2-x_1}$

Use the same point order in numerator and denominator.

Slope-intercept form

$y=mx+b$

$m$ is rate of change; $b$ is the output when the input is 0.

Model check

$\text{prediction} = m(\text{input})+b$

Interpret the result and ask whether the input range and trend make the prediction defensible.

Representation check: Compare the same mathematical features across equations, graphs, tables, and contexts. Visual steepness can mislead when graph scales differ.
Mastery Focus 1

Rate of Change & Reasonableness

Back to top
Mastery Goal

Interpret slope as constant rate of change across tables, graphs, and contexts and judge whether a rate is reasonable.

I can...

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

What to remember

  • Slope is constant change in output per unit change in input. Read it from tables, graphs, equations, or contexts, keep units attached, and check whether the sign and size make sense.
  • Use a second representation, feature, unit, or verification step when it strengthens the conclusion.
Key ideas:sloperate of changeriserununitsreasonableness

Evidence to coordinate

Slope triangles on coordinate graphs; Tables showing equal input intervals; Contextual rate statements; Ratio notation for vertical change over horizontal change

Common traps

Reversing vertical and horizontal change or using inconsistent point order

Mastery Focus 3

Comparing Linear Relationships

Back to top
Mastery Goal

Compare linear relationships shown in different representations using slope, intercepts, and contextual meaning.

I can...

  • I can construct comparison models for linear relationships shown in different forms.
  • I can use slope and intercept information to interpret similarities and differences.
  • I can critique conclusions about linear relationships using evidence from representations.

What to remember

  • Compare like features across representations: rate with rate, starting value with starting value, and outputs at the same input. Check axis scales before trusting visual steepness.
  • Use a second representation, feature, unit, or verification step when it strengthens the conclusion.

Depth of thinking

DOK perspective

DOK describes the kind of thinking a task asks for. It is not a proficiency score.

DOK 1 · Recall / Execute

Read or calculate

  • Calculate a slope.
  • Identify an intercept.
  • Evaluate a linear rule.
DOK 2 · Connect / Represent

Use relationships among ideas

  • Write an equation from a graph, table, or context.
  • Compare rates and starting values.
  • Interpret model parameters.
DOK 3 · Reason / Justify

Defend a conclusion

  • Critique a comparison using scale and feature evidence.
  • Judge whether a prediction is reasonable.
  • Explain why representations do or do not match.
Extended thinking

Only when the task genuinely requires it

  • Analyze richer data over time.
  • Build, test, and revise a model across connected steps.
