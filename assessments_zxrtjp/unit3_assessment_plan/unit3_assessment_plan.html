Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section 3.1: Graphing and Elimination

Learning Target: Solve systems by graphing or elimination and interpret the type of solution.

I Can Statements

  • Find a system solution from a graph.
  • Use elimination to solve a system.
  • Check an ordered-pair solution.
  • Recognize one, none, or infinitely many solutions.

Key Vocabulary / Notation

  • system
  • intersection
  • elimination
  • solution
  • solution type

Key Representations

  • Graphs of two lines
  • Systems
  • Elimination work
  • Solution statements

Common Misconceptions / Failure Points

  • Assuming every system has one solution.
  • Changing only one term during an equation operation.

Section 3.5: Linear Systems of Inequalities

Learning Target: Use several inequalities to describe a feasible region.

I Can Statements

  • Write inequalities from constraints.
  • Graph each boundary and solution region.
  • Find the overlap.
  • Test whether a point is feasible.

Key Vocabulary / Notation

  • system of inequalities
  • feasible region
  • constraint
  • boundary
  • solution region

Key Representations

  • Multiple inequalities
  • Overlapping regions
  • Feasible points
  • Contexts

Common Misconceptions / Failure Points

  • Using a point that satisfies only one constraint.
  • Forgetting that the feasible region is the overlap.
