Algebra 1 — Unit 4: Function Families and Transformations

Essential Standard / Enduring Understanding

Students will identify common function families from graphs, equations, tables, and contexts.

Unit Source Alignment

Framework Alignment
  • Framework Topics / Standards: 4.1: Recognizing Function Families; 4.2: Translations; 4.3: Transformations; 4.4: Polynomial Operations; 4.5: Polynomial Structure and Quadratic Graphs

Section Outline

Section 4.1: Recognizing Function Families

Learning Target: Students will identify common function families from graphs, equations, tables, and contexts.

I Can Statements

  • I can construct evidence for a function family using patterns in graphs, equations, tables, and contexts.
  • I can apply family features to sort representations into linear, quadratic, exponential, absolute value, and other familiar forms.
  • I can determine which representation gives the strongest evidence for a function family when features seem similar.

Key Vocabulary / Notation

  • function family
  • linear
  • quadratic
  • exponential
  • absolute value
  • representation

Key Representations

  • Graphs of parent and familiar function families
  • Tables showing constant differences, second differences, or ratios
  • Equations in recognizable family forms
  • Contexts involving change patterns
  • Feature language such as intercept, vertex, rate, and symmetry

Common Misconceptions / Failure Points

  • Classifies functions from a single superficial feature.
  • Confuses transformed functions with unrelated families.
  • Uses constant difference/ratio tests incorrectly when comparing table patterns.

Modeling / Application Opportunities

  • Use data patterns to choose a reasonable function family for a situation
  • Connect visible graph features to possible real-world behavior
  • Represent the same relationship with a graph, table, equation, and context
  • Critique whether a selected family fits all available evidence

Spiral Planning

Intro: Students will identify common function families from graphs, equations, tables, and contexts.

Review: Keep active: students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

Mastery: Gather repeated evidence that students can analyze and compare linear relationships using multiple representations, with increasing independence and accurate interpretation.

Section 4.2: Translations

Learning Target: Students will graph and write translated functions using key points and key features.

I Can Statements

  • I can build translated graphs by moving key points and key features from a parent function.
  • I can use horizontal and vertical shifts to write equations for translated functions.
  • I can predict how changing values in an equation moves a graph left, right, up, or down.

Key Vocabulary / Notation

  • translation
  • parent function
  • horizontal shift
  • vertical shift
  • key point
  • key feature

Key Representations

  • Parent function graphs
  • Translated graphs on coordinate grids
  • Equations in transformation form
  • Key points, vertices, intercepts, and asymptotes where appropriate
  • Tables before and after translation

Common Misconceptions / Failure Points

  • Moves a graph in the same direction as the sign inside the input expression without checking.
  • Shifts individual points inconsistently instead of translating the whole graph.
  • Changes shape or scale when only a translation is intended.

Modeling / Application Opportunities

  • Shift a model to represent a changed starting value or benchmark
  • Use key points to sketch a translated relationship efficiently
  • Connect equation parameters to movement on a graph
  • Translate a graph to satisfy contextual constraints

Spiral Planning

Intro: Students will graph and write translated functions using key points and key features.

Review: Keep active: students will graph and interpret linear inequalities.

Mastery: Gather repeated evidence that students can graph linear functions and interpret key features, with increasing independence and accurate interpretation.

Section 4.3: Transformations

Learning Target: Students will analyze and graph transformations involving stretches, compressions, and reflections.

I Can Statements

  • I can design transformed graphs using stretches, compressions, reflections, and translations of parent functions.
  • I can apply transformation rules to key points and features across function families.
  • I can assess whether an equation, graph, or table represents the same transformed function.

Key Vocabulary / Notation

  • transformation
  • stretch
  • compression
  • reflection
  • scale factor
  • parent function

Key Representations

  • Transformation equations using parameters
  • Graphs showing vertical stretches and compressions
  • Graphs reflected over an axis
  • Tables transformed from parent-function values
  • Key features such as vertex, intercepts, symmetry, and rate behavior

Common Misconceptions / Failure Points

  • Confuses vertical and horizontal effects.
  • Treats a negative factor only as a sign change in outputs without identifying the reflection.
  • Uses stretch/compression language without relating the factor to distances from the parent graph.

Modeling / Application Opportunities

  • Adjust a parent function to fit a steeper, flatter, or reflected situation
  • Use a transformed table to generate a graph and equation
  • Connect parameter values to meaningful changes in a context
  • Check whether multiple representations model the same transformation

Spiral Planning

Intro: Students will analyze and graph transformations involving stretches, compressions, and reflections.

Review: Keep active: students will solve systems graphically and by elimination while interpreting the meaning of different solution types.

Mastery: Gather repeated evidence that students can graph linear functions and interpret key features, with increasing independence and accurate interpretation.

Section 4.4: Polynomial Operations

Learning Target: Students will add, subtract, and multiply polynomial expressions.

I Can Statements

  • I can formulate polynomial sums, differences, and products from area, perimeter, and expression contexts.
  • I can use structure and like terms to add, subtract, and multiply polynomial expressions.
  • I can extend polynomial operations to equivalent expressions written in different forms.

Key Vocabulary / Notation

  • polynomial
  • term
  • degree
  • coefficient
  • like terms
  • product

Key Representations

  • Polynomial expressions in standard and factored forms
  • Area models and algebra tiles
  • Tables of expression values
  • Equivalent expressions after combining or multiplying terms
  • Contextual diagrams involving length, width, area, and total change

Common Misconceptions / Failure Points

  • Combines unlike polynomial terms.
  • Distributes incompletely when multiplying polynomials.
  • Loses negative signs or exponent structure during subtraction and multiplication.

Modeling / Application Opportunities

  • Represent area or perimeter situations with polynomial expressions
  • Use algebra tiles or area models to multiply binomials
  • Connect polynomial operations to equivalent forms of a model
  • Check whether an expression form makes sense for a context

Spiral Planning

Intro: Students will add, subtract, and multiply polynomial expressions.

Review: Keep active: students will solve systems using substitution and choose efficient forms for solving.

Mastery: Gather repeated evidence that students can write linear equations from graphs, tables, and situations, with increasing independence and accurate interpretation.

Section 4.5: Polynomial Structure and Quadratic Graphs

Learning Target: Students will connect polynomial expressions to quadratic graphs and key features.

I Can Statements

  • I can construct connections between polynomial structure, quadratic graphs, and key features.
  • I can predict graph features from equivalent quadratic expressions.
  • I can critique whether a polynomial expression supports a claimed vertex, intercept, axis of symmetry, or direction of opening.

Key Vocabulary / Notation

  • polynomial structure
  • quadratic function
  • vertex
  • intercept
  • axis of symmetry
  • standard form

Key Representations

  • Quadratic expressions in equivalent forms
  • Parabolas with vertex, intercepts, and axis of symmetry
  • Tables showing quadratic patterns
  • Factored or expanded expressions connected to graph features
  • Contexts modeled by quadratic relationships

Common Misconceptions / Failure Points

  • Assumes all quadratic graphs have the same vertex or intercepts.
  • Confuses coefficient structure with graph features that are not directly visible in standard form.
  • Uses a linear rate-of-change interpretation for a quadratic relationship.

Modeling / Application Opportunities

  • Use expression structure to predict features of a quadratic model
  • Connect expanded and factored forms to graph information
  • Choose a useful form for answering a contextual question
  • Revise a model when its graph features do not fit the situation

Spiral Planning

Intro: Students will connect polynomial expressions to quadratic graphs and key features.

Review: Keep active: students will analyze and interpret systems of linear inequalities.

Mastery: Gather repeated evidence that students can use linear models to represent and interpret real-world data, with increasing independence and accurate interpretation.

Unit Themes / Throughlines

  • Function families can be selected using evidence from rates, differences, ratios, symmetry, and key features.
  • Transformations connect parent functions to new situations through predictable changes in equations and graphs.
  • Tables, graphs, equations, and contexts provide complementary evidence for the same relationship.
  • Polynomial operations support the creation and revision of quadratic models.
  • Expression structure helps students interpret graph features and choose efficient solution strategies.

Mastery Goals

U4-MG01: Slope and linear graph meaning

Mastery Goal: Interpret slope as constant rate of change and graph linear functions while connecting slope and intercepts to meaning.

Supporting learning / prerequisites:

  • Students will interpret slope as a measure of constant rate of change.
  • Students will graph linear functions and interpret key features.

Key representations:

  • Slope triangles on coordinate graphs
  • Tables showing equal input intervals
  • Contextual rate statements
  • Ratio notation for vertical change over horizontal change
  • Positive, negative, zero, and undefined slope examples
  • Coordinate plane graphs
  • Slope-intercept form
  • Intercepts and starting values

Recurring practices: Reason with units and rate; connect graphs/tables/equations; model with linear functions; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence calculates/interprets slope accurately, graphs consistently, and connects rate and intercepts to units or context.

Common evidence weaknesses / misconceptions:

  • Uses $y/x$ instead of change in $y$ over change in $x$.
  • Ignores the order of points and creates a sign error in slope.
  • Interprets steepness without considering axis scales or units.
  • Graphs the intercept correctly but uses slope in the wrong direction.
  • Confuses an $x$-intercept with the $y$-intercept.
U4-MG02: Linear equation construction

Mastery Goal: Write linear equations from graphs, tables, and situations while preserving rate and starting value.

Supporting learning / prerequisites:

  • Students will write linear equations from graphs, tables, and situations.

Key representations:

  • Slope-intercept equations
  • Tables of input-output values
  • Graphs with marked intercepts
  • Verbal descriptions of rates and starting values
  • Equivalent equation forms

Recurring practices: Reason with units and rate; connect graphs/tables/equations; model with linear functions; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence selects or constructs an equation that matches the given representation and verifies it with corresponding values or features.

Common evidence weaknesses / misconceptions:

  • Uses a rate as the starting value or vice versa.
  • Writes an equation from one data point without verifying the rate.
  • Keeps an equation in a form that does not match the available evidence and then misreads its features.
U4-MG03: Comparison of linear relationships

Mastery Goal: Compare linear relationships across equations, graphs, tables, and contexts using matched features and values.

Supporting learning / prerequisites:

  • Students will analyze and compare linear relationships using multiple representations.

Key representations:

  • Pairs of graphs
  • Tables with different scales
  • Equations in slope-intercept form
  • Contextual descriptions
  • Feature comparison organizers

Recurring practices: Reason with units and rate; connect graphs/tables/equations; model with linear functions; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence makes a fair comparison and justifies conclusions using slope, intercept, or corresponding-value evidence.

Common evidence weaknesses / misconceptions:

  • Compares outputs at different input values.
  • Uses visual steepness alone when graph scales differ.
  • Claims two linear relationships are equivalent because they share either slope or intercept but not both.
U4-MG04: Linear modeling with data

Mastery Goal: Use linear models to represent, interpret, and make reasonable predictions from real-world data.

Supporting learning / prerequisites:

  • Students will use linear models to represent and interpret real-world data.

Key representations:

  • Scatter plots
  • Lines of fit
  • Tables of real-world data
  • Linear model equations
  • Residual-style reasonableness observations

Recurring practices: Reason with units and rate; connect graphs/tables/equations; model with linear functions; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence chooses a defensible linear model, interprets its parameters, and uses it within a reasonable context or input range.

Common evidence weaknesses / misconceptions:

  • Forces a linear model onto data without checking whether the rate is reasonably constant.
  • Treats the model as exact rather than an approximation when data vary.
  • Makes a prediction without interpreting units or the reasonable input range.

Unit 4 Summative Assessment

This summative gathers secure evidence on the Mastery Goals and Learning Ladder defined in this Assessment Plan.

Mastery Goals assessed: U4-MG01, U4-MG02, U4-MG03, U4-MG04.

Required evidence: Each Mastery Goal must receive enough independent evidence to support a defensible judgment. Evidence should collectively sample the delayed mastery focus—Unit 2: Linear Functions and Modeling—through accurate procedures, interpretation, representation connections, and reasoning appropriate to the goal.

Important representations / practices / contexts: Use a purposeful mix of Slope triangles on coordinate graphs, Tables showing equal input intervals, Contextual rate statements, Ratio notation for vertical change over horizontal change, Positive, negative, zero, and undefined slope examples, Coordinate plane graphs, Slope-intercept form, Intercepts and starting values, Slope-intercept equations, Tables of input-output values. Across the assessment, preserve the recurring emphasis on reasoning, precision, interpretation, and connections among representations.

Recommended balance: Use a conventional secure summative with selected-response or brief-response items for efficient breadth, constructed response for reasoning and representation evidence, and—when natural—a separate performance task or investigation that can contribute richer evidence. Do not force extended performance work into every paper assessment.

Materials / references: The framework does not specify an additional calculator or reference restriction for these unit plans; apply established coursewide norms consistently.

Assessment time: The existing plan reference used approximately 45 minutes for the conventional paper summative. Keep timing flexible for accommodations and for any separate performance evidence.

Reassessment / alternate forms: Reassessment should provide a new opportunity to demonstrate the same Mastery Goals and ladder without repeating the exact prompts. Changed numbers, contexts, methods, and representations should preserve the intended evidence.

Meeting and Exceeding: Meeting means sufficient evidence of mastery, not perfection. Exceeding may emerge through flexible transfer, stronger synthesis, or application beyond the expected challenge; it does not require every student to complete a special “Exceeding question.”

DOK note: Depth of Knowledge is descriptive, not a quota. Use the level of thinking naturally required by the evidence; do not force a fixed DOK distribution or DOK 4 into a conventional paper test.
