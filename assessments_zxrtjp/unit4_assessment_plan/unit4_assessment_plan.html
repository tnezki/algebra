Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section Outline and Evidence Plan

Section 4.1: Recognizing Function Families

Learning Target: Use patterns and features to identify common function families.

I Can Statements

  • Use first differences for linear patterns.
  • Use second differences for quadratic patterns.
  • Use ratios for exponential patterns.
  • Use graph or equation features as additional evidence.

Key Vocabulary / Notation

  • parent function
  • linear
  • quadratic
  • exponential
  • absolute value

Key Representations

  • Graphs
  • Tables
  • Equations
  • Contexts

Common Misconceptions / Failure Points

  • Using graph shape as the only evidence.
  • Confusing second differences with ratios.

Spiral Planning

Key Representations

Common Misconceptions / Failure Points

Mastery Goals

U4-MG01 · Slope and Rate of Change

Mastery Goal: Find slope across representations and explain what it means.

I Can Statements

  • Find slope from a graph, table, equation, or two points.
  • Use rise/run consistently.
  • Interpret slope with units in a context.
  • Recognize positive, negative, zero, and undefined slope.

U4-MG02 · Graph and Write Linear Functions

Mastery Goal: Use slope and starting value to graph and write linear functions.

I Can Statements

  • Graph a line from slope and an intercept.
  • Write a linear equation from a graph, table, or context.
  • Use f(x) notation to evaluate a linear function.
  • Identify meaningful domain and range from a linear graph or context when useful.
