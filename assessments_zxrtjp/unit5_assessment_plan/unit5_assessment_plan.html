Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section Outline and Evidence Plan

Section 5.1: GCF and Structure

Learning Target: Factor out a greatest common factor and check the result.

I Can Statements

  • Find the GCF of coefficients.
  • Find common variable factors.
  • Factor the GCF from every term.
  • Multiply back to verify.

Key Vocabulary / Notation

  • greatest common factor
  • factor
  • term
  • coefficient
  • equivalent expression

Key Representations

  • Expanded expressions
  • Factored expressions
  • Area models

Common Misconceptions / Failure Points

  • Factoring something not common to every term.
  • Leaving a common factor behind.

Spiral Planning

Review: Use patterns and features to identify common function families.

Mastery: U5-MG01 · Solve Systems: Solve systems by graphing, substitution, or elimination and choose a useful method.

Section 5.2: Factoring Trinomials

Learning Target: Factor quadratic trinomials using product-sum reasoning.

I Can Statements

  • Find factor pairs for the constant or product.
  • Use sum information to choose a pair.
  • Write binomial factors.
  • Multiply back to check.

Key Vocabulary / Notation

  • trinomial
  • binomial factor
  • product-sum
  • factor pair
  • quadratic

Key Representations

  • Trinomials
  • Binomial products
  • Diamond structures
  • Area models

Common Misconceptions / Failure Points

Section 5.5: Comparing Quadratic Forms

Learning Target: Choose the quadratic form that best shows the feature you need.

I Can Statements

  • Identify standard, vertex, and factored form.
  • Read useful features from each form.
  • Connect different forms to the same graph.
  • Explain which form is most useful for a question.

Key Vocabulary / Notation

  • standard form
  • vertex form
  • factored form
  • vertex
  • zeros

Key Representations

  • Three quadratic forms
  • Quadratic graphs
  • Feature tables

Common Misconceptions / Failure Points

  • Assuming one form is always best.
  • Reading a feature from the wrong part of an equation.
