Section Outline and Evidence Plan

Section 7.1: Recognizing Growth and Decay

Learning Target: Identify exponential growth and decay from repeated multiplicative change.

I Can Statements

  • Find a constant ratio in a table.
  • Tell additive change from multiplicative change.
  • Identify growth or decay.
  • Use a graph, equation, or context as supporting evidence.

Key Vocabulary / Notation

  • exponential growth
  • exponential decay
  • constant ratio
  • growth factor
  • decay factor

Key Representations

  • Tables
  • Graphs
  • Equations
  • Contexts

Common Misconceptions / Failure Points

  • Using constant differences as exponential evidence.
  • Confusing percent change with the factor.

Spiral Planning

Mastery: U7-MG01 · Greatest Common Factor: Factor polynomial expressions using a greatest common factor and check the result.

Key Representations

  • Graphs

  • Contexts

Section 7.5: Exponential Modeling with Data

Learning Target: Build or use an exponential model from data and judge its limits.

I Can Statements

  • Estimate or identify an initial value.
  • Estimate or identify a growth/decay factor.
  • Use the model to make a prediction.
  • Explain whether the prediction is reasonable.

Key Vocabulary / Notation

  • exponential model
  • data
  • growth factor
  • prediction
  • model fit

Key Representations

  • Data tables
  • Scatter plots
  • Exponential equations
  • Predictions

Common Misconceptions / Failure Points

  • Assuming noisy data have a perfect ratio.
  • Ignoring meaningful domain.
