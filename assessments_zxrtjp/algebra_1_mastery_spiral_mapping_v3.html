Second-pass rule for the spiral: Intro means students first learn the idea with support; Review means they use the same idea again with less support, a new representation, or a slightly harder context; Mastery means they can use it independently, choose an appropriate representation or method, and explain the result when needed. This keeps Review from becoming a duplicate of Intro.

Separate Warm-Up Fluency Track

Equation solving stays out of the unit-section structure. Warm-Up Question 1 builds it through daily repetition:

one-step -> mixed one-step -> two-step -> combining like terms -> distribution -> multi-step -> variables on both sides -> rational coefficients -> cumulative mixed solving

Older types continue to appear after harder types are introduced. Near the end of Algebra 1, solving can be assessed as its own cumulative proficiency.

Warm-Up Question 3 carries recurring integer/fraction work, distribution, combining like terms, and exponent-law fluency. Fraction/integer directions should encourage trying without a calculator first while clearly allowing calculator use if needed.

Mastery Goal: Find slope or rate of change from a graph, table, equation, or context.

Mastery Goal: Evaluate numerical and algebraic expressions using substitution and order of operations.

I Can Statements

  • Substitute a value for a variable.
  • Use order of operations correctly.
  • Evaluate expressions with positive and negative numbers.

U1-MG04
Input / Output Rules

Mastery Goal: Use an input-output rule to find values, ordered pairs, and patterns.

U2-MG01
Compare Relationships

Learning Target: Compare two relationships shown in different ways.

Mastery Goal: Compare relationships across graphs, tables, equations, and contexts using clear evidence.

I Can Statements

Mastery Goal: Solve one-step inequalities and show the solution on a number line.

I Can Statements

  • Use an open or closed circle correctly.

Mastery Goal: Use inputs and outputs to decide whether a relationship is a function.

I Can Statements

  • Decide whether a table is a function.
  • Decide whether ordered pairs or a mapping are a function.
  • Use a graph to decide whether each input has only one output.
  • Explain why a relationship is or is not a function.
U2-MG04
Move Between Representations

Mastery Goal: Create a new representation of a relationship and check that the important values and pattern stay the same.

What changed in this pass: the early function sequence is now more deliberate (input/output -> function or not -> f(x) -> domain/range and key features); Unit 2 comparison and representation goals are more clearly separated; Learning Targets stay short while Mastery Goals describe the durable skill; exponent laws are explicit inside polynomial work without creating a new section; and the Intro -> Review -> Mastery stages now define increasing independence rather than repeated copies of the same task.
Content decisions carried into this map: function language grows from input/output into f(x), evaluation, domain/range, and key features without a separate section; domain/range appears where function families make it useful; exponent laws are strengthened inside polynomial and exponential work; radicals and irrational values stay simple and appear naturally during quadratic solving; statistics stays light and model-focused.
