Algebra 1 Assessment Plan Rebuild

What changed: simpler Essential Standards and Learning Targets; short I Can statements; explicit Intro/Review/Mastery evidence; Exit Ticket anchors for every section; revised Unit 1 and Unit 2 mastery goals; equation-solving fluency kept in the warm-up track rather than inflated into extra sections.
Unit 1: Foundations of Functions and Algebra

Essential Standard: Use graphs, slope, rules, and expressions as basic tools for Algebra 1.

Intro: Unit 1 — Foundations of Functions and Algebra
Review: Readiness skills from prior learning
Mastery: Readiness skills from prior learning

  • U1-MG01 — Coordinate-Plane Graphs: Use ordered pairs, axes, scales, and intercepts to read and create graphs.
  • U1-MG02 — Slope in Four Views: Find slope or rate of change from a graph, table, equation, or context.
  • U1-MG03 — Evaluate Expressions: Evaluate numerical and algebraic expressions using substitution and order of operations.
  • U1-MG04 — Input / Output Rules: Use an input-output rule to find values, ordered pairs, and patterns.
Unit 2: Linear Functions and Modeling

Essential Standard: Use slope, linear functions, representations, and data to describe and compare linear relationships.

Intro: Unit 2 — Linear Functions and Modeling
Review: Unit 1 — Foundations of Functions and Algebra
Mastery: Readiness skills from prior learning

  • U2-MG01 — Compare Relationships: Compare relationships across graphs, tables, equations, and contexts using clear evidence.
  • U2-MG02 — One-Step Inequalities: Solve one-step inequalities and show the solution on a number line.
  • U2-MG03 — Function or Not a Function: Use inputs and outputs to decide whether a relationship is a function.
  • U2-MG04 — Move Between Representations: Create a new representation of a relationship and check that the important values and pattern stay the same.
Unit 3: Systems and Constraints

Essential Standard: Use systems and inequalities to represent, solve, and interpret situations with more than one condition.

Intro: Unit 3 — Systems and Constraints
Review: Unit 2 — Linear Functions and Modeling
Mastery: Unit 1 — Foundations of Functions and Algebra

  • U3-MG01 — Connect Representations: Connect tables, graphs, equations/rules, function notation, and contexts for the same relationship.
  • U3-MG02 — Understand Functions and Families: Use function notation and key features to describe functions and recognize common function families.
  • U3-MG03 — Equivalent Expressions: Use structure, like terms, the distributive property, and substitution to make equivalent expressions.
  • U3-MG04 — Equations in Context: Write an equation from a situation, solve when needed, and explain what the solution means.
Unit 4: Function Families and Transformations

Essential Standard: Recognize and transform function families and connect algebraic structure to graph features.

Intro: Unit 4 — Function Families and Transformations
Review: Unit 3 — Systems and Constraints
Mastery: Unit 2 — Linear Functions and Modeling

  • U4-MG01 — Slope and Rate of Change: Find slope across representations and explain what it means.
  • U4-MG02 — Graph and Write Linear Functions: Use slope and starting value to graph and write linear functions.
  • U4-MG03 — Compare Linear Relationships: Compare linear relationships using slope, starting value, outputs, and context.
  • U4-MG04 — Linear Models: Build or use a linear model and judge whether it is useful.
Unit 5: Factoring and Quadratic Functions

Essential Standard: Factor polynomial expressions and use quadratic forms to understand zeros and graph features.

Intro: Unit 5 — Factoring and Quadratic Functions
Review: Unit 4 — Function Families and Transformations
Mastery: Unit 3 — Systems and Constraints

  • U5-MG01 — Solve Systems: Solve systems by graphing, substitution, or elimination and choose a useful method.
  • U5-MG02 — Systems from Situations: Use two equations to model two constraints and interpret the solution.
  • U5-MG03 — Graph Linear Inequalities: Graph a linear inequality using a boundary line and a correct solution region.
  • U5-MG04 — Systems of Inequalities: Graph more than one inequality and use the overlap to represent possible solutions.
Unit 6: Solving and Modeling with Quadratics

Essential Standard: Solve quadratic equations in different ways and use quadratic models to answer real questions.

Intro: Unit 6 — Solving and Modeling with Quadratics
Review: Unit 5 — Factoring and Quadratic Functions
Mastery: Unit 4 — Function Families and Transformations

  • U6-MG01 — Recognize Function Families: Identify common function families from graphs, tables, equations, and contexts.
  • U6-MG02 — Transform Functions: Represent translations, stretches, compressions, and reflections across function families.
  • U6-MG03 — Polynomial Operations and Exponents: Add, subtract, and multiply polynomials using structure, like terms, distribution, and exponent laws.
  • U6-MG04 — Quadratic Structure and Graphs: Use polynomial and quadratic structure to identify features such as zeros, vertex, symmetry, and direction of opening.
Unit 7: Exponential Functions and Modeling

Essential Standard: Use exponential patterns, functions, and models to describe repeated multiplicative change.

Intro: Unit 7 — Exponential Functions and Modeling
Review: Unit 6 — Solving and Modeling with Quadratics
Mastery: Unit 5 — Factoring and Quadratic Functions

  • U7-MG01 — Greatest Common Factor: Factor polynomial expressions using a greatest common factor and check the result.
  • U7-MG02 — Factor Trinomials and Special Patterns: Factor quadratic trinomials and common special patterns.
  • U7-MG03 — Factors, Zeros, and Graphs: Use factored form to find and interpret zeros of a quadratic function.
  • U7-MG04 — Choose a Quadratic Form: Compare standard, vertex, and factored forms and use the most useful form.
Unit 8: Function Analysis, Modeling, and Synthesis

Essential Standard: Choose, transform, and analyze functions and models using the representation that best fits the problem.

Intro: Unit 8 — Function Analysis, Modeling, and Synthesis
Review: Unit 7 — Exponential Functions and Modeling
Mastery: Unit 6 — Solving and Modeling with Quadratics

  • U8-MG01 — Solve by Factoring: Use factoring and the zero product property to solve quadratic equations and interpret the solutions.
  • U8-MG02 — Complete the Square: Complete the square to solve a quadratic and connect the work to vertex and symmetry.
  • U8-MG03 — Quadratic Formula and Discriminant: Use the quadratic formula to solve and the discriminant to predict the number of real solutions.
  • U8-MG04 — Choose a Solution Method: Choose and explain an efficient method for solving a quadratic equation.
  • U8-MG05 — Quadratic Models: Build or use quadratic models and interpret maximums, minimums, intercepts, domains, and solutions.
