Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section 1.1: Multiple Representations of Relationships

Learning Target: Connect tables, graphs, equations or rules, and contexts that represent the same relationship.

I Can Statements

  • Find matching values across different representations.
  • Create a table or graph from another representation.
  • Check whether two representations describe the same relationship.
  • Use values, rate, or pattern as evidence.

Key Vocabulary / Notation

  • input
  • output
  • ordered pair
  • representation
  • rate

Key Representations

  • Tables
  • Coordinate graphs
  • Equations or rules
  • Contexts

Common Misconceptions / Failure Points

  • Matching by appearance instead of values.
  • Ignoring graph scale.

Spiral Planning

Intro: Connect tables, graphs, equations or rules, and contexts that represent the same relationship.

Intro path: This same idea is reviewed next unit and becomes U3-MG01 · Connect Representations at mastery.

Review: Solve one-step inequalities and show the solution on a number line.

Review source: Prior-course readiness. This review becomes U2-MG02 · One-Step Inequalities mastery in the next unit.

Mastery: U1-MG03 · Evaluate Expressions: Evaluate numerical and algebraic expressions using substitution and order of operations.

Section 1.2: Inputs, Outputs, and Functions

Learning Target: Use input-output rules and the basic idea of a function.

I Can Statements

  • Use a rule to find outputs.
  • Write ordered pairs from inputs and outputs.
  • Decide whether each input has only one output.

  • input
  • output
  • function

  • mapping

Key Representations

  • Input-output tables
  • Rules
  • Ordered pairs
  • Mappings
  • Simple graphs

Common Misconceptions / Failure Points
