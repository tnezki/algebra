Algebra 1 — Unit 1: Foundations of Functions and Algebra

Essential Standard / Enduring Understanding

Students will connect tables, graphs, equations, and contexts that represent the same relationship.

Unit Source Alignment

Framework Alignment
  • Framework Topics / Standards: 1.1: Multiple Representations of Relationships; 1.2: Inputs, Outputs, and Functions; 1.3: Function Families; 1.4: Expressions and Structure; 1.5: Equations as Models
  • Course-Specific Emphasis: Spiraled retrieval, delayed mastery, mathematical reasoning, communication, modeling, and connections among tables, graphs, equations, and contexts.
  • Pacing Guidance: The framework establishes the unit sequence but no fixed day-by-day calendar. Instruction and evidence opportunities remain flexible, with prior learning intentionally revisited over time.

Section Outline

Section 1.1: Multiple Representations of Relationships

Learning Target: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

I Can Statements

  • I can construct a table, graph, equation, or context from another representation of the same relationship.
  • I can use features in one representation to work with a related table, graph, equation, or context.
  • I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

Key Vocabulary / Notation

  • representation
  • table
  • graph
  • equation
  • context
  • ordered pair

Key Representations

  • Tables of input-output pairs
  • Coordinate graphs
  • Equations and rules
  • Verbal contexts
  • Connections among multiple representations

Common Misconceptions / Failure Points

  • Connects representations by appearance instead of checking corresponding values or features.
  • Builds a graph or table that changes the relationship while translating representations.
  • Uses inconsistent variable meanings across a table, graph, equation, and context.

Modeling / Application Opportunities

  • Build a graph from a context about distance, cost, or time.
  • Formulate an equation from a table of values.
  • Use a graph to predict a missing table value.
  • Check whether a context and equation communicate the same relationship.

Spiral Planning

Intro: Students will connect tables, graphs, equations, and contexts that represent the same relationship.

Review: Keep active: students will compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

Mastery: Gather repeated evidence that students can solve inequalities, represent solution sets graphically, and interpret solutions in context, with increasing independence and accurate interpretation.

Section 1.2: Inputs, Outputs, and Functions

Learning Target: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

I Can Statements

  • I can formulate a rule that connects inputs to outputs in a table, graph, equation, or context.
  • I can apply an input-output rule to generate missing values and ordered pairs.
  • I can assess whether a rule gives one output for each input in a situation.

Key Vocabulary / Notation

  • function
  • input
  • output
  • rule
  • ordered pair
  • mapping

Key Representations

  • Input-output tables
  • Function rules
  • Ordered pairs
  • Mapping diagrams
  • Context-based input and output quantities

Common Misconceptions / Failure Points

  • Assumes any input-output pairing is a function even when one input has multiple outputs.
  • Switches input and output roles when moving between representations.
  • Applies a rule inconsistently across different inputs.

Modeling / Application Opportunities

  • Build a function rule from repeated input-output calculations.
  • Use a context to assign inputs and outputs meaning.
  • Predict outputs for new inputs using a rule.
  • Check a mapping for repeated inputs with different outputs.

Spiral Planning

Intro: Students will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Review: Keep active: students will identify patterns and represent relationships using input-output rules, tables, words, and symbols.

Mastery: Gather repeated evidence that students can evaluate numerical and algebraic expressions correctly using substitution and order of operations, with increasing independence and accurate interpretation.

Section 1.3: Function Families

Learning Target: Students will recognize common function families from graphs, tables, equations, and contexts.

I Can Statements

  • I can design examples of linear, quadratic, exponential, and absolute value relationships using more than one representation.
  • I can extend patterns in tables, graphs, equations, and contexts to work with common function families.
  • I can critique a proposed function family choice using evidence from rate of change, shape, or equation structure.

Key Vocabulary / Notation

  • function family
  • linear
  • quadratic
  • exponential
  • absolute value
  • rate of change

Key Representations

  • Linear patterns
  • Quadratic patterns
  • Exponential growth and decay patterns
  • Absolute value patterns
  • Family features across representations

Common Misconceptions / Failure Points

  • Classifies a family from graph shape alone without checking table or equation evidence.
  • Confuses constant difference with constant ratio.
  • Treats a transformed family as a different family because its graph is shifted or reflected.

Modeling / Application Opportunities

  • Create a context that fits a given family feature.
  • Use table patterns to choose a likely family.
  • Predict how a graph changes when a family pattern changes.
  • Critique family choices that rely only on appearance.

Spiral Planning

Intro: Students will recognize common function families from graphs, tables, equations, and contexts.

Review: Keep active: students will recognize constant rate of change in tables, graphs, visual patterns, and situations.

Mastery: Gather repeated evidence that students can accurately perform operations with integers, fractions, and decimals while interpreting results in mathematical and contextual situations, with increasing independence and accurate interpretation.

Section 1.4: Expressions and Structure

Learning Target: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

I Can Statements

  • I can build equivalent expressions by using structure, grouping, and properties of operations.
  • I can apply rewriting strategies to make the meaning of an expression easier to work with.
  • I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Key Vocabulary / Notation

  • expression
  • term
  • coefficient
  • factor
  • equivalent form
  • structure

Key Representations

  • Algebraic expressions
  • Equivalent forms
  • Grouped terms and factors
  • Context meanings for terms
  • Substitution checks

Common Misconceptions / Failure Points

  • Combines unlike terms or distributes incompletely.
  • Assumes different-looking expressions cannot be equivalent.
  • Rewrites an expression in a way that changes its value instead of preserving equivalence.

Modeling / Application Opportunities

  • Build an expression for a cost, perimeter, or repeated quantity.
  • Rewrite an expression to reveal a useful structure.
  • Use substitution to test equivalence.
  • Connect terms and coefficients to a context.

Spiral Planning

Intro: Students will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Review: Keep active: students will identify patterns and represent relationships using input-output rules, tables, words, and symbols.

Mastery: Gather repeated evidence that students can analyze and rewrite algebraic expressions using properties of operations and algebraic structure, with increasing independence and accurate interpretation.

Section 1.5: Equations as Models

Learning Target: Students will write, solve, and interpret equations that model situations.

I Can Statements

  • I can construct an equation that models a situation using meaningful quantities and operations.
  • I can use solution steps to solve an equation and connect the result to the situation.
  • I can predict whether a solution is reasonable by interpreting it in the original context.

Key Vocabulary / Notation

  • equation
  • variable
  • solution
  • model
  • constraint
  • reasonableness

Key Representations

  • Context-based equations
  • Solution steps
  • Variables as quantities
  • Balanced relationships
  • Interpreted solutions

Common Misconceptions / Failure Points

  • Defines a variable but writes operations that do not match the context.
  • Solves an equation correctly but interprets the solution using the wrong quantity or unit.
  • Accepts extraneous or unreasonable contextual values without checking the model.

Modeling / Application Opportunities

  • Formulate an equation from a real-world situation.
  • Use a solution to answer a context question.
  • Predict a reasonable value before solving.
  • Check whether a solution makes sense in context.

Spiral Planning

Intro: Students will write, solve, and interpret equations that model situations.

Review: Keep active: students will represent linear relationships using tables, graphs, equations, and contextual descriptions.

Mastery: Gather repeated evidence that students can solve one-variable equations and interpret solutions within mathematical and contextual situations, with increasing independence and accurate interpretation.

Unit Themes / Throughlines

  • Relationships can be represented by tables, graphs, equations, and contexts.
  • Functions connect inputs to outputs through rules and patterns.
  • Function families have features that appear across representations.
  • Expression structure can reveal meaning and support rewriting.
  • Equations can model situations and produce interpretable solutions.

Mastery Goals

U1-MG01: Foundational computation and evaluation

Mastery Goal: Accurately compute with rational numbers and evaluate numerical or algebraic expressions using substitution and order of operations.

Supporting learning / prerequisites:

  • Students will accurately perform operations with integers, fractions, and decimals while interpreting results in mathematical and contextual situations.
  • Students will evaluate numerical and algebraic expressions correctly using substitution and order of operations.

Key representations:

  • Integer expressions
  • Fraction operations
  • Decimal operations
  • Number line models
  • Contextual quantities
  • Numerical expressions
  • Algebraic expressions
  • Substitution tables

Recurring practices: Attend to precision; reason quantitatively; use structure; verify equivalence and reasonableness.

What Meeting evidence should demonstrate: Meeting evidence shows accurate operations, appropriate grouping/substitution, and a reasonableness check when context is present.

Common evidence weaknesses / misconceptions:

  • Loses the sign when adding or subtracting negative quantities.
  • Treats fraction operations as if numerators and denominators always operate separately.
  • Accepts a computed result without checking whether its sign or size fits the context.
  • Ignores grouping symbols or changes the order of operations.
  • Substitutes a value without preserving parentheses around a negative input.
U1-MG02: Equivalent expression structure

Mastery Goal: Rewrite algebraic expressions into equivalent forms using properties, factors, terms, and structure.

Supporting learning / prerequisites:

  • Students will analyze and rewrite algebraic expressions using properties of operations and algebraic structure.

Key representations:

  • Equivalent expressions
  • Terms and coefficients
  • Factors and products
  • Distributive property structures
  • Algebra tiles or area models

Recurring practices: Attend to precision; reason quantitatively; use structure; verify equivalence and reasonableness.

What Meeting evidence should demonstrate: Meeting evidence preserves equivalence, uses properties accurately, and explains or verifies the structural rewrite.

Common evidence weaknesses / misconceptions:

  • Combines unlike terms because they contain some of the same symbols.
  • Distributes to only one term or mishandles a negative factor.
  • Assumes two expressions are equivalent because they look similar without structural or substitution evidence.
U1-MG03: Equation solving and interpretation

Mastery Goal: Solve one-variable equations while maintaining equivalence, checking solutions, and interpreting results.

Supporting learning / prerequisites:

  • Students will solve one-variable equations and interpret solutions within mathematical and contextual situations.

Key representations:

  • One-variable equations
  • Balance models
  • Inverse operations
  • Solution checks
  • Contextual equations

Recurring practices: Attend to precision; reason quantitatively; use structure; verify equivalence and reasonableness.

What Meeting evidence should demonstrate: Meeting evidence includes an accurate solution pathway, a valid check, and correct interpretation of the unknown when context is present.

Common evidence weaknesses / misconceptions:

  • Performs an operation on only one side of an equation.
  • Uses inverse operations mechanically but loses signs or coefficients.
  • Stops at a numerical answer without checking it in the original equation or context.
U1-MG04: Inequality solution sets

Mastery Goal: Solve and graph one-variable inequalities and interpret boundary values and solution sets.

Supporting learning / prerequisites:

  • Students will solve inequalities, represent solution sets graphically, and interpret solutions in context.

Key representations:

  • One-variable inequalities
  • Number line graphs
  • Open and closed circles
  • Solution set notation
  • Contextual constraints

Recurring practices: Attend to precision; reason quantitatively; use structure; verify equivalence and reasonableness.

What Meeting evidence should demonstrate: Meeting evidence includes correct inverse operations, direction changes when required, endpoint conventions, and contextual interpretation of the solution set.

Common evidence weaknesses / misconceptions:

  • Forgets to reverse the inequality when multiplying or dividing by a negative number.
  • Uses the wrong open/closed endpoint on a number line.
  • Treats one boundary value as the entire solution instead of interpreting a solution set.

Progress Tracking

Not Yet: The student’s work shows that the learning outcome is still developing. Additional practice, feedback, and evidence are needed to demonstrate progress toward mastery.
Approaching: The student’s work shows evidence of growth toward mastering the learning outcome. Additional evidence is needed to demonstrate mastery consistently.
Meeting: The student’s work provides sufficient evidence of mastering the learning outcome.
Exceeding: The student’s work provides evidence of applying skills and/or concepts beyond the expected challenge of the learning outcome.

Summative Assessment Plan

Unit 1 Summative Assessment

This summative gathers secure evidence on the Mastery Goals and Learning Ladder defined in this Assessment Plan.

Mastery Goals assessed: U1-MG01, U1-MG02, U1-MG03, U1-MG04.

Required evidence: Each Mastery Goal must receive enough independent evidence to support a defensible judgment. Evidence should collectively sample the delayed mastery focus—Rational-number, expression, equation, and inequality foundation skills—through accurate procedures, interpretation, representation connections, and reasoning appropriate to the goal.

Important representations / practices / contexts: Use a purposeful mix of Integer expressions, Fraction operations, Decimal operations, Number line models, Contextual quantities, Numerical expressions, Algebraic expressions, Substitution tables, Equivalent expressions, Terms and coefficients. Across the assessment, preserve the recurring emphasis on reasoning, precision, interpretation, and connections among representations.

Recommended balance: Use a conventional secure summative with selected-response or brief-response items for efficient breadth, constructed response for reasoning and representation evidence, and—when natural—a separate performance task or investigation that can contribute richer evidence. Do not force extended performance work into every paper assessment.

Materials / references: The framework does not specify an additional calculator or reference restriction for these unit plans; apply established coursewide norms consistently.

Assessment time: The existing plan reference used approximately 45 minutes for the conventional paper summative. Keep timing flexible for accommodations and for any separate performance evidence.

Reassessment / alternate forms: Reassessment should provide a new opportunity to demonstrate the same Mastery Goals and ladder without repeating the exact prompts. Changed numbers, contexts, methods, and representations should preserve the intended evidence.

Meeting and Exceeding: Meeting means sufficient evidence of mastery, not perfection. Exceeding may emerge through flexible transfer, stronger synthesis, or application beyond the expected challenge; it does not require every student to complete a special “Exceeding question.”

DOK note: Depth of Knowledge is descriptive, not a quota. Use the level of thinking naturally required by the evidence; do not force a fixed DOK distribution or DOK 4 into a conventional paper test.
