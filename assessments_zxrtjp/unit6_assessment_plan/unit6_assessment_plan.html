Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section 6.1: Solving Quadratics by Factoring

Learning Target: Solve quadratic equations using factoring and the zero product property.

I Can Statements

  • Set the equation equal to zero when needed.
  • Factor the quadratic.
  • Use the zero product property.
  • Connect solutions to x-intercepts or context.

Key Vocabulary / Notation

  • quadratic equation
  • factored form
  • zero product property
  • zero
  • solution

Key Representations

  • Factored equations
  • Zeros
  • Graphs
  • Contexts

Common Misconceptions / Failure Points

  • Using zero product before the equation equals zero.
  • Stopping at the factors.

Section 6.4: Choosing and Defending Solution Methods

Learning Target: Choose an efficient way to solve a quadratic equation.

I Can Statements

  • Look at equation structure before choosing a method.
  • Choose factoring when it is efficient.
  • Use completing the square or quadratic formula when appropriate.
  • Explain why the method fits.

Key Vocabulary / Notation

  • factoring
  • completing the square
  • quadratic formula
  • method
  • efficiency

Key Representations

  • Quadratics in different forms
  • Method comparisons
  • Written reasoning

Common Misconceptions / Failure Points

Mastery Goals

U6-MG01 · Recognize Function Families

Mastery Goal: Identify common function families from graphs, tables, equations, and contexts.

I Can Statements

  • Use differences, second differences, ratios, shape, or equation structure as evidence.
  • Use key features such as intercepts, vertex, symmetry, asymptotes, domain, and range when they help identify or describe a family.
  • Compare more than one piece of evidence before choosing a family.

U6-MG02 · Transform Functions

Mastery Goal: Represent translations, stretches, compressions, and reflections across function families.

I Can Statements

  • Move key points when a function is translated.
  • Recognize stretches, compressions, and reflections.
  • Connect equation changes to graph changes.
  • Describe changes in key features, including range when useful.

U6-MG03 · Polynomial Operations and Exponents

Mastery Goal: Add, subtract, and multiply polynomials using structure, like terms, distribution, and exponent laws.

I Can Statements

  • Combine like polynomial terms.
  • Distribute signs and factors correctly.
  • Use product, quotient, power-of-a-power, and zero-exponent rules when they appear in polynomial work.
  • Check whether two polynomial forms are equivalent.

U6-MG04 · Quadratic Structure and Graphs

Mastery Goal: Use polynomial and quadratic structure to identify features such as zeros, vertex, symmetry, and direction of opening.

I Can Statements

  • Connect factors to zeros and x-intercepts.
  • Connect vertex form to the vertex and axis of symmetry.
  • Use standard form to identify useful information.
  • Choose the form that best shows the feature needed.
