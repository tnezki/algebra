Section Outline

Section 2.1: Rate of Change and Slope

Learning Target: Students will interpret slope as a measure of constant rate of change.

I Can Statements

  • I can construct rate-of-change statements from tables, graphs, and situations.
  • I can apply slope calculations to interpret constant change between quantities.
  • I can determine whether a slope value is reasonable for a given context.

Key Vocabulary / Notation

  • slope
  • rate of change
  • rise
  • run
  • constant rate
  • increasing
  • decreasing

Key Representations

  • Slope triangles on coordinate graphs
  • Tables showing equal input intervals
  • Contextual rate statements
  • Ratio notation for vertical change over horizontal change
  • Positive, negative, zero, and undefined slope examples

Common Misconceptions / Failure Points

  • Uses $y/x$ instead of change in $y$ over change in $x$.
  • Ignores the order of points and creates a sign error in slope.
  • Interprets steepness without considering axis scales or units.

Modeling / Application Opportunities

  • Connect speed, cost per item, and growth rates to slope
  • Build verbal interpretations for slopes in real situations
  • Use table patterns to model constant change
  • Represent increasing and decreasing rates with graph features

Spiral Planning

Intro: Students will interpret slope as a measure of constant rate of change.

Review: Keep active: students will recognize common function families from graphs, tables, equations, and contexts.

Mastery: Gather repeated evidence that students can recognize constant rate of change in tables, graphs, visual patterns, and situations, with increasing independence and accurate interpretation.

Section 2.2: Graphing Linear Functions

Learning Target: Students will graph linear functions and interpret key features.

I Can Statements

  • I can build graphs of linear functions using slope and intercept information.
  • I can use key features of a line to interpret a relationship.
  • I can extend a graph to predict outputs within a meaningful range.

Key Vocabulary / Notation

  • linear function
  • slope
  • intercept
  • slope-intercept form
  • coordinate plane

Key Representations

  • Coordinate plane graphs
  • Slope-intercept form
  • Intercepts and starting values
  • Tables generated from linear rules
  • Contextual graphs with labeled axes

Common Misconceptions / Failure Points

  • Graphs the intercept correctly but uses slope in the wrong direction.
  • Confuses an $x$-intercept with the $y$-intercept.
  • Plots points without connecting graph features to the equation or context.

Modeling / Application Opportunities

  • Graph savings, distance, or subscription situations
  • Use intercepts to represent initial values
  • Connect slope direction to increasing or decreasing behavior
  • Create graphs from equations and contextual descriptions

Spiral Planning

Intro: Students will graph linear functions and interpret key features.

Review: Keep active: students will connect tables, graphs, equations, and contexts that represent the same relationship.

Mastery: Gather repeated evidence that students can interpret and create graphs on the coordinate plane while connecting points, axes, intercepts, and graphical information to mathematical situations, with increasing independence and accurate interpretation.

Section 2.3: Writing Linear Equations

Learning Target: Students will write linear equations from graphs, tables, and situations.

I Can Statements

  • I can formulate linear equations from graphs, tables, and situations.
  • I can apply slope-intercept structure to connect rate and starting value.
  • I can design equivalent equations that represent the same linear relationship.

Key Vocabulary / Notation

  • linear equation
  • slope
  • intercept
  • point-slope reasoning
  • table
  • context

Key Representations

  • Slope-intercept equations
  • Tables of input-output values
  • Graphs with marked intercepts
  • Verbal descriptions of rates and starting values
  • Equivalent equation forms

Common Misconceptions / Failure Points

  • Uses a rate as the starting value or vice versa.
  • Writes an equation from one data point without verifying the rate.
  • Keeps an equation in a form that does not match the available evidence and then misreads its features.

Modeling / Application Opportunities

  • Write rules for cell phone plans, savings, or distance
  • Translate graphs into equations
  • Use tables to calculate slope and initial value
  • Revise equations to make context features visible

Spiral Planning

Intro: Students will write linear equations from graphs, tables, and situations.

Review: Keep active: students will write, solve, and interpret equations that model situations.

Mastery: Gather repeated evidence that students can represent linear relationships using tables, graphs, equations, and contextual descriptions, with increasing independence and accurate interpretation.

Section 2.4: Comparing Linear Representations

Learning Target: Students will analyze and compare linear relationships using multiple representations.

I Can Statements

  • I can construct comparison models for linear relationships shown in different forms.
  • I can use slope and intercept information to interpret similarities and differences.
  • I can critique conclusions about linear relationships using evidence from representations.

Key Vocabulary / Notation

  • rate of change
  • starting value
  • representation
  • equation
  • graph
  • table

Key Representations

  • Pairs of graphs
  • Tables with different scales
  • Equations in slope-intercept form
  • Contextual descriptions
  • Feature comparison organizers

Common Misconceptions / Failure Points

  • Compares outputs at different input values.
  • Uses visual steepness alone when graph scales differ.
  • Claims two linear relationships are equivalent because they share either slope or intercept but not both.

Modeling / Application Opportunities

  • Compare competing plans or rates
  • Use representations to support choices
  • Translate unlike representations into common features
  • Check claims about which relationship grows faster

Spiral Planning

Intro: Students will analyze and compare linear relationships using multiple representations.

Review: Keep active: students will connect tables, graphs, equations, and contexts that represent the same relationship.

Mastery: Gather repeated evidence that students can compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions, with increasing independence and accurate interpretation.

Section 2.5: Linear Modeling with Data

Learning Target: Students will use linear models to represent and interpret real-world data.

I Can Statements

  • I can design linear models that represent patterns in real-world data.
  • I can predict values using a linear model and interpret the result.
  • I can assess whether a linear model fits a data situation well enough for the question being asked.

Key Vocabulary / Notation

  • linear model
  • data
  • trend
  • prediction
  • rate of change
  • intercept

Key Representations

  • Scatter plots
  • Lines of fit
  • Tables of real-world data
  • Linear model equations
  • Residual-style reasonableness observations

Common Misconceptions / Failure Points

  • Forces a linear model onto data without checking whether the rate is reasonably constant.
  • Treats the model as exact rather than an approximation when data vary.
  • Makes a prediction without interpreting units or the reasonable input range.

Modeling / Application Opportunities

  • Model trends in measurement, cost, or time data
  • Use lines of fit to make predictions
  • Interpret slope and intercept in data contexts
  • Discuss when linear models are useful or limited

Spiral Planning

Intro: Students will use linear models to represent and interpret real-world data.

Review: Keep active: students will write, solve, and interpret equations that model situations.

Mastery: Gather repeated evidence that students can identify patterns and represent relationships using input-output rules, tables, words, and symbols, with increasing independence and accurate interpretation.

Unit Themes / Throughlines

  • Slope as constant rate of change across representations
  • Initial value as a contextual starting point
  • Linear equations as compact models of repeated change
  • Comparing relationships by translating features into common language
  • Using linear models to make and critique predictions from data

Mastery Goals

U2-MG01: Coordinate graph interpretation

Mastery Goal: Read, construct, and interpret coordinate graphs using ordered pairs, axes, scales, and intercepts.

Supporting learning / prerequisites:

  • Students will interpret and create graphs on the coordinate plane while connecting points, axes, intercepts, and graphical information to mathematical situations.

Key representations:

  • Coordinate plane graphs
  • Ordered pairs
  • Axis labels and scales
  • Intercepts
  • Contextual graph features

Recurring practices: Attend to coordinate/representation precision; reason with rate; connect multiple representations; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence uses coordinate conventions accurately and connects key graph features to the represented quantities.

Common evidence weaknesses / misconceptions:

  • Reverses the coordinates in an ordered pair.
  • Uses inconsistent axis scales or reads an intercept as an arbitrary point.
  • Describes graph appearance without connecting the feature to the represented quantities.
U2-MG02: Patterns and constant rate

Mastery Goal: Use input-output rules and constant rate of change to extend and interpret linear patterns.

Supporting learning / prerequisites:

  • Students will identify patterns and represent relationships using input-output rules, tables, words, and symbols.
  • Students will recognize constant rate of change in tables, graphs, visual patterns, and situations.

Key representations:

  • Input-output tables
  • Verbal rules
  • Symbolic rules
  • Pattern diagrams
  • Ordered pairs
  • Tables with equal input steps
  • Linear graphs
  • Visual patterns

Recurring practices: Attend to coordinate/representation precision; reason with rate; connect multiple representations; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence identifies a consistent rule or rate, applies it across values, and distinguishes constant-rate evidence from other patterns.

Common evidence weaknesses / misconceptions:

  • Finds a pattern that fits only one row instead of a rule that works throughout.
  • Confuses the input with the output.
  • Extends a table by visual guessing instead of applying the stated rule.
  • Uses total change instead of change in output per unit of input.
  • Assumes every increasing pattern has a constant rate.
U2-MG03: Linear relationships across representations

Mastery Goal: Represent a linear relationship with tables, graphs, equations, and contexts while preserving rate and starting value.

Supporting learning / prerequisites:

  • Students will represent linear relationships using tables, graphs, equations, and contextual descriptions.

Key representations:

  • Linear equations
  • Tables
  • Graphs
  • Contextual descriptions
  • Slope and starting value

Recurring practices: Attend to coordinate/representation precision; reason with rate; connect multiple representations; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence keeps rate, starting value, variables, and corresponding values consistent across representations.

Common evidence weaknesses / misconceptions:

  • Writes an equation with the rate and starting value reversed.
  • Creates a table or graph that does not match the equation.
  • Treats the starting value as the value after one unit rather than at input zero.
U2-MG04: Comparison with representation evidence

Mastery Goal: Compare relationships using equations, graphs, tables, visual patterns, and contexts and justify conclusions with relevant evidence.

Supporting learning / prerequisites:

  • Students will compare relationships using equations, graphs, tables, visual patterns, and contexts, then justify conclusions.

Key representations:

  • Equations
  • Graphs
  • Tables
  • Visual patterns
  • Context comparisons

Recurring practices: Attend to coordinate/representation precision; reason with rate; connect multiple representations; justify comparisons.

What Meeting evidence should demonstrate: Meeting evidence compares corresponding features fairly and supports the conclusion with rate, starting value, or matched-value evidence.

Common evidence weaknesses / misconceptions:

  • Compares representations using unrelated features.
  • Assumes two relationships are the same because they share one point.
  • Uses graph steepness without accounting for axis scale.

Progress Tracking

Not Yet: The student’s work shows that the learning outcome is still developing. Additional practice, feedback, and evidence are needed to demonstrate progress toward mastery.
Approaching: The student’s work shows evidence of growth toward mastering the learning outcome. Additional evidence is needed to demonstrate mastery consistently.
Meeting: The student’s work provides sufficient evidence of mastering the learning outcome.
Exceeding: The student’s work provides evidence of applying skills and/or concepts beyond the expected challenge of the learning outcome.

Summative Assessment Plan

Unit 2 Summative Assessment

This summative gathers secure evidence on the Mastery Goals and Learning Ladder defined in this Assessment Plan.

Mastery Goals assessed: U2-MG01, U2-MG02, U2-MG03, U2-MG04.

Required evidence: Each Mastery Goal must receive enough independent evidence to support a defensible judgment. Evidence should collectively sample the delayed mastery focus—Coordinate-plane, input-output, constant-rate, linear-representation, and comparison readiness skills—through accurate procedures, interpretation, representation connections, and reasoning appropriate to the goal.

Important representations / practices / contexts: Use a purposeful mix of Coordinate plane graphs, Ordered pairs, Axis labels and scales, Intercepts, Contextual graph features, Input-output tables, Verbal rules, Symbolic rules, Pattern diagrams, Tables with equal input steps. Across the assessment, preserve the recurring emphasis on reasoning, precision, interpretation, and connections among representations.

Recommended balance: Use a conventional secure summative with selected-response or brief-response items for efficient breadth, constructed response for reasoning and representation evidence, and—when natural—a separate performance task or investigation that can contribute richer evidence. Do not force extended performance work into every paper assessment.

Materials / references: The framework does not specify an additional calculator or reference restriction for these unit plans; apply established coursewide norms consistently.

Assessment time: The existing plan reference used approximately 45 minutes for the conventional paper summative. Keep timing flexible for accommodations and for any separate performance evidence.

Reassessment / alternate forms: Reassessment should provide a new opportunity to demonstrate the same Mastery Goals and ladder without repeating the exact prompts. Changed numbers, contexts, methods, and representations should preserve the intended evidence.

Meeting and Exceeding: Meeting means sufficient evidence of mastery, not perfection. Exceeding may emerge through flexible transfer, stronger synthesis, or application beyond the expected challenge; it does not require every student to complete a special “Exceeding question.”

DOK note: Depth of Knowledge is descriptive, not a quota. Use the level of thinking naturally required by the evidence; do not force a fixed DOK distribution or DOK 4 into a conventional paper test.
