Course-Long Fluency Overlay

Equation solving develops mainly through daily warm-up repetition, not extra sections.

one-step → mixed one-step → two-step → combining like terms → distribution → multi-step → variables on both sides → rational coefficients → cumulative mixed solving

Older types continue to reappear. Near the end of Algebra 1, equation solving can be assessed as its own cumulative proficiency.

Section 8.1: Selecting Appropriate Models

Learning Target: Choose a linear, quadratic, or exponential model from evidence.

I Can Statements

  • Use first differences, second differences, and ratios.
  • Use graph and equation features.
  • Connect the model choice to the context.
  • Change the model choice if new evidence does not fit.

Key Vocabulary / Notation

  • model
  • linear
  • quadratic
  • exponential
  • difference
  • ratio

Key Representations

  • Tables
  • Graphs
  • Equations
  • Contexts

Common Misconceptions / Failure Points

  • Choosing from one or two points.
  • Using the wrong change pattern as evidence.

Section 8.2: Transformations Across Function Families

Learning Target: Analyze transformations across several function families.

I Can Statements

  • Use parent functions as a reference.
  • Track translations, reflections, stretches, and compressions.
  • Move key points and features consistently.
  • Describe changes in domain or range when useful.

Key Vocabulary / Notation

  • parent function
  • parameter
  • translation
  • reflection
  • stretch
  • compression

Key Representations

  • Parent graphs
  • Transformed equations
  • Key points
  • Feature tables

Common Misconceptions / Failure Points

I Can Statements

  • Choose a representation based on the information needed.
  • Check that representations describe the same relationship.
  • Use mathematical evidence to support a conclusion.

  • representation

Key Representations

  • Tables
  • Equations
  • Function notation
  • Contexts

Mastery Goals

U8-MG01 · Solve by Factoring

Mastery Goal: Use factoring and the zero product property to solve quadratic equations and interpret the solutions.

I Can Statements

  • Set the equation equal to zero when needed.
  • Factor the quadratic.
  • Use the zero product property.
  • Connect solutions to zeros and x-intercepts.

U8-MG02 · Complete the Square

Mastery Goal: Complete the square to solve a quadratic and connect the work to vertex and symmetry.

I Can Statements

  • Build a perfect-square trinomial.
  • Keep both sides of an equation balanced.
  • Use square roots to solve.
  • Simplify common radicals such as √72, recognize an irrational result, and distinguish exact from approximate answers.

MEETING evidence should demonstrate: independent, accurate work with enough visible reasoning or representation evidence to support the answer.

U8-MG03 · Quadratic Formula and Discriminant

Mastery Goal: Use the quadratic formula to solve and the discriminant to predict the number of real solutions.

I Can Statements

  • Identify a, b, and c.
  • Use the quadratic formula correctly.
  • Use the discriminant to predict real solutions.
  • Give exact or approximate answers when appropriate.

MEETING evidence should demonstrate: independent, accurate work with enough visible reasoning or representation evidence to support the answer.

U8-MG04 · Choose a Solution Method

Mastery Goal: Choose and explain an efficient method for solving a quadratic equation.

I Can Statements

  • Choose factoring when the structure makes it useful.
  • Choose completing the square when it is useful.
  • Choose the quadratic formula when it is useful.
  • Explain why the chosen method fits the equation.

MEETING evidence should demonstrate: independent, accurate work with enough visible reasoning or representation evidence to support the answer.

U8-MG05 · Quadratic Models

Mastery Goal: Build or use quadratic models and interpret maximums, minimums, intercepts, domains, and solutions.

I Can Statements

  • Use a quadratic model from data, a graph, or a context.
  • Interpret a vertex as a maximum or minimum.
  • Interpret intercepts or zeros in context.
  • Use a meaningful domain and reject impossible solutions.
