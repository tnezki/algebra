Station 1 Answers

Question 1

Identify the axis of symmetry of $y=(x+2)^2-5$.

Solution:

Vertex form $y=(x-h)^2+k$ has axis $x=h$.

Here $x+2=x-(-2)$, so the axis of symmetry is $x=-2$.

Question 2

Solve or interpret the quadratic situation for Completing the Square. Show the algebra that supports your answer.

Complete the square to solve $x^2-4x-12=0$.

Solution:

Move the constant: $x^2-4x=12$.

Complete the square by adding $4$ to both sides: $x^2-4x+4=16$.

Then $(x-2)^2=16$, so $x-2=\pm4$ and $x=6$ or $x=-2$.

Question 3

Structure Analysis. Analyze the quadratic evidence for Completing the Square. Write a conclusion and justify it with algebraic or graphical evidence.

Analyze $y=(x-4)^2+6$. Without expanding first, decide whether the equation $0=(x-4)^2+6$ has real solutions and justify.

Solution:

Because $(x-4)^2\ge 0$ for every real $x$, $(x-4)^2+6\ge 6$.

The equation $0=(x-4)^2+6$ would require a nonnegative square to equal $-6$, which is impossible over the reals.

So there are no real solutions.

Question 4

Create With Constraints. Create or revise a quadratic task for Completing the Square using the constraints below.

  • Include at least two representations among equation, table, graph, or context.
  • Make the solution method visible from structure, not from a hint.
  • Interpret the solution in words.

Use the provided graph as one representation. Create a quadratic with vertex $(5,60)$ that opens downward, write it in vertex and standard form, and explain how completing the square connects the two forms.

Solution:

One model is $y=-4(x-5)^2+60$, which opens downward and has vertex $(5,60)$.

Expand to standard form: $y=-4(x^2-10x+25)+60=-4x^2+40x-40$.

Completing the square reverses this process: $-4x^2+40x-40=-4(x^2-10x+10)=-4((x-5)^2-15)=-4(x-5)^2+60$.

Question 5

The point $(2,4)$ on $f$ moves to $(2,9)$ on $g$. What vertical translation occurred?

Solution:

The $x$-coordinate stayed $2$, and the output changed from $4$ to $9$.

The graph translated up $5$ units.

Question 6

The point $(-1,1)$ on $f$ moves to $(3,1)$ on $g$. What horizontal translation occurred?

Solution:

The output stayed $1$, and the point moved from $x=-1$ to $x=3$.

That is a horizontal translation right $4$ units.

Question 7

In $y=|x-6|+2$, identify the translated vertex.

Solution:

The translated vertex is $(6,2)$.

Question 8

Write an equation for a translation of $y=x^2$ whose vertex is $(3,-5)$. Then give two points that should appear on the graph.

Solution:

One equation is $y=(x-3)^2-5$.

Two points are $(3,-5)$ and $(4,-4)$; by symmetry, $(2,-4)$ is another point.

Question 9

A function model must have the same shape as $y=|x|$ but its minimum value must be $2$ when $x=-7$. Write the translated equation and state the vertex.

Solution:

Use $y=|x+7|+2$.

The vertex is $(-7,2)$, which is the minimum because the absolute value opens upward.

Question 10

Use the blank coordinate plane to graph $y=-2|x+1|+3$. Plot the vertex and at least four transformed key points.

Solution:

The vertex is $(-1,3)$.

Use transformed points from the parent: one unit from the vertex gives $y=1$, so points $(-2,1)$ and $(0,1)$; two units away gives $y=-1$, so $(-3,-1)$ and $(1,-1)$.

Question 11

Construct an efficient strategy for determining whether $y=-3|x+2|+1$ and the table below represent the same function without graphing every point.

$x$-4-201
$y$-51-5-8
Solution:

Check key points rather than graphing every point. The vertex should be $(-2,1)$, which matches the table.

Evaluate the other inputs: $x=-4$ gives $-5$, $x=0$ gives $-5$, and $x=1$ gives $-8$.

All listed values match, so the table represents the same function.

Question 12

Design a short context that can be modeled by a translated quadratic with vertex $(-1, 4)$. State what the vertex means and give a table with four values.

Solution:

Sample context: a small bowl has minimum depth $4$ cm at horizontal position $x=-1$.

Model: $y=(x+1)^2+4$. Vertex $(-1,4)$ means the minimum depth is $4$ at position $-1$.

Table: $x=-3,-2,-1,0$ gives $y=8,5,4,5$.
