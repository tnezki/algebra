Answer:

Add $49$: $(x+7)^2=81$; $x=2,-16$.

Problem 8

Solve $x^2+16x=36$ by completing the square.

Answer:

Add $64$: $(x+8)^2=100$; $x=2,-18$.

Problem 15

A profit model is $P(x)=-(x-8)^2+45$. State the maximizing input and maximum profit predicted by the model.

Answer:

Maximum at $x=8$; maximum value $45$.

Problem 16

A student changes $x^2+12x=28$ to $(x+6)^2=28$. Identify what was omitted and correct the equation before solving.

Answer:

Completing the square adds $36$ to both sides: $(x+6)^2=64$, so $x=2,-14$.

Problem 17

Rewrite $x^2-10x+19$ in vertex form.

Answer:

$(x-5)^2-6$.

Problem 18

For $f(x)=-3(x-3)^2-7$, name the feature visible immediately and state it.

Answer:

Vertex form reveals the vertex $(3,-7)$ immediately.

Problem 19

A quadratic is available in standard, vertex, and factored form. Which form exposes its zeros most directly, and why?

Answer:

Factored form; its zero-producing factors are visible and can each be set equal to zero.

Problem 20

If you need the maximum or minimum of a quadratic, which form gives the key feature with the least additional work? Why?

Answer:

Vertex form; the vertex $(h,k)$ is displayed directly.

Answer:

Problem 24

Explain why $y=(x-6)^2$ shifts the graph right rather than left.

Answer:

The inside expression is zero at $x=6$, so the vertex moves from $x=0$ to $x=6$, which is 6 units right.
