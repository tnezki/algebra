Stations
Multiple Representations of Relationships
Source: practice_set_1_1_3(1).html
Time: 20–30 min
Groups: Stations (max 4 per station)
Materials: Printed station cards + record sheet
StructureSmall-group rotation through station cards with answer checks after each station.
SetupFour stations around the room; each station has one printed station card and a record sheet per student.
Directions
  1. Groups begin at assigned stations.
  2. Students solve all four questions at the station on their own record sheets.
  3. Groups compare reasoning before checking the station answer page.
  4. At the signal, groups rotate to the next station.
  5. Complete the exit ticket individually after rotations.
Goal: Students practice varied problems while using movement and immediate answer checks to revise reasoning.
✓ Looks Like Success
  • Each station card has four attempted responses on the record sheet.
  • Groups discuss before looking at the station answer page.
  • Students rotate with their own work, not the station card.
✗ Doesn't Look Like
  • Students crowd one station while others sit unused.
  • Groups check answers before attempting all four questions.
  • One recorder writes while other students do not solve.

Station 1 Answers

Question 1

Use the graph to estimate the output when the input is $2$.
Solution: From the graph, the line appears to follow $y=2x+1$. At input $2$, the output is about $5$.

Question 2

Decide whether the table and equation represent the same relationship. Use at least two values as evidence.
Solution: Yes. For $x=0,1,2,3$, $y=4x-1$ gives $-1,3,7,11$, which matches the table. Two checks are $4(1)-1=3$ and $4(3)-1=11$.

Question 3

Determine whether the point $(5,17)$ belongs to the relationship shown by $y=3x+2$. Use two methods: one from the equation and one from a table or verbal pattern. Explain which method is more efficient for this point.
Solution: Equation method: $3(5)+2=17$, so $(5,17)$ belongs. Table/pattern method: the rule starts at $2$ and adds $3$ each step, so at $x=5$ the output is $17$. The equation is more efficient because it checks the point directly.

Question 4

Design a connected model for a short situation where a total begins at $6$ and changes by the same amount each step. Include a context, equation, four-row table, and graph on the blank coordinate plane. Make sure all four representations agree.
Solution: One valid model: A school club starts with $6$ members and gains $2$ members each week. Equation: $y=6+2x$. Table: $(0,6),(1,8),(2,10),(3,12)$. The graph should plot those points on a straight line with vertical intercept $6$ and rate $2$.

Question 5

Evaluate each expression with decimals.
Solution:
  1. $-3.6+1.25=-2.35$.
  2. $4.8-(-2.05)=6.85$.
  3. $(-1.2)(0.45)=-0.54$.
  4. $-7.5\div1.5=-5$.

Question 6

Determine whether each result is positive, negative, or zero before calculating. Then calculate.
Solution:
  1. Positive; $(-6)(-\frac{2}{3})=4$.
  2. Zero; $0\div(-9.4)=0$.
  3. Negative; $-\frac{5}{8}-\frac{1}{4}=-\frac{5}{8}-\frac{2}{8}=-\frac{7}{8}$.
  4. Zero; $2.1+(-2.1)=0$.

Question 7

Use the number line to plot $-\frac{3}{2}$ and $2.25$. Then state which number is greater.
Solution: Plot $-\frac{3}{2}=-1.5$ and $2.25$ on the number line. Since $2.25$ is to the right of $-1.5$, $2.25$ is greater.

Question 8

Complete the diamond problem. The top is the product and the bottom is the sum. Explain which operation you used first.
Solution: The two numbers are $6$ and $-4$ because $6(-4)=-24$ and $6+(-4)=2$. Start by finding factor pairs of $-24$, then check their sums.

Station 3 Answers

Question 9

Three students each compute $-\frac{5}{6}-\left(-\frac{1}{4}\right)$. One uses common denominators, one uses decimals, and one uses a number line. Choose one valid method and show enough work to verify the result.
Solution: Common denominator method: $-\frac{5}{6}-\left(-\frac{1}{4}\right)=-\frac{5}{6}+\frac{1}{4}=-\frac{10}{12}+\frac{3}{12}=-\frac{7}{12}$.

Question 10

A team earns $3\frac{1}{2}$ points for a successful trial and loses $1\frac{3}{4}$ points for an unsuccessful trial. The team has $4$ successful trials and $6$ unsuccessful trials. Find the net point change.
Solution: Successful trials: $4\cdot3\frac{1}{2}=14$. Unsuccessful trials: $6\cdot(-1\frac{3}{4})=-10\frac{1}{2}$. Net change: $14-10\frac{1}{2}=3\frac{1}{2}$ points.

Question 11

The expression $2x+5$ is represented by the table. One table entry is wrong. Identify the first mismatch, correct it, and explain how you know.
Solution: For $2x+5$, outputs should be $5,7,9,11$ for $x=0,1,2,3$. The first mismatch is at $x=2$, where the table shows $8$ but should show $9$.

Question 12

A lab report states: "The sample changed by $-1.2$, then by $-\frac{3}{5}$, so the total change is $-1.7$ because $\frac{3}{5}=0.5$." Revise the model and write the corrected total change with units.
Solution: $\frac{3}{5}=0.6$, not $0.5$. The corrected total change is $-1.2-0.6=-1.8$ units. The model should show two negative changes being added.

Station 4 Answers

Question 13

A graph uses the horizontal axis for time in minutes and the vertical axis for distance in meters. What does the point $({6},{18})$ mean in the context?
Solution: The point $(6,18)$ means that after $6$ minutes, the distance is $18$ meters.

Question 14

The line shown models profit after selling items. Identify the break-even point and explain how the graph shows it.
Solution: The break-even point is about $(4,0)$. It is where the profit line crosses the horizontal axis, so profit is $0$.

Question 15

You need to graph a school hallway walk where distance is measured every ${30}$ seconds for ${5}$ minutes. Construct a strategy for choosing axis scales so the graph is readable and precise.
Solution: Use seconds or minutes consistently. Since $5$ minutes is $300$ seconds, a readable horizontal scale could mark every $30$ seconds. Choose a vertical scale based on the largest distance so the data use most of the graph without crowding.

Question 16

Design a short coordinate-plane model for a classroom situation involving a starting amount and steady change. Include axis labels, three ordered pairs, a graph, and a sentence explaining one intercept.
Solution: One valid model: pencils in a cup start at $4$ and increase by $3$ per class. Axis labels: classes and pencils. Points: $(0,4),(1,7),(2,10)$. The intercept $(0,4)$ means there were $4$ pencils before any classes added pencils.

Question 9

Three students each compute $-\frac{5}{6}-\left(-\frac{1}{4}\right)$. One uses common denominators, one uses decimals, and one uses a number line. Choose one valid method and show enough work to verify the result.
Solution: Common denominator method: $-\frac{5}{6}-\left(-\frac{1}{4}\right)=-\frac{5}{6}+\frac{1}{4}=-\frac{10}{12}+\frac{3}{12}=-\frac{7}{12}$.

Question 10

A team earns $3\frac{1}{2}$ points for a successful trial and loses $1\frac{3}{4}$ points for an unsuccessful trial. The team has $4$ successful trials and $6$ unsuccessful trials. Find the net point change.
Solution: Successful trials: $4\cdot3\frac{1}{2}=14$. Unsuccessful trials: $6\cdot(-1\frac{3}{4})=-10\frac{1}{2}$. Net change: $14-10\frac{1}{2}=3\frac{1}{2}$ points.
