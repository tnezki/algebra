Use the table to choose a function family and write one matching equation.

$x$0123
$y$51545135
Answer:

Exponential; one matching equation is $y=5(3)^x$.

2

Two models fit early data: a linear model adds 90 each period; an exponential model grows 5% each period. What additional evidence would best help choose between them?

Answer:

Examine later equally spaced data and compare additive differences with multiplicative ratios or residuals from the two candidate models.

3

A table has outputs [20, 15, 10, 5] for consecutive integer inputs, while a proposed equation is $y=6(1.3)^x$. Explain the conflict and identify what should be rechecked.

Answer:

The table has constant first differences, so it is linear, while the proposed equation is exponential. Recheck whether the equation and table describe the same relationship.

4

A club models membership by $M(t)=250+30t$. Actual totals for $t=0,1,2,3$ are 250, 282, 309, and 343. Use both representations to judge whether the linear model is exact or approximate.

Answer:

Approximate: the model predicts 250, 280, 310, and 340, close to but not identical to the observed totals.

5

A problem asks for a model family, an exact value, and a reasonableness check. Propose an efficient order for using graph, equation, table, and/or context representations.

Answer:

One efficient pathway is table/graph for family evidence, equation for the exact value, then context for reasonableness; other justified orders are possible.

6

For $y=1.5|x-5|+2$, create three table values centered at the vertex and explain what the table reveals about symmetry.

Answer:

Using $x=4,5,6$ gives $y=3.5,2,3.5$; equal horizontal distances from $x=5$ give equal outputs, showing symmetry about $x=5$.

7

A quantity triples every 3 hours from an initial value of 4. Choose a function family, write a model, and predict the value after 6 hours.

Answer:

Exponential; $Q(t)=4(3)^{t/3}$, so $Q(6)=36$.

8

When deciding between linear and quadratic, name one useful piece of evidence you could collect from each of an equation, graph, table, and context before making a final conclusion.

Answer:

Equation: structure/parameters; graph: shape/key features; table: differences/ratios or exact values; context: quantities, constraints, and reasonable domain.

The panel shows linear, quadratic, exponential, and absolute-value graphs. Choose two panels and explain one feature that distinguishes their families.

Answer:

Any correct pair with a valid distinguishing feature, such as constant slope for linear versus a turning point for quadratic, or V-shape for absolute value versus multiplicative growth for exponential.

10

You need to identify a turning point and overall shape quickly. Which representation—equation, graph, or table—is usually the most direct starting point, and why?

Answer:

A graph is usually most direct because shape and turning points are visible.

12

Early data can be fit by either a quadratic or an exponential model. What pattern in several later equally spaced values would best distinguish the two families?

Answer:

Check whether second differences stabilize for a quadratic pattern or ratios stabilize for an exponential pattern.

14

15

A problem asks for exact zeros and the overall shape of a quadratic. Propose an efficient order for using equation and graph representations.

Answer:

Use the equation for exact zeros, then graph to verify intercepts, opening direction, and overall shape; other justified orders are possible.

16

For $y=2|x-4|+3$, create three table values centered at the vertex and explain what the table reveals about symmetry. State the line of symmetry.

Answer:

For example, $x=3,4,5$ gives $y=5,3,5$. Equal distances from $x=4$ give equal outputs, so the graph is symmetric about $x=4$.

Linear; $Q(t)=20+7t$, so $Q(6)=62$.

You are checking a transformed function model. Name one useful check from the equation, graph, key-point table, and context.

Answer:

Equation: parameter changes; graph: shifted/reflected/stretched features; key-point table: transformed coordinates; context: whether the change is meaningful and respects constraints.

Answer:

$V(t)=150(1.12)^t$.

24

Without fully solving, use the discriminant to predict the number of real solutions of $2x^2+3x+7=0$.

Answer:

$b^2-4ac=9-56=-47\lt 0$, so there are no real solutions.
