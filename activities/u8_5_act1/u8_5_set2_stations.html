Station 1 Answers

Question 1

For a piecewise function, explain why each formula needs an interval.

Solution:

Each formula needs an interval so the function knows which rule to use for each input. Without intervals, two formulas could give conflicting outputs for the same $x$.

Question 2

For $f(x)=|x-3|+2$, find $f(-1)$, $f(3)$, and $f(8)$, then explain which output is the minimum.

Solution:

Compute $f(-1)=|-4|+2=6$, $f(3)=0+2=2$, and $f(8)=5+2=7$. The minimum is 2 at $x=3$ because the absolute value is smallest there.

Question 3

Create a strategy for solving a mixed-representation problem when you are given a graph of one function and an equation for another. Include how to estimate and how to verify.

Solution:

Estimate from the graph first by reading key points or intersections.

Question 4

Create a capstone task with a context, table, and equation that require a student to choose between linear and exponential models. Include the correct model choice and the evidence you expect.

Solution:

One example: a website starts with 50 views and grows by 60% weekly.

Question 5

Interpret the $y$-intercept of $h(t)=-16t^2+32t+6$.

Solution:

The $y$-intercept is $h(0)=6$. In context, the object starts 6 feet above the ground.

Question 6

Explain why negative time is not meaningful in a projectile model.

Solution:

Negative time would refer to a moment before the model starts, such as before launch. In a projectile context, the meaningful domain usually begins at $t=0$.

Question 7

Write a factored model with zeros $0$ and $10$ and maximum $25$.

Solution:

Use zeros 0 and 10: $y=a x(x-10)$. The vertex is midway at $x=5$, and $25=a(5)(-5)=-25a$, so $a=-1$. A model is $y=-x(x-10)$.

Question 8

Solve or interpret the quadratic situation for Solving Quadratics by Factoring. Show the algebra that supports your answer.

The graph shows a quadratic. Estimate the zeros, then write a possible factored equation.

Solution:

From the graph, the zeros are about $x=2$ and $x=6$. A possible factored equation is $y=(x-2)(x-6)$.

Question 9

Solve or interpret the quadratic situation for Solving Quadratics by Factoring. Show the algebra that supports your answer.

Solve $3x^2+12x=0$ and connect each solution to an intercept.

Solution:

Factor: $3x^2+12x=3x(x+4)=0$. Therefore $x=0$ or $x=-4$, giving intercepts $(0,0)$ and $(-4,0)$.

Question 10

Solve or interpret the quadratic situation for Solving Quadratics by Factoring. Show the algebra that supports your answer.

Solve $(2x-5)(x+4)=0$.

Solution:

Set each factor equal to zero: $2x-5=0$ gives $x=\frac{5}{2}$, and $x+4=0$ gives $x=-4$.

Question 11

Structure Analysis. Analyze the quadratic evidence for Choosing and Defending Solution Methods. Write a conclusion and justify it with algebraic or graphical evidence.

Analyze $y=(x-4)^2+6$. Without expanding first, decide whether the equation $0=(x-4)^2+6$ has real solutions and justify.

Solution:

There are no real solutions because $(x-4)^2\ge0$, so $(x-4)^2+6\ge6$. The expression can never equal 0.

Question 13

Use the blank coordinate plane to sketch $y=8(0.5)^x$ using at least four accurate points.

Solution:

Use points such as $(-1,16)$, $(0,8)$, $(1,4)$, and $(2,2)$. The graph decreases from left to right and approaches the horizontal asymptote $y=0$.

Question 14

The graph shows a shifted exponential function. Estimate the horizontal asymptote and the y-intercept, then explain how you know from the graph.

Solution:

For the shown shifted exponential, estimate the horizontal asymptote from the leveling-off value and read the y-intercept where the graph crosses the y-axis.

Question 15

A data set begins 100, 170, 289, 491.3, but a proposed model is $y=100(1.5)^x$.

  1. Analyze the model structure against the data.
  2. Explain whether the mismatch is small enough to keep the model or large enough to revise it.
Solution:

The data use a ratio of about 1.7 each step, but the proposed model uses 1.5.

Question 16

A student graphs $f(x)=3(2)^x+1$ with y-intercept 3 and asymptote $y=0$.

  1. Revise the graph features so they match the equation.
  2. Explain how the +1 changes both the y-intercept and asymptote.
Solution:

For $f(x)=3(2)^x+1$, the y-intercept is $f(0)=4$, not 3. The $+1$ shifts the graph up, so the horizontal asymptote is $y=1$, not $y=0$.
