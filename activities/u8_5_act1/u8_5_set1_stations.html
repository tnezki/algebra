Question 1

For $y=5(0.6)^x$, identify the family and whether it represents growth or decay.

Solution:

This is an exponential family. Since the multiplier 0.6 is between 0 and 1, it represents decay.

Question 2

For $y=|x-8|+2$, identify the family and vertex.

Solution:

This is an absolute value family. The vertex is $(8,2)$.

Question 4

A student predicts $20(1.1)^{12}$ people from a model built on weeks $0$ through $4$. Give a reasonableness argument for whether the prediction should be trusted.

Solution:

The model is being used far beyond weeks 0 through 4, so the prediction is extrapolation. It should be treated cautiously unless there is evidence the 10% growth pattern continues through week 12.

Question 5

For $A(x)=x(30-x)$, state a reasonable domain.

Solution:

A reasonable domain is $0\le x\le30$ if both dimensions must be nonnegative.

Question 6

Find the maximum value of $P(x)=-(x-6)^2+40$.

Solution:

The equation is in vertex form and opens downward. The maximum value is 40 at $x=6$.

Question 7

Solve or interpret the quadratic situation for Solving Quadratics by Factoring. Show the algebra that supports your answer.

A rectangle has area $54$ and side lengths $x$ and $x+3$. Find possible positive $x$.

Solution:

Set $x(x+3)=54$, so $x^2+3x-54=0=(x+9)(x-6)$. The positive solution is $x=6$.

Question 12

  • Make the solution method visible from structure, not from a hint.

Student A expands $(x-3)(x+7)=0$ and then uses the quadratic formula because the final report must include standard form. Student B uses the zero product property first and expands afterward for the report. Recommend an order of work, solve, write the standard form, and explain how the structure supports your choice.

Solution:

Use zero product first: $x=3$ or $x=-7$. Then expand for standard form: $(x-3)(x+7)=x^2+4x-21$, so $x^2+4x-21=0$.

This order uses the structure efficiently.

Question 13

Find the output for each input, then use the pattern to describe the graph as increasing or decreasing.

$x$-1012
$y=4(0.5)^x$
Solution:

For $y=4(0.5)^x$: at $x=-1$, $y=8$; at $x=0$, $y=4$; at $x=1$, $y=2$; at $x=2$, $y=1$. The graph is decreasing.

Question 14

State the horizontal asymptote for each function.

  1. $y=5(2)^x$
  2. $y=3(0.7)^x$
  3. $y=2(1.5)^x+4$
  4. $y=9(0.5)^x-1$
Solution:

$y=5(2)^x$ has asymptote $y=0$; $y=3(0.7)^x$ has $y=0$; $y=2(1.5)^x+4$ has $y=4$; $y=9(0.5)^x-1$ has $y=-1$.

Question 15

Make a table of values for $y=6(0.5)^x$ using $x=-2,-1,0,1,2$. Then describe the end behavior in words and identify the horizontal asymptote.

Solution:

The outputs are 24, 12, 6, 3, and 1.5. As $x$ increases, the graph decreases toward the horizontal asymptote $y=0$.

Question 16

The imperfect data set below is being modeled exponentially. Construct a modeling strategy for this data set. Your strategy must explain how to estimate a multiplier, how to make a week 6 prediction, and how to decide whether the prediction is reasonable.

Week01234
Amount100132174229306
Solution:

Estimate ratios such as $132/100=1.32$, $174/132\approx1.32$, and $306/229\approx1.34$. Use an average multiplier near 1.32 to 1.33; a week 6 prediction is about $306(1.33)^2\approx541$.

Check reasonableness by noting the data are imperfect and the prediction extends beyond the observed domain.
