Solution:

A quadratic model is more reasonable because gravity causes height to change with a constant second difference and the path has a maximum. A linear model would imply a constant velocity forever, which does not match an object rising then falling.

Solution 15

Two methods are proposed for deciding whether the outputs 10, 15, 22.5, 33.75, 50.625 are exponential.

  1. Method 1 checks first differences.
  2. Method 2 checks ratios.

Use both methods, then explain which method gives stronger evidence for this pattern and why.

Solution:

First differences are not constant, but ratios are constant: $15/10=22.5/15=33.75/22.5=50.625/33.75=1.5$. The ratio test gives stronger evidence for an exponential pattern.
