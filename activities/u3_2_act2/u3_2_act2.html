Solving Systems by Substitution
Source: practice_set_3_2_3.html
Time: 20–30 min
Groups: Pairs
Materials: Two whiteboards or papers per pair
StructurePartner simultaneous solving + compare-and-revise
SetupStudents work in pairs. Each student needs a whiteboard or paper.
Directions
  1. Both partners solve the same problem silently at the same time.
  2. Partners reveal work and compare the setup, steps, and answer.
  3. If the work differs, partners identify the first place the solutions diverge.
  4. Partners revise as needed before checking the solution page.
Goal: Use side-by-side work to surface errors and improve explanations.
✓ Looks Like Success
  • Both partners work at the same time before comparing.
  • Partners compare setup, operations, and final answer.
  • Different answers trigger a first-error conversation.
✗ Doesn't Look Like
  • One partner waits and copies the other.
  • Only final answers are compared.
  • Partners erase mistakes without discussing why.

Does $(4,-1)$ satisfy both $x+y=3$ and $y=-x+3$?

Solution:

Check $x+y=3$: $4+(-1)=3$, true. Check $y=-x+3$: $-1=-4+3=-1$, true. So $(4,-1)$ satisfies both.

Solution 2
Current · DOK 2

Solve by substitution. State whether the result is one solution, no solution, or infinitely many solutions.

$$\begin{aligned}y=4x-6\\8x-2y=12\end{aligned}$$

Solution:

Substitute $y=4x-6$ into $8x-2y=12$: $8x-2(4x-6)=12$, so $8x-8x+12=12$, or $12=12$. This identity means infinitely many solutions.

Solution 4
Current · DOK 4

Create a system of two linear equations that has solution $(4,3)$ and is efficient to solve by substitution because one equation is already solved for $y$.

  1. Write the system.
  2. Show a substitution solution path.
  3. Explain why your structure makes substitution efficient.
Solution:

One possible system is $y=x-1$ and $2x+y=11$. Substitution gives $2x+(x-1)=11$, so $3x-1=11$, $3x=12$, and $x=4$. Then $y=4-1=3$. It is efficient because the first equation already gives $y$.

Solution:

A classmate writes the expression $12x+30$ for a rectangle model but cannot explain its structure. Revise the model by giving two equivalent factored forms, choosing the more useful one for finding dimensions, and explaining why.

Solution:

$12x+30$ can be factored as $6(2x+5)$ or $3(4x+10)$. The form $6(2x+5)$ is useful for dimensions because both terms share a common factor of $6$, so one rectangle could have side lengths $6$ and $2x+5$.

4. Mastery · DOK 1–2

Solve $2x-5=11$.

Key:

  1. Substitute $y=5-x$ into $3x+y=13$: $3x+5-x=13$, so $2x=8$ and $x=4$. Then $y=1$. Solution: $(4,1)$.

  2. $0=7$ is a contradiction, so the system has no solution.

  3. Slope is $\frac{9-1}{6-2}=\frac{8}{4}=2$.

  4. $2x-5=11$ gives $2x=16$, so $x=8$.
