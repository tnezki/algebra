Station 1 Answers

Question 1

For the system $4x-y=9$ and $2x+y=3$, which operation would eliminate $y$ first?

Solution:

Add the two equations. The $-y$ and $+y$ terms cancel, so addition eliminates $y$ first.

Question 2

Use algebra to determine the solution type for the system. Then describe what the graph would show and why.

$$\begin{aligned}y=-2x+5\\2y+4x=10\end{aligned}$$

Solution:

Substitute $y=-2x+5$ into $2y+4x=10$: $2(-2x+5)+4x=10$, so $-4x+10+4x=10$, giving $10=10$. This identity means infinitely many solutions, and the graph shows the same line twice.

Question 3

For the system below, compare graphing and elimination as solving methods.

$$\begin{aligned}y=-x+8\\3x+3y=24\end{aligned}$$

Which method is more efficient, and how does the structure of the equations support your choice?

Solution:

Elimination is most efficient. The second equation $3x+3y=24$ divides by $3$ to give $x+y=8$, or $y=-x+8$, which is exactly the first equation. The system has infinitely many solutions; graphing would only confirm the same line.

Question 4

A school fundraiser can rent Table Plan A for \$40 plus \$6 per table or Table Plan B for \$16 plus \$9 per table.

  1. Define variables and write a system that models the two plans.
  2. Solve the system and interpret the break-even point.
  3. Write one additional sentence explaining which plan is cheaper before and after the break-even point.
Solution:

Let $x$ be the number of tables and $y$ be total rental cost. Plan A: $y=40+6x$. Plan B: $y=16+9x$. Set them equal: $40+6x=16+9x$, so $24=3x$ and $x=8$. The cost is $40+6(8)=88$. Break-even is $(8,88)$. Before $8$ tables, Plan B is cheaper; after $8$ tables, Plan A is cheaper.

Question 5

Which representation uses points on a coordinate plane: a table, a graph, an equation, or a context?

Solution:

A graph uses points on a coordinate plane.

Question 6

Use the graph to estimate the output when the input is $2$.

Solution:

The graphed line is $y=2x+1$. At input $x=2$, the output is $y=2(2)+1=5$.

Question 7

A table has outputs $4, 7, 10, 13$ as inputs increase by $1$. What is the repeated change in the outputs?

Solution:

The outputs increase $4$ to $7$ to $10$ to $13$, so the repeated change is $3$.

Question 8

The graph shows a cost relationship. Use the graph to estimate the cost for $8$ tickets and explain how you used the axes.

Solution:

The graph shows $y=5+4x$. For $8$ tickets, $y=5+4(8)=37$, so the estimated cost is about \$37. Use $x=8$ on the horizontal axis and read the corresponding $y$ value.

Question 9

Create a table with four input-output pairs for $y=2x-3$, using inputs of your choice. Then state one pattern you notice.

Solution:

One possible table is $(0,-3),(1,-1),(2,1),(3,3)$. A pattern is that the output increases by $2$ whenever the input increases by $1$.

Question 10

One of these representations does not match the others. Identify it and explain the mismatch.

Context: A plant is $6$ cm tall and grows $2$ cm each week.

Equation: $h=6+2w$

$w$0123
$h$681012

Claimed point: $(3,10)$

Solution:

The context, equation, and table match: starting height $6$ and growth $2$ each week. The claimed point $(3,10)$ does not match because at $w=3$, $h=6+2(3)=12$, not $10$.

Question 11

A rule for a school fundraiser is proposed as $C=25n$, where $n$ is the number of tickets and $C$ is cost. The flyer says there is also a one-time \$10 processing charge. Is the proposed rule reasonable? Explain and revise it if needed.

Solution:

The proposed rule is not reasonable because it leaves out the one-time charge. The revised rule is $C=25n+10$. The $25n$ part counts ticket costs and $10$ adds the processing charge.

Question 12

A table for an input-output rule is flawed: $(0,3),(1,6),(2,9),(2,12),(3,12)$. Revise the relation in two different ways: one revision that makes it a function with a constant increase, and one revision that makes it a function but not a constant-increase rule. Explain both choices.

Solution:

One constant-increase function revision is $(0,3),(1,6),(2,9),(3,12)$, which follows $y=3x+3$. One function but not constant-increase revision is $(0,3),(1,6),(2,9),(3,15)$; each input has one output, but the differences are $3,3,6$, not constant.

Station 4 Answers

Question 13

State the slope of a horizontal line through $(3,-4)$ and $(9,-4)$. Explain in one sentence why.

Solution:

The slope is $0$ because both points have the same $y$ value, so the vertical change is $-4-(-4)=0$.

Question 14

Without graphing, find the slope of each line:

  1. Through $(4,1)$ and $(2,5)$
  2. Through $(0,0)$ and $(10,5)$
  3. A vertical line through $(6,-5)$
  4. Through $(1,6)$ and $(10,6)$
Solution:

Through $(4,1)$ and $(2,5)$: $m=\frac{5-1}{2-4}=\frac{4}{-2}=-2$. Through $(0,0)$ and $(10,5)$: $m=\frac{5}{10}=\frac12$. A vertical line has undefined slope. Through $(1,6)$ and $(10,6)$: $m=0$.

Question 15

A student claims a walking rate of $42$ miles per hour is reasonable because the slope calculation $84\div 2=42$ is correct. Decide whether the slope is reasonable for the context and support your answer with units and a more realistic comparison.

Solution:

The calculation $84\div2=42$ may be arithmetically correct, but $42$ miles per hour is not a reasonable walking rate. A more realistic walking speed is around $3$ to $4$ miles per hour, so the units show the model or data should be questioned.

Question 16

Create a short context with a constant rate of change of $-4$ units per step and a starting value of $30$. Include a table for four input values and one sentence explaining what the slope means in your context.

Solution:

Example: a water tank starts with $30$ gallons and loses $4$ gallons each minute. Equation: $y=30-4x$. Table: $(0,30),(1,26),(2,22),(3,18)$. The slope $-4$ means the amount decreases by $4$ gallons per minute.
