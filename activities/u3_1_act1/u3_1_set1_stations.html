Question 1

The equations $y=-2x+5$ and $2y+4x=10$ represent the same line. Classify the solution type.

Solution:

Rewrite $2y+4x=10$ as $2y=-4x+10$, so $y=-2x+5$. The two equations are the same line, so there are infinitely many solutions.

Question 2

In elimination, which variable is ready to eliminate in the system $3x+2y=11$ and $-3x+5y=10$?

Solution:

The $x$ terms are $3x$ and $-3x$. Adding the equations makes those terms sum to $0$, so $x$ is ready to eliminate.

Question 3

Solve the system. Then write one sentence explaining what the graph of the two equations would look like.

$$\begin{aligned}y=3x+2\\6x-2y=8\end{aligned}$$

Solution:

Substitute $y=3x+2$ into $6x-2y=8$: $6x-2(3x+2)=8$, so $6x-6x-4=8$. This gives $-4=8$, a contradiction, so there is no solution. The graph would show parallel lines.

Question 4

Analyze the system without graphing it first.

$$\begin{aligned}4x-6y=12\\-2x+3y=-6\end{aligned}$$

Use equation structure to decide the solution type, then explain what the graph would show.

Solution:

Multiply the second equation by $-2$: $-2(-2x+3y=-6)$ gives $4x-6y=12$, exactly the first equation. The system has infinitely many solutions, and the graph would show one line drawn on top of the other.

Solution:

Look under the column where $x=2$. The matching $y$ value is $9$, so the ordered pair is $(2,9)$.

Question 6

In the context "the total cost is \$8 plus \$2 per game," which number represents the starting value?

Solution:

The starting value is the fixed amount before any games are added. In “\$8 plus \$2 per game,” the starting value is $8$.

Question 7

Use the blank coordinate plane to graph the relationship shown in the table.

$x$0123
$y$1357
Solution:

Plot the points $(0,1)$, $(1,3)$, $(2,5)$, and $(3,7)$. They rise by $2$ each time $x$ increases by $1$, so the graph is the line $y=2x+1$ through those points.

Question 8

A gym membership costs \$25 to join and \$15 each month. Write an equation and use it to find the cost after $6$ months.

Solution:

Let $m$ be months and $C$ be cost. The equation is $C=25+15m$. At $m=6$, $C=25+15(6)=25+90=115$, so the cost is \$115.

Question 9

Decide whether the table and equation represent the same relationship. Use at least two values as evidence.

Equation: $y=4x-1$

$x$0123
$y$-13711
Solution:

Check values in $y=4x-1$: when $x=0$, $y=-1$; when $x=1$, $y=3$; when $x=2$, $y=7$. These match the table, so the table and equation represent the same relationship.

Question 10

Determine whether the point $(5,17)$ belongs to the relationship shown by $y=3x+2$. Use two methods: one from the equation and one from a table or verbal pattern. Explain which method is more efficient for this point.

Solution:

Equation method: $3(5)+2=17$, so $(5,17)$ satisfies the equation. Table/pattern method: outputs increase by $3$ for each increase of $1$ in $x$; from $x=0$, $y=2$, so at $x=5$, $y=17$. The equation is more efficient because it checks the point directly.

Question 11

Compare the graph and context. Context: A cyclist starts $4$ miles from home and rides away at $2$ miles per hour. Decide whether the graph could model the context and justify your conclusion with the intercept and rate.

Solution:

The context has starting value $4$ and rate $2$ miles per hour. The graph shown has slope $2$ but a $y$-intercept of $1$, so it does not model the cyclist context because the starting distance is wrong.

Question 12

You are given two facts about one relationship: when $x=0$, $y=9$; when $x=4$, $y=21$. Synthesize a table, equation, context, and one additional point that all represent the same relationship. Explain how each representation shows the same starting value and change.

Solution:

The change from $(0,9)$ to $(4,21)$ is $12$ over $4$, so the rate is $3$. An equation is $y=3x+9$. A matching table could be $(0,9),(1,12),(2,15),(4,21)$. A context: a club starts with $9$ points and earns $3$ points per round. One additional point is $(5,24)$.

Question 13

Calculate the slope of the line through $(1,5)$ and $(4,11)$.

Solution:

Slope is $\frac{11-5}{4-1}=\frac{6}{3}=2$.

Question 14

$x$0246
$y$7111519

Use adjacent rows to find the constant rate of change.

Solution:

Using adjacent rows, $\Delta y=11-7=4$ and $\Delta x=2-0=2$. The rate of change is $\frac{4}{2}=2$.

Question 15

A line passes through $A(-3,-2)$ and $B(2,1)$. Does it also pass through $C(5,3)$? Justify by comparing slopes.

Solution:

Slope from $A$ to $B$ is $\frac{1-(-2)}{2-(-3)}=\frac{3}{5}$. Slope from $B$ to $C$ is $\frac{3-1}{5-2}=\frac{2}{3}$. The slopes are not equal, so $C$ is not on the same line.

Question 16

Two students calculate the slope of the same line. Andre uses two points from a graph; Elena uses this table.

$x$-1135
$y$-3036

Compare the two methods. Which method is less likely to create an arithmetic error here, and why?

Solution:

The table has slope $\frac{0-(-3)}{1-(-1)}=\frac{3}{2}=1.5$, matching the graph. The table method is less likely to create an arithmetic error here because the coordinate values are written exactly instead of estimated from a graph.
