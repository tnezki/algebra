Graphing and Elimination
Source: practice_set_3_1_2.html
Time: 20–30 min
Groups: Teams of 3–4
Materials: Student whiteboards, markers, erasers
StructureIndependent whiteboard solving + simultaneous team reveal
SetupStudents work in teams of 3–4. Each student needs a whiteboard, marker, and eraser.
Directions
  1. Display or distribute one problem at a time.
  2. Each student solves independently on a whiteboard without showing teammates.
  3. When the teacher says “Showdown,” all students reveal boards at the same time.
  4. Teammates compare strategies, discuss differences, and agree on a final answer before checking the solution page.
Goal: Make every student commit to a solution before group discussion begins.
✓ Looks Like Success
  • Every student writes a complete board before the reveal.
  • The team compares different solving paths before checking the key.
  • Students revise boards after identifying the exact error.
✗ Doesn't Look Like
  • One student solves while teammates wait to copy.
  • Boards are shown early before everyone commits.
  • The team checks the key without discussing mismatches.

Solution 3
Current · DOK 2

Solve the system. Then write one sentence explaining what the graph of the two equations would look like.

$$\begin{aligned}y=3x+2\\6x-2y=8\end{aligned}$$

Solution:

Substitute $y=3x+2$ into $6x-2y=8$: $6x-2(3x+2)=8$, so $6x-6x-4=8$. This gives $-4=8$, a contradiction, so there is no solution. The graph would show parallel lines.

Solution 10
Mastery · DOK 3

Determine whether the point $(5,17)$ belongs to the relationship shown by $y=3x+2$. Use two methods: one from the equation and one from a table or verbal pattern. Explain which method is more efficient for this point.

Solution:

Equation method: $3(5)+2=17$, so $(5,17)$ satisfies the equation. Table/pattern method: outputs increase by $3$ for each increase of $1$ in $x$; from $x=0$, $y=2$, so at $x=5$, $y=17$. The equation is more efficient because it checks the point directly.

A line passes through $A(-3,-2)$ and $B(2,1)$. Does it also pass through $C(5,3)$? Justify by comparing slopes.

Solution:

Slope from $A$ to $B$ is $\frac{1-(-2)}{2-(-3)}=\frac{3}{5}$. Slope from $B$ to $C$ is $\frac{3-1}{5-2}=\frac{2}{3}$. The slopes are not equal, so $C$ is not on the same line.

Write the equation of a line with slope $3$ and $y$-intercept $-4$.

4. Mastery · DOK 1–2

Simplify $5a-2a+7$.

Key:

  1. Add the equations: $(2x+y)+(2x-y)=11+5$, so $4x=16$ and $x=4$. Then $2(4)+y=11$, so $y=3$. Solution: $(4,3)$.

  2. Parallel lines never intersect, so the system has no solution.

  3. Slope-intercept form is $y=mx+b$. With slope $3$ and intercept $-4$, the equation is $y=3x-4$.

  4. Combine like terms: $5a-2a+7=3a+7$.
