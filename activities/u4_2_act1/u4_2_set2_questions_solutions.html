Create a system of two linear equations that has solution $(4,3)$ and is efficient to solve by substitution because one equation is already solved for $y$.

  1. Write the system.
  2. Show a substitution solution path.
  3. Explain why your structure makes substitution efficient.
Performance notes: The created system must actually have $(4,3)$ as its solution and include one substitution-ready equation.

Solution: One valid system is $y=x-1$ and $2x+y=11$. Substitute $y=x-1$ into $2x+y=11$: $2x+(x-1)=11$, so $3x=12$ and $x=4$. Then $y=4-1=3$. The structure is efficient because one equation is already solved for $y$.
