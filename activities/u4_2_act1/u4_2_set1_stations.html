Problem 1

The left graph is a parent function and the right graph is a translation. Describe the horizontal and vertical shift, then write a matching translated equation.

Answer:

Right 1 and up 3, $y=|x-1|+3$.

Problem 2

A student says $y=(x+4)^2+3$ moves $y=x^2$ right 4 and up 3. Identify and correct the horizontal-shift error.

Answer:

Inside the input, the sign acts oppositely: $x+4$ shifts the graph left 4. The vertical shift up 3 is correct.

Problem 3

Start with $y=x$. Translate the graph 1 units right and 1 units up. Write an equation for the translated function.

Answer:

$y=(x-1)+1$.

Problem 4

Describe the translation from $y=x^2$ to $y=(x-1)^2+2$.

Answer:

1 units right and 2 units up.

Problem 10

parent point
(-1,1)
(0,0)
(1,1)
Answer:

$y=(x+1)^2+4$ with vertex $(-1,4)$.

Problem 11

Use the absolute-value graph pair to locate the parent vertex and translated vertex. Then write the translated equation and describe both shifts.

Answer:

The parent vertex is $(0,0)$ and the translated vertex is $(-1,-3)$. The equation is $y=|x+1|-3$, so the graph shifts left 1 and down 3.

Problem 12

A student says $y=|x+1|-4$ translates the parent function right 1 and down 4. Identify the error and give the correct translation.

Answer:

The horizontal direction is reversed. The correct translation is left 1 and down 4; the sign inside the input acts opposite the visible horizontal movement.
