Station 1 Answers

Question 1

After substituting $y=x+6$ into $2x+y=15$, what one-variable equation should be solved?

Solution:

Replace $y$ with $x+6$: $2x+(x+6)=15$. That is the one-variable equation to solve.

Question 2

Does $(2,7)$ satisfy the equation $y=3x+1$?

Solution:

Substitute $x=2$: $3(2)+1=7$. Since the output is $7$, $(2,7)$ satisfies the equation.

Question 3

Rewrite the first equation to isolate $y$, then solve the system by substitution.

$$\begin{aligned}3x+y=17\y=x+1\end{aligned}$$

Solution:

From $3x+y=17$, isolate $y$: $y=17-3x$. Set equal to the second equation: $17-3x=x+1$. Then $16=4x$, so $x=4$. Substitute into $y=x+1$ to get $y=5$. Solution: $(4,5)$.

Question 4

Estimate the solution before solving: $y=0.5x+1$ and $y=-x+10$. Explain why your estimate should have $x$ between $5$ and $7$, then solve by substitution to verify.

Solution:

The lines should meet with $x$ between $5$ and $7$ because at $x=5$, $0.5x+1=3.5$ and $-x+10=5$, while at $x=7$, $0.5x+1=4.5$ and $-x+10=3$. Solve: $0.5x+1=-x+10$, so $1.5x=9$ and $x=6$. Then $y=0.5(6)+1=4$. Solution: $(6,4)$.

Question 5

In the rule "multiply the input by $2$, then subtract $5$," write the operation that happens first.

Solution:

The first operation is multiplying the input by $2$.

Question 6

A graph crosses the vertical axis at $7$. What table value does that help you identify?

Solution:

A vertical-axis crossing at $7$ identifies the table value when $x=0$, so the ordered pair is $(0,7)$.

Question 7

A rule is described as "triple the input, then subtract $8$." Generate four ordered pairs using inputs $0,1,2,3$.

Solution:

The rule is $y=3x-8$. For inputs $0,1,2,3$, the ordered pairs are $(0,-8),(1,-5),(2,-2),(3,1)$.

Question 8

Decide whether the context can be modeled as a function: each student ID number is assigned to one student name. Explain using input-output language.

Solution:

Yes. Each student ID number is one input and is assigned to exactly one student name as its output, so it can be modeled as a function.

Station 3 Answers

Question 9

For $f(x)=|x-3|+5$, find all input values that give an output of $10$.

Solution:

Set $|x-3|+5=10$, so $|x-3|=5$. Then $x-3=5$ or $x-3=-5$, giving $x=8$ or $x=-2$.

Question 10

Two students classify the table. Student A checks first differences; Student B checks ratios. Use both methods to decide the family and explain which method gives clearer evidence here.

$x$0123
$y$481632
Solution:

First differences are $4,8,16$, not constant. Ratios are $\frac84=2$, $\frac{16}{8}=2$, and $\frac{32}{16}=2$, constant. The table is exponential, and ratios give clearer evidence.

Question 11

A coach records jump heights: $1.0,1.4,1.9,2.5,3.2$ feet. A student claims an exponential model is best because the values increase. Is that reasonable? Use approximate differences or ratios as evidence.

Solution:

The increases are $0.4,0.5,0.6,0.7$, which are not constant but grow gradually. The ratios are about $1.4,1.36,1.32,1.28$, not constant. The claim that exponential is best just because values increase is not strong; the data shows increasing differences but not a constant ratio.

Question 12

Create a real context that can be represented by both $8x+20$ and $4(2x+5)$. Then explain what each form reveals about the situation and give one input-output check that confirms equivalence.

Solution:

Example context: a party has $8$ tables with $x$ students and $20$ extra seats, or $4$ groups each containing $2x+5$ seats. The form $8x+20$ shows total variable seats plus fixed seats; $4(2x+5)$ shows four equal groups. At $x=3$, both give $44$.

Question 13

Choose the more precise slope statement: “the graph goes up” or “$y$ increases by $4$ when $x$ increases by $1$.” Explain briefly.

Solution:

“$y$ increases by $4$ when $x$ increases by $1$” is more precise because it gives the exact rate of change.

Question 14

A bicyclist begins at mile $12$ and rides at $7$ miles per hour. Which value is the slope, $12$ or $7$?

Solution:

The slope is $7$ because it is the rate in miles per hour. The $12$ is the starting value.

Question 15

Time (hr)0246
Distance (mi)15253545

Find the constant rate of change and explain why the starting value does not change the slope.

Solution:

From $0$ to $2$ hours, distance changes from $15$ to $25$, so the slope is $\frac{10}{2}=5$ miles per hour. The starting value shifts the graph up or down but does not affect the rate of change.

Question 16

A graph of $y=4$ and a graph of $x=4$ are both described as “lines with a $4$.” Analyze the structure of each equation and explain why one is horizontal and one is vertical.

Solution:

$y=4$ means every point has $y$-coordinate $4$, so the line is horizontal. $x=4$ means every point has $x$-coordinate $4$, so the line is vertical.
