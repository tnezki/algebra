Station 1 Answers

Question 1

Does $(4,-1)$ satisfy both $x+y=3$ and $y=-x+3$?

Solution:

Check $x+y=3$: $4+(-1)=3$, true. Check $y=-x+3$: $-1=-4+3=-1$, true. So $(4,-1)$ satisfies both.

Question 2

Solve by substitution. State whether the result is one solution, no solution, or infinitely many solutions.

$$\begin{aligned}y=4x-6\\8x-2y=12\end{aligned}$$

Solution:

Substitute $y=4x-6$ into $8x-2y=12$: $8x-2(4x-6)=12$, so $8x-8x+12=12$, or $12=12$. This identity means infinitely many solutions.

Question 3

The expression $2x+3$ and the table row are supposed to match before being substituted into a second equation.

$x$0123
$2x+3$3589

Find the first mismatch, correct it, and explain why the error would affect a substitution solution.

Solution:

For $x=2$, $2x+3=2(2)+3=7$, not $8$. The first mismatch is the $x=2$ entry. The corrected row is $3,5,7,9$. The error would change a substituted value and could lead to a wrong solution.

Question 4

Create a system of two linear equations that has solution $(4,3)$ and is efficient to solve by substitution because one equation is already solved for $y$.

  1. Write the system.
  2. Show a substitution solution path.
  3. Explain why your structure makes substitution efficient.
Solution:

One possible system is $y=x-1$ and $2x+y=11$. Substitution gives $2x+(x-1)=11$, so $3x-1=11$, $3x=12$, and $x=4$. Then $y=4-1=3$. It is efficient because the first equation already gives $y$.

Question 9

The table shows a relation. If possible, write a rule using $x$ and $y$. If not possible, explain what prevents one rule from working for the repeated input.

$x$0122
$y$3579
Solution:

The input $2$ has two outputs, $7$ and $9$. Because one input is paired with two different outputs, one function rule cannot represent the relation as written.

Question 10

Use the table to identify the likely family. Support your choice with a pattern in the outputs.

$x$01234
$y$25101726
Solution:

The outputs $2,5,10,17,26$ have first differences $3,5,7,9$ and second differences $2,2,2$. Constant second differences suggest a quadratic family.

Question 11

Construct a strategy for choosing among linear, quadratic, exponential, and absolute value families when you have a table but no graph. Apply your strategy to outputs $6,1,-2,-3,-2,1,6$ for consecutive inputs.

Solution:

Check first differences for linear, second differences for quadratic, ratios for exponential, and symmetry with a turning point for absolute value. The outputs $6,1,-2,-3,-2,1,6$ are symmetric around $-3$, with a V-like pattern of distances from the center, so absolute value is likely.

Question 12

A classmate writes the expression $12x+30$ for a rectangle model but cannot explain its structure. Revise the model by giving two equivalent factored forms, choosing the more useful one for finding dimensions, and explaining why.

Solution:

$12x+30$ can be factored as $6(2x+5)$ or $3(4x+10)$. The form $6(2x+5)$ is useful for dimensions because both terms share a common factor of $6$, so one rectangle could have side lengths $6$ and $2x+5$.

Solution:

Question 14

On the blank coordinate plane, graph a line with slope $\frac{3}{2}$ through $(0,-4)$. Then name one other point on your line.

Solution:

Starting at $(0,-4)$ and using slope $\frac32$, go right $2$ and up $3$ to get another point $(2,-1)$. The graph is the line through those points.

Question 15

Compare this graph with the equation $y=-\frac{3}{4}x+5$. Decide whether the graph could represent the equation, and support your answer with slope and intercept evidence.

Solution:

The graphed line has slope $-\frac12$ and intercept $3$. The equation $y=-\frac34x+5$ has slope $-\frac34$ and intercept $5$. Since both slope and intercept differ, the graph does not represent the equation.

Question 16

Design two different real-world situations that both have slope $6$ but different starting values. For each, give one ordered pair and explain why the slopes match but the intercepts do not.

Solution:

Example 1: a taxi costs \$10 to start and \$6 per mile, so $C=6m+10$ and one point is $(2,22)$. Example 2: a club has $25$ members and gains $6$ per month, so $M=6t+25$ and one point is $(2,37)$. The slopes match because both increase by $6$ per input, but the starting values differ.
