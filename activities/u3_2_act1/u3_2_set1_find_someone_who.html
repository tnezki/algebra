Set 1 • Unit 3 • Section 3.2
Problem 1

Which method is more efficient for $2x+y=6$ and $y=-x+3$: substitution or elimination? Explain the structural cue.

Answer:

Substitution is more efficient because one equation is already solved for $y$.

Problem 2

A student substitutes $4x-2$ for $y$ in $5x+3y=-6$ but writes $5x+3(4x)-2=-6$. Identify and correct the substitution error.

Answer:

The entire expression must replace $y$: $5x+3(4x-2)=-6$.

Problem 3

Check whether $(-2,-3)$ satisfies both $y=-2x-7$ and $x+y=-5$.

Answer:

Yes. Substitution gives $-3=-2(-2)-7$ and $-2+(-3)=-5$, so both equations are true.

Problem 4

Solve the system by substitution. $\begin{cases}y=3x-3\\4x+y=-3\end{cases}$

Answer:

Substitute the expression for $y$ into the second equation. The solution is $(0,-3)$.

Problem 5

Solve the system by substitution. $\begin{cases}y=-3x\\2x+y=0\end{cases}$

Answer:

Substitute the expression for $y$ into the second equation. The solution is $(0,0)$.

Problem 6

For the system $y=-3x+3$ and $2x+y=3$, identify the most efficient first substitution step before solving.

Answer:

Substitute $-3x+3$ for $y$ in the second equation because $y$ is already isolated.

Problem 7

Which method is more efficient for $2x+2y=2$ and $-2x+3y=-17$: substitution or elimination? Explain the structural cue.

Answer:

Elimination is more efficient because the $x$-coefficients are opposites, so adding the equations eliminates $x$ immediately.

Problem 8

A student substitutes $3x+2$ for $y$ in $3x-3y=13$ but writes $3x-3(3x)+2=13$. Identify and correct the substitution error.

Answer:

The entire expression must replace $y$: $3x-3(3x+2)=13$.
