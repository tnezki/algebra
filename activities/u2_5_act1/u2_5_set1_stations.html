Question 9

A graph shows a line through $({0},{5})$ and $({4},{17})$. A table shows outputs ${2}$, ${8}$, ${14}$, ${20}$ for inputs ${0}$, ${2}$, ${4}$, ${6}$. Compare the rates of change.

Solution: The graph rate is $\frac{17-5}{4-0}=3$. The table rate is $\frac{8-2}{2-0}=3$ (and remains $3$), so both have the same rate of change, $3$ units of output per input.

Question 10

Analyze the pattern two ways: by calculating repeated differences and by writing a rule from the starting value and rate. Explain how each method predicts Figure ${15}$.

Figure01234
Tiles610141822
Solution: The repeated difference is $4$ tiles per figure. Starting from Figure $0$ with $6$ tiles gives $T=4n+6$. For Figure $15$, $T=4(15)+6=66$. Both the difference pattern and the rule predict $66$ tiles.

Question 11

A graph passes through $({0},{6})$, $({2},{14})$, and $({4},{22})$. A table shows $x$-values ${0}$, ${2}$, ${4}$ with outputs ${6}$, ${14}$, ${23}$. A context says the amount starts at ${6}$ and increases by ${4}$ for each input step. Construct a strategy for testing whether all three representations show the same constant rate of change. Your strategy must include at least three checks.

Solution: Check 1: the graph rate is $\frac{14-6}{2-0}=4$ and again $\frac{22-14}{4-2}=4$. Check 2: the table changes by $8$ and then $9$ while $x$ changes by $2$, so its rates are $4$ and $4.5$; it is not constant. Check 3: the context states a constant increase of $4$ per input step. Therefore the graph and context agree, but the table does not.

Question 12

Create a coordinate graph with constraints: the $y$-intercept must be ${6}$, one point must be $({4},{14})$, and the context must make negative outputs unreasonable. Then explain why your graph satisfies all constraints.

Solution: The line must pass through $(0,6)$ and $(4,14)$, so its slope is $\frac{14-6}{4-0}=2$ and an equation is $y=2x+6$. Plot those points and extend the line only over a context-appropriate domain such as $x\ge0$ if negative outputs/inputs are unreasonable. The intercept is $6$ and $(4,14)$ lies on the graph.

Station 4 Answers

Question 13

The equation $y=x^2+3$ belongs to which common family?

Solution: $y=x^2+3$ is a quadratic function because the variable is squared.

Question 14

The equation $y=2|x-5|+1$ belongs to which common family?

Solution: $y=2|x-5|+1$ is an absolute-value function because it contains an absolute-value expression.

Question 15

Use the grid to build evidence, not just a shape match. For each panel, estimate three ordered pairs or describe a rate, ratio, or symmetry feature from the axes. Then name the likely family and connect it to that evidence.

Solution: Use the plotted points/axes to identify evidence such as constant rate for a line, constant ratio for an exponential, symmetry and a turning point for a quadratic, or V-shaped symmetry for absolute value. The family name must be justified by those numerical/structural features, not shape alone.

Question 16

A concert ticket costs \$18 plus a \$4 service fee. A student writes $18+4t=90$ to find the number of tickets bought with \$90. Decide whether the model is reasonable and revise it if needed.

Solution: The model $18+4t=90$ treats the $\$4$ fee as if it were charged once per ticket and the $\$18$ cost as a one-time fee, which reverses the situation. If $t$ is the number of tickets, the reasonable model is $18t+4=90$. Then $18t=86$, so $t\approx4.78$; therefore $90$ is not exactly enough for a whole-number ticket count under this pricing.
