A graph passes through $({0},{6})$, $({2},{14})$, and $({4},{22})$. A table shows $x$-values ${0}$, ${2}$, ${4}$ with outputs ${6}$, ${14}$, ${23}$. A context says the amount starts at ${6}$ and increases by ${4}$ for each input step. Construct a strategy for testing whether all three representations show the same constant rate of change. Your strategy must include at least three checks.

Solution: Check 1: the graph rate is $\frac{14-6}{2-0}=4$ and again $\frac{22-14}{4-2}=4$. Check 2: the table changes by $8$ and then $9$ while $x$ changes by $2$, so its rates are $4$ and $4.5$; it is not constant. Check 3: the context states a constant increase of $4$ per input step. Therefore the graph and context agree, but the table does not.

Solution 16
Last · DOK 3

A concert ticket costs \$18 plus a \$4 service fee. A student writes $18+4t=90$ to find the number of tickets bought with \$90. Decide whether the model is reasonable and revise it if needed.

Solution: The model $18+4t=90$ treats the $\$4$ fee as if it were charged once per ticket and the $\$18$ cost as a one-time fee, which reverses the situation. If $t$ is the number of tickets, the reasonable model is $18t+4=90$. Then $18t=86$, so $t\approx4.78$; therefore $90$ is not exactly enough for a whole-number ticket count under this pricing.
