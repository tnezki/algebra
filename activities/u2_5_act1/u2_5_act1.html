Linear Modeling with Data
Source: practice_set_2_5_2.html
Time: 20–30 min
Groups: Groups of 4
Materials: One whiteboard and one marker per group
Structure One step per student
Setup Groups of 4. One whiteboard and one marker per group.
Directions
  1. Groups of 4. One whiteboard and marker per group.
  2. Each student completes ONE step, then passes the board.
  3. Rotate until the problem is complete.
  4. Compare when the solution is shown.
  5. If everyone understands, celebrate.
Goal: Sequential reasoning + shared responsibility
✓ Looks Like Success
  • Only one student completes the current step before passing.
  • The next student continues from the previous work instead of restarting.
  • The group compares the finished sequence to the shown solution.
✗ Doesn't Look Like
  • One student completes the whole problem alone.
  • Students pass without reading the previous step.
  • The group celebrates before checking every step for sense.

Unit 2.5 · Activity 1 Exit Ticket Answer Key
Exit Ticket
1.Current · DOK 1–2

A line of fit has slope $1.5$. Interpret that as a rate of change.

2.Current · DOK 1–2

Use $y=3x+20$ to predict $y$ when $x=6$.

3.Last · DOK 1–2

Write an equation with slope $-2$ and intercept $9$.

4.Mastery · DOK 1–2

Solve $2x-5=13$.

Key:
  1. For each $1$-unit increase in $x$, the prediction increases by about $1.5$ units.
  2. $y=3(6)+20=38$.
  3. One example is $y=-2x+9$.
  4. $2x-5=13\Rightarrow 2x=18\Rightarrow x=9$.
