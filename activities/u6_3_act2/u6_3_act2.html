Unit 6 · Section 3 · Activity 2
Mathematical Hot Seat
Quadratic Formula
Source: practice_set_6_3_3.html
Time: 20–30 min
Groups: Groups
Materials: One whiteboard and marker per member
Structure Verbal description only → Blind solving → Role rotation
Setup Groups. One whiteboard and one marker per member.
Directions
  1. One student per team sits facing away from the screen (the Hot Seat)
  2. Teacher projects a problem — only teammates can see it
  3. Teammates describe the problem using words only — no gestures, no writing
  4. Hot Seat student solves based solely on the verbal description
  5. After solving, the student turns around and compares to the original problem
  6. Rotate the Hot Seat for each round
Goal: Mathematical vocabulary + precise communication
✓ Looks Like Success
  • Teammates describe equations and features using precise vocabulary only.
  • The Hot Seat student solves from verbal information before seeing the screen.
  • Roles rotate so every student practices both describing and solving.
✗ Doesn't Look Like
  • Teammates point, gesture, or write the problem for the Hot Seat.
  • The Hot Seat turns around before solving.
  • One student stays in the same role every round.

Solution 14
Last · DOK 2

Factor each quadratic completely. If it is not factorable over the integers, explain why not.

  1. $2x^2+3x-5$
  2. $x^2-x-6$
  3. $3x^2+13x+4$
  4. $2x^2+5x+7$
Solution:

$2x^2+3x-5=(2x+5)(x-1)$.

$x^2-x-6=(x-3)(x+2)$.

$3x^2+13x+4=(3x+1)(x+4)$.

$2x^2+5x+7$ is not factorable over the integers because no integer split of $ac=14$ adds to $5$ with the needed signs.

Solution 15
Last · DOK 3

A classmate claims $x^2-12x+40$ is almost a perfect square because $40$ is close to $36$. Is that reasoning sufficient? Give a reasonableness argument based on structure, not closeness.

Solution:

Closeness is not sufficient. A perfect-square trinomial with middle term $-12x$ would have half coefficient $-6$ and constant $36$.

$x^2-12x+40=(x-6)^2+4$, so it is not a perfect square even though $40$ is close to $36$.

4. Mastery · DOK 1–2

Factor $x^2+5x+6$.

Key:
  1. Compare to $ax^2+bx+c=0$. $a=2$, $b=-7$, and $c=3$.
  2. $b^2-4ac=(-6)^2-4(1)(8)=36-32=4$. Because the discriminant is positive, there are two real solutions.
  3. Half of $6$ is $3$, and $3^2=9$. $x^2+6x+9=(x+3)^2$.
  4. Find factors of $6$ that add to $5$: $2$ and $3$. $x^2+5x+6=(x+2)(x+3)$.
