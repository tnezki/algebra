Unit 4 · Section 1 · Activity 1
Mathematical Hot Seat
Recognizing Function Families
Source: practice_set_4_1_2.html
Time: 20–30 min
Groups: Groups. One whiteboard and one marker per member.
Materials: Groups. One whiteboard and one marker per member.
StructureVerbal description only → Blind solving → Role rotation
SetupGroups. One whiteboard and one marker per member.
Directions
  1. One student per team sits facing away from the screen (the Hot Seat)
  2. Teacher projects a problem — only teammates can see it
  3. Teammates describe the problem using words only — no gestures, no writing
  4. Hot Seat student solves based solely on the verbal description
  5. After solving, the student turns around and compares to the original problem
  6. Rotate the Hot Seat for each round
Goal: Mathematical vocabulary + precise communication
✓ Looks Like Success
  • Teammates describe equations, tables, and graph features using precise words before the Hot Seat student solves.
  • The Hot Seat student records a solution from verbal information only, then checks it against the original problem.
  • Teams rotate the Hot Seat role so each student practices listening and mathematical language.
✗ Doesn't Look Like
  • A teammate points, gestures, or writes the problem for the Hot Seat student.
  • Only one teammate talks while others stop listening for precision.
  • The Hot Seat student turns around before attempting a solution.

An equation has the form $y=m x+b$ with $m\ne 0$. Name the family and one graph feature to expect.

Solution: The family is linear. In $y=mx+b$, $m$ is a nonzero constant slope, so the graph is a straight line with constant rate of change.

Solution: A slope of $-2$ means for every increase of $1$ in $x$, $y$ decreases by $2$. The $x$-values change by $3$, so each step changes $y$ by $-6$.
