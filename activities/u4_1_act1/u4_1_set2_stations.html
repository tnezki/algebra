Classify the function family represented by $y=2x^2-1$. Give one feature of the equation that supports your classification.

Quadratic; the equation structure is characteristic of a quadratic function.

Answer:

Problem 3

The top-left and bottom-left graphs both increase. Which one would produce constant first differences in a table, and which one would produce a constant ratio? Identify both families.

Answer:

Top-left is linear and would produce constant first differences. Bottom-left is exponential and would produce a constant ratio.

Problem 4

A table has constant first differences while a cropped graph window looks slightly curved. Decide which evidence is more reliable for classification.

Answer:

The constant first differences are stronger exact evidence, so the relationship should be classified as linear unless other exact data contradict it.
