Station 1 Answers

Question 1

An equation has the form $y=a|x-h|+k$ with $a\ne 0$. Name the family and the key point shown by the form.

Solution: The family is absolute value. The form $y=a|x-h|+k$ shows the vertex at $(h,k)$.

Question 2

Use the graph set and the evidence cards below. Match each evidence card to a graph, then identify the family. For each match, cite the evidence you used; do not use graph shape alone.

Evidence cardGiven evidence
1For equal input steps, the outputs change by the same amount each time.
2Outputs mirror across one input value and have constant second differences.
3Outputs decrease to a single turning point and then increase at a constant rate away from that point.
4After accounting for a vertical shift, equal input steps multiply the output pattern by a common factor.

Solution: Card 1 matches Graph A, a linear graph, because equal input steps have equal output changes. Card 2 matches Graph B, a quadratic graph, because the outputs mirror and have constant second differences. Card 3 matches Graph C, an absolute value graph, because values move toward a turning point and then away at a constant rate. Card 4 matches Graph D, an exponential graph, because equal input steps multiply the adjusted outputs by a common factor.

Question 3

Two students classify a relationship. Student A uses the equation $y=(x-1)^2+4$. Student B uses the table below. Explain two different methods that should lead to the same family classification.

$x$0123
$y$5458

Solution: Student A can use the equation form: $y=(x-1)^2+4$ is quadratic because the input expression is squared. Student B can use the table: outputs $5,4,5,8$ have first differences $-1,1,3$ and second differences $2,2$, which is evidence of a quadratic relationship. Both methods classify the relationship as quadratic.

Question 5

State the slope of a horizontal line through $(3,-4)$ and $(9,-4)$. Explain in one sentence why.

Solution: The slope is $0$ because the $y$-values are the same: $\frac{-4-(-4)}{9-3}=\frac{0}{6}=0$.

Question 6

A vertical line passes through $x=5$. Describe what happens to $\Delta x$ between any two points on that line, then state the slope category.

Solution: On a vertical line, two different points have the same $x$-value, so $\Delta x=0$. The slope is undefined because division by zero is not allowed.

Question 7

A runner travels $18$ miles in $3$ hours at a constant pace. Write the rate as a slope with units.

Solution: Rate $=\frac{18\text{ miles}}{3\text{ hours}}=6$ miles per hour. The slope is $6$ mi/hr.

Question 8

Find the constant rate of change and explain why the starting value does not change the slope.

Solution: Distance increases by $10$ miles when time increases by $2$ hours, so the rate is $\frac{10}{2}=5$ miles per hour. The starting value $15$ is the distance at time $0$, but slope depends on change, not the initial amount.

Station 3 Answers

Question 9

On the blank coordinate plane, graph a line with slope $\frac{3}{2}$ through $(0,-4)$. Then name one other point on your line.

Solution: Start at $(0,-4)$. A slope of $\frac{3}{2}$ means move right $2$ and up $3$, giving another point $(2,-1)$. Draw the line through those points.

Question 10

A rental company charges a starting fee of \$18 plus \$4 per hour. Identify the slope and use it to predict the charge for $7$ hours.

Solution: The slope is $4$ dollars per hour. For $7$ hours, cost $=18+4(7)=18+28=46$, so the charge is \$46.

Question 11

The equation $y=3x+2$ and the table are meant to match. Find the first mismatch, explain how you know, and revise the incorrect value.

$x$0123
$y$25711

Solution: Check $y=3x+2$. At $x=0$, $y=2$; at $x=1$, $y=5$. At $x=2$, the equation gives $y=8$, but the table shows $7$. The first mismatch is at $x=2$, and the correct value is $8$.

Question 12

Design two different real-world situations that both have slope $6$ but different starting values. For each, give one ordered pair and explain why the slopes match but the intercepts do not.

Solution: Example 1: a gym charges \$10 to start and \$6 per visit, so $y=6x+10$ and one point is $(1,16)$. Example 2: a club charges \$25 to start and \$6 per month, so $y=6x+25$ and one point is $(1,31)$. The slopes match because both increase by $6$ per input, but the intercepts differ because the starting values are different.

Station 4 Answers

Question 13

In elimination, which variable is ready to eliminate in the system $3x+2y=11$ and $-3x+5y=10$?

Solution: The $x$-terms are opposites, $3x$ and $-3x$, so $x$ is ready to eliminate.

Question 14

Solve the system by elimination and check your ordered pair in both equations.

$$\begin{aligned}x+5y=8\\-x+2y=-1\end{aligned}$$

Solution: Add the equations: $(x+5y)+(-x+2y)=8+(-1)$, so $7y=7$ and $y=1$. Substitute into $x+5y=8$: $x+5=8$, so $x=3$. Check: $3+5(1)=8$ and $-3+2(1)=-1$. The solution is $(3,1)$.

Question 15

For the system below, compare graphing and elimination as solving methods.

$$\begin{aligned}y=-x+8\\3x+3y=24\end{aligned}$$

Which method is more efficient, and how does the structure of the equations support your choice?

Solution: Rewrite the second equation: $3x+3y=24$ becomes $x+y=8$, or $y=-x+8$. It is the same as the first equation. Elimination or rewriting is more efficient than graphing because the structure immediately shows the equations are equivalent, so there are infinitely many solutions.

Question 16

A school fundraiser can rent Table Plan A for \$40 plus \$6 per table or Table Plan B for \$16 plus \$9 per table.

  1. Define variables and write a system that models the two plans.
  2. Solve the system and interpret the break-even point.
  3. Write one additional sentence explaining which plan is cheaper before and after the break-even point.
Performance notes: Look for clear variable definitions, a correct break-even system, accurate solving, and interpretation of both coordinates.

Solution: Let $x$ be the number of tables and $y$ be total cost. The plans are $y=40+6x$ and $y=16+9x$. Set them equal: $40+6x=16+9x$, so $24=3x$ and $x=8$. Then $y=40+6(8)=88$. The break-even point is $(8,88)$: both plans cost \$88 for $8$ tables. Before $8$ tables Plan B is cheaper; after $8$ tables Plan A is cheaper because it has the smaller rate.
