Rally Coach
Expressions and Structure
Source: practice_set_1_4_2(1).html
Time: 20–30 min
Groups: Pairs
Materials: Whiteboards or paper
StructurePartner rotation between Solver and Coach.
SetupPairs; one student solves aloud while the other coaches, then roles switch on the next problem.
Directions
  1. Partner A is Solver and Partner B is Coach for the displayed problem.
  2. The Solver explains each step while writing.
  3. The Coach asks questions, checks steps, and gives hints without taking over.
  4. Partners compare with the solution page.
  5. Switch Solver and Coach roles for the next problem.
Goal: Students verbalize procedures and practice giving useful mathematical coaching.
✓ Looks Like Success
  • The Solver talks through each algebra step.
  • The Coach asks prompts and checks work without taking the marker.
  • Roles switch after each problem.
✗ Doesn't Look Like
  • The Coach takes over the solving.
  • The Solver writes silently with no explanation.
  • Partners skip the role switch.

Solution: For $x=5$: $3(5+4)=27$ and $3(5)+12=27$. For $x=-2$: $3(-2+4)=6$ and $3(-2)+12=6$. They match for both checks, and by distribution they are equivalent for all $x$.

Solution 10
Mastery · DOK 3

Construct a step-by-step strategy for evaluating $\left|-4.5+\frac{7}{3}\right|-\left(-\frac{5}{6}\right)$. Your strategy must explain when to use absolute value and when to combine rational numbers.

Solution: Combine inside the absolute value first: $-4.5+\frac{7}{3}=-\frac{13}{6}$. Absolute value gives $\frac{13}{6}$. Then subtracting $-\frac{5}{6}$ means add: $\frac{13}{6}+\frac{5}{6}=3$.

A student wrote $y=x+4$ for a table where inputs ${1}$, ${2}$, ${3}$ have outputs ${6}$, ${8}$, ${10}$. Write the correct rule and explain the repeated change.

Solution: The outputs increase by $2$, so the rate is $2$. Using input $1$ and output $6$, $6=2(1)+b$, so $b=4$. The correct rule is $y=2x+4$.
