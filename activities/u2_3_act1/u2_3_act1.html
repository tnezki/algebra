Whiteboard Indy

Individual -> Independent practice
↑ Activity Options
Set 1 · Set 2
Setup

Each student gets a whiteboard and one marker.

Directions
  1. Notes are welcome.
  2. Try something.
  3. Write large and clearly - your work should be readable from across the room.
  4. Use your resources: ask your partner first, then the teacher. Do not copy.
  5. Mistakes are part of learning - fix them together and discuss what went wrong.

Goal: Individual accountability + low-stakes problem entry

Looks Like Success
  • Everyone attempts each problem before checking.
  • Boards show readable work, not only final answers.
  • Mistakes are corrected and discussed.
Doesn't Look Like
  • Waiting for someone else to solve first.
  • Copying an answer without understanding the work.
  • Erasing mistakes without discussing what changed.

Whiteboard Partners

Fast partner practice
↑ Activity Options
Set 1 · Set 2
Setup

Work with your partner. One whiteboard and one marker between you.

Directions
  1. Work with a partner.
  2. Both students stay engaged.
  3. Alternate who writes.
  4. Write clearly and large.
  5. Stay focused and collaborate.
  6. Fix mistakes and discuss.

Goal: Engagement + quick feedback

Looks Like Success
  • Both partners contribute on every problem.
  • The writer role alternates.
  • Partners discuss and repair errors together.
Doesn't Look Like
  • One partner does all of the writing and thinking.
  • Partners rush to copy the projected solution.
  • Conversation drifts away from the mathematics.

Rally Coach

Partner explanation + alternating roles
↑ Activity Options
Set 1 · Set 2
Setup

Sit with your partner. Each person needs one whiteboard and one marker.

Directions
  1. Work with a partner.
  2. Partner A explains, Partner B writes.
  3. Switch roles.
  4. Check answers with teacher.
  5. Rotate partners.

Goal: Verbal reasoning + procedural accuracy

Looks Like Success
  • The coach explains the reasoning aloud.
  • The writer records what the coach describes.
  • Roles switch consistently.
Doesn't Look Like
  • The coach takes the marker and solves silently.
  • The writer ignores the explanation and works independently.
  • Partners check without comparing reasoning.

Speed Dating Math

Paired practice -> Timed rotation -> Strategy sharing
↑ Activity Options
Set 1 · Set 2
Setup

Partners. One whiteboard or blank paper for each person.

Directions
  1. Work with a partner on the projected problem - both students write on their own paper.
  2. Compare strategies and methods with your partner before rotating.
  3. After 3-4 minutes, one row shifts one seat to create a new pairing.
  4. Bring your previous work and share your strategy with your new partner.
  5. Repeat across multiple problems and partner pairings.

Goal: Multiple representations + collaborative problem solving

Looks Like Success
  • Both students keep their own written work.
  • Partners compare methods before the rotation.
  • New partners explain prior strategies rather than merely showing answers.
Doesn't Look Like
  • One student records for both partners.
  • Students rotate before comparing methods.
  • The new pairing begins by copying the previous answer.

Showdown

Indy -> Group comparison -> Consensus
↑ Activity Options
Set 1 · Set 2
Setup

Groups of 4. Each person has a whiteboard. Rotate the Captain each round.

Directions
  1. Each student solves the problem individually.
  2. When prompted, students Showdown (reveal answers at the same time).
  3. Discuss differences and justify reasoning.
  4. Group agrees on a correct final answer.
  5. Repeat.

Goal: Accountability + justification

Looks Like Success
  • Everyone solves before the reveal.
  • Boards are revealed at the same time.
  • Differences lead to mathematical justification and consensus.
Doesn't Look Like
  • Students reveal early and copy.
  • The loudest answer becomes the group answer without discussion.
  • The same student serves as Captain every round.

Think, Trade, Agree

Indy -> Group comparison -> Consensus
↑ Activity Options
Set 1 · Set 2
Setup

Groups of 4. Each person has a whiteboard.

Directions
  1. Teacher presents problem.
  2. Each student solves the problem individually.
  3. When all students are done, exchange boards.
  4. Discuss differences and justify reasoning.
  5. Come to an agreement or ask teacher to help.
  6. Repeat exchange with someone different.

Goal: Accountability + justification

Looks Like Success
  • Each student has an independent attempt before trading.
  • Students read and discuss another person's reasoning.
  • Agreement is based on evidence, not speed.
Doesn't Look Like
  • Boards are traded before everyone has attempted the problem.
  • Students change answers without discussing why.
  • The same partners trade every round.

Round Table

One step per student
↑ Activity Options
Set 1 · Set 2
Setup

Groups of 4. One whiteboard and one marker per group.

Directions
  1. Groups of 4. One whiteboard and marker per group.
  2. Each student completes ONE step, then passes the board.
  3. Rotate until the problem is complete.
  4. Compare when the solution is shown.
  5. If everyone understands, celebrate.

Goal: Sequential reasoning + shared responsibility

Looks Like Success
  • Each person contributes one meaningful step.
  • Students read the existing work before adding the next step.
  • The group checks the complete reasoning together.
Doesn't Look Like
  • One student keeps the marker for multiple steps.
  • Students add steps without reading prior work.
  • The group stops once an answer appears, without checking understanding.

Mathematical Hot Seat

Verbal description only -> Blind solving -> Role rotation
↑ Activity Options
Set 1 · Set 2
Setup

Groups. One whiteboard and one marker per member.

Directions
  1. One student per team sits facing away from the screen (the Hot Seat).
  2. Teacher projects a problem - only teammates can see it.
  3. Teammates describe the problem using words only - no gestures, no writing.
  4. Hot Seat student solves based solely on the verbal description.
  5. After solving, the student turns around and compares to the original problem.
  6. Rotate the Hot Seat for each round.

Goal: Mathematical vocabulary + precise communication

Looks Like Success
  • Teammates use precise mathematical language.
  • The Hot Seat student relies only on verbal information.
  • The role rotates so everyone practices describing and solving.
Doesn't Look Like
  • Teammates gesture, point, or write the problem.
  • Someone says the answer instead of describing the mathematics.
  • One student remains in the Hot Seat for multiple rounds.

Rally Coach II

Teammate lists steps other 3 write
↑ Activity Options
Set 1 · Set 2
Setup

Group of 4. Each person needs one whiteboard and one marker.

Directions
  1. Pick Starter.
  2. Starter lists steps to solve; teammates write.
  3. Check answers with teacher.
  4. Rotate starter.

Goal: Verbal reasoning + procedural accuracy

Looks Like Success
  • The Starter verbalizes a complete sequence of steps.
  • Teammates write from the verbal directions.
  • The Starter rotates after checking.
Doesn't Look Like
  • The Starter writes on everyone's boards.
  • Teammates solve ahead without listening.
  • The same person remains Starter.

Desmos Activity

Individual or Partners -> Teacher-paced investigation
↑ Activity Options
Teacher supplies the activity code/link.
Setup

Individual or partner work, computer/iPad.

Directions
  1. Open the teacher-selected activity using the code/link supplied by the teacher.
  2. Work through each screen thoughtfully.
  3. Pause for whole-class discussion when prompted.

Goal: Conceptual exploration + interactive sense-making

Looks Like Success
  • Students use the teacher-supplied activity code or link.
  • Screens are completed thoughtfully rather than clicked through.
  • Students pause and contribute during discussion moments.
Doesn't Look Like
  • A made-up or unofficial link is used.
  • Students race through screens without reasoning.
  • Discussion pauses are ignored.

Stations

Timed rotations
↑ Activity Options
Set 1 Stations · Set 2 Stations
Setup

Use the current Framework's station count/page contract. Students pick up a record sheet before beginning.

Directions
  1. Get the record sheet.
  2. Choose a starting station within the posted group-size limit.
  3. Work until the teacher signals rotation.
  4. Rotate as directed; do not crowd one station.

Goal: Repetition + varied problem exposure

Looks Like Success
  • Groups spread across the six stations.
  • Students work all four questions before rotating when time allows.
  • Rotations happen on the teacher signal and keep traffic moving.
Doesn't Look Like
  • Several groups crowd the same station.
  • Students rotate without recording work.
  • Groups skip stations because another station looks easier.

Find Someone Who

Movement + peer interaction
↑ Activity Options
Set 1 Handout · Set 2 Handout
Setup

Students need the printable worksheet/record sheet and a pencil.

Directions
  1. Work alone first and attempt as many problems as possible.
  2. Find a partner and compare completed work.
  3. Work together on one unfinished or disagreed-on problem; both students record the reasoning.
  4. Find someone new and repeat.
  5. Return with the work completed and understood, not merely filled in.

Goal: Exposure to multiple explanations

Looks Like Success
  • Students begin with independent attempts.
  • Each new partner comparison focuses on reasoning.
  • Signature lines represent genuine mathematical interaction.
Doesn't Look Like
  • Students collect signatures without discussing a problem.
  • One student simply gives another student an answer.
  • Students stay with the same partner for the whole activity.

Tarsia (Puzzle Activity)

Matching puzzle (self-checking)
↑ Activity Options
Practice Tarsia source
Setup

Groups of 4. Copies of puzzle.

Directions
  1. Students match expressions, answers, or steps.
  2. Pieces form a complete shape.
  3. If correct, the puzzle fits.

Goal: Error detection + pattern recognition

Looks Like Success
  • Students justify matches before locking pieces in place.
  • The group uses the completed shape as a self-check.
  • Disagreements are resolved by checking the mathematics.
Doesn't Look Like
  • Pieces are matched only by physical fit.
  • One student assembles while others watch.
  • The group accepts a mismatch without rechecking the mathematics.
