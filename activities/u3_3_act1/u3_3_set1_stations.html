Station 1 Answers

Question 1

Why should variables be defined before writing a system from a situation?

Solution:

Variables should be defined first so each equation uses the same meanings and units. That prevents mixing quantities or writing a system that cannot be interpreted.

Question 2

Which phrase usually suggests a total equation: “altogether,” “per hour,” or “starts with”?

Solution:

“Altogether” usually suggests a total equation.

Question 3

Two water tanks are draining. Tank A has 80 gallons and loses 5 gallons per minute. Tank B has 50 gallons and loses 2 gallons per minute. Write and solve a system to find when they contain the same amount.

Solution:

Let $t$ be minutes and $g$ be gallons. Tank A: $g=80-5t$. Tank B: $g=50-2t$. Set equal: $80-5t=50-2t$, so $30=3t$ and $t=10$. They contain the same amount after $10$ minutes.

Question 4

For the taxi plans \$5 plus \$2 per mile and \$11 plus \$1.25 per mile, compare solving by graphing, substitution, and elimination. Which method gives the cleanest paper-only solution, and why?

Solution:

Let $m$ be miles. The plans are $C=5+2m$ and $C=11+1.25m$. Substitution is clean because both equations are already solved for cost. Set equal: $5+2m=11+1.25m$, so $0.75m=6$ and $m=8$.

Question 9

The table has constant first differences of $-4$. Write a linear equation if the output is $18$ when $x=0$.

Solution:

A constant first difference of $-4$ means slope $-4$. With output $18$ at $x=0$, the equation is $y=-4x+18$.

Question 10

Two students solve $3(x+4)=30$. Student A divides by $3$ first. Student B distributes first. Use both methods to solve, then explain which method is more efficient and why.

Solution:

Student A: divide by $3$ to get $x+4=10$, so $x=6$. Student B: distribute to get $3x+12=30$, so $3x=18$ and $x=6$. Dividing first is more efficient because it avoids extra distribution.

Question 11

A concert ticket costs \$18 plus a \$4 service fee. A student writes $18+4t=90$ to find the number of tickets bought with \$90. Decide whether the model is reasonable and revise it if needed.

Solution:

The model is not reasonable if $t$ is tickets, because the \$4 service fee is one time, not per ticket. A better model is $18t+4=90$. Then $18t=86$, so $t=\frac{86}{18}\approx4.78$, which means \$90 is not enough for exactly $5$ tickets with this fee.

Question 12

You are given two facts about one relationship: when $x=0$, $y=9$; when $x=4$, $y=21$. Synthesize a table, equation, context, and one additional point that all represent the same relationship. Explain how each representation shows the same starting value and change.

Solution:

The rate is $\frac{21-9}{4-0}=3$, so $y=3x+9$. Table: $(0,9),(1,12),(2,15),(4,21)$. Context: start with $9$ and add $3$ each step. Additional point: $(5,24)$.

Question 15

Four related lines are shown. Use slope and intercept features to decide which one could represent $y=2x+3$, $y=2x-2$, $y=2x+1$, and $y=-2x+1$. Explain one choice.

Solution:

Match slope and intercept. The line with slope $2$ and intercept $3$ represents $y=2x+3$; the one with slope $2$ and intercept $-2$ represents $y=2x-2$; the one with slope $2$ and intercept $1$ represents $y=2x+1$; the line with negative slope $-2$ and intercept $1$ represents $y=-2x+1$.

Question 16

A model for a school fundraiser is $M=250+45d$, where $d$ is days. A student predicts \$4,750 after $100$ days. Is the prediction arithmetically correct and contextually reasonable for a short fundraiser? Justify both parts.

Solution:

Arithmetic: $M=250+45(100)=250+4500=4750$, so the calculation is correct. Contextually, $100$ days may be unreasonable for a short school fundraiser, so the prediction may extend beyond the useful range of the model.
