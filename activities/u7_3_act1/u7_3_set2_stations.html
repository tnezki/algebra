Question 1

For $f(x)=6(0.5)^x$, choose the correct domain and range from the statements below.

  1. Domain: all real numbers; Range: $y\gt 0$
  2. Domain: $x\gt 0$; Range: all real numbers
  3. Domain: all real numbers; Range: $y\lt 0$

Solution: The correct choice is: Domain: all real numbers; Range: $y\gt0$. Exponential functions with positive starting value and no vertical shift are defined for all real $x$ and stay positive.

Question 2

For $h(x)=4(0.75)^x+2$, make a table for x = 0, 1, 2, 3, then identify the horizontal asymptote and explain why it is not the x-axis.

Solution: $h(0)=4(1)+2=6$, $h(1)=4(0.75)+2=5$, $h(2)=4(0.75)^2+2=4.25$, and $h(3)=4(0.75)^3+2=3.6875$. The horizontal asymptote is $y=2$, not the x-axis, because the whole graph is shifted up $2$ units.

Question 3

A student predicts that $y=100(0.9)^x$ will equal 0 after enough steps because it keeps decreasing. Assess the reasonableness of this claim using graph behavior and the multiplier.

Solution: The claim is not reasonable. Multiplying by $0.9$ repeatedly makes the value smaller, but it stays positive because a positive number times $0.9$ is still positive. The graph approaches $y=0$ as an asymptote but does not equal $0$.

Question 4

A student graphs $f(x)=3(2)^x+1$ with y-intercept 3 and asymptote $y=0$.

  1. Revise the graph features so they match the equation.
  2. Explain how the +1 changes both the y-intercept and asymptote.

Solution: For $f(x)=3(2)^x+1$, the y-intercept is $f(0)=3(1)+1=4$. The horizontal asymptote is $y=1$. The $+1$ shifts the basic graph up $1$ unit, so both the y-intercept and asymptote increase by $1$.

Question 5

Classify each expression as a difference of squares, a perfect-square trinomial, or neither.

  1. $x^2-64$
  2. $y^2-6y+9$
  3. $4x^2+4x+1$
  4. $5x^2-45$

Solution: $x^2-64$ is a difference of squares. $y^2-6y+9$ is a perfect-square trinomial. $4x^2+4x+1$ is a perfect-square trinomial. $5x^2-45$ has a GCF first, then a difference of squares after factoring $5$.

Question 6

Factor each difference of squares.

  1. $x^2-16$
  2. $9x^2-16$
  3. $64m^2-25$
  4. $9x^2y^2-49$

Solution: $x^2-16=(x-4)(x+4)$. $9x^2-16=(3x-4)(3x+4)$. $64m^2-25=(8m-5)(8m+5)$. $9x^2y^2-49=(3xy-7)(3xy+7)$.

Question 7

Identify the squared-binomial form for each expression.

  1. $x^2-10x+25$
  2. $x^2+4x+4$
  3. $a^2+8ab+16b^2$
  4. $c^2-10c+25$

Solution: $x^2-10x+25=(x-5)^2$. $x^2+4x+4=(x+2)^2$. $a^2+8ab+16b^2=(a+4b)^2$. $c^2-10c+25=(c-5)^2$.

Question 8

Rewrite $49x^2+14x+1$ so its perfect-square structure is visible, then factor it.

Solution: Write $49x^2+14x+1=(7x)^2+2(7x)(1)+1^2$. Therefore it factors as $(7x+1)^2$.

Question 9

Find the value of $k$ that makes $x^2+kx+36$ a perfect-square trinomial with a negative binomial factor. Then factor it.

Solution: A negative binomial factor means $(x-6)^2=x^2-12x+36$. Therefore $k=-12$, and the factorization is $(x-6)^2$.

Question 10

Factor $4x^2-8x+4$ and explain why the result has a repeated factor.

Solution: Factor out $4$: $4x^2-8x+4=4(x^2-2x+1)=4(x-1)^2$. It has a repeated factor because the trinomial is a perfect square.

Question 11

Construct a strategy for choosing among standard, vertex, and factored form when a problem asks for y-intercept, zeros, or vertex. Test your strategy on $y=x^2-4x-5$.

Solution: Use standard form for the y-intercept, factored form for zeros, and vertex form for the vertex. For $y=x^2-4x-5$, standard form gives y-intercept $-5$; factored form $(x-5)(x+1)$ gives zeros $5$ and $-1$; vertex form $(x-2)^2-9$ gives vertex $(2,-9)$.

Question 12

Create a factored quadratic model for a situation where an object starts on the ground, rises, and returns to the ground after $6$ seconds. Include the equation, the zeros, and a sentence interpreting the zeros.

Solution: Answers vary. One model is $h(t)=-t(t-6)$. The zeros are $t=0$ and $t=6$, meaning the object starts on the ground and returns to the ground after $6$ seconds. The negative leading coefficient makes the object rise then fall.

Question 13

Solve $x^2+2x-8=0$ by first making a perfect square.

Solution: Move the constant: $x^2+2x=8$. Complete the square: $x^2+2x+1=9$, so $(x+1)^2=9$. Then $x+1=\pm3$, giving $x=2$ or $x=-4$.

Question 14

Solve or interpret the quadratic situation for Completing the Square. Show the algebra that supports your answer.

Find the missing area pieces needed to complete a square for $x^2+6x$.

Solution: Split $6x$ into two equal pieces of $3x$. The missing corner is $3\cdot3=9$, so $x^2+6x+9=(x+3)^2$.

Question 15

Mismatch. Analyze the quadratic evidence for Quadratic Formula. Write a conclusion and justify it with algebraic or graphical evidence.

The equation and table are supposed to match. Find the first incorrect table value and revise it.

$x$0123
$x^2+2x+1$14816

Solution: Check the rule $x^2+2x+1=(x+1)^2$. At $x=0$, value $1$; at $x=1$, value $4$; at $x=2$, value $9$; at $x=3$, value $16$. The first incorrect table value is at $x=2$, where $8$ should be $9$.

Question 16

Revise A Flawed Model. Create or revise a quadratic task for Solving Quadratics by Factoring using the constraints below.

  • Include at least two representations among equation, table, graph, or context.
  • Make the solution method visible from structure, not from a hint.
  • Interpret the solution in words.

A student writes $A(x)=(x+3)(x+9)$ for a rectangular area model that should have positive side lengths $x-3$ and $x+9$. Revise the model, solve $A(x)=0$, and explain why any negative solution is not a valid length.

Solution: Positive side lengths $x-3$ and $x+9$ give $A(x)=(x-3)(x+9)$. Solving $A(x)=0$ gives $x=3$ or $x=-9$. The negative solution is not valid for a length, and $x=3$ makes one side length $0$, so the rectangle context needs $x\gt3$ for positive area.
