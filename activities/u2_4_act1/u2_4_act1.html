Unit 2 · Section 4 · Activity 1
Mathematical Hot Seat
Comparing Linear Representations
Source: practice_set_2_4_2.html
Time: 20–30 min
Groups: Groups
Materials: One whiteboard and one marker per member
Structure Verbal description only → Blind solving → Role rotation
Setup Groups. One whiteboard and one marker per member.
Directions
  1. One student per team sits facing away from the screen (the Hot Seat)
  2. Teacher projects a problem — only teammates can see it
  3. Teammates describe the problem using words only — no gestures, no writing
  4. Hot Seat student solves based solely on the verbal description
  5. After solving, the student turns around and compares to the original problem
  6. Rotate the Hot Seat for each round
Goal: Mathematical vocabulary + precise communication
✓ Looks Like Success
  • Teammates describe slope, intercept, table, or graph features using words only.
  • The Hot Seat student solves without seeing the projected problem.
  • After solving, the team compares the verbal description to the original.
✗ Doesn't Look Like
  • Teammates point, gesture, or write the problem for the Hot Seat student.
  • The Hot Seat student turns around before finishing.
  • The team skips the comparison after the answer is shown.

Exit Ticket
1.Current · DOK 1–2

Compare $y=-2x+10$ and $y=4x-1$: which line increases faster?

2.Current · DOK 1–2

A table starts at 8 and changes by $-3$ each input. Write a rule.

3.Last · DOK 1–2

Name the slope and intercept of $y=\frac{1}{2}x-5$.

4.Mastery · DOK 1–2

Solve $4x+1=17$.

Key:
  1. $y=4x-1$ increases faster because its slope $4$ is greater than $-2$.
  2. $y=-3x+8$.
  3. Slope $=\frac{1}{2}$ and intercept $=-5$.
  4. $4x+1=17\Rightarrow 4x=16\Rightarrow x=4$.
