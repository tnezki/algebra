Problem 11

A student calls $g(x)=\frac12 f(x)$ a vertical stretch because the coefficient is positive. Correct the claim.

Answer:

Because the output multiplier has magnitude between 0 and 1, the graph is vertically compressed by factor $1/2$; positivity only tells us there is no x-axis reflection.

Problem 19

Describe the solution region for the system $y\gt x+2$ and $y\le-2x+5$, including which boundary is dashed and which is solid.

Answer:

Shade above the dashed line $y=x+2$; shade on or below the solid line $y=-2x+5$; the overlap is the solution region.
