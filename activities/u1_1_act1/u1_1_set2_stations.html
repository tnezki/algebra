5. A delivery fee is modeled by \(C=9+3n\), where n is the number of packages. Interpret the ordered pair (4,21) in context.

Solution: Four packages cost a total of 21 dollars.

6. A and B have rules \(y=-4x+6\) and \(y=-4x-1\). Compare their rates and starting values, then decide whether they can ever have the same output.

Solution: Both rates are -4, but starts are 6 and -1. The lines stay 7 units apart, so they never have the same output.

7. A table contains (0,2), (2,10), and (5,22). Another representation claims the rule is \(y=4x+2\). Is the claim supported? Cite at least two checks.

Solution: Yes. The rule gives 2, 10, and 22 for those inputs; the rate is also 4.

9. A monthly plan starts at $27 and increases $5 per month. Write a rule and give two ordered pairs that could appear in a matching table.

Solution: Example: \(C=27+5m\); (0,27) and (4,47).

10. The points (-1,8), (2,2), and (5,-4) form a linear relationship. Find the rule.

Solution: Rate is -2. Using (-1,8): 8=2+b, so b=6. \(y=-2x+6\).

11. A relationship starts at 15 and decreases 3 each step. Create a four-row table using x=0,1,3,6.

Solution: Outputs are 15, 12, 6, -3.

12. A table shows a change of +18 in y while x changes by +6. Explain how this rate would appear in an equivalent equation.

Solution: The rate is 18/6=3, so the coefficient of x in a linear rule would be 3.

Station 4 Solutions • Set 2
Answer Key
13. Translate \(y=-5x+12\) into a context where the negative rate makes sense. Identify the starting value and rate with units.

Solution: Example: 12 liters remain initially and 5 liters drain per minute; start 12 L, rate -5 L/min.

14. Relationship A has rule \(y=3x+1\). Relationship B has the same output 13 at x=4 but rate 2. Explain why one matching point does not make them the same relationship.

Solution: A has rate 3 while B has rate 2, so their outputs change differently; one shared point is insufficient.

15. A line has rate -1 and passes through (0,9). Write the rule and use it to generate one new pair not already given.

Solution: \(y=-x+9\); for example x=4 gives (4,5).

16. A table lists pairs out of x-order: (5,16), (-1,-2), (2,7), and (0,1). Explain a reliable way to check whether they fit \(y=3x+1\).

Solution: Substitute each x into the rule and compare the resulting y; display order does not matter. All four pairs match.

Station 5 Solutions • Set 2
Answer Key
17. A point is 4 units left and 8 units down from the origin. Write the pair and name the quadrant.

Solution: (-4,-8), Quadrant III.

18. For the point (-9,2), which coordinate controls horizontal movement and which controls vertical movement? State both moves.

Solution: x=-9 controls 9 units left; y=2 controls 2 units up.

19. A graph will use number of practice problems as input and minutes spent as output. Assign each quantity to an axis and explain the order of an ordered pair.

Solution: Problems on x-axis; minutes on y-axis. Pair order is (problems, minutes).

20. A student says the point (-6,3) means 6 units up and 3 units left. Identify the coordinate-order error and state the correct movement.

Solution: The first coordinate controls horizontal movement: 6 left; the second controls vertical: 3 up.

Station 6 Solutions • Set 2
Answer Key
21. Two consecutive labeled y-values are -15 and -5 with five equal small intervals between them. What is the value of one interval?

Solution: 2 units.

22. The x-axis labels -12 and 0 have six equal small intervals between them. What x-value is two intervals left of 0?

Solution: Each interval is 2, so two intervals left is -4.

23. A line crosses the axes at (7,0) and (0,-3). Name the x-intercept and y-intercept, then explain why their zero coordinates are different.

Solution: x-intercept (7,0); y-intercept (0,-3). On x-axis y=0; on y-axis x=0.

24. A savings graph has y-intercept (0,25). Its x-intercept would represent a balance of zero. Explain the meaning of the y-intercept and what an x-intercept would mean in this context.

Solution: At time 0 there are 25 dollars saved. An x-intercept would be a time when the balance is 0 dollars.
