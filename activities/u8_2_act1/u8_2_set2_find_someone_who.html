Teacher Key — Section 8.2 · Set 2
1

Describe the horizontal and vertical translation from $f(x)=|x|$ to $g(x)=|x-5|+3$.

Answer:

Shift 5 units right and 3 units up.

2

Write a transformed rule for $f(x)=(0.5)^x$ shifted 1 unit left.

Answer:

$g(x)=(0.5)^{x+1}$.

3

For $g(x)=-0.5f(x-2)$, transform each listed parent point and describe the coordinate rule.

Parent $x$Parent $y$
-24
00
24
Answer:

Each x-coordinate moves right 2 and each y-coordinate is multiplied by -0.5. The new points are $(0,-2),(2,0),(4,-2)$.

4

Compare $g(x)=-0.5|x+2|+5$ with $f(x)=|x|$. Describe the reflection/compression and translations.

Answer:

Reflect across the x-axis, vertically compress by factor 0.5, shift left 2, and shift up 5.

Teacher Key — Section 8.2 · Set 2
5

Compare the parent graph on the left with the transformed graph on the right. Describe the transformation using key features, not just overall appearance.

Answer:

The second absolute-value graph is reflected over the x-axis, stretched by a factor of $1.5$, shifted left 1, and shifted up 2.

6

A transformation takes $f(x)$ to $g(x)=f(x+1)+6$. State the horizontal and vertical shifts.

Answer:

Left 1 unit and up 6 units.

7

The point $(-2,6)$ lies on $y=f(x)$. Under $g(x)=0.5f(x)$, where does that key point move?

Answer:

$(-2,3)$. The x-coordinate stays fixed and the y-value is multiplied by 0.5.

8

A revenue model $R(t)$ is adjusted by adding a fixed 150-dollar service credit to every output. Write the transformed model and describe the graph change.

Answer:

$g(t)=R(t)+150$; every point moves up 150 units.

Teacher Key — Section 8.2 · Set 2
9

Compare $x^2$, $|x|$, and $2^x$. If each parent is replaced by $f(x-2)+3$, what transformation is common to all three families?

Answer:

Each graph shifts right 2 units and up 3 units, although the key features being moved differ by family.

10

Start with $f(x)=x^2$. Write the rule for a graph shifted 1 unit(s) right and 2 unit(s) down.

Answer:

$g(x)=(x-1)^2-2$

11

Describe the horizontal and vertical translation from $f(x)=|x|$ to $g(x)=|x+3|+4$.

Answer:

Shift 3 unit(s) left and 4 unit(s) up.

12

Write a transformed rule for $f(x)=2^x$ shifted 5 unit(s) up.

Answer:

$g(x)=2^x+5$.

Teacher Key — Section 8.2 · Set 2
17

The point $(2,5)$ lies on $y=f(x)$. Under $g(x)=2f(x)$, where does that key point move?

Answer:

$(2,10)$. The x-coordinate stays fixed; the y-value is multiplied by 2.

18

A quadratic height model $h(t)$ is recalibrated so every measured height is 1.5 meters higher, while time is unchanged. Write the transformed model in function notation and explain the graph change. State which key features change and which do not.

Answer:

Use $g(t)=h(t)+1.5$; every point moves up 1.5 units.

19

For $y=8(0.5)^x-1$, state the y-intercept and horizontal asymptote.

Answer:

$y$-intercept $(0,7)$; horizontal asymptote $y=-1$.

20

The right-hand graph in the exponential panel is a transformation of $2^x$. Identify the horizontal asymptote and whether it represents growth or decay.

Answer:

The graph is growth and has horizontal asymptote $y=1$.

Solve $x^2-10x+16=0$ by completing the square.

Answer:

What term must be added to $x^2-12x$ to create a perfect-square trinomial? Write the resulting square.

Answer:

Add 36; $x^2-12x+36=(x-6)^2$.
