Unit 7 · Section 3 · Activity 2
Mathematical Hot Seat
Graphing and Analyzing Exponential Functions
Source: practice_set_7_3_3.html
Time: 20–30 min
Groups: Groups
Materials: One whiteboard and marker per member
Structure Verbal description only → Blind solving → Role rotation
Setup Groups. One whiteboard and one marker per member.
Directions
  1. One student per team sits facing away from the screen (the Hot Seat)
  2. Teacher projects a problem — only teammates can see it
  3. Teammates describe the problem using words only — no gestures, no writing
  4. Hot Seat student solves based solely on the verbal description
  5. After solving, the student turns around and compares to the original problem
  6. Rotate the Hot Seat for each round
Goal: Mathematical vocabulary + precise communication
✓ Looks Like Success
  • Teammates describe symbols, graphs, and tables using precise words only.
  • The Hot Seat student solves without seeing the projected problem.
  • Roles rotate so each student practices both describing and blind solving.
✗ Doesn't Look Like
  • Teammates point, gesture, or write the problem for the Hot Seat student.
  • The Hot Seat student turns around before completing the attempt.
  • One student remains in the same role for every round.

Solution 2
Current · DOK 2

For $h(x)=4(0.75)^x+2$, make a table for x = 0, 1, 2, 3, then identify the horizontal asymptote and explain why it is not the x-axis.

Solution: $h(0)=4(1)+2=6$, $h(1)=4(0.75)+2=5$, $h(2)=4(0.75)^2+2=4.25$, and $h(3)=4(0.75)^3+2=3.6875$. The horizontal asymptote is $y=2$, not the x-axis, because the whole graph is shifted up $2$ units.

Solution: The claim is not reasonable. Multiplying by $0.9$ repeatedly makes the value smaller, but it stays positive because a positive number times $0.9$ is still positive. The graph approaches $y=0$ as an asymptote but does not equal $0$.

Solution: Use standard form for the y-intercept, factored form for zeros, and vertex form for the vertex. For $y=x^2-4x-5$, standard form gives y-intercept $-5$; factored form $(x-5)(x+1)$ gives zeros $5$ and $-1$; vertex form $(x-2)^2-9$ gives vertex $(2,-9)$.

Solve $x^2+2x-8=0$ by first making a perfect square.

Solution 16
Last · DOK 4

Revise A Flawed Model. Create or revise a quadratic task for Solving Quadratics by Factoring using the constraints below.

  • Include at least two representations among equation, table, graph, or context.
  • Make the solution method visible from structure, not from a hint.
  • Interpret the solution in words.

A student writes $A(x)=(x+3)(x+9)$ for a rectangular area model that should have positive side lengths $x-3$ and $x+9$. Revise the model, solve $A(x)=0$, and explain why any negative solution is not a valid length.

Solution: Positive side lengths $x-3$ and $x+9$ give $A(x)=(x-3)(x+9)$. Solving $A(x)=0$ gives $x=3$ or $x=-9$. The negative solution is not valid for a length, and $x=3$ makes one side length $0$, so the rectangle context needs $x\gt3$ for positive area.
