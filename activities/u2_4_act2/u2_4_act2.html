Rally Coach II
Comparing Linear Representations
Source: practice_set_2_4_3.html
Time: 20–30 min
Groups: Group of 4
Materials: One whiteboard and one marker per person
Structure Teammate lists steps other 3 write
Setup Group of 4. Each person needs one whiteboard and one marker.
Directions
  1. Pick Starter
  2. Starter list steps to solve, teammates write
  3. Check answers with teacher
  4. Rotate starter
Goal: Verbal reasoning + procedural accuracy
✓ Looks Like Success
  • The Starter lists steps while the other three write them out.
  • The group checks one completed board before rotating the Starter.
  • Each new Starter names the strategy before calculations begin.
✗ Doesn't Look Like
  • The Starter does all of the writing for the group.
  • Teammates write answers without listening to the step list.
  • The same student remains Starter for multiple rounds.

For $f(x)=|x-3|+5$, find all input values that give an output of $10$.

Solution:
  1. Solve $|x-3|+5=10$.
  2. $|x-3|=5$.
  3. $x-3=5$ or $x-3=-5$, so $x=8$ or $x=-2$.

Exit Ticket
1.Current · DOK 1–2

Two plans are $A=10+2x$ and $B=4+5x$. Which starts higher? Which grows faster?

2.Current · DOK 1–2

A line and a table both have slope $3$. What else must match for them to be the same function?

3.Last · DOK 1–2

Find the rate of change from $(0,12)$ to $(4,0)$.

4.Mastery · DOK 1–2

Factor $12x+18$ by the GCF.

Key:
  1. Plan A starts higher; Plan B grows faster.
  2. The starting value/intercept must also match.
  3. Slope $=\frac{0-12}{4-0}=-3$.
  4. $12x+18=6(2x+3)$.
