Station 1 Answers

Question 1

In $y\le -2x+5$, should the solution region be above or below the boundary line?

Solution:

For $y\le -2x+5$, the solution region is below the boundary line because the $y$ values are less than or equal to the line.

Question 2

What point is most often easiest to use as a test point when it is not on the boundary?

Solution:

The easiest test point is often $(0,0)$, as long as it is not on the boundary line.

Question 3

Use the test point $(0,0)$ to decide whether it is a solution to $y\le 2x-5$. Then state which side should be shaded.

Solution:

Substitute $(0,0)$: $0\le 2(0)-5$, so $0\le -5$ is false. Therefore $(0,0)$ is not a solution, and the opposite side of the line should be shaded.

Question 4

The inequality $y\ge x-2$ and the table are supposed to agree about which points satisfy the inequality.

Point$(0,0)$$(3,0)$$(1,1)$$(-2,-3)$
Listed resultYesYesYesNo

Find the first mismatch, correct it, and justify with substitution.

Solution:

Check $(0,0)$: $0\ge0-2$, true. Check $(3,0)$: $0\ge3-2$, so $0\ge1$ is false. The first mismatch is $(3,0)$; its result should be No, not Yes.

Question 5

A linear table has first differences that are constant. What table pattern do you check first for a quadratic relationship?

Solution:

For a quadratic relationship, check whether second differences are constant.

Question 6

What family often has a graph shaped like a V?

Solution:

An absolute value family often has a graph shaped like a V.

Question 7

Decide whether $(x+5)(x+2)$ has the same expanded form as $x^2+7x+10$. Use distribution or an area model explanation.

Solution:

Distribute: $(x+5)(x+2)=x^2+2x+5x+10=x^2+7x+10$. Yes, the expanded form is the same.

Question 8

A movie rental service charges \$6 plus \$3 per movie. Write and solve an equation to find how many movies can be rented for \$27.

Solution:

Let $m$ be movies. $6+3m=27$, so $3m=21$ and $m=7$. The service can rent $7$ movies for \$27.

Station 3 Answers

Question 9

Solve $4(x-2)+6=30$ and show each step.

Solution:

$4(x-2)+6=30$ gives $4x-8+6=30$, so $4x-2=30$, $4x=32$, and $x=8$.

Question 10

Compare the graph and context. Context: A cyclist starts $4$ miles from home and rides away at $2$ miles per hour. Decide whether the graph could model the context and justify your conclusion with the intercept and rate.

Solution:

The cyclist context starts at $4$ and has rate $2$. The graph has slope $2$ but intercept $1$, so it does not model the context because the starting value does not match.

Question 11

A rule for a school fundraiser is proposed as $C=25n$, where $n$ is the number of tickets and $C$ is cost. The flyer says there is also a one-time \$10 processing charge. Is the proposed rule reasonable? Explain and revise it if needed.

Solution:

The proposed rule is missing the one-time charge. The revised rule is $C=25n+10$.

Question 12

Create a real context that can be represented by both $8x+20$ and $4(2x+5)$. Then explain what each form reveals about the situation and give one input-output check that confirms equivalence.

Solution:

Example context: $x$ boxes each have $8$ items, plus $20$ extra items; equivalently, there are $4$ groups of $2x+5$ items. $8x+20$ shows the total variable and fixed parts; $4(2x+5)$ shows equal groups. At $x=2$, both equal $36$.

Station 4 Answers

Question 13

State whether $x=4$ graphs as a horizontal line or a vertical line.

Solution:

$x=4$ graphs as a vertical line because every point has $x$-coordinate $4$.

Question 14

Describe the graph of $y=-2$, including which axis it is parallel to.

Solution:

$y=-2$ is a horizontal line through $-2$ on the $y$-axis. It is parallel to the $x$-axis.

Question 15

A subscription begins with a \$15 setup charge and costs \$6 each month. Graph the first six months using month as $x$ and total cost as $y$.

Solution:

The equation is $y=15+6x$. For months $0$ through $6$, points include $(0,15),(1,21),(2,27),(3,33),(4,39),(5,45),(6,51)$.

Question 16

A student claims Plan B is always cheaper because it starts lower: Plan A is $A=20+5x$ and Plan B is $B=5+8x$. Critique the claim and include a value of $x$ that supports your reasoning.

Solution:

Plan B starts lower, but it has a larger slope. Set $20+5x=5+8x$ to get $15=3x$, so $x=5$. Before $5$ uses, B is cheaper; after $5$ uses, A is cheaper. For example at $x=10$, A costs $70$ and B costs $85$.
