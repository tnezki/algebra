Problem 13

A graphing problem asks where a quadratic crosses the $x$-axis. Which form—standard, vertex, or factored—usually lets you read those values with the least algebra?

Factored form, because the zeros come directly from setting each factor equal to zero.

Problem 14

A design problem asks for the highest point of a parabolic arch. Which form—standard, vertex, or factored—usually makes that point most direct?

Vertex form, because the vertex $(h,k)$ is visible in $a(x-h)^2+k$.

Problem 15

A model asks for the initial value $f(0)$. Which form—standard, vertex, or factored—usually displays that value directly?

Standard form $ax^2+bx+c$, because $c=f(0)$ is the $y$-intercept.

Problem 16

A student says standard form is always the most useful form. Give one task for which vertex form is more efficient.

Finding the maximum or minimum, the vertex, or the axis of symmetry is generally more efficient in vertex form.

Problem 21

For $y=(x-3)^2-8$, which visible feature would take more work to obtain: the vertex or the zeros?

The zeros take more work; the vertex is already visible.

Problem 22

A ball's height model is being used to find the maximum height and when it occurs. Which quadratic form is the most useful first choice, and why?

Vertex form, because the vertex gives both the maximum height and the input value where it occurs.

Problem 23

A revenue model asks for the input values where revenue is zero. Would factored form or standard form usually be the more useful first choice? Explain.

Factored form, because the zero-revenue inputs come from setting the factors equal to zero.

Problem 24

Rewrite $y=(x+4)^2-16$ in factored form by recognizing a difference of squares.

$y=x(x+8)$.
