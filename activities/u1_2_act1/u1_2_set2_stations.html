Classroom Copy 1
Station 5 Answers • Set 2

A parking garage charges 2 dollars per hour parked. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: cost C in dollars. One rule is $C=2h$.

A conveyor packs 6 boxes each minute. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: minutes. Output: boxes B. One rule is $B=6m$.

A tank begins with 80 liters and drains 5 liters each minute. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: minutes. Output: volume V in liters. One rule is $V=80-5t$.

A hiker starts 3 kilometers from a trailhead and moves away at 2 kilometers per hour. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: distance d in kilometers. One rule is $d=2h+3$.
