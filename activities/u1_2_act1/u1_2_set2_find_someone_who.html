Find Someone Who — Set 2 — Answer Key

Unit 1 · Section 1.2
1. A rule is \(p=7n+2\). Name the input and output quantities symbolically, then find p when n=-3.
Solution: Input n; output p. p=7(-3)+2=-19.
2. A table has the input-output rows shown. Write the ordered pairs and identify the output when the input is 6.
inputoutput
-413
05
6-7
Solution: Pairs: (-4,13), (0,5), (6,-7). The output for input 6 is -7.
3. A machine says “divide the input by 2, then add 6.” Write a rule and find the output for input 10.
Solution: \(y=x/2+6\); output 11.
4. A concert venue uses number of tickets as input and total seats occupied as output. If 12 tickets correspond to 12 occupied seats, write the ordered pair and explain its coordinate order.
Solution: (12,12); input is written first and output second, even when the values happen to match.
5. Does {(1,8), (2,5), (3,8), (4,5)} define a function? Explain.
Solution: Yes. Each input has one output; repeated outputs 8 and 5 are allowed.
6. Does {(0,1), (2,4), (5,7), (5,7)} define a function? Explain why repeating the same pair does or does not break the rule.
Solution: Yes. Input 5 is not paired with a different output; duplicating the identical pair does not create a second output.
7. A table lists input -1 twice, once with output 3 and once with output -6. Decide whether it is a function and cite the violation.
Solution: Not a function because input -1 has two different outputs.
8. Build a four-row input-output table for the rule \(y=2x+9\) using four different inputs. Explain why a rule like this automatically gives one output for each chosen input.
Solution: Example inputs -2,0,3,5 give outputs 5,9,15,19. Substitution into a deterministic rule gives a single value for each input.

Find Someone Who — Set 2 — Answer Key

Unit 1 · Section 1.2
9. Decide whether {(-5,2), (-1,2), (3,10)} is a function and explain the role of the repeated 2.
Solution: Yes. The repeated 2 is an output, which is allowed.
10. A relation contains (2,6), (4,9), (7,12), and (2,-1). Which input causes failure, and what two outputs are attached to it?
Solution: Input 2; outputs 6 and -1.
11. Add one ordered pair to {(0,3), (2,7), (4,11)} that keeps the relation a function but does not follow the visible linear pattern.
Solution: Example: (6,100). It is still a function because input 6 is new; function status does not require linearity.
12. A mapping sends 1→4, 2→4, 3→8, and 4→8. Function or not? Give the function-test reason, not a pattern reason.
Solution: Function. Each input has exactly one output.
13. A student says a relation is not a function whenever any number repeats anywhere. Give a counterexample with repeated outputs.
Solution: Example {(1,5),(2,5)} is a function; output 5 repeats but each input has one output.
14. The relation {(3,-2), (6,1), (9,1)} is a function. Describe what a vertical-line test would need to confirm if these points were graphed.
Solution: No vertical line should hit more than one plotted point; no x-value may have two y-values.
15. A table shows inputs 2, 4, 6, 8 and outputs 7, 11, ?, 19. Explain why function status alone is not enough information to determine the missing output.
Solution: A function only says input 6 has one output, not what the value must be. A rule or pattern is needed.
16. A mapping has one input with two outgoing arrows. Rewrite that situation as two ordered pairs and explain why it fails the function rule.
Solution: Example if input 5 points to 2 and 9: (5,2) and (5,9). Same input, different outputs, so not a function.
Answer Key 2

Find Someone Who — Set 2 — Answer Key

Unit 1 · Section 1.2
17. Evaluate \(5x+12\) when x=-7.
Solution: 5(-7)+12=-23.
18. A temperature conversion approximation is \(F=2C+30\). Find F when C=-12.
Solution: F=2(-12)+30=6.
19. A student evaluates \(x^2-8\) at x=-5 as -33. Diagnose the substitution error and give the correct value.
Solution: The negative input must be grouped: (-5)²-8=25-8=17.
20. Evaluate \(42-3(6)+2^3\) and identify which operation must be completed before subtraction.
Solution: Exponent and multiplication first: 42-18+8=32.
21. Evaluate \(\frac{3(6-2)+8}{5^2-20}\).
Solution: Numerator=20; denominator=5; value=4.
22. Evaluate \(4a-3b\) when a=-6 and b=-2.
Solution: 4(-6)-3(-2)=-24+6=-18.
23. Compare \(-7^2\) and \((-7)^2\).
Solution: -49 and 49, respectively.
24. A calculation gives 3,920 for \(79(49)\). Estimate with 80·50 and decide whether the result is reasonable.
Solution: 80·50=4,000, so 3,920 is reasonable.
