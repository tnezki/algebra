Problem 17

A delivery service charges 3 dollars per mile traveled. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: miles. Output: cost C in dollars. One rule is $C=3m$.

Problem 18

A faucet fills 2 liters each minute. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: minutes. Output: water W in liters. One rule is $W=2t$.

Problem 19

A phone battery begins at 100 percent and drops 8 percentage points each hour. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: battery B in percent. One rule is $B=100-8h$.

Problem 20

A runner starts 1 kilometer from home and moves away at 5 kilometers per hour. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: distance d in kilometers. One rule is $d=5h+1$.
