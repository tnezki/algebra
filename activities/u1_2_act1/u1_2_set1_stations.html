1. For \(y=6x-5\), identify the input variable and output variable. Then find the output for input x=-2.

Solution: Input: x; output: y. y=6(-2)-5=-17.

1
4

Solution: Outputs are 14, 5, -4. Pairs: (-2,14), (1,5), (4,-4).

3. An input-output machine says “multiply the input by 5, then subtract 9.” Write a symbolic rule and find the output for input 4.

Solution: \(y=5x-9\); output 11.

4. The pairs (-1,4), (2,13), and (5,22) follow a pattern. For the pair (2,13), name the input and output, then describe the change in output between consecutive listed inputs.

Solution: Input 2, output 13. Each +3 in input gives +9 in output, a per-1 rate of 3.

Station 3 Solutions • Set 1
Answer Key
9. Does {(0,-2), (2,3), (5,8), (7,13)} define a function? State the test you used.

Solution: Yes. No input is paired with more than one output.

10. A relation contains (1,4), (3,8), (5,12), and (1,10). Identify the exact pair that creates the function violation and explain.

Solution: (1,10) creates a second output for input 1, which already maps to 4.

11. A mapping sends -2→5, 0→5, 3→9, and 6→12. Is it a function? Justify.

Solution: Yes. Each input has one arrow/output; multiple inputs may share 5.

12. A mapping sends input 4 to both -1 and 7. What is the minimum change needed to make the mapping a function?

Solution: Remove either 4→-1 or 4→7 so input 4 has only one output.

Station 4 Solutions • Set 1
Answer Key
13. Explain why two different inputs are allowed to share one output in a function.

Solution: The function rule restricts outputs per input, not inputs per output.

14. Add one ordered pair to {(2,6), (4,10), (6,14)} that would make the relation fail the function test.

Solution: Example: (4,99), because input 4 would then have outputs 10 and 99.

15. Add one ordered pair to {(-1,3), (0,7), (2,11)} that keeps the relation a function while reusing an existing output.

Solution: Example: (5,7). The new input is unique even though output 7 repeats.

16. Write a two-step checklist for deciding whether an ordered-pair relation is a function.

Solution: List/scan the inputs; if any input repeats, verify all occurrences have the same output. A repeated input with different outputs means not a function.

Answer Key
17. Evaluate \(9x-4\) when x=-3. Show the substituted expression.

Solution: \(9(-3)-4=-31\).

18. The area of a triangle is \(A=bh/2\). Find A when b=12 cm and h=7 cm.

Solution: A=12·7/2=42 cm².

19. Evaluate \(36-4(5)+3^2\) using order of operations.

Solution: 36-20+9=25.

20. Evaluate \(\frac{2(8-3)+6}{2^2}\). State the numerator and denominator values first.

Solution: Numerator=16; denominator=4; value=4.

Station 6 Solutions • Set 1
Answer Key
21. Evaluate \(2a^2+3b\) when a=-4 and b=-5. Show parentheses around the substituted negative values.

Solution: 2(-4)^2+3(-5)=32-15=17.

22. Compare \(-6^2\) and \((-6)^2\). Give both values and explain why they differ.

Solution: -6²=-(36)=-36; (-6)²=36. Parentheses make the negative part of the squared base.

23. Estimate \(29.7(4.1)\) using convenient nearby numbers, then state whether an exact value near 122 would be reasonable.

Solution: 30·4=120, so 122 is reasonable.

24. A student evaluates \(48-5(7)+2^2\) as 189. Without doing every step first, explain why the answer is unreasonable, then find the correct value.

Solution: The expression is near 48-35+4≈17, not 189. Exact value is 17.
