Problem 17

A taxi charges 4 dollars per mile traveled. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: miles. Output: cost C in dollars. One rule is $C=4m$.

Problem 18

A fountain releases 5 liters of water each minute. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: minutes. Output: water W in liters. One rule is $W=5t$.

Problem 19

A phone battery begins at 90 percent and drops 6 percentage points each hour. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: battery B in percent. One rule is $B=90-6h$.

Problem 20

A cyclist starts 2 kilometers from a park and moves away at 4 kilometers per hour. Identify a sensible input and output, then write a rule connecting them.

Answer:

Input: hours. Output: distance d in kilometers. One rule is $d=4h+2$.
