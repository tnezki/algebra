Selecting Appropriate Models
Source: practice_set_8_1_3.html
Time: 20–30 min
Groups: Groups of 4
Materials: One whiteboard per student
Structure Indy → Group comparison → Consensus
Setup Groups of 4. Each person has a whiteboard. Rotate the Captain each round.
Directions
  1. Each student solves the problem individually
  2. When prompted, students Showdown (reveal answers at the same time)
  3. Discuss differences and justify reasoning
  4. Group agrees on a correct final answer
  5. Repeat
Goal: Accountability + justification
✓ Looks Like Success
  • Every student writes an independent answer before the reveal.
  • Groups reveal boards at the same time and compare differences.
  • The captain asks for justification before the group records a consensus answer.
✗ Doesn't Look Like
  • One student announces the answer before others finish.
  • Boards are revealed one at a time and copied.
  • The group chooses an answer without explaining why it works.

Solution 2
Current · DOK 2

A ball is thrown upward from $4$ feet with initial velocity $32$ feet per second. Explain why a quadratic model is more reasonable than a linear model for height over time.

Solution:

A quadratic model is more reasonable because gravity causes height to change with a constant second difference and the path has a maximum. A linear model would imply a constant velocity forever, which does not match an object rising then falling.

Solution 15
Last · DOK 3

Two methods are proposed for deciding whether the outputs 10, 15, 22.5, 33.75, 50.625 are exponential.

  1. Method 1 checks first differences.
  2. Method 2 checks ratios.

Use both methods, then explain which method gives stronger evidence for this pattern and why.

Solution:

First differences are not constant, but ratios are constant: $15/10=22.5/15=33.75/22.5=50.625/33.75=1.5$. The ratio test gives stronger evidence for an exponential pattern.
