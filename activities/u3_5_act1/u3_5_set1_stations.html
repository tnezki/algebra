Station 1 Answers

Question 1

Can a point on a solid boundary line be feasible if it satisfies the other inequality too?

Solution:

Yes. A solid boundary line is included in its inequality, so a point on it can be feasible if it also satisfies the other inequality.

Question 2

Can a point on a dashed boundary line be included as a solution for that inequality?

Solution:

No. A dashed boundary line is not included, so a point on that boundary cannot satisfy that inequality.

Question 3

The graph shows a system of inequalities. Name two feasible points and one non-feasible point.

Solution:

The graph represents the overlap of $y\ge x+1$ and $y\le -x+7$. Examples of feasible points are $(2,4)$ and $(3,4)$. A non-feasible point is $(0,0)$.

Question 4

A food truck can carry at most 60 meals. It needs at least 20 vegetarian meals. Let $v$ be vegetarian meals and $r$ be regular meals.

Before solving or graphing, estimate whether $(18,30)$, $(22,45)$, and $(30,25)$ are feasible. Justify each conclusion using the constraints.

Solution:

The constraints are $v+r\le60$ and $v\ge20$. $(18,30)$ is not feasible because $v=18$ is below $20$. $(22,45)$ is not feasible because $22+45=67\gt60$. $(30,25)$ is feasible because $30\ge20$ and $30+25=55\le60$.

Question 5

Which terms are like terms in $7x+2+5x+9$?

Solution:

The like terms are $7x$ and $5x$, and the constants $2$ and $9$ are also like terms.

Question 6

Simplify $4x+3x$.

Solution:

$4x+3x=7x$.

Question 7

The table represents a linear relationship. Write an equation for $y$ in terms of $x$.

$x$0123
$y$471013
Solution:

The $y$ values increase by $3$ each time $x$ increases by $1$, and the intercept is $4$. The equation is $y=3x+4$.

Question 8

The equation $p=5n+2$ represents the number of points $p$ after completing $n$ levels in a game. Write a one-sentence context that matches the starting value and repeated change.

Solution:

Example context: a player starts with $2$ points and earns $5$ points for each level completed, so $p=5n+2$.

Question 10

A coach records jump heights: $1.0,1.4,1.9,2.5,3.2$ feet. A student claims an exponential model is best because the values increase. Is that reasonable? Use approximate differences or ratios as evidence.

Solution:

The differences are $0.4,0.5,0.6,0.7$, while ratios are not constant. Increasing values alone do not prove an exponential model; the evidence is weak for exponential.

Question 11

Construct a strategy for choosing among linear, quadratic, exponential, and absolute value families when you have a table but no graph. Apply your strategy to outputs $6,1,-2,-3,-2,1,6$ for consecutive inputs.

Solution:

Check first differences for linear, second differences for quadratic, ratios for exponential, and symmetry with a vertex for absolute value. The outputs $6,1,-2,-3,-2,1,6$ are symmetric around the middle value $-3$, so the pattern fits an absolute value relationship.

Question 12

You are given two facts about one relationship: when $x=0$, $y=9$; when $x=4$, $y=21$. Synthesize a table, equation, context, and one additional point that all represent the same relationship. Explain how each representation shows the same starting value and change.

Solution:

The rate is $3$, so $y=3x+9$. Table: $(0,9),(1,12),(2,15),(4,21)$. Context: start at $9$ and add $3$ per step. Additional point: $(5,24)$.

Question 13

A table increases by $4$ in $y$ whenever $x$ increases by $1$, and the output at $x=0$ is $7$. Write the equation.

Solution:

The equation is $y=4x+7$.

Question 14

State the slope of the line $y=12$.

Solution:

The line $y=12$ is horizontal, so its slope is $0$.

Question 15

$x$0246
$y$391521

Write a linear equation for the table and explain how you found the slope.

Solution:

From $x=0$ to $x=2$, $y$ changes from $3$ to $9$, so slope is $\frac{6}{2}=3$. Since $y=3$ when $x=0$, the equation is $y=3x+3$.

Question 16

A model has equation $y=12x+5$. Analyze the structure of the model: what does the slope assume about the data pattern, and what would make that assumption weak?

Solution:

The slope $12$ assumes the output increases by exactly $12$ for every increase of $1$ in $x$. That assumption is weak if the data curve, levels off, has large scatter, or changes rate over time.
