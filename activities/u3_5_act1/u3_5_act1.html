Linear Systems of Inequalities
Source: practice_set_3_5_2.html
Time: 20–30 min
Groups: Groups of 3–4
Materials: One shared whiteboard or large paper per group
StructurePassed-board group solution, one contribution at a time
SetupStudents work in groups of 3–4 with one shared whiteboard or paper passed around the table.
Directions
  1. The first student writes the setup or first step, then passes the board.
  2. The next student continues the solution or explains a correction before passing.
  3. The board keeps moving until the group has a complete solution and explanation.
  4. Groups compare with the solution page and discuss any changes.
Goal: Make each group member contribute to a shared multi-step solution.
✓ Looks Like Success
  • The board passes after each meaningful contribution.
  • Each student adds a step or correction.
  • The group final answer includes a shared explanation.
✗ Doesn't Look Like
  • One student keeps the board for the whole problem.
  • Students pass without reading prior work.
  • The group copies the solution page before attempting.

Solution 4
Current · DOK 3

A food truck can carry at most 60 meals. It needs at least 20 vegetarian meals. Let $v$ be vegetarian meals and $r$ be regular meals.

Before solving or graphing, estimate whether $(18,30)$, $(22,45)$, and $(30,25)$ are feasible. Justify each conclusion using the constraints.

Solution:

The constraints are $v+r\le60$ and $v\ge20$. $(18,30)$ is not feasible because $v=18$ is below $20$. $(22,45)$ is not feasible because $22+45=67\gt60$. $(30,25)$ is feasible because $30\ge20$ and $30+25=55\le60$.

Construct a strategy for choosing among linear, quadratic, exponential, and absolute value families when you have a table but no graph. Apply your strategy to outputs $6,1,-2,-3,-2,1,6$ for consecutive inputs.

Solution:

2. Current · DOK 1–2

3. Last · DOK 1–2

Solve by elimination: $x+y=9$ and $x-y=3$.

4. Mastery · DOK 1–2

Find the slope from $(0,4)$ to $(3,10)$.

Key:

  1. Check $y\ge2x$: $5\ge4$, true. Check $y\lt x+4$: $5\lt6$, true. So $(2,5)$ satisfies both.

  2. If the shaded regions do not overlap, there are no points that satisfy both inequalities, so the solution set is empty.

  3. Add the equations: $2x=12$, so $x=6$. Then $6+y=9$, so $y=3$. Solution: $(6,3)$.

  4. Slope is $\frac{10-4}{3-0}=\frac{6}{3}=2$.
