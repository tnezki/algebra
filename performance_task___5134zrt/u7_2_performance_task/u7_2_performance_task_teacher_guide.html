Evidence Focus
  1. I can build exponential equations using an initial value and a growth or decay factor.
  2. I can use exponential equations to predict values from tables, graphs, and situations.
  3. I can formulate exponential equations that represent repeated percent increase or decrease.

A device is worth \$900 when purchased and loses 18% of its value each year. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Initial value = \$900; annual decrease = 18%.
Pencil, calculator if normally allowed

Build the factor

Convert the 18% decrease to a multiplicative decay factor.

Teacher evidence / sample: 1-0.18=0.82.

Write the model

Write an exponential equation for value V after t years.

Teacher evidence / sample: V=900(0.82)^t.
