Evidence Focus
  1. I can construct an equation that models a situation using meaningful quantities and operations.

A school booth charges a setup fee and a per-item amount. You must model the total, solve a target equation, and judge whether the result makes sense. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

The booth pays a \$42 setup fee plus \$3.50 for each item produced. The budget is \$126.
Pencil, calculator if normally allowed

Model the situation

Define a variable and write an equation that models using the full \$126 budget.

Predict before solving

Give a reasonable interval for n before solving and explain how you estimated it.
