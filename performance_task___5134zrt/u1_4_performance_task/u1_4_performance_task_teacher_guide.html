Evidence Focus
  1. I can build equivalent expressions by using structure, grouping, and properties of operations.
  2. I can apply rewriting strategies to make the meaning of an expression easier to work with.
  3. I can determine whether two expressions are equivalent by using structure, substitution, or properties.

Two shipping teams wrote different expressions for the same bundle cost. You must decide which forms are equivalent and which form is most useful. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Package A: 3(2x + 5) + 4x    Package B: 10x + 15    Package C: 6x + 9
Pencil, calculator if normally allowed

Build an equivalent form

Rewrite Package A as a simplified equivalent expression. Show the structural moves you used.

Teacher evidence / sample: 3(2x+5)+4x = 6x+15+4x = 10x+15.

Interpret the structure

Explain one possible meaning for x, the coefficient 10, and the constant 15 in a bundle context.

Teacher evidence / sample: Example: x is cost per variable item; 10x is ten variable items and 15 is fixed packaging cost.

Test the competing forms

Use x=2 and one second value of your choice to test Packages B and C against Package A.

Teacher evidence / sample: At x=2, A=B=35 while C=21. A and B agree for all x by algebra; C does not.

Choose the useful form

Teacher evidence / sample: Example: simplified 10x+15 makes total variable rate and fixed amount easy to see; original may preserve grouped package structure.
