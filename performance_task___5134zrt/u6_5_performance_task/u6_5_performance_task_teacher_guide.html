Evidence Focus
  1. I can construct quadratic models from real-world constraints, data, or key features.
  2. I can extend quadratic models to predict maximums, minimums, intercepts, and meaningful solution values.
  3. I can assess whether a quadratic model and its solutions are reasonable for the situation.

A rectangular garden uses 40 meters of fencing for all four sides. Find dimensions that maximize area and explain the model. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

If width is x, length is 20-x, so A(x)=x(20-x).
Pencil, calculator if normally allowed

Build equivalent model forms

Expand A(x) and identify why the model is quadratic.

Teacher evidence / sample: A(x)=-x^2+20x.

Locate the optimum

Use symmetry/completing square/vertex reasoning to find the x-value that maximizes area.

Teacher evidence / sample: Vertex at x=-b/(2a)=10, or A=-(x-10)^2+100.
