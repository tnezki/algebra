Evidence Focus
  1. I can design a coefficient map that organizes $a$, $b$, and $c$ before using the quadratic formula.
  2. I can apply the quadratic formula to solve equations with rational, irrational, or no real solutions.
  3. I can assess how the discriminant predicts the number and type of real solutions.

A calculation sheet uses the quadratic formula on two equations. You will predict solution type first, then verify the computations. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Equation A: 2x^2-3x-2=0.   Equation B: x^2+4x+8=0.
Pencil, calculator if normally allowed

Predict with the discriminant

Compute b^2-4ac for each equation and predict the number of real solutions.

Teacher evidence / sample: A: 9+16=25 -> two real solutions. B:16-32=-16 -> no real solutions.

Solve the real-solution case

Use the quadratic formula to solve Equation A exactly.

Teacher evidence / sample: x=(3+/-5)/4 -> x=2 or x=-1/2.

Audit sign handling

Explain why writing -b as -3 for Equation A would be incorrect.

Teacher evidence / sample: Here b=-3, so -b=3. Substitution must preserve the signed coefficient.

Interpret the no-real case

State what Equation B tells you about x-intercepts of y=x^2+4x+8.

Teacher evidence / sample: No real solutions means the graph has no x-intercepts; it remains above the x-axis (vertex y=4).
