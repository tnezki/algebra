Evidence Focus
  1. I can build transformed function rules from parent functions across linear, quadratic, exponential, and absolute value families.
  2. I can use key points and key features to graph transformations across multiple function families.
  3. I can formulate a transformation description that connects parameter changes to key point shifts across function families.

Complete the connected performance. Shared setup or exchange is allowed only where the task says so; record your own mathematical evidence and final conclusions.

Create a Consistent Evidence Set

Choose one transformation (translation plus optional reflection/stretch) and apply it consistently to two different parent-function families.
Sample standard: all created representations describe the same relationship; hidden information can be reconstructed uniquely from the evidence provided.
Partner reconstruction should be independent. Final revision explains any mismatch rather than simply replacing an answer.
Accept different valid values/contexts if the mathematics remains consistent and the exact I-can evidence is visible.
Section-specific sample: Student-created transformations vary. Under a translation, the same $(h,k)$ shift applies to every key point across families while each parent function keeps its characteristic shape/structure.
