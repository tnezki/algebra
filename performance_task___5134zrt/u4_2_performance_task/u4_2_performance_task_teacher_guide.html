Evidence Focus
  1. I can build translated graphs by moving key points and key features from a parent function.
  2. I can use horizontal and vertical shifts to write equations for translated functions.
  3. I can predict how changing values in an equation moves a graph left, right, up, or down.

A design starts from the parent parabola y=x^2. One team must translate it; another should be able to reconstruct the equation from key points. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

Parent key points: (-2,4), (-1,1), (0,0), (1,1), (2,4). Target vertex: (3,-2).
Pencil, calculator if normally allowed

Move the key points

Translate every listed parent point so the vertex moves from (0,0) to (3,-2).

Teacher evidence / sample: Add (3,-2) to each point: (1,2),(2,-1),(3,-2),(4,-1),(5,2).

Write the translated rule

Write the equation of the translated parabola.

Teacher evidence / sample: y=(x-3)^2-2.
