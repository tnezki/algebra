Evidence Focus
  1. I can construct equivalent polynomial expressions by factoring out a greatest common factor.
  2. I can apply structure to rewrite polynomial expressions in a more useful form.
  3. I can determine whether a rewritten expression is reasonable by checking common factors and equivalent products.

Build the Structure

Build an area/shared-side model for $12x+18$. Identify the greatest shared factor, rewrite the expression, and verify by expansion.
Sample standard: the constructed model matches the algebraic structure, labels are consistent, and the generalized rule works beyond the first example.
Reverse-engineering must reproduce the supplied result when checked forward.
Accept alternative models when they preserve the same factors/terms/features and the student can verify equivalence.
Section-specific sample: For the suggested expression, $12x+18=6(2x+3)$. Expansion must return the original polynomial, confirming that 6 is a common factor of both terms.
