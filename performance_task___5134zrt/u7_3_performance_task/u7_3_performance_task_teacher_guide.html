  1. I can design graphs of exponential functions using key points, growth or decay factors, and asymptote behavior.

A graph summary for f(x)=3(2)^x contains one impossible statement. Use equation and key points to repair it. Work so another person can follow the mathematical evidence you used.

Situation / Starting Evidence

f(x)=3(2)^x. Claims: y-intercept 3; outputs are positive; horizontal asymptote y=0; graph decreases as x increases.
Pencil, calculator if normally allowed

Generate key points

Make a table for x=-2,-1,0,1,2.

Teacher evidence / sample: Values: 0.75,1.5,3,6,12.

Audit the claims

Identify the false claim and repair it.

Teacher evidence / sample: The graph increases as x increases because base 2>1; other claims are correct.
