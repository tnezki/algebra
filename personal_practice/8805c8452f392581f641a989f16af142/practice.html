Lesson 3.1.1

1.I can simplify expressions using exponent properties.

Simplify.

\((2x^{7}y^{4})^{2}\)

Answer: \(4 x^{14} y^{8}\)

Apply the outer power to each factor: 2^2, x^(7×2), y^(4×2).

\(4 x^{14} y^{8}\)

2.I can simplify expressions using exponent properties.

Write as a single power.

\(p^{7}\cdot p\)

Answer: \(p^{8}\)

The base is the same; add the exponents: 7+1=8.

\(p^{8}\)

3.Original CPM mixed/spaced homework problem (all original subparts).

A trail has 214 miles left to walk. A hiker completes 7 miles each day. Write an expression for the distance remaining after d days.

Answer: \(214-7d\)

Start with the initial amount and add or subtract the amount per time period.

\(214-7d\)

4.Original CPM mixed/spaced homework problem (all original subparts).

Gerardo made these three claims. Decide which are correct, and correct the others.

a.
\(\frac{x^{98}}{x^{15}}\Rightarrow x^{85}\)
b.
\(y^{83}\cdot y^{15}\Rightarrow y^{98}\)
c.
\((6m^{15})^2\Rightarrow 6m^{30}\)

Answer: a. Incorrect, x^83; b. Correct; c. Incorrect, 36m^30.

Subtract exponents for quotients; add for products; apply outer powers to coefficients as well.

Lesson 3.1.2

5.I can explain zero and negative exponents and rewrite expressions.

Simplify. Assume variables are nonzero.

\(\frac{(3a)^0+(3a)^0}{(2a^2)^0}\)

Answer: \(2\)

Each nonzero expression to power 0 equals 1.

Then (1+1)/1=2.

6.I can explain zero and negative exponents and rewrite expressions.

Rewrite with positive exponents. Assume variables are nonzero.

\(x^{-4}\)

Answer: \(\frac{1}{x^{4}}\)

A negative exponent indicates a reciprocal, not a negative value.

\(\frac{1}{x^{4}}\)

7.Original CPM mixed/spaced homework problem (all original subparts).

Determine the equation of the line containing the points in the table.

x-2-123
y-7-8-11-12

Answer: \(y=-x-9\)

Differences in y divided by differences in x give slope -1.

The intercept is -9.

\(y=-x-9\)
