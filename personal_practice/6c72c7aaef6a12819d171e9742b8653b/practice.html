Lesson 3.1.1

1.I can simplify expressions using exponent properties.

Multiply and write one monomial.

\((-2a^{6}y^{5})(2a^{6}y^{4})\)

Answer: \(- 4 a^{12} y^{9}\)

Multiply coefficients: -2×2=-4.

Add each variable’s exponents: 6+6=12 and 5+4=9.

\(- 4 a^{12} y^{9}\)

2.I can simplify expressions using exponent properties.

Write as one power.

\((p^{5})^{5}\)

Answer: \(p^{25}\)

Multiply the exponents: 5×5=25.

\(p^{25}\)

5.I can explain zero and negative exponents and rewrite expressions.

Write an equivalent expression with positive exponents.

\(\frac{y^{-4}}{y^{-4}}\)

Answer: \(\frac{y^{4}}{y^{4}}\)

A negative exponent means reciprocal; simplify the factors in the numerator and denominator.

\(\frac{y^{4}}{y^{4}}\)

6.I can explain zero and negative exponents and rewrite expressions.

Simplify. Assume variables are nonzero.

\(\frac{(5y)^0+(5y)^0}{(2y^2)^0}\)

Answer: \(2\)

Each nonzero expression to power 0 equals 1.

Then (1+1)/1=2.

7.Original CPM mixed/spaced homework problem (all original subparts).

Determine the equation of the line containing the points in the table.

x-2-123
y-14-11-21

Answer: \(y=3x-8\)

Differences in y divided by differences in x give slope 3.

The intercept is -8.

\(y=3x-8\)

8.Original CPM mixed/spaced homework problem (all original subparts).

Samantha has $2350 in the bank and spends $25 per week. In how many weeks will her balance be $1900? Define a variable and solve.

Answer: \(18\text{ weeks}\)

\(2350-25w=1900\)

Subtract: 25w=450.

Divide: w=18.
