Lesson 3.1.1

1.I can simplify expressions using exponent properties.

Simplify.

\((2x^{4}y^{4})^{3}\)

Answer: \(8 x^{12} y^{12}\)

Apply the outer power to each factor: 2^3, x^(4×3), y^(4×3).

\(8 x^{12} y^{12}\)

  2. Quotient of Powers
  3. Power of a Power

  5. Negative Exponent

\(p^{8}\)

4.Original CPM mixed/spaced homework problem (all original subparts).

A savings account starts with $185. A student deposits $7 each week. Write an expression for its balance after w weeks, defining w.

Answer: \(185+7w\)

Start with the initial amount and add or subtract the amount per time period.

\(185+7w\)

5.I can explain zero and negative exponents and rewrite expressions.

Simplify using positive exponents.

\((a^{-4})(a^{3})\)

Answer: \(\frac{1}{a}\)

Combine exponents: −4+3=-1.

\(\frac{1}{a}\)
