I can simplify expressions using exponent properties.

1.
Simplify.

\((3x^{5}y)^{2}\)

Answer: \(9 x^{10} y^{2}\)

Apply the outer power to each factor: 3^2, x^(5×2), y^(1×2).

\(9 x^{10} y^{2}\)

2.
Simplify. Assume variables are nonzero.

\(\frac{25p^{5}}{5p^{2}}\)

Answer: \(5 p^{3}\)

Divide the coefficients: 25/5=5.

Subtract exponents: 5−2=3.

\(5 p^{3}\)

A collector starts with 95 cards and collects 16 more cards each week. Write an expression for the collection size after w weeks.

Answer: \(95+16w\)

Start with the initial amount and add or subtract the amount per time period.

\(95+16w\)

\(y = - 2 x - 5\)

Answer: Slope \(-2\); y-intercept -5

The slope is the rise divided by the run; the y-intercept is where x=0.

I can explain zero and negative exponents and rewrite expressions.

5.
Simplify. Assume variables are nonzero.

\(\frac{(7y^{7})^0+(3y)^0}{(y^2)^0}\)

Answer: \(2\)

Each nonzero expression to power 0 equals 1.

Then (1+1)/1=2.
