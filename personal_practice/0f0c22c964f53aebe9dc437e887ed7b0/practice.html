Lesson 3.1.1

1.I can simplify expressions using exponent properties.

Simplify.

\((2a^{8})(3a^{3})\)

Answer: \(6 a^{11}\)

Multiply coefficients: (2)(3)=6.

Add exponents of a: 8+3=11.

\(6 a^{11}\)

2.I can simplify expressions using exponent properties.

Simplify. Assume variables are nonzero.

\(\frac{16x^{10}y^{5}}{4x^{8}y^{2}}\)

Answer: \(4 x^{2} y^{3}\)

Divide coefficients: 16/4=4.

Subtract exponents for each base: x^(10−8) and y^(5−2).

\(4 x^{2} y^{3}\)

Lesson 3.1.2

5.I can explain zero and negative exponents and rewrite expressions.

Rewrite with positive exponents. Assume variables are nonzero.

\(7y^{-7}\)

Answer: \(\frac{7}{y^{7}}\)

The coefficient 7 stays in the numerator; move only the base with exponent −7.

\(\frac{7}{y^{7}}\)

6.I can explain zero and negative exponents and rewrite expressions.

Simplify using positive exponents.

\((y^{-2})(y^{6})\)

Answer: \(y^{4}\)

Combine exponents: −2+6=4.

\(y^{4}\)
