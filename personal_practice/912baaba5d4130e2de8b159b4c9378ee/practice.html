Lesson 3.1.1

1.I can simplify expressions using exponent properties.

Fill in the missing exponent.

\(a^{3}\cdot a^{2}=a^{\square}\)

Answer: \(a^{5}\)

The base is the same; add the exponents: 3+2=5.

\(a^{5}\)

2.I can simplify expressions using exponent properties.

Simplify. Assume variables are nonzero.

\(\frac{16x^{5}y^{3}}{4x^{3}y}\)

Answer: \(4 x^{2} y^{2}\)

Divide coefficients: 16/4=4.

Subtract exponents for each base: x^(5−3) and y^(3−1).

\(4 x^{2} y^{2}\)

3.Original CPM mixed/spaced homework problem (all original subparts).

A trail has 179 miles left to walk. A hiker completes 20 miles each day. Write an expression for the distance remaining after d days.

Answer: \(179-20d\)

Start with the initial amount and add or subtract the amount per time period.

\(179-20d\)

Simplify using positive exponents.

\((p^{-6})(p)\)

Answer: \(\frac{1}{p^{5}}\)

Combine exponents: −6+1=-5.

\(\frac{1}{p^{5}}\)

6.I can explain zero and negative exponents and rewrite expressions.

Simplify. Assume variables are nonzero.

\(\frac{(5x^{2})^0+(4x)^0}{(5x^2)^0}\)

Answer: \(2\)

Each nonzero expression to power 0 equals 1.

Then (1+1)/1=2.

8.Original CPM mixed/spaced homework problem (all original subparts).

Samantha has $1250 in the bank and spends $50 per week. In how many weeks will her balance be $900? Define a variable and solve.

Answer: \(7\text{ weeks}\)

\(1250-50w=900\)

Subtract: 50w=350.

Divide: w=7.
