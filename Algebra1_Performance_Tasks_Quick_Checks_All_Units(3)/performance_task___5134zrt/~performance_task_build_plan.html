Algebra 1 Performance Task Build Plan

Map-first authoring plan for all 40 Algebra 1 sections. Exact Assessment Plan I-can wording is preserved.

1.1 — Multiple Representations of Relationships

Exact I-can statements

  1. I can construct a table, graph, equation, or context from another representation of the same relationship.
  2. I can use features in one representation to work with a related table, graph, equation, or context.
  3. I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

create_trade_reconstruct_evaluate_reviseDOK 4

A community bike-share trip is represented in several forms. Build a complete representation set, exchange an intentionally incomplete version with a partner, reconstruct the missing form, and evaluate whether all forms preserve the same relationship.

Action sequence

  1. Create a valid representation/model that satisfies the stated constraints.
  2. Exchange an intentionally partial version with a partner.
  3. Reconstruct the missing information independently from the evidence provided.
  4. Evaluate equivalence/consistency and revise the original if needed.

Artifact: created representation set + partner reconstruction + individual evaluation/revision

Representations: Tables of input-output pairs, Coordinate graphs, Equations and rules, Verbal contexts, Connections among multiple representations

DOK rationale: DOK 4 is justified because the student must sustain a connected performance across representations/steps, make or revise a model/decision, and validate or defend the result; no single learned procedure determines the full pathway.
