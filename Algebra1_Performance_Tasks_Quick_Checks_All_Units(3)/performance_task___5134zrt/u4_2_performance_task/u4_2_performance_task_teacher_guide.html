Evidence Focus
  1. I can build translated graphs by moving key points and key features from a parent function.
  2. I can use horizontal and vertical shifts to write equations for translated functions.
  3. I can predict how changing values in an equation moves a graph left, right, up, or down.

Complete the connected performance. Shared setup or exchange is allowed only where the task says so; record your own mathematical evidence and final conclusions.

Set Up the Physical Model

Use small paper key-point cards or sticky notes on a coordinate grid. Place parent key points, physically move every point according to an assigned translation vector, then record the before/after coordinates and equation.
Sample standard: recorded movement/key-point data are genuine, units/coordinates are clear, and the graph/equation matches the recorded data.
Prediction follows from the model, then a second movement/point check is used to validate.
Accept natural measurement variation; judge the model/interpretation rather than perfect physical execution.
Section-specific sample: For a translation vector \((h,k)\), every key point \((x,y)\) becomes \((x+h,y+k)\). The equation and moved points must encode the same horizontal and vertical shifts.
