Algebra 1 Quick Check Build Plan

Map-first authoring plan for all 40 Algebra 1 sections. Exact Assessment Plan I-can wording is preserved.

1.1 — Multiple Representations of Relationships

Exact I-can statements

  1. I can construct a table, graph, equation, or context from another representation of the same relationship.
  2. I can use features in one representation to work with a related table, graph, equation, or context.
  3. I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.

~12 min6 parallel versions / 1 HTML

Evidence blueprint

  1. I-can: I can construct a table, graph, equation, or context from another representation of the same relationship.
    Give a table and ask students to choose the matching graph/equation, then justify with two ordered pairs.
  2. I-can: I can use features in one representation to work with a related table, graph, equation, or context.
    Give a graph and a nearly matching table with one wrong row; locate and correct the mismatch.
  3. I-can: I can determine whether two representations belong to the same relationship using evidence from values, rates, or patterns.
    Start from a context with a starting value and constant change; build table -> equation -> graph.

Why bigger than an Exit Ticket: Section 1.1 needs more than a one-slice exit pulse because students must coordinate 3 distinct jobs: construct, use, determine. The check samples each job independently and uses a real graph/table/equation connection so a teacher can distinguish a procedural miss from a representation or interpretation miss.
