Algebra Practice 7.3 :::: Set 3

1. Without graphing every point, identify the $y$-intercept of $f(x)=11(\frac{4}{3})^x$ and explain how you know.

2. For the basic exponential function $y=8(\frac{4}{3})^x$, state the horizontal asymptote and describe whether the graph reaches it.

3. State the domain and range of $f(x)=10(\frac{5}{3})^x$.

4. Use the graph to identify the $y$-intercept, describe the end behavior, and decide whether it shows exponential growth or decay.

5. A student graphs $y=4(1.25)^x$ and draws the curve crossing the x-axis at $x=3$. Assess the description and name the exponential-graph feature that decides the issue.

6. Graphs A and B have the same positive initial value, but one uses factor 1.5 and the other uses factor 2. Which graph grows faster for positive $x$? Explain how the graph supports your answer.

7. Describe what happens to $f(x)=2(3)^x$ as $x$ becomes very large and as $x$ becomes very negative.

8. A bacteria culture is modeled by $P(t)=30(\frac{5}{4})^t$. Describe the graph’s initial value and long-term behavior in the context.

9. For $f(x)=8(\frac{4}{3})^x$, complete a key-point table for $x=-1,0,1,2$. Use the points to describe the graph as growth or decay.

10. Make a small table of key points and sketch $y=5(\frac{5}{3})^x$. Label the $y$-intercept and horizontal asymptote.

11. Without graphing every point, identify the $y$-intercept of $f(x)=15(\frac{3}{2})^x$ and explain how you know.

12. For the basic exponential function $y=11(\frac{3}{2})^x$, state the horizontal asymptote and describe whether the graph reaches it.

13. State the domain and range of $f(x)=12(\frac{4}{5})^x$.

14. Use the graph to identify the $y$-intercept, describe the end behavior, and decide whether it shows exponential growth or decay.

15. A student graphs $y=8(0.5)^x$ approaching but not touching the x-axis as x increases. Assess the description and name the exponential-graph feature that decides the issue.

16. Use the two exponential graphs to explain why sharing the same $y$-intercept does not mean two functions have the same growth rate.

17. Describe what happens to $f(x)=11(\frac{5}{3})^x$ as $x$ becomes very large and as $x$ becomes very negative.

18. A savings balance is modeled by $B(t)=40(\frac{4}{3})^t$. Describe the graph’s initial value and long-term behavior in the context.

19. Solve $x^2-4x-5=0$ by completing the square.

20. Rewrite $y=x^2-8x+5$ in vertex form by completing the square, then state the vertex.

21. Solve $(x-2)^2=9$ by using the square-root step that appears after completing the square.

22. For $f(x)=(x-1)(x-5)$, find the zeros and state the corresponding $x$-intercepts.

23. A monic quadratic has zeros $x=-5$ and $x=1$. Write the function in factored form and identify its $x$-intercepts.

24. The graph crosses the $x$-axis at $x=-2$ and $x=3$. Write a possible monic quadratic in factored form and explain how the factors encode the intercepts.
