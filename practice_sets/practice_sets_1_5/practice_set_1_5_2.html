Algebra Practice 1.5 :::: Set 2

Intro

1. A museum charges $12 per ticket plus a one-time $6 processing fee. Define a variable for ticket count and write an equation for a total of $54.

2. A tank begins with 70 liters and drains 4 liters per minute. Define variables and write a rule for the amount after m minutes.

3. Write an equation for “five more than 6 times a number is 47.” Define the variable.

4. A student writes \(7+4x=39\) for “four more than 7 times x is 39.” Diagnose the translation error and write the correct equation.

5. Solve \(6x+5=41\) using equivalent steps.

6. Solve \(4(x-3)=28\) and check the result in the original equation.

7. A club wants exactly $144. It already has $36 and earns $9 per item sold. Write and solve an equation for items sold, then interpret.

8. A trail is 45 miles long. After 17 miles, the remaining distance is modeled by \(d+17=45\). Solve and explain d.
