Algebra Practice 3.2

1. For the system $y=x+2$ and $3x+y=10$, identify the most efficient first substitution step before solving.

2. Which method is more efficient for $2x+y=3$ and $y=3x-12$: substitution or elimination? Explain the structural cue.

3. A student substitutes $x-4$ for $y$ in $2x+2y=-12$ but writes $2x+2(x)-4=-12$. Identify and correct the substitution error.

4. Check whether $(-2,2)$ satisfies both $y=2x+6$ and $x+y=1$.

5. Solve the system by substitution. $\begin{cases}y=3x-14\\2x+y=6\end{cases}$

6. Solve the system by substitution. $\begin{cases}y=2x-1\\x+y=8\end{cases}$

7. For the system $y=-x-3$ and $3x+y=-7$, identify the most efficient first substitution step before solving.

8. Which method is more efficient for $3x+y=7$ and $y=x-1$: substitution or elimination? Explain the structural cue.

9. A student substitutes $-2x-3$ for $y$ in $5x-3y=15$ but writes $5x-3(-2x)-3=15$. Identify and correct the substitution error.

10. Check whether $(3,-2)$ satisfies both $y=x-5$ and $x+y=2$.

11. Solve the system by substitution. $\begin{cases}y=-x+6\\4x+y=12\end{cases}$

12. Solve the system by substitution. $\begin{cases}y=-2x-3\\x+y=0\end{cases}$

13. For the system $y=x+4$ and $4x+y=-1$, identify the most efficient first substitution step before solving.

14. Which method is more efficient for $3x-y=2$ and $-3x=-6$: substitution or elimination? Explain the structural cue.

15. A student substitutes $-x-1$ for $y$ in $4x-2y=10$ but writes $4x-2(-x)-1=10$. Identify and correct the substitution error.

16. Check whether $(4,-2)$ satisfies both $y=2x-10$ and $x+y=2$.

17. Solve the system by substitution. $\begin{cases}y=-2x+8\\3x+y=10\end{cases}$

18. Solve the system by substitution. $\begin{cases}y=-x-3\\3x+y=-7\end{cases}$

19. For the system $y=2x+4$ and $3x+y=-11$, identify the most efficient first substitution step before solving.

20. Which method is more efficient for $3x+y=5$ and $y=2x-2$: substitution or elimination? Explain the structural cue.

21. A student substitutes $x-1$ for $y$ in $3x-3y=8$ but writes $3x-3(x)-1=8$. Identify and correct the substitution error.

22. Check whether $(3,4)$ satisfies both $y=2x-2$ and $x+y=7$.

23. Solve the system by substitution. $\begin{cases}y=x+4\\x+y=2\end{cases}$
