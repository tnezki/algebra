Algebra Practice 3.2 :::: Set 3

1. A student substitutes $2x+3$ for $y$ in $3x-2y=10$ but writes $3x-2(2x)+3=10$. Identify and correct the substitution error.

2. Check whether $(-2,5)$ satisfies both $y=x+7$ and $x+y=3$.

3. Solve the system by substitution. $\begin{cases}y=2x+2\\x+y=5\end{cases}$

4. Solve the system by substitution. $\begin{cases}y=x-1\\x+y=5\end{cases}$

5. For the system $y=2x+1$ and $2x+y=5$, identify the most efficient substitution step before solving.

6. Which method is more efficient for $2x+y=11$ and $y=2x+4$: substitution or elimination? Explain the structural cue.

7. A student substitutes $2x-2$ for $y$ in $4x+3y=-36$ but writes $4x+3(2x)-2=-36$. Identify and correct the substitution error.

8. Check whether $(0,3)$ satisfies both $y=-x+3$ and $x+y=3$.

9. Solve the system by substitution. $\begin{cases}y=2x-7\\x+y=5\end{cases}$

10. Solve the system by substitution. $\begin{cases}y=x+5\\x+y=1\end{cases}$

11. For the system $y=-x+4$ and $3x+y=12$, identify the most efficient first substitution step before solving.

12. Which method is more efficient for $x+y=2$ and $-x+2y=7$: substitution or elimination? Explain the structural cue.

13. A student substitutes $-x-2$ for $y$ in $2x-2y=16$ but writes $2x-2(-x)-2=16$. Identify and correct the substitution error.

14. Check whether $(0,3)$ satisfies both $y=x+3$ and $x+y=3$.

15. Solve the system by substitution. $\begin{cases}y=2x-3\\x+y=0\end{cases}$

16. Solve the system by substitution. $\begin{cases}y=2x\\x+y=6\end{cases}$

17. For the system $y=-3x+10$ and $3x+y=10$, identify the most efficient first substitution step before solving.

18. Which method is more efficient for $x+y=-5$ and $y=-x-5$: substitution or elimination? Explain the structural cue.

19. A student substitutes $4x-2$ for $y$ in $2x+3y=-48$ but writes $2x+3(4x)-2=-48$. Identify and correct the substitution error.

20. Check whether $(-1,2)$ satisfies both $y=-x+1$ and $x+y=2$.

21. Solve the system by substitution. $\begin{cases}y=2x+4\\4x+y=4\end{cases}$

22. Solve the system by substitution. $\begin{cases}y=-2x+6\\4x+y=14\end{cases}$

23. For the system $y=-x+7$ and $x+y=7$, identify the most efficient first substitution step before solving.

24. Which method is more efficient for $2x+y=9$ and $y=3x+1$: substitution or elimination? Explain the structural cue.
