Algebra Practice 3.2 :::: Set 2

1. Which method is more efficient for $2x+y=6$ and $y=-x+3$: substitution or elimination? Explain the structural cue.

2. A student substitutes $4x-2$ for $y$ in $5x+3y=-6$ but writes $5x+3(4x)-2=-6$. Identify and correct the substitution error.

3. Check whether $(-2,-3)$ satisfies both $y=-2x-7$ and $x+y=-5$.

4. Solve the system by substitution. $\begin{cases}y=3x-3\\4x+y=-3\end{cases}$

5. Solve the system by substitution. $\begin{cases}y=-3x\\2x+y=0\end{cases}$

6. For the system $y=-3x+3$ and $2x+y=3$, identify the most efficient first substitution step before solving.

7. Which method is more efficient for $2x+2y=2$ and $-2x+3y=-17$: substitution or elimination? Explain the structural cue.

8. A student substitutes $3x+2$ for $y$ in $3x-3y=13$ but writes $3x-3(3x)+2=13$. Identify and correct the substitution error.

9. Check whether $(4,-1)$ satisfies both $y=-2x+7$ and $x+y=4$.

10. Solve the system by substitution. $\begin{cases}y=-x-3\\2x+y=-4\end{cases}$

11. Solve the system by substitution. $\begin{cases}y=3x-4\\x+y=8\end{cases}$

12. For the system $y=-2x$ and $4x+y=4$, identify the most efficient first substitution step before solving.

13. Which method is more efficient for $4x+2y=4$ and $-4x-3y=-2$: substitution or elimination? Explain the structural cue.

14. A student substitutes $x$ for $y$ in $5x-3y=11$ but writes $5x-3(x)+0=11$. Identify and correct the substitution error.

15. Check whether $(1,-1)$ satisfies both $y=-3x+2$ and $x+y=1$.

16. Solve the system by substitution. $\begin{cases}y=-3x+10\\x+y=4\end{cases}$

17. Solve the system by substitution. $\begin{cases}y=3x+8\\2x+y=-7\end{cases}$

18. For the system $y=2x-4$ and $x+y=-1$, identify the most efficient first substitution step before solving.

19. Which method is more efficient for $x+y=11$ and $y=-x+3$: substitution or elimination? Explain the structural cue.

20. A student substitutes $2x+1$ for $y$ in $2x-2y=12$ but writes $2x-2(2x)+1=12$. Identify and correct the substitution error.

21. Check whether $(1,3)$ satisfies both $y=-2x+5$ and $x+y=4$.

22. Solve the system by substitution. $\begin{cases}y=-2x+9\\x+y=6\end{cases}$

23. Solve the system by substitution. $\begin{cases}y=-x+7\\3x+y=17\end{cases}$

24. For the system $y=x+8$ and $2x+y=-4$, identify the most efficient first substitution step before solving.
