3. A machine multiplies an input by 4 and then adds 7. Write the rule and find the output for input 5.

4. The ordered pairs are (1, 7), (2, 10), (3, 13). State the input and output in the second pair and describe the pattern.

5. Decide whether {(1,7), (2,9), (1,11), (4,13)} is a function. Use the repeated input as evidence.

6. Decide whether {(-2,7), (0,7), (3,7), (5,9)} is a function. Explain why repeated outputs do or do not matter.

7. A table gives one output for every listed input except x = 1. Two different outputs appear for that same input. Explain what this tells you about whether the relationship is a function.

8. Create four ordered pairs for the rule output = 3(input) + 6. Then state whether the rule defines a function and why.

Review

9. Is {(0,7), (2,8), (4,9), (6,10)} a function? State the input-output test you used.

10. Is {(-1,7), (2,11), (2,11), (5,16)} a function? Explain how repeating the same ordered pair affects the decision.

11. A mapping sends input 1 to 7, input 2 to 9, and input 3 to 11. Does the mapping represent a function? Explain.

12. A mapping sends input 4 to both 7 and 12. What single feature makes the relation fail the function test?

13. A relation has several different inputs that all point to the same output. Explain why this can still be a function.

14. Write one additional ordered pair that would make {(1,7), (2,9), (3,11)} no longer a function. Explain your choice.

15. Write one additional ordered pair that keeps {(-2,7), (0,8), (2,9)} a function and uses an output already present.

16. Describe a quick function test for a list of ordered pairs and a quick function test for an input-output mapping.

Mastery

17. Evaluate 7x + 7 when x = -4. Show the substituted expression before simplifying.

18. The area of a rectangle is A = lw. Find A when l = 9 cm and w = 4 cm. Include units.

19. Evaluate 30 - 3(5) + 23. Show the order in which you perform the operations.

20. Evaluate [4(7-2)+8] / [3+2]. Show the numerator and denominator values before dividing.

21. Evaluate 3a2 - 2b when a = -3 and b = -6. Use parentheses when substituting negative values.

22. A student says -(4)2 and (-4)2 have the same value. Evaluate both and explain the difference.

23. Before calculating 19.8(5) - 2.1, estimate the value. Then evaluate and decide whether the exact answer is reasonable.

24. A formula should produce a value between 40 and 60 for the given input. A student obtains 150. Explain why the result should be questioned and name one step you would recheck.
