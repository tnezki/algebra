9. Does {(0,-2), (2,3), (5,8), (7,13)} define a function? State the test you used.

10. A relation contains (1,4), (3,8), (5,12), and (1,10). Identify the exact pair that creates the function violation and explain.

11. A mapping sends -2→5, 0→5, 3→9, and 6→12. Is it a function? Justify.

16. Write a two-step checklist for deciding whether an ordered-pair relation is a function.

Mastery
