Algebra Check Your Understanding 8.4

1. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

2. A rental model is $C(h)=6+4h$ for $0\le h\le 10$. Predict the cost for 7 hours and interpret the result.

3. A fitted model describes pond depth for days 0 through 12. Explain why a prediction at day 150 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

4. A linear model predicts packages processed over a short shift. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

5. A model predicts $y=3x+2$. For the observed point $(4,15)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

6. For data that increase by about 12% each equal time interval, compare a linear model and an exponential model. Which better matches the stated change pattern and why?
