1. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

3. A fitted model describes website traffic for days 0 through 21. Explain why a prediction at day 180 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

4. A linear model predicts distance climbed on a conveyor over a short interval. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

5. A model predicts $y=2x-1$. For the observed point $(6,13)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

6. For data that increase by about 10% each equal time interval, compare a linear model and an exponential model. Which better matches the stated change pattern and why?

7. A linear model fits measurements for $x=0$ through $5$, but later points bend upward with increasing first differences. What model revision should be investigated?
