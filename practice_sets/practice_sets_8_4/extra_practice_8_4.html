Algebra Extra Practice 8.4

1. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

2. A rental model is $C(h)=9+6h$ for $0\le h\le9$. Predict the cost for 5 hours and interpret the result.

3. A fitted model describes seedling height for days 0 through 24. Explain why a prediction at day 180 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

4. A linear model predicts fuel level while a tank drains. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

5. A model predicts $y=2x+5$. For the observed point $(6,18)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

6. For data that are multiplied by about 1.15 each equal time interval, compare a linear model and an exponential model. Which better matches and why?

7. A quadratic model was proposed, but new data show nearly constant first differences. What simpler model should be reconsidered and why?

8. A population model is $P(t)=150(1.12)^t$. Interpret 150 and 1.12 in context.

9. Write a linear rule that exactly fits the data, then state the domain represented by the table.

$x$1234
$y$6101418

10. Choose a model family for the data and state the evidence that supports it.

11. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

12. A height model is $h(t)=-5(t-2)^2+25$ for $0\le t\le4$. Predict the height at $t=3$ and interpret the result.

13. A fitted model describes algae growth for days 0 through 18. Explain why a prediction at day 210 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

14. A linear model predicts the amount of material cut from a roll during steady production. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

15. A model predicts $y=x^2+1$. For the observed point $(3,11)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

16. A table has constant first differences of $-12$. Which is more appropriate, a linear or exponential model? Explain.

17. A single quadratic model fits early data, but later observations follow one steady rate before a breakpoint and a different steady rate after it. What revision should be investigated?

18. A height model is $h(t)=-2(t-3)^2+18$. Interpret the vertex values 3 and 18 in context.

19. A population starts at 300 and grows 8% per year. Write an exponential model for its value after $t$ years.

20. For $P(t)=2200(0.96)^t$, state the percent change per time unit and whether the model is growth or decay.

21. Use $P(t)=25(2)^t$ to predict $P(4)$.

22. A projectile is modeled by $h(t)=-3(t-5)^2+36$. State the maximum height and when it occurs.

23. A revenue-change model is $R(x)=(x-4)(x-12)$. Find the zeros and interpret them as input values where the modeled change is zero.

24. A rectangular garden has width $x$ and length $30-x$. Write a quadratic area model and state a reasonable domain.
