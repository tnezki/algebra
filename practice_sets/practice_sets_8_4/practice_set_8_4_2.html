Algebra Practice 8.4 :::: Set 2

1. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

2. A taxi model is $C(m)=4+2.5m$ for $0\le m\le20$. Predict the cost for 8 miles and interpret the result.

3. A fitted model describes population count for days 0 through 8. Explain why a prediction at day 80 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

4. A linear model predicts temperature change over a short controlled interval. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

5. A model predicts $y=2x+3$. For the observed point $(6,14)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

6. For data that increase by about 12 units each equal time interval, compare a linear model and an exponential model. Which better matches the stated change pattern and why?

7. A linear model fits early measurements, but later first differences increase by about the same amount each step. What model revision should be investigated, and what pattern would support it?

8. A savings model is $S(t)=600(1.03)^t$. Interpret 600 and 1.03 in context.

9. Write a linear rule that exactly fits the data, then state the domain represented by the table.

$x$0369
$y$5111723

10. Choose a model family for the data and state the evidence that supports it.

$x$01234
$y$25101726

11. Use the scatterplot shape and the changing pattern to choose a reasonable model family. Give one reason.

12. A delivery model is $C(d)=6+2.5d$ for $0\le d\le12$. Predict the cost for 8 miles and interpret the result.

13. A fitted model describes machine output for days 0 through 30. Explain why a prediction at day 365 should be treated cautiously even if the formula can be evaluated. Name one condition that might change outside the observed window.

14. A linear model predicts cost versus units produced. State one assumption needed for a constant-rate linear model to remain reasonable, and describe what a violation would look like in the data.

15. A model predicts $y=-2x+9$. For the observed point $(3,2)$, compute observed minus predicted and say whether the model underpredicts or overpredicts.

16. A data set has first differences $3,7,11,15$. Compare linear, quadratic, and exponential models. Which family is best supported by this evidence?

17. An exponential model fits early measurements, but later ratios stop being constant while the first differences settle at 5. What revision should be investigated?

18. A value model is $V(t)=1200(0.85)^t$. Interpret 1200 and 0.85 in context.

19. An investment starts at 650 dollars and grows 4% per year. Write an exponential model for its value after $t$ years.

20. For $P(t)=600(1.12)^t$, state the percent change per time unit and whether the model is growth or decay.

21. Use $N(t)=40(1.5)^t$ to predict $N(2)$.

22. A projectile is modeled by $h(t)=-5(t-4)^2+42$. State the maximum height and when it occurs.

23. A profit model is $P(x)=-(x-3)(x-9)$. Find the zeros and interpret them as break-even input values.

24. A rectangular garden has width $x$ and length $16-x$. Write a quadratic area model and state a reasonable domain.
