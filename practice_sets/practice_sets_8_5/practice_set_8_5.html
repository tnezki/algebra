1. Use the table to choose a function family and write one matching equation. $x$: 0, 1, 2, 3; $y$: 3, 12, 48, 192.

2. Two models fit early data: a linear model adds 30 each period; an exponential model grows 12% each period. What additional evidence would best help choose between them?

3. A table has outputs [18, 14, 10, 6] for consecutive integer inputs, while a proposed equation is $y=9(0.75)^x$. Explain the conflict and identify what should be rechecked.

4. A venue models attendance by $A(t)=200+25t$ for the first several weeks. Actual attendance is [200, 228, 247, 281]. Use both representations to judge whether the linear model is exact or approximate.

5. A problem asks for end behavior, a vertex, and exact solutions. Propose an efficient order for using graph, equation, table, and/or context representations.

6. For $y=3|x+2|-1$, create three table values centered at the vertex and explain what the table reveals about symmetry. State the line of symmetry your table supports.

7. A quantity doubles every 4 hours from an initial value of 30. Choose a function family, write a model, and predict the value after 8 hours.

8. When deciding between linear and exponential, name one useful piece of evidence you could collect from each of an equation, graph, table, and context before making a final conclusion.

9. The panel shows linear, quadratic, exponential, and absolute-value graphs. Choose two panels and explain one feature that distinguishes their families.

10. You need the exact value at an input that is not already tabulated. Which representation—equation, graph, or table—is usually the most direct starting point, and why?
