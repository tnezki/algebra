Algebra Practice 5.2 :::: Set 2

1. Factor $x^{2} + 7x + 12$.

2. Factor $x^{2} + 9x + 20$.

3. Factor $x^{2} + 8x - 20$.

4. Factor $x^{2} + 4x - 12$.

5. Factor $x^{2} - 7x + 12$.

6. Factor $x^{2} - x - 20$.

7. Factor $x^{2} + 9x + 18$.

8. Factor $x^{2} - 5x - 14$.

9. Factor $2x^{2} + 9x + 4$.

10. Factor $3x^{2} + 10x + 3$.

11. Factor $2x^{2} + 9x - 5$.

12. Factor $2x^{2} - 3x - 9$.

13. Factor $3x^{2} + 10x - 8$.

14. Factor $4x^{2} + 8x + 3$.

15. For $x^2+11x+28$, build a product-sum table of integer factor pairs of 28 until you find a pair with sum 11. Use that pair to factor the trinomial.

16. Use product-sum reasoning to factor $x^2+2x-15$.

17. One factor of $x^{2} + 10x + 24$ is $(x+4)$. Determine the missing factor.

18. Find $m$ so $x^2+11x+m=(x+5)(x+6)$.

19. A student factors $x^2+11x+28$ as $(x+4)(x+7)$. Multiply the factors and decide whether the claim is correct.

20. A rectangle has side lengths $(x+4)$ and $(x+7)$. Write the area in standard form and factored form.

21. Factor $x^{2} - 11x + 24$.

22. Factor $x^{2} + 2x - 24$.

23. Compare $(x+4)(x+6)$ and $(x+3)(x+7)$. Do they have the same constant term? Do they have the same middle coefficient?

24. A factor pair for a trinomial must have product -20 and sum 1. Can both integers be positive? Explain.
