Algebra Practice 5.2

1. Factor $x^{2} + 6x + 9$.

2. Factor $x^{2} + 8x + 16$.

3. Factor $x^{2} + 5x + 6$.

4. Factor $x^{2} + 3x - 10$.

5. Factor $x^{2} - 6x + 9$.

6. Factor $x^{2} + x - 12$.

7. Factor $x^{2} + 8x + 12$.

8. Factor $x^{2} - 2x - 15$.

9. Factor $2x^{2} + 7x + 3$.

10. Factor $3x^{2} + 7x + 2$.

11. Factor $2x^{2} + 7x - 4$.

12. Factor $2x^{2} - x - 6$.

13. Factor $3x^{2} + 7x - 6$.

14. Factor $4x^{2} + 6x + 2$.

15. For $x^2+9x+18$, build a product-sum table of integer factor pairs of 18 until you find a pair with sum 9. Use that pair to factor the trinomial.

16. Use product-sum reasoning to factor $x^2+2x-8$.

17. One factor of $x^{2} + 8x + 15$ is $(x+3)$. Determine the missing factor.

18. Find $m$ so $x^2+9x+m=(x+4)(x+5)$.

19. A student factors $x^2+9x+18$ as $(x+3)(x+6)$. Multiply the factors and decide whether the claim is correct.

20. A rectangle has side lengths $(x+3)$ and $(x+6)$. Write the area in standard form and factored form.

21. Factor $x^{2} - 9x + 14$.

22. Factor $x^{2} + 2x - 15$.

23. Compare $(x+3)(x+5)$ and $(x+2)(x+6)$. Do they have the same constant term? Do they have the same middle coefficient?

24. A factor pair for a trinomial must have product -12 and sum 1. Can both integers be positive? Explain.
