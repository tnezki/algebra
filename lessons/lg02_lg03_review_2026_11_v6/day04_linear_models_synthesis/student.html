Writing & Interpreting Linear Models

LEARNING FOCUS & NOTES
Learning focus | LG 03-ican-2 / LG 03-ican-5

• I can write y = mx + b from a description, table, or two points.

• I can explain what the slope and starting value mean.

• I can check whether a model makes sense for a stated input.

Vocabulary | Highlight the important words

Linear modelAn equation, table, or graph using constant change to represent a situation.
Slope-intercept formThe equation y = mx + b, where m is slope and b is the output at x = 0.
Slope / rate mThe change in output for each 1-unit input increase; include units.
y-intercept / starting value bThe value of y when x = 0; often the starting amount in context.
VariableA letter representing a changing or unknown quantity, with an assigned meaning.
Domain restrictionA limit on which inputs make sense, based on the situation or mathematical rule.

Meaning & Method | Rewritten review notes

1. Read the story first: choose an input x and an output y with meaningful units.

2. Identify the starting amount b at input zero, then identify the constant change m per one input unit. Write y = mx + b.

3. Check the model using an input and output from the context. State restrictions such as nonnegative whole-number counts.
