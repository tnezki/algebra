Functions, Rules, Domain & Range

LEARNING FOCUS & NOTES
Learning focus | LG 02-ican-1 / LG 02-ican-2 / LG 02-ican-3

• I can use an input-output rule to find outputs.

• I can explain why a relation is or is not a function.

• I can list the domain and range of a set of ordered pairs.

Vocabulary | Highlight the important words

RelationA collection of input-output pairs; it may or may not be a function.
FunctionA relation that assigns exactly one output to each input.
Input / outputAn input is the starting value (often x); an output is the resulting value (often y).
DomainThe set of all distinct input values used by a relation.
RangeThe set of all distinct output values produced by a relation.
Function ruleAn equation or instruction that tells how to get an output from an input.

Meaning & Method | Rewritten review notes

1. Read an ordered pair as (input, output). A repeated input is allowed only if it gives the SAME output.

2. To test a function, inspect whether any input has two different outputs. On a graph, a vertical line should not hit more than one point.

3. For a finite relation, list each domain and range value only once; order from least to greatest.
