Algebra 1 · Section 8.3 Investigation Teacher Guide

Distance from a Target

Absolute Value Functions and Piecewise Thinking

Why This Fits

Absolute value is distance, and a human number line makes symmetry and the two linear pieces emerge naturally.

TimeAbout 20–30 minutes
Groupingwhole class number line, then pairs
Core ideaStudents will analyze and model situations involving absolute value functions.

Materials

floor number line or tape, position cards, graph grid

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Place a target at x=3 on a floor number line.
  2. Students at several x-values report their distance from the target and record |x-3|.
  3. Build a table showing symmetric input pairs with equal distance.
  4. Plot the table to create the V-shaped graph and identify the vertex.
  5. Describe the rule separately to the left and right of the target, connecting to piecewise thinking.

Answer / Evidence Guide

  • Outputs: 4,3,2,1,0,1,2,3,4.
  • Vertex is (3,0); graph is symmetric about x=3.
  • Left piece decreases with slope -1 as x approaches 3; right piece increases with slope +1.

Watch For

  • Treating absolute value as ordinary linear behavior across the vertex.
  • Ignoring interval conditions in a piecewise rule.

Strong Synthesis

Target: The vertex marks zero distance at the target; equal horizontal offsets left/right produce equal nonnegative distances, creating two linear pieces with opposite slopes.

Synthesis — student prompt

How does the absolute-value graph encode “distance from a target”?

Suggested / acceptable response: The vertex marks zero distance at the target; equal horizontal offsets left/right produce equal nonnegative distances, creating two linear pieces with opposite slopes.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Pair symmetric inputs.
  • Connect the two slope signs to movement toward/away from the target.
