Algebra 1 · Section 2.4 Investigation Teacher Guide

Which Plan Is Better?

Comparing Linear Representations

Why This Fits

The investigation makes students compare meaning across unlike representations and use a common representation only when it helps answer a decision.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will analyze and compare linear relationships using multiple representations.

Materials

plan cards, graph paper, calculator optional

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Read Plan A from an equation and Plan B from a table without converting immediately.
  2. Extract each starting value and rate into a common feature table.
  3. Predict which plan is cheaper for small and large usage.
  4. Build both representations on one graph and locate the break-even point.
  5. Write a recommendation that states the usage range where each plan wins.

Answer / Evidence Guide

  • Plan A starts at 12 and grows $3/month.
  • Plan B starts at 4 and grows $4/month, so $B=4+4m$.
  • Break-even: 12+3m=4+4m gives m=8; B is cheaper before 8 months, equal at 8, A cheaper after 8.

Watch For

  • Comparing lines only by current output values instead of rate and starting value.
  • Assuming the steeper-looking graph has greater slope without checking axis scales.

Strong Synthesis

Target: Graph scale can distort appearance. Compare numerical slopes/rates and starting values, then use the context/question to decide what matters.

Synthesis — student prompt

Why is “this line looks steeper” not enough to compare two linear relationships?

Suggested / acceptable response: Graph scale can distort appearance. Compare numerical slopes/rates and starting values, then use the context/question to decide what matters.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Convert the table to an equation only when it helps.
  • State the recommendation as a range, not one universal winner.
