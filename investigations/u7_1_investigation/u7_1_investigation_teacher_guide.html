Algebra 1 · Section 7.1 Investigation Teacher Guide

Additive vs Multiplicative Growth

Recognizing Growth and Decay

Why This Fits

Generating the patterns makes the distinction between additive change and multiplicative change unavoidable.

TimeAbout 20–30 minutes
Groupingpairs
Core ideaStudents will identify exponential relationships from patterns, tables, graphs, and situations.

Materials

counters or paper squares, recording table, graph grid

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Start two patterns at 20: Pattern A adds 10 each round; Pattern B multiplies by 1.5 each round.
  2. Build or record six rounds and calculate differences/ratios.
  3. Sketch both patterns on the same coordinate grid.
  4. Identify which is exponential and whether it represents growth or decay.
  5. Create a decay pattern with a constant factor between 0 and 1 and explain the percent decrease.

Answer / Evidence Guide

  • Additive pattern: 20,30,40,50,60,70 with constant difference 10.
  • Multiplicative: 20,30,45,67.5,101.25,151.875 with constant ratio 1.5.
  • A decay example with factor 0.8 decreases by 20% each step.

Watch For

  • Using constant differences to justify an exponential relationship.
  • Confusing a decay factor with the percent decrease.

Strong Synthesis

Target: The multiplicative ratio/factor stays constant for equal input intervals; in a linear relationship the additive difference stays constant.

Suggested / acceptable response: The multiplicative ratio/factor stays constant for equal input intervals; in a linear relationship the additive difference stays constant.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:

  • Use the table before relying on graph shape.
