Graphing and Elimination

Why This Fits

Students connect geometric solution types with algebraic elimination behavior rather than learning the methods as disconnected procedures.

TimeAbout 20–30 minutes
Groupinggroups of 3 rotating through graph/equation stations
Core ideaStudents will solve systems graphically and by elimination while interpreting the meaning of different solution types.

Materials

system graph stations, equation cards, recording sheet

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. At each graph station, classify the system as one solution, no solution, or infinitely many solutions.
  2. Use graph features to predict what the equation coefficients must imply.
  3. Match each graph to a pair of equations.
  4. For one one-solution system, use elimination to verify the intersection algebraically.
  5. Explain how elimination behaves differently for no-solution and same-line systems.

Answer / Evidence Guide

  • A has one solution; solving gives (2,3).
  • B has no solution because equal slopes and different intercepts are parallel.
  • C has infinitely many solutions because the second equation is twice the first.
  • Elimination mirrors these: a variable pair remains/solves, a contradiction like 0=constant appears, or an identity like 0=0 appears.

Watch For

  • Assuming every system has exactly one solution.
  • Eliminating terms without applying equivalent operations to an entire equation.

Strong Synthesis

Target: A unique ordered pair corresponds to one intersection; a false statement corresponds to parallel distinct lines; an identity corresponds to equivalent equations/same line.

Synthesis — student prompt

How can the result of elimination tell you the geometry of a system even before you graph it?

Suggested / acceptable response: A unique ordered pair corresponds to one intersection; a false statement corresponds to parallel distinct lines; an identity corresponds to equivalent equations/same line.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • What coefficient pattern do you notice in the same-line system?
  • What should the graph show if elimination gives 0=0?
