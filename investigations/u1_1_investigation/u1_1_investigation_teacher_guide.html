Algebra 1 · Section 1.1 Investigation Teacher Guide

Four-View Relationship Detective

Multiple Representations of Relationships

Why This Fits

The target is equivalence across representations, so students must translate and defend rather than merely identify.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will connect tables, graphs, equations, and contexts that represent the same relationship.

Materials

four-view cards, ruler, graph grid, pencil

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Inspect a context, table, equation, and several graph candidates without matching by appearance alone.
  2. Use two ordered pairs and the rate/start value to match the first three views.
  3. Construct the missing graph on the supplied grid.
  4. Trade sets with another group and challenge one match using numerical evidence.
  5. Write a two-sentence rule for proving two representations describe the same relationship.

Answer / Evidence Guide

  • Rate 2 and starting value 3 must appear in every view.
  • The graph must contain (0,3), (1,5), (2,7), and (4,11).
  • A valid evidence statement names specific values/rate, not visual similarity.

Watch For

  • Matching representations by visual appearance while ignoring scale or values.
  • Changing a table or graph without preserving the same ordered pairs or relationship.

Strong Synthesis

Target: Check invariant evidence such as matching ordered pairs, the same rate/pattern of change, and the same starting value or other defining feature.

Synthesis — student prompt

Write a short rule for proving that two different representations describe the same relationship.

Suggested / acceptable response: Check invariant evidence such as matching ordered pairs, the same rate/pattern of change, and the same starting value or other defining feature.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Which two numerical facts are hardest for a wrong match to fake?
  • How does scale affect visual appearance?
