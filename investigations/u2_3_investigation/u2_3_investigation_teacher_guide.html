Algebra 1 · Section 2.3 Investigation Teacher Guide

Reverse-Engineer the Line

Writing Linear Equations

Why This Fits

Writing linear equations becomes a translation task across representations instead of a single formula exercise.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will write linear equations from graphs, tables, and situations.

Materials

graph panel, data cards, equation record sheet

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. From a graph, identify two points and determine slope and intercept.
  2. From a separate table, determine the constant rate and recover the value at x=0.
  3. From a context, name the starting amount and rate with units.
  4. Write an equation for each source and test it with one known point/value.
  5. Trade one equation and ask another group to reconstruct its likely graph features.

Answer / Evidence Guide

  • Provided graph is built for $y=2x-2$.
  • Table has slope 3 and intercept 5, so $y=3x+5$.
  • Context gives $C=4v+12$.
  • Verification should substitute a known ordered pair or context value.

Watch For

  • Using an arbitrary table value as the intercept.
  • Confusing the roles of $m$ and $b$ in $y=mx+b$.

Strong Synthesis

Target: Constant rate of change (slope) and the starting value (y-intercept when x=0).

Synthesis — student prompt

Across graph, table, and context, what two linear features are you usually trying to recover?

Suggested / acceptable response: Constant rate of change (slope) and the starting value (y-intercept when x=0).
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Which source makes b easiest to read?
  • How do you recover b if x=0 is not shown in a table?
