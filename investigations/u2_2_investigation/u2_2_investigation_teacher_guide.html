Linear Graph Construction Relay

Graphing Linear Functions

Why This Fits

Students build and communicate graph features rather than only copy a finished line from an equation.

TimeAbout 20–30 minutes
Groupingpairs, then trade
Core ideaStudents will graph linear functions and interpret key features.

Materials

graph grids, rulers, colored pencils, feature cards

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Graph a line from a given intercept and slope, respecting scale and sign.
  2. Mark two slope triangles of different sizes that lie on the same line.
  3. Create a second line with the same slope but a different intercept.
  4. Write a feature card that describes a third line without giving its equation.
  5. Trade cards and construct the partner line, then verify with two points.

Answer / Evidence Guide

  • Line A is $y=2x+1$; Line B is $y=2x-4$.
  • The lines are parallel because slopes match and intercepts differ.
  • Any traded graph must respect the grid scale and signed rise/run.

Watch For

  • Plotting the intercept on the wrong axis.
  • Using slope steps without respecting graph scale or sign.

Strong Synthesis

Target: A point and a slope are sufficient; in slope-intercept form, the y-intercept supplies the point and m supplies the slope.

Synthesis — student prompt

What information is sufficient to construct one unique nonvertical line?

Suggested / acceptable response: A point and a slope are sufficient; in slope-intercept form, the y-intercept supplies the point and m supplies the slope.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Show two different slope triangles on one line.
  • How would a negative slope change the movement?
