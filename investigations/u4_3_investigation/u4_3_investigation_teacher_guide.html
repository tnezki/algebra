Algebra 1 · Section 4.3 Investigation Teacher Guide

Transformation Parameter Lab

Transformations

Why This Fits

Controlled parameter changes let students isolate transformation effects instead of memorizing unrelated rules.

TimeAbout 20–30 minutes
Groupingpairs with graphing technology; paper comparison panels as fallback
Core ideaStudents will analyze and graph transformations involving stretches, compressions, and reflections.

Materials

approved graphing tool or calculator, fallback graph panels, recording sheet

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Start with a parent function and change one parameter at a time.
  2. Record what a, h, and k change about key points and orientation/scale.
  3. Repeat the same parameter change on a second function family.
  4. Identify one effect that behaves consistently and one feature that depends on the family.
  5. Given a target graph, choose parameters and justify them from key-point movement.

Answer / Evidence Guide

  • +2 changes every y-value by +2: vertical translation.
  • 2f(x) doubles y-values: vertical stretch; points on the x-axis remain fixed.
  • f(x-2) shifts right 2.
  • -f(x) reflects across the x-axis.

Watch For

  • Confusing vertical stretch/compression with horizontal movement.
  • Reflecting or scaling points inconsistently across the graph.

Strong Synthesis

Target: Vertical shift: (x,y)→(x,y+k); horizontal shift: (x,y)→(x+h,y) with notation interpreted carefully; vertical scale/reflection: (x,y)→(x,ay).

Synthesis — student prompt

Which transformation descriptions can be stated in coordinate language that works across function families?

Suggested / acceptable response: Vertical shift: (x,y)→(x,y+k); horizontal shift: (x,y)→(x+h,y) with notation interpreted carefully; vertical scale/reflection: (x,y)→(x,ay).
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • What happens to a point with y=0 under vertical scaling?
  • Which features stay family-specific even when the coordinate rule generalizes?
