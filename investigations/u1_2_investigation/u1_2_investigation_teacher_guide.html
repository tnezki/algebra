Algebra 1 · Section 1.2 Investigation Teacher Guide

Function Machine Audit

Inputs, Outputs, and Functions

Why This Fits

Rotation makes students repeatedly inspect the one-output-per-input structure without turning the lesson into routine computation.

TimeAbout 20–30 minutes
Groupingpairs rotating through stations
Core ideaStudents will interpret functions as rules that connect inputs and outputs without relying on formal domain and range language.

Materials

station cards, audit sheet, pencils

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. At each station, name the input and output quantities or labels.
  2. Decide whether each input has exactly one output and mark the evidence.
  3. Repair one non-function by changing the smallest possible part.
  4. At a final station, infer a rule from input-output pairs and predict two outputs.
  5. Create a mapping that is a function but includes a repeated output.

Answer / Evidence Guide

  • A is a function even though output 4 repeats.
  • B is not a function because input 1 has two outputs.
  • C follows output = 3(input)+5.
  • In D, each time should correspond to one distance for a single trip model.

Watch For

  • Reversing inputs and outputs when applying a rule.
  • Treating a repeated input with two different outputs as a function.

Strong Synthesis

Target: Each input must have exactly one output. Repeated outputs are allowed; repeated inputs with different outputs are not.

Synthesis — student prompt

What is the smallest, most reliable test for whether an input-output relation is a function?

Suggested / acceptable response: Each input must have exactly one output. Repeated outputs are allowed; repeated inputs with different outputs are not.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Point to the input that causes the failure.
  • Can two people have the same output and still preserve the rule?
