Algebra 1 · Section 8.1 Investigation Teacher Guide

Model Diagnostics Lab

Selecting Appropriate Models

Why This Fits

Model selection should be evidence-driven and revisable when more data change the apparent pattern.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will determine whether a situation is best modeled by a linear, quadratic, or exponential function.

Materials

diagnostic data sets, calculators, graph reveal

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. For three data sets, calculate first differences, second differences, and ratios only as needed.
  2. Select linear, quadratic, or exponential based on the strongest stable pattern.
  3. Read a proposed model choice from another “student” and critique the evidence.
  4. Use a graph reveal to check whether the model behavior is consistent beyond the first few points.
  5. Revise one choice after an additional data point is revealed.

Answer / Evidence Guide

  • A linear: first differences +4.
  • B quadratic: first differences 3,5,7; second differences +2.
  • C exponential: ratio ×1.5.
  • Model choice should be revisable if new data break the assumed pattern.

Watch For

  • Choosing a model from one or two points without checking the pattern of change.
  • Using additive evidence to justify an exponential model or ratio evidence to justify a linear model.

Strong Synthesis

Target: Check constant first differences for linear, constant second differences for quadratic, and constant ratios for exponential; then validate with graph/context behavior and domain.

Synthesis — student prompt

What evidence hierarchy helps you choose among linear, quadratic, and exponential models from equally spaced table inputs?

Suggested / acceptable response: Check constant first differences for linear, constant second differences for quadratic, and constant ratios for exponential; then validate with graph/context behavior and domain.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Use only the diagnostics you need.
  • What new point would falsify your current choice?
