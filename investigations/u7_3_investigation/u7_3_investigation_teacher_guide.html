Algebra 1 · Section 7.3 Investigation Teacher Guide

Exponential Base Comparison

Graphing and Analyzing Exponential Functions

Why This Fits

Side-by-side graphs and values connect the base to rate of multiplicative change and end behavior.

TimeAbout 20–30 minutes
Groupingpairs
Core ideaStudents will graph exponential functions and analyze key features.

Materials

comparison graph panel, calculator, prediction grid

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Predict graphs for y=2^x, y=1.5^x, and y=(0.5)^x from a few key values.
  2. Compare predictions to generated graph panels.
  3. Record the common y-intercept and describe how base changes growth/decay behavior.
  4. Use tables to explain why the graph approaches but does not cross the horizontal asymptote in the basic models.
  5. Rank several bases by long-run growth and justify without relying only on a snapshot.

Answer / Evidence Guide

  • All equal 1 at x=0.
  • 2^x grows faster than 1.5^x for positive x.
  • (0.5)^x decays toward 0 as x increases and is always positive.
  • Basic exponential graphs have horizontal asymptote y=0 and do not cross it.

Watch For

  • Drawing an exponential graph through its horizontal asymptote.
  • Treating end behavior as linear or ignoring the effect of the growth/decay factor.

Strong Synthesis

Target: For b>1 the function grows; for 0<b<1 it decays. Values closer to 1 change more slowly per step.

Synthesis — student prompt

How does the base b control whether $b^x$ grows or decays?

Suggested / acceptable response: For b>1 the function grows; for 0<b<1 it decays. Values closer to 1 change more slowly per step.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Use ratio language.
  • Explain the shared y-intercept from exponent 0.
