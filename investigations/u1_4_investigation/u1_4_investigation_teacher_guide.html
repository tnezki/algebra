Algebra 1 · Section 1.4 Investigation Teacher Guide

Build the Distributive Property

Expressions and Structure

Why This Fits

Area makes distribution and grouping visible, so equivalent forms come from one shared object rather than a memorized rule.

TimeAbout 20–30 minutes
Groupingpairs
Core ideaStudents will interpret and rewrite algebraic expressions by identifying structure, meaning, and equivalent forms.

Materials

paper algebra tiles or cut rectangles, markers, recording page

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Build a rectangle with side lengths 3 and x+4 using pieces.
  2. Partition the rectangle and record the two partial areas.
  3. Write two expressions for the same total area and explain why they must be equivalent.
  4. Build a second model for 2(2x+5), then diagnose a model for 2(2x)+5.
  5. Use substitution at one value of x as a check, not as the proof.

Answer / Evidence Guide

  • $3(x+4)=3x+12$ because 3 multiplies both terms.
  • $2(2x+5)=4x+10$.
  • $4x+5$ omits distribution to the 5 and changes the area/value.

Watch For

  • Combining unlike terms as though they were like terms.
  • Distributing a factor to only one term or changing the value while rewriting.

Strong Synthesis

Target: Both expressions describe the same total area assembled from the same subareas for every admissible x, so the equivalence is structural, not a one-value coincidence.

Synthesis — student prompt

How can an area model show that two expressions are equivalent without checking many values of x?

Suggested / acceptable response: Both expressions describe the same total area assembled from the same subareas for every admissible x, so the equivalence is structural, not a one-value coincidence.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Which subarea corresponds to each term?
  • What would the wrong expression require the picture to look like?
