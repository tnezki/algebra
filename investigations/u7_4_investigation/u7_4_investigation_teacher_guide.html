Function Family Race

Comparing Function Families

Why This Fits

A common-input race emphasizes growth structure and crossover behavior rather than isolated family labels.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will compare linear, quadratic, and exponential functions using multiple representations.

Materials

calculator, common-input table, graph reveal

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Evaluate a linear, quadratic, and exponential function at the same inputs.
  2. Track first differences, second differences, and ratios in the table.
  3. Predict which function will eventually dominate and estimate when one overtakes another.
  4. Compare the prediction to a generated overlay graph.
  5. Explain why a small interval can make different families look deceptively similar.

Answer / Evidence Guide

  • L has constant first difference 8.
  • Q has constant second difference 2.
  • E has constant ratio 1.5.
  • Depending on input range, models can cross; long-run exponential eventually dominates these particular linear/quadratic examples.

Watch For

  • Using only graph shape instead of differences, ratios, and equation structure.
  • Confusing constant second differences with constant ratios.

Strong Synthesis

Target: A small set of outputs can be close even when the underlying change structures differ. Extending inputs and checking differences/ratios reveals the family behavior.

What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Do not decide from the largest current value alone.
  • Locate a crossover numerically, then check graphically.
