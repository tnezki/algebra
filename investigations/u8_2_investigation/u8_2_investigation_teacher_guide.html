Algebra 1 · Section 8.2 Investigation Teacher Guide

Transformation Passport

Transformations Across Function Families

Why This Fits

Rotating the same transformation idea across families separates general coordinate effects from family-specific features.

TimeAbout 20–30 minutes
Groupinggroups of 4 rotating among family stations
Core ideaStudents will analyze transformations across multiple function families.

Materials

family station panels, transformation passport, colored pencils

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. At each family station, apply the same vertical shift to selected key points and compare with the panel.
  2. Repeat a horizontal shift or reflection and record how coordinates change.
  3. Identify a feature that is family-specific (vertex, asymptote, slope pattern) and track what happens to it.
  4. Compare station records to find transformation rules that generalize across families.
  5. At the final station, reverse-engineer the transformation from parent and target graphs.

Answer / Evidence Guide

  • Up 3 adds 3 to all y-coordinates across every family.
  • Right 2 adds 2 to all x-coordinates of corresponding points (represented as f(x-2)).
  • Reflection over x-axis negates y-values.
  • Family-specific features transform consistently but remain different kinds of features.

Watch For

  • Applying a transformation rule as though it behaves identically in every algebraic position.
  • Moving one key feature without transforming the rest of the function consistently.

Strong Synthesis

Target: Coordinate changes such as shifts/reflections/scales generalize; the named key features affected—slope, vertex, asymptote, intercepts—depend on the family.

Synthesis — student prompt

What transformation ideas generalize across families, and what must still be interpreted family by family?

Suggested / acceptable response: Coordinate changes such as shifts/reflections/scales generalize; the named key features affected—slope, vertex, asymptote, intercepts—depend on the family.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • State changes with coordinates, not only notation.
  • Track more than one point.
