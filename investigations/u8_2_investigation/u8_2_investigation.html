Part 2 · Same Parameter, Different Feature

Compare $g(x)=f(x-2)+4$ when $f$ is quadratic, absolute value, and exponential. Identify which key feature is easiest to track in each family.

Part 3 · Scale and Reflect

Apply $g(x)=-2f(x)$ to the key points $(0,0)$, $(1,1)$, and $(2,4)$. Explain what is universal about the output rule.

Synthesis

Separate two ideas: what transformation rules are universal across families, and what features remain family-specific?
