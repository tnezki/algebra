Algebra 1 · Section 4.2 Investigation Teacher Guide

Translation Tracing Lab

Translations

Why This Fits

Physical overlays make translation a movement of every point, preventing students from shifting only the vertex or intercept.

TimeAbout 20–30 minutes
Groupingpairs
Core ideaStudents will graph and write translated functions using key points and key features.

Materials

tracing paper, graph panel, colored pencils, key-point table

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Trace the parent graph and mark two or three key points.
  2. Slide the tracing horizontally or vertically to match a target graph without rotating or stretching.
  3. Record how every marked point changed.
  4. Connect the movement to f(x-h)+k notation.
  5. Reverse-engineer one translated graph by estimating h and k from corresponding key points.

Answer / Evidence Guide

  • g shifts right 3 and up 2; vertex moves (0,0)→(3,2).
  • h shifts left 2 and down 4; vertex moves (0,0)→(-2,-4).
  • Every point translates by the same vector; shape/orientation stay unchanged.

Watch For

  • Reversing the direction of horizontal shifts in equation form.
  • Moving only the vertex while leaving other key points inconsistent.

Strong Synthesis

Target: A true translation moves every point by the same horizontal/vertical amount. Multiple points reveal whether only a single feature was moved or the whole graph was transformed.

Synthesis — student prompt

How can tracking two or three corresponding points prevent a transformation mistake?

Suggested / acceptable response: A true translation moves every point by the same horizontal/vertical amount. Multiple points reveal whether only a single feature was moved or the whole graph was transformed.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Say the translation as a vector.
  • Explain the inside-sign reversal using input values, not a mnemonic.
