Algebra 1 · Section 7.2 Investigation Teacher Guide

Build the Exponential Rule

Writing Exponential Equations

Why This Fits

Translation among table, context, and equation makes a and b meaningful parameters instead of slots in a template.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will write exponential equations from tables, graphs, and situations.

Materials

table/context cards, organizer, calculator optional

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. From a table, identify the value at x=0 and the constant ratio between outputs.
  2. Write y=a(b)^x and verify it on two rows.
  3. From a percent-growth context, convert the percent to a multiplicative factor.
  4. Create a decay equation from an assigned initial value and percent decrease.
  5. Trade an equation; the receiving group writes a matching context and two-row table.

Answer / Evidence Guide

  • Table: a=120, b=1.25, so y=120(1.25)^x.
  • Growth: y=900(1.06)^t.
  • Decay: y=1400(0.82)^t.

Watch For

  • Using the percent change itself as the multiplicative factor.
  • Switching the roles of initial value and growth/decay factor.

Strong Synthesis

Target: a is the value when x=0; b is the constant multiplicative factor for each one-unit increase in x.

Synthesis — student prompt

How can you read the two parameters in $y=a(b)^x$ from a table or context?

Suggested / acceptable response: a is the value when x=0; b is the constant multiplicative factor for each one-unit increase in x.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Convert percent change to “keep + change.”
  • Verify with two rows.
