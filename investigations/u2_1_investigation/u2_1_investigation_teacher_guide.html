Algebra 1 · Section 2.1 Investigation Teacher Guide

Walk the Slope

Rate of Change and Slope

Why This Fits

Embodied rise/run makes sign, direction, and ratio meaning visible before symbolic slope calculation becomes routine.

TimeAbout 20–30 minutes
Groupinggroups of 4 on a taped coordinate grid
Core ideaStudents will interpret slope as a measure of constant rate of change.

Materials

floor tape or tile grid, point cards, recording sheet

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Place two students at assigned coordinate points.
  2. A third student walks the horizontal change and vertical change as two separate legs.
  3. Record rise, run, slope, sign, and a verbal rate statement.
  4. Repeat with negative, zero, and undefined slope cases.
  5. Sketch one case and explain how the same slope can appear with a larger slope triangle.

Answer / Evidence Guide

  • Case 1 slope 4/4=1.
  • Case 2 slope -4/4=-1.
  • Case 3 slope 0.
  • Case 4 has run 0, so slope is undefined.
  • Consistent point order is essential: reversing both rise and run keeps the ratio.

Watch For

  • Reversing vertical and horizontal change or using inconsistent point order.
  • Interpreting slope as a starting value rather than a rate.

Strong Synthesis

Target: All slope triangles on the same nonvertical line are similar, so rise and run scale by the same factor and preserve their ratio.

Synthesis — student prompt

Why can a line have many different slope triangles but only one slope?

Suggested / acceptable response: All slope triangles on the same nonvertical line are similar, so rise and run scale by the same factor and preserve their ratio.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • What changes if you reverse point order?
  • Where do units belong in a contextual slope?
