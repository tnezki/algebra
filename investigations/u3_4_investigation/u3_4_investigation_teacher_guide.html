Algebra 1 · Section 3.4 Investigation Teacher Guide

Which Side of the Boundary?

Graphing Linear Inequalities

Why This Fits

Movement and test-point placement make half-plane membership concrete while preserving the graphing decisions students must make.

TimeAbout 20–30 minutes
Groupingpairs rotating through inequality posters
Core ideaStudents will graph and interpret linear inequalities.

Materials

poster graphs, rulers, colored pencils, test-point cards

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. At each station, graph the boundary line from the inequality.
  2. Decide solid or dashed from the inequality symbol.
  3. Choose a test point not on the line and use it to decide which side satisfies the inequality.
  4. Shade the solution half-plane and place one point card that definitely works.
  5. Compare two stations where the boundary is the same but the shading differs.

Answer / Evidence Guide

  • Strict < or > uses a dashed boundary; ≤ or ≥ uses a solid boundary.
  • For y>2x+1, test (0,0): 0>1 is false, so shade the side not containing the origin.
  • For y≤-x+4, (0,0) works, so shade the side containing the origin.

Watch For

  • Using a solid boundary for a strict inequality or dashed boundary for an inclusive inequality.
  • Shading by memorized direction instead of testing a point.

Strong Synthesis

Target: Boundary style communicates whether equality is included; shading communicates all ordered pairs that satisfy the inequality.
