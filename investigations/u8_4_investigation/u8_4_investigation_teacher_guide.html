Algebra 1 · Section 8.4 Investigation Teacher Guide

Tossed-Ball Modeling Investigation

Modeling Investigation

Why This Fits

The task runs a full modeling cycle: choose, fit, interpret, validate, and limit the model using real-style data.

TimeAbout 20–30 minutes
Groupinggroups of 3
Core ideaStudents will create and analyze mathematical models using real-world data.

Materials

data table, calculator or graphing tool, model comparison sheet

Before Class

Prepare the listed materials and, when a generated representation is used, verify the local figure opens. Keep the task optional: students should still receive required core instruction elsewhere.

Suggested Flow

  1. Analyze time-height measurements from a tossed ball video and describe the shape/change pattern.
  2. Compare linear, quadratic, and exponential candidate models using both data and behavior.
  3. Estimate a quadratic model or use a provided candidate set and justify the best fit.
  4. Use the model to estimate maximum height and landing time, then compare with observed data.
  5. State assumptions, meaningful domain, and one reason predictions should not be treated as exact.

Answer / Evidence Guide

  • The data rise then fall, strongly favoring a downward-opening quadratic.
  • Candidate Q captures a single maximum and decline; linear/exponential candidates cannot represent the full rise-and-fall pattern.
  • The model domain should be limited roughly to the observed flight interval; predictions are estimates because data are measured/noisy.

Watch For

  • Reporting a model without stating assumptions or a meaningful domain.
  • Treating a model prediction as exact even when data or constraints show limitations.

Strong Synthesis

Target: It must match the structural behavior, respect context/domain, have interpretable parameters/features, and remain reasonably consistent across the data—not just fit selected points.

Synthesis — student prompt

What makes a model defensible besides having a small numerical error on a few points?

Suggested / acceptable response: It must match the structural behavior, respect context/domain, have interpretable parameters/features, and remain reasonably consistent across the data—not just fit selected points.
What to listen for: Students should generalize from the investigation evidence, not repeat a procedure. Teacher press:
  • Use family behavior to rule out models before fine-tuning coefficients.
  • State what would count as evidence to revise the model.
